OpenAGI: When LLM Meets Domain Experts

OpenAGI：当 LLM 遇见领域专家模型

简介

该论文针对现有 LLM 工具编排工作的三大局限——模型集合固定难扩展、任务规划多为线性串行、缺乏量化评测——提出开源平台 OpenAGI，让 LLM 作为规划者选择、合成并执行领域专家模型解决多步真实任务。平台采用双轨设计：基准任务基于 Hugging Face 等来源的专家模型与数据增强构造 185 个多步任务（117 线性、68 非线性），配 CLIP/BERT/ViT 三类量化指标；开放任务则集成 LangChain 提供可扩展工具。方法上提出 RLTF（Reinforcement Learning from Task Feedback），以任务执行结果为奖励、用 REINFORCE 结合 LoRA 微调开源 LLM，并用约束 beam search 保证生成的规划合法可执行。实验显示 GPT-4 在闭源模型中领先，开源模型经 RLTF 调优均达各自最佳，LLaMA-2-13B 性能接近 GPT-3.5；提示实验表明详细模型描述能提升闭源模型零样本表现但可能误导小模型。对团队而言，这是'LLM 作为规划器编排工具'范式的早期代表作，其基准构建方法、约束解码与提示设计实验均有直接参考价值。

问题

现有将 LLM 与外部模型/工具结合的工作存在三个显著挑战：1) 可扩展性差，如 WebGPT、ToolFormer 使用固定数量的模型，难以扩展能力；2) 任务规划多为线性串行，每个子任务完成后才能开始下一个，无法满足复杂多模态输入任务的需求；3) 缺乏量化评测，如 HuggingGPT 只提供定性结果，难以判断 LLM 的规划策略是否最优。论文要构建一个可扩展的开源平台，让 LLM 生成并执行任务规划以解决多步真实任务，同时能定量评估 LLM 的规划能力，并让 LLM 从任务反馈中自我改进。

方法

OpenAGI 平台双轨设计：1) 基准任务——选取 Hugging Face transformers/diffusers 及 GitHub 仓库中的领域专家模型，对 ImageNet-1K、COCO、CNN/Daily Mail、SST2、TextVQA、SQuAD 等原始数据集施加 Gaussian Blur、Gaussian Noise、Grayscale、Low Resolution、Translation、Word Mask 等增强，构造 185 个多步任务（117 线性、68 非线性），按任务类别用 CLIP Score、BERT Score、ViT Score 量化评估；2) 开放任务——集成 LangChain 提供 Google Search、Wikipedia、Wolfram Alpha 等可扩展工具。流程为：自然语言任务经人工设计的 prompt 增强后输入 LLM 生成规划，由基于 GPT-3.5 的 parser 抽取模型序列，并用约束 beam search（prefix trie 限定只能生成模型名、按输入输出模态匹配限定后继模型、支持并行序列）保证规划可执行。提出 RLTF：以任务执行结果作为奖励信号 R，用 REINFORCE 策略梯度结合 LoRA 微调开源 LLM（Flan-T5-Large、Vicuna-7B、LLaMA-2-13B），形成无需人工干预的自我改进闭环，区别于依赖人工标注质量的 RLHF。

关键结果

共构建 185 个多步任务，其中 117 个为线性结构、68 个为非线性结构，每个基准任务附带 100 条增强数据样本

闭源 LLM 整体优于开源：GPT-4 在 zero-shot 与 few-shot 场景下均领先；开源阵营中 LLaMA-2-13B 在各学习模式下 consistently 位居第一

开源 LLM（Flan-T5-Large、Vicuna-7B、LLaMA-2-13B）从 Fine-tuning 与 RLTF 中显著获益，且均在 RLTF 下达到各自最佳；经 RLTF 调优后 LLaMA-2-13B 的性能接近 GPT-3.5

提示实验：提供详细模型描述的 Prompt-1/Prompt-2 在多数情况下提升闭源 LLM（GPT 系列、Claude-2）的零样本表现，但会误导理解与推理能力较弱的开源小模型的模型选择

案例研究：GPT-3.5 能生成非线性（树状/并行）规划，如对含噪模糊灰度图像的德语问答任务，先并行处理图像与文本再用 VQA 模型作答；开放任务中 GPT 先用 Google Search 检索陌生概念再组织 prompt 调用 Text-to-Image Generation

创新点

相比 WebGPT、ToolFormer 等固定模型集合的工作，OpenAGI 的模型/工具集可由用户灵活扩展；相比多数只支持线性规划的工作，它支持非线性（并行/树状）任务规划，并借助约束 beam search 保证生成规划合法；相比 HuggingGPT 等只给定性结果的工作，它提供带数据集与量化指标（CLIP/BERT/ViT Score）的统一基准。此外提出 RLTF，直接用任务执行结果（而非人工标注反馈）作为奖励信号做强化学习，无需人工干预即可改进 LLM 的规划策略，与依赖标注员质量的 RLHF 形成区别。
