Summarization is (Almost) Dead

Summarization（文本摘要）已（几乎）终结

higharXiv评测基准可靠性与安全其他基于arXiv版本
下载原文 PDF

简介

论文通过构建五个任务（单新闻、多新闻、对话、代码、跨语言摘要）各 50 条、取自 LLM 训练截止日期之后的全新评测集以避免数据污染，用人工两两对比方式系统评估 GPT-3/GPT-3.5/GPT-4 的 zero-shot 摘要能力，对照 BART、T5、Pegasus、CodeT5 等微调模型与人工撰写参考摘要。结果显示：人类评审在全部任务上均显著偏好 LLM 摘要，其事实一致性更好、extrinsic hallucination 更少，甚至优于被视为 oracle 的人工参考摘要；微调模型则存在长度僵化、多主题覆盖不足的问题。作者据此提出挑衅性判断——约 70% 的传统摘要研究已不再必要，并给出领域转型方向：更高质量的评测数据集、面向应用的摘要方法（定制化/实时/交互式）、以及超越 ROUGE 的新评测范式（LLM 评测与 extrinsic evaluation）。

问题

评估 LLM 的 zero-shot 摘要生成能力是否已全面超越微调模型与人工参考摘要，并回答在 LLM 时代，以'提出新摘要模型并在标准数据集上刷指标'为主的传统文本摘要研究是否仍有必要。

方法

构建 5 个任务（single-news、multi-news、dialogue、source code、cross-lingual）各 50 条样本的新评测集，数据均取自模型训练截止日期（2021 年 9 月）之后以确保 zero-shot 评估无污染；每任务对比 GPT-3(text-davinci-003)/GPT-3.5/GPT-4 与 1-2 个微调小模型（BART、T5、Pegasus、MT5、MBART、CodeT5）及人工参考摘要；每任务 2 名标注者对全部系统做两两比较，计算 WinRate 与 Cohen's kappa；另做句子级幻觉标注，按 intrinsic/extrinsic 两类分析事实一致性差异的成因。

关键结果

人工评审在全部 5 个任务上一致偏好 LLM 生成的摘要，LLM 的人类偏好分数均超过 50%

人工撰写的参考摘要在句子级幻觉数量上等于或高于 GPT-4，在 multi-news 与 code 摘要任务上事实一致性明显更差

人类参考摘要事实一致性差的主因是 extrinsic hallucination 占比高（multi-news 与 code 任务尤为显著）

微调模型摘要长度固定僵化、多主题输入下主题覆盖率低，而 LLM 能按信息量调整长度并覆盖全部主题

抽样近 3 年 ACL/EMNLP/NAACL/COLING 的 100 篇摘要论文，约 70% 的主要贡献是提出方法并在标准数据集上验证

标注者间 Cohen's kappa 为 0.558，一致性可接受

创新点

与此前仅评估单一新闻摘要的工作（Goyal et al. 2023、Zhang et al. 2023）不同，本文覆盖 5 类摘要任务（含代码与跨语言），使用训练截止日期之后的数据确保真正的 zero-shot 评估，并纳入 GPT-4；除整体质量对比外，还做了句子级幻觉的 intrinsic/extrinsic 分类归因，并从数据集、应用导向方法、评测方法三方面给出领域转型路线图，明确提出'传统摘要研究大多不再必要'的立场性结论。
