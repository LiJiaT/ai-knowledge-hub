Investigating Answerability of LLMs for Long-Form Question Answering

探究 LLM 在长文本问答（LFQA）任务中的可答性

简介

论文研究长文本问答（LFQA）场景下 ChatGPT 等大型 LLM 与 Llama、Alpaca 等开源小模型及其蒸馏版的能力差距。方法上提出可扩展的评测构造：先用 ChatGPT 对 Wikipedia 九个领域的长文档分段做摘要，再从摘要生成按复杂度排序的 top-3 追问（QG-Summary），并以直接从原文生成问题（QG-Passage）作 baseline；答案由各模型 zero-shot 生成，用 GPT-4 按 coherence、relevance、factual consistency、accuracy 四维 0-3 分评分，并通过 TruthfulQA 代理测试（>90% 偏好人类答案）与 50 条人工标注验证 judge 可靠性。关键结论：ChatGPT 全面领先第二名 Alpaca-13B 达 22.4%-40.1%；所有模型在 QG-Summary 上表现更差，开源模型对上下文的依赖下降且在 >1024 tokens 后加速退化，而 ChatGPT 在 2k tokens 内保持稳健。其'摘要→追问'的评测集构造与 LLM-as-judge 校验流程可直接借鉴到团队的知识库问答评测体系建设。

问题

现有 QA 基准多为短答案、短上下文，难以刻画 LLM 在长文本问答（LFQA）上跨段落推理的能力；同时人工评测长文本自由答案昂贵且难以扩展。论文要解决的问题是：构建一种可扩展的评测方法，系统刻画 massive LLM（ChatGPT）与较小的开源 LLM（Llama-7B/13B）及其蒸馏版（Alpaca-7B/13B）在 LFQA 上的能力差距与局限。

方法

两步问题生成：(1) 用 ChatGPT（gpt-turbo-3.5）对 Wikipedia 九个领域（物理、娱乐、历史、计算机科学等）的长文档分段做摘要，prompt 中附带文章标题与领域信息作为上下文；(2) 以摘要为上下文，让 ChatGPT 生成按复杂度降序排列的 top-3 追问（QG-Summary），并以相同指令直接从原文生成问题作为 baseline（QG-Passage）。每个领域 50 篇 × 3 问，共 1350 问/设置，经 ChatGPT 在多个 top_p 下多数投票过滤不可答问题后剩 1278 问。答案生成采用 zero-shot（上下文上限 2k tokens），对比 ChatGPT、Alpaca-7B/13B、Llama-7B/13B；评测采用 GPT-4 作为 judge，按 coherence/relevance/factual consistency/accuracy 四指标 0-3 打分，prompt 中加入避免位置偏差的指令，并通过 TruthfulQA 代理测试与 50 条双标注者人工评估验证评测 prompt 的可靠性。

关键结果

ChatGPT 在全部四项指标上大幅领先第二名 Alpaca-13B，领先幅度 22.4%-40.1%

所有模型（含 ChatGPT）在 QG-Summary 上的 accuracy 与 relevance 均低于 QG-Passage，开源模型差距更大；模型对上下文的依赖差距在 QG-Summary 更大（平均差距 0.2 vs QG-Passage 的 0.12）

Alpaca-7B/13B 在 QG-Passage 设置下无上下文反而表现更好；蒸馏模型在 1024 tokens 内表现稳定，但超过 >1024 tokens 后性能退化速度高于 Llama，而 ChatGPT 在 2k tokens 内保持稳健

GPT-4 评测 prompt 在 TruthfulQA 代理测试（随机 50 条）中超过 90% 的情况在 factual consistency 与 correctness 上偏好人类撰写的答案；50 条人工标注与 GPT-4 评分在各项指标上具有高一致性

Alpaca 生成的问题超过 80% 不可答（上下文中不存在）或为乱码，无法作为开源问题生成 baseline

每个设置生成 1350 个问题（9 领域 × 50 篇 × 3 问），过滤后保留 1278 个

创新点

区别于以往依赖短答案 QA 基准（SQuAD、HotpotQA）与 ROUGE/BLEU 等自动指标的工作，本文提出从抽象摘要生成追问（QG-Summary）作为可扩展的 LFQA 压力测试构造，迫使模型综合长文档多个部分的信息作答；同时采用经 TruthfulQA 代理测试与人工一致性双重验证的 GPT-4-as-judge 多维评分来评测自由文本长答案，并系统刻画了开源小模型及其蒸馏版在长上下文下的退化行为。
