PEARL: Prompting Large Language Models to Plan and Execute Actions Over Long Documents

PEARL：提示 LLM 在长文档上进行规划与动作执行

简介

论文针对 CoT 等推理提示难以用于长文档复杂推理的问题（问题分解与每步中间输出都难以获得），提出 PEARL 提示框架，含三阶段：action mining 用少量人工种子动作作示范、让 LLM 从训练集问题中自动挖掘带参数的函数式动作库；plan generation 不把长文档放入 prompt、基于动作库与 few-shot 示例生成解题计划；plan execution 用模板填入前序步骤输出、zero-shot 地在长文档上逐步执行，并以 self-correction/self-refinement 保障计划格式与示例质量，全程仅靠 GPT-4 的 zero/few-shot 提示实现。在 QuALITY 长文本问答挑战子集上，PEARL 显著优于 zero-shot 与 CoT 基线，需最长上下文的问题准确率由 61.9% 提至 72.4%；消融显示动作数量、真实执行与 self-refinement 均对性能关键。代价是 prompt token 约为基线 4.4 倍、生成 token 1.3 倍，且对仅需短上下文的简单问题可能过度复杂化。

问题

Chain-of-Thought 等推理提示方法在长文档（数千 token）复杂推理任务上不适用：原始问题的分解与每步中间输出都 non-trivial、难以获得。论文要解决如何让 LLM 对长文档完成需要全局理解与多步推理的问答，而不依赖人工逐步编写推理过程。

方法

PEARL（Planning and Executable Actions for Reasoning over Long documents）三阶段提示框架：(1) Action mining：以 7 个人工种子动作为示范，让 LLM 从训练集问题中挖掘任务特定动作（格式为带输入参数的程序化函数+自然语言定义），经两轮抽象化简从 407 个收敛到 81 个动作；(2) Plan generation：规划时不展示长文档以腾出上下文空间放 few-shot 示例，让 LLM 基于动作库生成形如 output=ACTION(args) 的计划；(3) Plan execution：用模板填入动作定义、当前步骤参数及前序输出，zero-shot 地在长文档上逐步执行。另设 plan parser 做 self-correction（格式错误时回传错误信息让 LLM 修正），并通过执行计划+任务评分函数验证来 self-refinement 模型生成的 in-context 示例。

关键结果

在 QuALITY 中需最长上下文的问题上，PEARL 准确率 72.4% vs zero-shot GPT-4 的 61.9%

PEARL 在 Long 子集上准确率高于所有对比方法（zero-shot GPT-4、GPT-3.5、zero-shot CoT），并报告了相对 zero-shot 基线的统计显著性 p 值

动作数量是关键超参：仅 1 个动作时 Long 子集准确率降至 64%，过多（140 个）也退化，最终采用 81 个动作

去掉计划执行结果使绝对准确率下降约 3 点；仅给计划不执行仍比 zero-shot/CoT 基线高约 2 个绝对点

去掉 self-refinement 后整体准确率下降近 3 个绝对点

成本：平均每例 PEARL 需处理 4.4 倍 prompt token、生成 1.3 倍 token

人工评估：97% 以上计划被认为正确（94%+ 置信度，因标注者未读原文而偏高），主要问题是 10% 的计划含不必要步骤

用 11 个人工编写示例替换模型生成示例的变体达到 70.3（Long）/76.8（Short）/72.3（总体），说明额外人工投入并非必需

1K 样本中仅 4 例在重试上限内无法生成可解析计划

GPT-4 标准多选设置：全 QuALITY dev 84.4%、1000 难例子集 78.7%；对选项顺序敏感，四种排序均答对的题目降至 68.7%；答案映射与人工一致率约 83%（κ=0.677）

创新点

区别于 ReAct、Toolformer 等假设预定义动作空间的方法，PEARL 从同分布训练数据中自动挖掘任务特定动作库，减少人工设计动作的成本；区别于 CoT，它将规划与执行解耦——规划阶段不接触长文档以腾出上下文放 few-shot 示例，执行阶段才逐段处理长文档；并通过 plan parser 自纠错与基于执行+评分函数的 self-refinement 自动保证计划与 in-context 示例质量。论文自称是首个专为长文档复杂推理设计并在其上评测的提示技术（Table 1）。
