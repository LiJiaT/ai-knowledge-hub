简介

该综述系统梳理了 NLP 从“预训练-微调”向“预训练-提示-预测”范式转变的研究全景：不再通过目标函数工程适配下游任务，而是用模板把任务改写成与 LM 预训练一致的形式，让模型直接填空或续写得到输出。论文给出统一数学框架（prompt addition、answer search、answer mapping），并从预训练模型选择、prompt engineering（cloze/prefix、手工/自动、离散/连续）、answer engineering、multi-prompt learning（集成/增强/组合/分解）与五种参数更新策略等维度组织已有工作。核心结论：给定合适的一组提示，单个完全无监督训练的 LM 即可解决大量任务，实现 few-shot 甚至 zero-shot；但 few-shot 示例的选择与顺序会造成从接近 SOTA 到接近随机猜测的性能波动，且 LM 概率分布存在多种偏差需要校准。对团队而言，这是提示工程概念框架的奠基性参考。

问题

传统全监督 NLP 需要大量任务标注数据，“预训练-微调”范式也要为每个下游任务微调模型；prompt-based learning 通过模板将任务改写为 LM 的填空/续写形式，可减少甚至免除标注数据需求，但由此产生新的 prompt engineering 问题——如何为每个任务找到最合适的提示，且该领域发展迅速、工作分散、缺乏系统化整理。论文旨在对这一新范式给出统一定义、结构化类型学、应用全景与挑战清单。

方法

系统综述+统一形式化：定义提示函数 f_prompt(x) 将输入 x 经模板变为提示 x'（cloze 与 prefix 两种形状），用预训练 LM 在答案空间 Z 中搜索最高分答案，再经映射得到最终输出 y。在此框架下按维度组织文献：(1) 预训练 LM 选择（训练目标、噪声函数、表示方向性与任务/提示形状的匹配）；(2) prompt engineering（手工模板；离散自动搜索：prompt mining、paraphrasing、梯度搜索、prompt generation、prompt scoring；连续提示：Prefix Tuning、P-tuning、PTR 等；静态 vs 动态）；(3) answer engineering（答案空间设计与搜索、verbalizer）；(4) multi-prompt learning（prompt ensembling、prompt augmentation 即 in-context 示例、prompt composition、prompt decomposition）；(5) 五种参数更新策略（promptless fine-tuning、tuning-free prompting、fixed-LM prompt tuning、fixed-prompt LM tuning、prompt+LM tuning）。另覆盖知识探测、分类、信息抽取、推理、QA、文本生成、生成文本自动评测、多模态等应用，并给出挑战清单与元分析。

关键结果

本文为综述、无自身对比实验；元分析显示 2021 年 prompt-based 论文数量激增，作者归因于 GPT-3 的流行

引用 Scao and Rush (2021)：在分类任务上平均而言，添加提示带来的准确率提升相当于增加数百个数据点

引用 Lu et al. (2021)：few-shot 示例的选择可导致从接近 SOTA 到接近随机猜测的巨大性能差异

引用 Zhao et al. (2021)：识别出 majority label bias、recency bias、common token bias 三类偏差，导致 LM 在给定示例后偏向特定答案

趋势分析：自动模板搜索随时间从离散搜索转向连续搜索，原因包括离散搜索更难优化、soft prompt 表达能力更强

创新点

首个将 prompt-based learning 作为独立范式系统化组织的综述：提供覆盖大量异质工作的统一数学记号、高度结构化的概念类型学（prompt/answer/multi-prompt/tuning 多轴分类、五种 tuning 策略），并配套持续更新的网站与论文列表资源；同时将提示学习与 ensemble learning、few-shot learning、larger-context learning、query reformulation、controlled generation 等相邻领域建立联系，指出可互相借鉴之处。
