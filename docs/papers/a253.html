Reasoning Theater: Disentangling Model Beliefs from Chain-of-Thought

Reasoning Theater：将模型内部信念与 Chain-of-Thought 解耦

简介

论文研究推理模型中的'表演性思维链'（performative CoT）现象：模型可能在推理早期内部就已锁定最终答案，却继续生成看似逐步推理的文本而不透露真实置信度。作者在 DeepSeek-R1 671B 与 GPT-OSS 120B 上对比三种早期解码方法——基于残差流激活的 attention probe、中途截断的 forced answering、以及用 Gemini-2.5-Flash 充当的 CoT monitor——发现简单回忆型 MMLU 上探针远早于 monitor 解码出答案（performativity rate 0.417，GPQA 仅 0.012），而困难的多跳任务 GPQA-Diamond 上三者同步渐进提升，说明 CoT 忠实性取决于任务难度；backtracking、'aha'等转折点更多出现在内部不确信的回答中，属于真实的不确定性表达而非表演。应用层面，校准良好的探针可实现 early exit：MMLU 上 95% 置信度退出保留 97% 准确率并节省 68% token。对团队的核心启示是：CoT 文本并非模型内部状态的可靠证据，任何基于 CoT 的监控、审计或评测都会系统性滞后于模型真实信念。

问题

推理模型的 Chain-of-Thought 未必忠实反映其内部计算，已有研究表明 CoT 可能省略真实决策原因。论文聚焦其中一种具体失真——'表演性 CoT'（performative CoT）：模型在推理早期内部已高度确信最终答案，却继续生成看似在逐步推理的 token 而不透露该信念。这直接威胁以 CoT 文本为依据的安全监控与审计的可靠性，并引出两个问题：如何判断模型在推理过程中'何时已经知道答案'，以及能否利用内部信号提前终止不必要的推理以节省算力。

方法

在 DeepSeek-R1-0528 671B、GPT-OSS 120B 及 DeepSeek-R1 蒸馏 Qwen2.5 系列（1.5B–32B）上，对 MMLU-Redux 2.0 与 GPQA-Diamond 的回答，用三种特权信息递增的方法追踪答案信息何时出现：(1) Attention Probes：在每层残差流激活上训练注意力池化探针，训练时随机采样序列前缀以预测最终选项，推理时在每个前缀位置评估；(2) Forced Answering：在中间步骤截断并注入强制作答提示，取四个选项 logits 的 softmax 分布；(3) CoT Monitor：用 Gemini-2.5-Flash 读 CoT 前缀预测模型将选的答案（可输出 N/A），并标注 backtracking/realization/reconsideration 转折点。通过探针/强制作答与 monitor 准确率斜率之差定义并量化 performativity rate；最后利用探针的校准置信度阈值实现 early exit。

关键结果

MMLU 上 DeepSeek-R1 的 performativity rate 为 0.417，GPQA-Diamond 仅 0.012（GPT-OSS 与 forced answering 趋势一致），说明简单任务 CoT 大量表演、困难任务接近真实推理

attention probe 最佳层测试准确率 87.98%，远超 linear probe 的 31.85%；随机标签训练的探针接近随机水平，证明探针读取的是残差流中已有信息

MMLU 上探针与 forced answering 在推理一开始即达高准确率，而 CoT monitor 要到更晚才能识别答案；GPQA-D 上三种方法同步渐进提升

High Confidence（探针全程≥90%）回答中转折点密度约为其他回答的一半：R1 MMLU 上 reconsideration 占高置信回答步骤的 1.4% vs 其他回答的 3.2%

Early exit：MMLU 上 95% 置信度退出保留 97% 原性能并节省 68% token；GPQA 上 80% 置信度退出保留 97% 性能并节省 50% token；摘要称探针引导的 early exit 最高可省 MMLU 80%、GPQA-Diamond 30% token

模型越大表演性越强：671B R1 在推理开始前即可高准确率解码答案，1.5B–32B 蒸馏模型的 probe-monitor 差距更小、CoT 更忠实

MMLU 训练的探针可直接迁移到 GPQA-D，在 19 题上微调相比直接迁移提升可忽略

创新点

不同于以往依赖 CoT monitor、重采样或单 token/逐层探针的忠实性研究，本文用跨序列维度的 attention pooling 探针在 token 级追踪答案表征在整个推理过程中的出现时点，并在同一框架下系统对比白盒探针、forced answering 与黑盒 CoT monitor 三类方法；首次按任务难度与模型规模刻画 performative CoT 的分布规律，并用 Grice 合作原则解释为何以 outcome reward 优化的推理模型是'不合作的说话者'；同时将探针校准性转化为可落地的 early exit 省 token 手段。
