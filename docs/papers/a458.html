Automatic Prompt Augmentation and Selection with Chain-of-Thought from Labeled Data

Automate-CoT：从标注数据中进行思维链（CoT）提示的自动增强与选择

higharXiv提示技术自动提示优化思维链与推理上下文窗口成本与效率基于arXiv版本
下载原文 PDF

简介

Manual-CoT 等思维链提示依赖人工精心编写的推理链示例，且示例的顺序、复杂度、多样性与语言风格都会显著影响效果（不同标注者可造成高达 28.2% 的准确率差异），人工适配新任务成本很高。论文提出 Automate-CoT 三步流水线：先由 LLM 对有标注的问题自动生成多条伪推理链，再依据生成答案与 ground-truth 的一致性剪枝保留高质量示例，最后用方差缩减策略梯度估计（VR-PGE）以黑盒方式优化隐变量，从候选池中自动选出最优的 4-8 条 CoT 示例组合。在 text-davinci-002、code-davinci-002 与 gpt-3.5-turbo 上，方法在算术、常识、符号推理及非推理任务上分别取得 +2.7%、+3.4%、+3.2%、+2.5% 的提升，并优于 Auto-CoT、BM25 检索、K-Means 聚类与 PromptPG 等示例选择方法。成本分析显示其优化开销约 $4.7，比 fine-tuning（约 $57.6）低 12 倍，且仅需 100 条标注样本。对团队而言，这是一套可直接借鉴的'从标注数据自动构建与优选 CoT 提示'的工程化方案。

问题

人工编写的 CoT 示例成本高且难以迁移到新任务：不仅需要挑选问题、设计推理步骤，还受四个敏感性因素困扰——示例顺序（GSM8K 上打乱顺序最低可到 59.8%，比平均 63.1% 低 3.3%）、推理链复杂度（步数）、不同复杂度示例的组合多样性、以及语言风格（不同标注者可造成高达 28.2% 的准确率差异）。论文目标是给出一种自动、任务无关的流程，在只有问答标注、没有人工推理链的数据上自动构建并优选 CoT 提示。

方法

Automate-CoT 三步流水线： 用 LLM 对每个问题自动生成多条伪推理链（可完全零样本，仅加 'Let's think step by step.'，m=0 时也能工作）； 依据'生成正确推理是生成正确答案的必要条件'这一假设，按生成答案与 ground-truth 的一致性剪掉错误链，构建约 100 条高质量示例池； 将示例选择建模为带隐变量（每个示例位置上的类别分布 p_i）的监督优化，因商业 API 不可获取梯度，采用方差缩减策略梯度估计（VR-PGE）配合投影随机梯度下降（AdamW，5 epochs，学习率 1e-3，batch size 10），利用 API 返回的 logprobs 计算答案 token 的交叉熵损失，最终取验证集准确率最高的示例组合用于推理。

关键结果

text-davinci-002 上平均超过 Manual-CoT 2.6%、超过 self-consistency (SC) 3.7%；code-davinci-002 上分别超过 2.7% 与 2.2%

整体提升：算术推理 +2.7%、常识推理 +3.4%、符号推理 +3.2%、非推理任务 +2.5%；GSM8K 上超过 Auto-CoT 4.8%

gpt-3.5-turbo 上：算术 +2.8%、常识 +3.9%、符号 +3.2%、整体 +2.8%；平均比 BM25 检索高 3.8%、比 K-Means 聚类高 2.6%，并优于 PromptPG

候选池需达到 20 条及以上才能超过 Manual-CoT，性能随池增大持续提升（附加实验最大池为 150）

风格消融中，Automate-CoT 能从 16 条好/坏风格混合的示例中正确选回原始 8 条，选中示例比未选中者高 2%

成本对比：gpt-3.5-turbo 下 Automate-CoT 优化开销约 $4.7，fine-tuning 约 $57.6（12 倍差距），且 fine-tuned 模型后续推理单价高 8 倍；Automate-CoT 仅需 100 条训练样本，而 fine-tuning 需约 8000 条

零样本设置（仅加 'Let's think step by step.'）下结果可比甚至略超 Manual-CoT 与 Auto-CoT；GSM8K 上加 tricks 后达 69.8%（+2.2%），self-consistency 下 83.0%（+0.6%）

创新点

相比依赖固定人工示例的 Manual-CoT/SC、基于聚类的 Auto-CoT、基于检索的 BM25 与基于强化学习的 PromptPG，Automate-CoT 把'生成—按标签一致性剪枝—黑盒选择'统一为全自动流水线，并显式针对顺序、复杂度、多样性、风格四类敏感性进行优化（如自动达成 complexity-diversity trade-off）；同时 VR-PGE 只需 API 返回的 logprobs 即可优化离散示例选择，适用于不开放梯度的黑盒商业模型，而此前的 black-box prompt learning 方法受限于零样本分类任务、推理能力不足。
