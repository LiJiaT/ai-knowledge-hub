Human-inspired Episodic Memory for Infinite Context LLMs

受人类情景记忆启发的无限上下文 LLM（EM-LLM）

简介

预训练 LLM 在超出训练窗口的长上下文任务中表现显著下降，现有 RAG 与 KV 检索方法（如 InfLLM）与短上下文性能之间仍有明显差距。论文提出 EM-LLM，借鉴人类情景记忆与事件认知机制，在推理时用 Bayesian surprise（token 负对数似然超过滑动窗口自适应阈值）在线把上下文切分为'情景事件'，再用基于 attention key 相似度图的 modularity/conductance 图论指标细化边界，检索时采用'相似性 buffer + 时间连续性 buffer'两阶段机制，无需任何微调即可通过 attention 层 patch 挂接到预训练 LLM。在 LongBench 与 ∞-Bench 上，EM-LLM 全面超越 SOTA 检索方法 InfLLM，并在多数任务上超过 RAG（NV-Embed-v2）与 full-context，Passkey.Retrieval 在约 1000 万 token 长度下仍达 100% 准确率。对团队而言，这篇论文为知识库问答的 RAG 选型与 Agent 长期记忆系统提供了新的上下文组织与检索范式，是上下文工程与记忆域的直接参考。

问题

预训练 LLM 难以处理超出训练窗口的长上下文：Transformer 难以外推到更长序列，softmax attention 计算开销大，且聚合后的 value 表示容易噪声化、失去区分度；现有检索式方案（RAG、基于 KV 的 k-NN 检索如 InfLLM）在长上下文任务上与短上下文性能仍存在显著差距。论文目标是让现有预训练 LLM 在不做任何微调的前提下，以计算高效的方式处理'实际上无限'的上下文长度。

方法

提出 EM-LLM 架构，将上下文划分为三组：128 个 initial tokens（作为 attention sink）、evicted tokens（由情景记忆模型管理）与 local context（完整 softmax attention）。记忆形成：推理时以 Bayesian surprise（当前 token 的负对数似然）超过滑动窗口自适应阈值 T 作为事件边界初判（阈值随上下文漂移自适应，γ 控制灵敏度）；再用图论方法细化边界——把 attention key 相似度矩阵视为邻接矩阵，以 modularity（效果最佳）或 conductance 为目标函数在相邻初始边界间寻找最优位置，整体复杂度 O(nm)。记忆检索：两阶段机制——先用 k-NN（点积相似度，大规模用近似 k-NN）按事件代表 token 检索 k_s 个事件构成 similarity buffer，再用大小为 k_c 的队列 contiguity buffer 纳入相邻事件以保留时间连续性与 asymmetry 效应，且每层独立检索。全程无需微调，通过兼容 Huggingface Transformers 的 attention 层 patch 实现，并支持 KV cache 的 CPU/磁盘 offload 与模型并行。

关键结果

在 LongBench 与 ∞-Bench 上超越 SOTA KV 检索方法 InfLLM：跨 5 个基座 LLM、80% 的 LongBench 任务组及总体平均均更优；检索类任务最高提升 40%，QA 类任务最高提升 29.7%（benchmark 级差异显著，双尾 z 检验 p<0.05，Phi-3.5 的 LongBench 除外 p=0.23）

对比 RAG：在 LLaMA 3.1-8B 上超过 SOTA 检索器 NV-Embed-v2——LongBench 高出 30.5%、∞-Bench 高出 11.5%，且在多数任务上超过 full-context 模型

Passkey.Retrieval 任务在最长 10.2M token 的序列上达到 100% 准确率，该规模对 full-context 模型在计算上不可行

消融：加入边界细化后在 LongBench 与 ∞-Bench 60% 的任务上取得最佳表现，加入 contiguity buffer 后在 44% 的任务上最佳；SM+C 变体下检索类任务相对 InfLLM 平均提升 19.4%、多文档 QA 平均提升 9.2%

切分质量：基于 surprise 的切分与人类标注事件边界最接近（Wasserstein 距离最小），在 PG-19 上 surprise+refinement 的 modularity 与 intra/inter-similarity 指标优于固定与随机切分

创新点

相对 InfLLM 等固定大小分块的组检索方法，EM-LLM 首次在 LLM 中用 Bayesian surprise 阈值在线动态确定记忆单元边界（作者称该阈值机制为首次用于 LLM），并用图论指标（modularity/conductance）做边界细化；检索上把人类自由回忆研究中的 temporal contiguity 与 asymmetry 机制与相似性检索结合为两阶段过程；与 RAG 的单次检索不同，它在每层独立做 KV 检索，且无需微调即可应用于任意预训练 Transformer LLM。
