Self-RAG: Learning to Retrieve, Generate, and Critique through Self-Reflection

Self-RAG：通过自我反思学习检索、生成与批判

简介

LLM 仅依赖参数化知识易产生事实错误，而传统 RAG 无差别检索固定数量文档，既不判断是否需要检索也不校验文档相关性，导致输出质量下降且缺乏可验证归因。SELF-RAG 训练单个 LM 通过扩充词表引入 reflection tokens（Retrieve/ISREL/ISSUP/ISUSE），学会按需调用检索器、并行评估多个候选段落，并对自身每段生成做相关性、支持度与效用自评。训练上先用 GPT-4 蒸馏出 critic 模型，再由 critic 离线把 reflection tokens 插入语料，用标准 next-token 目标训练 generator，成本远低于 RLHF。推理时通过阈值触发检索与 segment 级 beam search（以 critique token 概率加权和评分），可在不重训的情况下定制检索频率与 citation 严谨度。7B/13B 模型在六个任务上超过 ChatGPT 与检索增强 Llama2-chat，长文本生成的 FactScore 与 citation 精度显著提升。

问题

LLM 仅依赖参数化知识易产生事实错误；现有 RAG 方法无差别检索固定数量的文档，不判断检索是否必要、文档是否相关，既损害 LLM 通用性也可能引入无关内容导致低质量输出；且模型未被显式训练去遵循检索内容，输出不保证与检索段落一致，缺乏可验证的引用归因。

方法

提出 SELF-RAG 框架：在词表中加入 reflection tokens（Retrieve 判断是否需要检索；ISREL 评估段落相关性；ISSUP 评估输出是否被段落支持；ISUSE 评估整体效用），端到端训练单个 LM 学会按需检索、生成与自我批判。训练分两步：(1) 用 GPT-4 按类型化指令生成 reflection token 标注（每类 4k-20k 条），蒸馏训练 in-house critic（Llama2-7B 初始化）；(2) critic 离线将 reflection tokens 与检索段落插入约 150k 指令语料，再用标准 next-token 目标训练 generator（Llama2 7B/13B），训练时 mask 检索文本块，无需 RLHF/PPO。推理时：模型先预测 Retrieve 决定是否调用检索器（可设概率阈值软触发）；需要检索时并行处理 K 个段落生成候选，做 segment 级 beam search，以各 critique token 最优取值的归一化概率线性加权和（权重推理时可调）作为段评分，支持软约束重排与硬约束过滤（如剔除 ISSUP=No support 的续写），从而在不重训的情况下定制检索频率、citation 严谨度与创造性之间的权衡。

关键结果

SELF-RAG（7B/13B）在 PubHealth、PopQA、传记生成与 ASQA（Rouge、MAUVE）上超过 ChatGPT，在全部六个任务上超过 Llama2-chat 与 Alpaca；在传记生成上超过基于 Llama2-65B 迭代提示的并发方法 CoVE

ASQA 上 citation precision 超过包括 ChatGPT 在内的所有对比模型（该指标衡量生成论断是否被引用证据完全支持）

Critic 模型在大多数 reflection token 类别上与 GPT-4 判断一致率超过 90%；GPT-4 与作者人工评估在 relevance、retrieval necessity 上一致率 95%，support 90%，usefulness 80%

答案溯源分析：SELF-RAG 的正确答案中仅 2% 不在所提供证据内，而 Alpaca-30B 为 20%、Llama2-chat-13B 为 18%、Alpaca 为 15%

消融实验：固定只使用 top-1 检索文档（传统 RAG 方式）在 PopQA 与 ASQA 上造成大幅性能下降；beam search 中移除 ISSUP 评分会损害 ASQA 表现，说明基于细粒度多准则选择生成是性能增益的关键

训练数据从 5k 扩到 150k 性能持续上升（PopQA、ASQA 尤明显），而 Llama2-FT 基线从 50k 到 150k 无显著提升；推理时调高 ISSUP 权重可提升 citation precision 但降低 MAUVE 流畅度

创新点

区别于传统 RAG 的固定数量无差别检索，SELF-RAG 让单个 LM 按需决定检索时机，并用 reflection tokens 对检索段落与自身生成做段级细粒度自评；区别于 RLHF/PPO，critique 离线插入训练语料、用标准 LM 目标训练，训练成本大幅降低；区别于仅用控制 token 在生成开头引导的工作，SELF-RAG 在每段生成后自评，并支持推理时软约束重排与硬约束过滤的测试时定制；区别于 Self-Refine 等迭代精炼方法，不牺牲推理效率；区别于依赖外部 NLI/摘要模型过滤或压缩检索结果的方法，SELF-RAG 推理时不依赖外部模型。
