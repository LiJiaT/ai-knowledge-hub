Multi-Head RAG: Solving Multi-Aspect Problems with LLMs

Multi-Head RAG：解决 LLM 的多方面（Multi-Aspect）问题

higharXivRAG与检索评测基准成本与效率基于arXiv版本
下载原文 PDF

简介

现有 RAG 方法难以处理需要同时检索多个语义差异很大文档的"多方面"查询，因为相关文档在 embedding 空间中相距很远、难以联合召回。论文提出 Multi-Head RAG（MRAG）：不再使用 decoder 最后一层的单一向量，而是提取 embedding LLM 最后一个 MHA 模块中各 attention head 合并前的激活作为检索键，为每个文档与查询生成多个"单方面"向量，且无需任何额外微调。配合一次性的 head 重要性打分与指数折扣投票重排，MRAG 可无缝接入现有向量库与 RAG 框架。实验显示，在法律文档合成与化工厂事故分析等真实场景中检索成功率最高提升 20%，多方面查询平均提升 10-20%，单方面查询无退化，且不增加推理延迟与存储开销；下游 LLM 生成的事实信息量从每查询 11.2 条提升到 15.4 条。

问题

现有 RAG 方法与基准均未显式针对"多方面查询"——即需要同时获取多个内容差异巨大、在 embedding 空间中相距很远的文档的查询（如化工厂事故归因需同时调取人员心理、设备记录、天气、微气候等多类文档）。标准 RAG 用单一 last-layer embedding 表示文档，难以联合召回这类语义上彼此远离的文档。

方法

MRAG 的核心是利用 Transformer 多头注意力（MHA）的内部结构：从 embedding 模型（如 SFR-Embedding-Mistral、e5-mistral-7b-instruct）最后一个 decoder block 的 MHA 中，提取最后一个 token 在各 attention head 合并前的激活，得到 h 个"single-aspect embedding"（如 32 个 head 共 1024 维），替代标准 RAG 的单一 FFN 输出向量。数据预处理时为每个 head 向量空间做一次性重要性打分（平均 L2 范数 × 平均余弦距离）；查询执行时在各 head 空间并行做 top-c ANN 检索，再用 s_i·2^-p 的指数折扣投票合并为 topk 列表，且 reranker-agnostic、可外接 cross-encoder；reader 端用多方面 prompt 模板将各文档分节放入上下文。全程无需额外微调、无架构修改，总存储与计算复杂度与标准 RAG 相同（O(nd)），多向量检索可由 Milvus、Pinecone 等现代向量库并行执行。

关键结果

相对 18 个 RAG 基线，真实场景（法律文档合成、化工厂事故分析）检索成功率最高提升 20%

Wikipedia 多方面数据集（固定 10 个方面）：精确文档匹配的检索成功率平均提升 >10%，类别匹配平均提升 >25%

在不同方面数（1-25）与两个 embedding 模型（SFR、e5）下，MRAG 平均比 Standard RAG 高 10-20%

下游生成质量：MRAG 每查询平均产出 15.4 条事实信息，Standard RAG 为 11.2 条

单方面查询上与 Standard RAG 性能持平，仅有可忽略的精度损失

无额外推理延迟与存储开销（如 1024 维拆分为 32 个 head 向量）；head 重要性打分的预处理开销低于 5%（SciFact 2.7%、NFCorpus 1.75%）

验证了 head 特化现象：某些 head-类别对的检索量高于平均值 2 倍以上（如 head 7 对 mathematical transforms 类别）

与 Fusion RAG 组合后的 Fusion MRAG 一致优于纯 Fusion RAG，但引入更多 token 成本与更大方差

创新点

据论文所述，MRAG 是首个利用预训练 decoder-based embedding LLM 的 MHA 内部激活做 RAG 检索的方法：与 Poly-encoder、ColBERT 等因 token 级表示而天然多向量的方案不同，MRAG 的多个向量对应不同语义方面而非 token 覆盖；与需要训练或架构修改的 MHA 变体（MHSAN、PIT、MAGE 等）不同，MRAG 免训练、免修改、即插即用，并保持与 vanilla RAG 相同的渐近复杂度。同时论文贡献了多方面 RAG 的评测方法论（三个数据集、1600 条查询、Retrieval/Category/Weighted Success Ratio 三个新指标），可扩展 RAGAs 等现有基准。
