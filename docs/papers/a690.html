Large Language Models can be Guided to Evade AI-Generated Text Detection

大语言模型（LLM）可被引导以规避 AI 生成文本检测

简介

该论文评估现有 AI 生成文本检测器（微调分类器、统计方法、商业 API）对提示引导式攻击的脆弱性。与依赖外部改写模型（如 DIPPER）的 paraphrase attack 不同，作者提出 SICO（Substitution-based In-Context example Optimization）：仅用 40 条人工样本和少量 LLM 推理（约 1 美元 GPT-3.5 API 成本），以代理检测器给出的 AI 概率作为效用函数，通过词级同义词替换与句级改写迭代优化 in-context 示例，自动构造出让 LLM 生成'类人'文本的 prompt。在学术写作、开放问答、虚假评论三个任务上，SICO 使 GPT-3.5 成功规避六种检测器，平均降低 AUC 约 0.5，多数情况降至随机分类器水平，且生成文本的可读性与任务完成率接近人工水平。论文还提出双检测器 ensemble 防御，并建议将 SICO 作为未来检测器的标准评测工具。对团队而言，其核心价值在于展示了一套'以自动评测信号闭环驱动 prompt 自动优化'的通用范式。

问题

现有 AI 生成文本检测方法（training-based 分类器、统计方法、watermarking、商业 API 如 GPTzero）的鲁棒性未被充分评估；已有的 paraphrase attack 需要训练额外外部改写模型（如在大型数据集上微调 13B 模型），计算开销大。论文要验证：能否不依赖外部改写器，仅通过自动构造的 prompt 引导 LLM 本身生成可规避检测的文本，并给出对应的防御方案。

方法

提出 SICO 自动提示构造方法：(1) 用 LLM 从人工/AI 文本对中提取人类写作的语言特征 t_feature；(2) 用改写后的 AI 文本初始化 in-context 示例；(3) 以代理检测器（proxy detector）预测的 AI 概率 P_AI 定义效用函数 U(p)=1-平均 P_AI，通过 GreedyOPT 贪心替换迭代优化 in-context 示例——词级用 WordNet 同义词（限内容词、POS 对齐、mask LM 过滤），句级用 LLM 结合特征文本改写；(4) 最终 prompt = 特征文本 + 任务指令 + 优化后示例，保留效用最高的版本。提供 SICO-Gen（直接生成）与 SICO-Para（两步改写）两种用法。防御端提出分别针对原始 AI 文本与 SICO 文本训练两个检测器、取两者最大概率的 ensemble 方法。

关键结果

SICO 使 GPT-3.5 成功规避六种检测器（GPT3-D、GPT2-D、DetectGPT、Log-Rank、GPTzero、OpenAI-D），平均降低 AUC 约 0.5，多数情况降至 0.5 以下（随机分类器水平），在所有任务上显著优于 DIPPER、Parrot、GPT-Para、Human Prompt 基线

人工评测（600 样本）：SICO 文本的可读性与任务完成率与人工文本差距小于 0.1，而 DIPPER 可读性相对人工文本下降 0.27

不可感知性：在 QA 与评论生成任务上，SICO 显著降低文本被人工标注者识别为 AI 生成的比例

成本效率：仅需 40 条人工样本（K=8, |X_eval|=32），prompt 构造成本约 1 美元（Writing 1.04±0.04、QA 1.08±0.05、Review 0.75±0.04）

消融实验：优化步骤是关键，未优化的 in-context 示例等同于不使用示例；直接用人工文本作示例反而使检测更准确；特征文本的重要性低于优化后的示例

更换代理检测器（GPT3-D、GPTzero、DetectGPT）与 LLM（Vicuna-13B、WizardLM-13B、GPT-3.5、GPT-4-0613）后，SICO 仍保持约 0.4 的 AUC 降幅

ensemble 防御：用 5k SICO 样本 + 5k 人工样本微调 RoBERTa 与 GPT2-D 组合，显著提升对 SICO 文本的检测，同时保持对原始 AI 文本的检测能力

创新点

与已有 paraphrase attack（DIPPER、Parrot 需训练/微调外部 13B 改写模型）不同，SICO 不需要额外模型或训练步骤，仅通过自动优化 prompt 即可实现规避，是首个'LLM 可通过 prompt 引导规避检测器'的实证证据；在 in-context learning 研究中，不同于示例选择/排序/格式化（如 CoT 及自动 CoT），SICO 聚焦于通过替换迭代优化示例内容本身，且原则上可与上述方法组合使用。
