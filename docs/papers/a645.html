ChatCoT: Tool-Augmented Chain-of-Thought Reasoning on Chat-based Large Language Models

ChatCoT：基于对话式大语言模型的工具增强思维链推理

简介

该论文针对 LLM 在需要特定功能（如算术计算、信息检索）与多跳推理的复杂任务上，外部工具调用会打断 CoT 推理连续性的问题，提出 ChatCoT 框架。核心方法是把 CoT 推理建模为多轮对话：先在对话早期轮次注入工具说明、检索到的相似任务示例、多轮推理格式三类'对话知识记忆'，再迭代执行'推理—选择工具—构造参数—执行—反馈'的工具增强推理步骤，直到得出答案。在 MATH 数据集上平均准确率相对 SOTA 基线 PHP 取得 7.9% 相对提升，在 HotpotQA 上也优于对比基线；消融实验显示去掉检索增强知识或多轮推理格式记忆会大幅掉分，且生成 token 量与普通 CoT 同量级、无显著额外开销。对团队而言，这是一篇'不训练模型、仅靠提示与对话结构组织工具调用'的代表性方法论文，其上下文初始化与迭代式工具调用模式可直接借鉴到 Agent 工具编排与提示设计中。

问题

LLM 在需要特定功能（如算术计算、信息检索）与多步推理的复杂任务上仍表现不佳。引入外部工具时，已有两类方法各有缺陷：预规划式方法（先生成工具使用计划再执行）在生成计划后无法再与工具交互，即使看到明显错误也无法纠正；形式化动作式方法需要为特定任务设计形式化动作，频繁在 LLM 推理与执行动作之间切换，打断 CoT 推理过程的连续性。论文寻求一种统一方式来整合 CoT 推理与工具操作。

方法

ChatCoT 将 CoT 推理分解为多轮对话，每轮 LLM 既可与工具交互也可自行推理。包含两个组件：(1) 对话知识记忆初始化——在对话早期轮次注入三类知识：手工编写的工具功能描述（Tools Knowledge）、用 SimCSE 检索器从训练集检索 top-k 相似示例并拼接问题与解答（Retrieval-Augmented Task Knowledge）、人工标注的多轮推理格式示例（Multi-turn Reasoning Format）；(2) 迭代工具增强推理步骤——每轮先由 LLM 基于当前结果做自然语言推理，再通过固定提示（'To solve this sub-problem, which tool can we use?'）让 LLM 选择工具并构造参数，由遵循预定义规则的 agent 执行工具并返回结果，必要时加入反馈轮次让 LLM 判断结果是否有用并重新调用；设置最大对话轮数并用强制提示让 LLM 停止推理给出答案。实现上基于 ChatGPT (gpt-3.5-turbo)，计算器与方程求解器用 SymPy 实现，检索器为在任务训练集上微调的 SimCSE (RoBERTa)。

关键结果

MATH 数据集：平均准确率相对当时 SOTA 基线 PHP 取得 7.9% 相对提升，在七个子任务中的六个上超过 PHP

HotpotQA（distractor 设置开发集）：优于所对比的其他基线方法

消融实验：去掉任一类对话记忆都会降低性能，其中去掉检索增强任务知识或多轮推理格式记忆导致大幅下降

结合 self-consistency（采样 5 个输出做多数投票）：ChatCoT 的绝对提升略高于 CoT，说明其能很好适配 CoT 改进策略

工具调用分析（MATH Number Theory 子任务）：ChatCoT 在工具调用频率与成功率之间取得平衡，去掉工具知识或多轮推理格式二者之一，频率或成功率都会下降

生成 token 数分析：ChatCoT 与 CoT、CoT w/ Tool 等基线处于同一数量级，未带来显著额外计算开销

创新点

与已有两类方法不同：预规划式方法生成计划后无法与工具交互、无法纠错；形式化动作式方法需频繁在推理与动作间切换、损害推理连续性。ChatCoT 将 CoT 推理与工具操作统一建模为 LLM 与工具之间的多轮对话，利用 chat-based LLM 的多轮对话能力保持推理连续性，并提出以对话形式组织的'对话知识记忆'（工具/任务/推理格式三类知识）在早期轮次初始化上下文，使 LLM 无需专门提示即可跟随示例自然推理与调用工具。作者称该框架与任务类型和工具实现无关（agnostic），是可泛化的通用框架。
