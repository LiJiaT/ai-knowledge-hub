简介

该综述系统梳理了 Agentic RL（智能体强化学习）新范式：不同于将 LLM 视为单步静态生成器的传统 LLM RL（PBRFT），Agentic RL 把 LLM 嵌入 POMDP 序贯决策循环，通过环境交互与奖励优化规划、工具调用、记忆、推理与自我改进等 Agent 能力。论文用 MDP/POMDP 形式化刻画范式差异，提出'能力×任务'双重分类法，综合 500 余篇工作，覆盖搜索/Deep Research、代码、数学、GUI、多智能体等应用域，并汇总开源环境、基准与 RL 框架形成实用手册。关键结论：RL 是把静态启发式 Agent 模块转化为自适应行为的关键机制；可信性（reward hacking、幻觉、sycophancy）、训练规模化与环境规模化是三大开放挑战；真实部署依赖 guardrails、HITL、层级编排与通信协议等架构模式。对团队价值主要在能力分类框架、评测基准清单与部署模式参考，而非可直接复用的训练方法。

问题

现有研究对'将 LLM 作为序贯决策过程中可优化策略'的 Agentic RL 缺乏统一处理：各工作孤立考察单一能力、领域或自定义环境，术语与评测协议不一致，难以系统比较与跨域泛化；同时传统 LLM RL（PBRFT）将模型视为单步静态生成器，无法覆盖真实交互场景中的多轮决策、工具调用与长程信用分配需求。

方法

提出 Agentic RL 的统一形式化：用退化的单步 MDP 刻画 PBRFT、用时间扩展的 POMDP 刻画 Agentic RL，明确二者在环境状态、动作空间（A_text 与 A_action 双子空间）、转移动态、奖励函数与学习目标上的差异；构建双重分类法——按核心能力（planning、tool use、memory、self-improvement、reasoning、perception）与按任务域（搜索/Deep Research、代码、数学、GUI、视觉、具身、多智能体等）组织文献；系统比较 REINFORCE/PPO/DPO/GRPO 四大算法族及变体；汇总开源环境（WebArena、AppWorld、OSWorld、SWE-bench 等）、基准与 RL 框架（Verl、AWorld、Agent Lightning、ROLL 等）形成实用手册；最后讨论可信性、训练规模化、环境规模化三大挑战及真实部署架构模式。

关键结果

OpenAI Deep Research 在 BrowseComp 上取得 51.5% pass@1（论文引用的闭源系统数据）

rStar2-Agent（14B）经 510 步 agentic RL 训练，AIME24 平均 pass@1 达 80.6%、AIME25 达 69.8%

SkyRL-SQL 仅用 653 条训练样本，SkyRL-SQL-7B 在 SQL 生成基准上超越 GPT-4o 与 o4-mini

PRLCoder 的行级过程监督相对基模型带来 +10.5% 的 pass-rate 提升

AWorld 分布式 Agentic RL 框架通过大规模并行 rollout 相对单节点取得 14.6× 加速

1-shot RLVR：仅用 1 个样本做 RL 的性能接近 1.2k 样本数据集，2 个样本接近 7.5k MATH 训练集，并观察到 post-saturation generalization 现象

论文对被引数学/代码 RL 研究的统计：约 2/3 主要报告 pass@1 提升，约 1/3 明确报告 pass@k 前沿扩展

创新点

首个在 MDP/POMDP 层面将 Agentic RL 与传统 LLM RL（PBRFT）统一形式化区分的综述；提出'能力×任务'双重分类法，把 planning、tool use、memory、self-improvement 等模块统一视为 RL 可优化的相互依赖策略而非静态流水线；并首次将分散的开源环境、基准与框架整合为实用手册，综合 500 余篇工作，填补该领域缺乏系统性全景的空白。
