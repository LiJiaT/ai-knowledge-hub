Tree-of-Mixed-Thought: Combining Fast and Slow Thinking for Multi-hop Visual Reasoning

简介

论文研究 LLM 生成 code-like plan 做多跳视觉推理时准确率与效率难以兼顾的问题：one-stop 一次性生成（fast thinking）只需访问 LLM 一次但计划精度不足，Tree-of-Thought（slow thinking）靠回溯迭代保证长程规划准确率却消耗大量推理步数。受人类双系统认知启发，作者提出 Tree-of-Mixed-Thought（ToMT），含两种混合策略：ToT-One-Stop 在树搜索找到可行节点后一次性生成剩余计划，ToT-Block 让每个节点一次生成 k 步计划块，并以'代码可运行 + 参数与场景图一致'作为中间步骤评估器。作者还改造 PTR 与 CLEVR 数据集，构建了按推理结构与 hop 数分层、可独立评估 LLM 自身规划能力的评测框架。实验表明 ToT-OS 在保持 ToT 准确率的同时推理步数节省过半（RSSI 最高 2.89），且在 max step 受限的低资源场景下优势更大。对团队而言，其快慢混合规划与步数成本量化的思路对 Agent 规划环节的成本控制有直接借鉴价值。

问题

LLM 生成 code-like plan 进行多跳视觉推理时，准确率与规划搜索复杂度难以平衡：one-stop 一次性生成（fast thinking）效率高但受 'next token prediction' 范式限制、计划精度不足；Tree-of-Thought（slow thinking）通过回溯迭代提升长程规划准确率，但需多次访问 LLM，时间与计算资源消耗大。此外，现有评测受视觉专家模型准确率制约、且问题多为少跳简单题，难以系统评估 LLM 自身的长程规划能力。

方法

提出 Tree-of-Mixed-Thought（ToMT）分层规划搜索算法，包含两种快慢结合策略：(1) ToT-One-Stop（ToT-OS）：贪心策略，当 ToT 在深度达到 start depth（最优为 2）的节点找到通过评估的计划后，改用 one-stop 一次性生成全部剩余计划，若未通过规则校验则回溯继续树搜索；(2) ToT-Block：每个树节点一次生成 k 步计划块，缩短搜索深度。评估器采用两条标准：生成的代码能否正确运行（函数与参数使用正确）、通过工具与场景图交互验证参数一致性。搜索采用 DFS（max step 30，ToT/ToT-OS 分支因子 3，ToT-Block 为 5），生成时随机选取不同示例作 demonstration 以增加搜索路径多样性。同时改造 PTR 与 CLEVR 数据集（4 类推理结构、9 类问题、每类 120 样本，其中 20 个作 few-shot 示例库、100 个测试），配合与场景图精确交互的四类工具（Filter/Algebra/Relation/Attribution），实现独立于视觉专家模型准确率的 LLM 规划能力评测。

关键结果

ToT-OS 在所有题型上达到与 ToT 相同的计划准确率，同时推理步数节省过半；除 Long relation 外各场景准确率还略有提升

难题上节省显著：Long relation 与 Logic 类型 ToT 平均推理步数为 17.24 和 12.81，ToT-OS 仅需 9.63 和 5.50

推理步数节省指数 RSSI：ToT-OS 各题型 consistently 高于 1.7，Compare 题型最高达 2.89；ToT-Block 在 Sequence reasoning 题型 RSSI 大于 1.5 且准确率与 ToT 相当

三种树搜索算法（ToT、ToT-OS、ToT-Block）均大幅优于 naive one-stop 推理

消融实验：ToT-OS 在 start depth d=2 时最优；ToT-Block 增大 block size 持续减少推理步数但准确率普遍下降

低资源设定：max step 从 30 降至 10 或 20 时，本方法显著优于 naive ToT

引入 fast thinking 后规划准确率与 hop 数呈负相关（One-Stop 最明显）；ToT-OS 的推理步数与 hop 数几乎不相关，而 ToT/ToT-Block 呈强正相关

Parallel 类型中 ToT-OS 在 Sum 题型零失误，但 Compare 题型准确率仅 63%

创新点

已有规划范式分三类：one-stop 一次性生成、ReAct/Toolformer/Reflexion 等无法回溯的迭代生成、纯 ToT 树搜索，前者保效率不保准确率、后者保准确率不保效率。本文受人类'双过程'认知启发，提出两种将 fast 与 slow thinking 系统性结合的分层搜索策略（ToT-OS 贪心混合、ToT-Block 分块生成），在保留 ToT 回溯与迭代能力的同时大幅降低 LLM 访问次数；并提出用场景图改造 PTR/CLEVR、按推理结构与 hop 数分层、配合精确工具集来评测 plan-search 算法性能与效率的系统性框架，规避了视觉专家模型误差对评测的干扰。
