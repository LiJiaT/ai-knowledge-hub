Episodic Memories Generation and Evaluation Benchmark for Large Language Models

面向大语言模型的情景记忆（Episodic Memories）生成与评测基准

简介

论文针对 LLM 缺乏'情景记忆'——即对特定时间与空间中具体事件的回忆能力——这一问题，提出受认知科学启发的建模与评测框架。方法上将事件建模为（时间、空间、实体、内容）四元组，用 LLM 生成带受控 ground truth 的合成'书籍'与模板化问答对，构建无污染、可扩展的 benchmark（开源 11 个数据集），并系统对比 in-context、RAG、fine-tuning 三种记忆策略。关键结论：GPT-4o（in-context）与 Claude 3.5 Sonnet（RAG）表现最好，除 GPT-4o 外 RAG 普遍优于 in-context；cue 匹配多事件时所有模型 F1 降至 0.60 以下，实体状态跟踪 ≤36%、全事件召回 ≤18%、时序排序能力差；naive fine-tuning 只过拟合单事件、无法泛化。对团队而言，它为评估知识库问答/RAG/Agent 记忆模块在多事件、时序与状态跟踪类问题上的能力提供了现成工具与评测方法论。

问题

现有 LLM 记忆/长上下文评测（needle-in-a-haystack、长上下文 QA、bAbI 类合成任务等）只测简单检索或推理，存在捷径、数据泄漏、缺乏时空感知等缺陷，无法评估 LLM 对'特定时间与空间中发生的事件'的情景记忆能力，包括时序/空间上下文理解、实体状态跟踪、基于线索（cue）的召回以及避免虚构（confabulation）。

方法

受认知科学启发，将情景事件建模为四元组 (t, s, ent, c)；从含 100 个日期/地点/实体/内容的静态宇宙按截断几何分布采样事件，用 LLM（Claude 3.5 Sonnet / GPT-4o）逐章生成连贯叙事'书籍'，经精确解析校验与 LLM-as-a-judge 布尔问答双重质检保证一致性；用模板系统按 cue 组合生成问答对（含空答案题测幻觉），并平衡匹配事件数分布；评测采用 LLM-as-a-judge 语义匹配打分计算 F1（时序题加 Kendall's τ），在 in-context、RAG（paragraph/chapter 两种分块粒度）、fine-tuning 三种记忆策略下评测 GPT-4o、Claude、Llama 3.1 405B、o1-mini 等模型。

关键结果

GPT-4o（in-context）与 Claude 3.5 Sonnet（RAG）在 long book 上平均排名最高，两者无统计显著差异；除 GPT-4o 外，RAG 普遍优于 in-context

cue 匹配 2 个及以上事件时所有模型性能一致下降（F1 ≤ 0.60）；fine-tuned GPT-4o-mini 在单事件题上 F1=0.83 领先，但多事件题 F1 ≤ 0.37，暴露 naive fine-tuning 只会过拟合单事件

150 道 0 匹配事件问题（测 confabulation）中无模型达到完美 F1：o1-mini 最好，RAG 帮助有限，小模型困难，fine-tuned 模型持续失败；GPT-4o 有 24/150（16%）答错

对涉及 ≥2 个事件的问题：最新状态精确匹配 ≤ 36%，全部事件精确召回 ≤ 18%，时序排序的 Kendall's τ 普遍很低

long book 含 196 个事件、686 道题、约 102,870 tokens；共生成并开源 11 个 benchmark 数据集，另生成 2000 章（1M+ tokens）书籍验证可扩展性

RAG 消融：chapter 粒度分块优于 paragraph 粒度（因单事件常跨多段，paragraph 检索会丢失相关信息）

创新点

区别于 needle-in-a-haystack、长上下文 QA 与 bAbI 类基准，本文首次以认知科学的 episodic memory 视角系统建模与评测 LLM：显式纳入时间/空间上下文与实体状态跟踪，基于 encoding specificity 原理系统变化 cue 特异性并考察 cue overload，加入空答案题测 confabulation；同时用 LLM 生成连贯叙事书籍，实现无污染、ground truth 可控、低人工成本可扩展的合成基准，并统一对比 in-context/RAG/fine-tuning 三种记忆编码方式。
