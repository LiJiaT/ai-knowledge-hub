MemAgent: Reshaping Long-Context LLM with Multi-Conv RL-based Memory Agent

MemAgent：用基于 Multi-Conv RL 的记忆 Agent 重塑长上下文 LLM

简介

论文解决超长文档处理中上下文窗口溢出与长度外推性能衰减的问题：位置编码外推、稀疏/线性注意力、上下文压缩三类现有方案分别受制于 O(n²) 复杂度、需从头训练或改动架构、需额外模块破坏标准生成流程。方法上提出 MemAgent 工作流：将长文档切成约 5000 token 的分段流式输入，模型在固定 8K 窗口内逐步读取分段并覆写一段固定 1024 token 的记忆，最后仅凭问题与记忆作答；记忆只是窗口内的普通 token，不改架构且计算复杂度保持线性。训练上把 DAPO 扩展为 Multi-Conv DAPO，将每次记忆更新视为上下文独立的对话，用规则化的最终答案奖励端到端优化整条记忆读写轨迹。基于 Qwen2.5-7B/14B-Instruct、仅用 60K 长度文档训练，即可外推到 3.5M token 的 QA 任务且性能损失小于 10%，512K NIAH 超过 95%，并优于 Mem0 与多配置 RAG Agent。对团队而言，其分段+固定记忆覆写的推理侧工作流与提示模板可直接借鉴用于长文档/长会话的上下文管理，而 RL 训练部分超出团队不训练模型的边界。

问题

如何让 LLM 在不修改模型架构、保持线性计算成本的前提下处理近乎无限长的文档，且在长度外推时不出现明显性能下降。论文指出已有三条路线各有缺陷：位置编码外推+继续预训练存在性能衰减且因 O(n²) 复杂度处理极长文本速度慢；稀疏/线性注意力通常需从头训练；token 级或外部记忆插件的上下文压缩外推困难、需集成额外模块并破坏标准生成流程与并行化。

方法

MemAgent 将任意长文档视为受控的分段证据流：每步模型只看到下一个 chunk（5000 token）与一段固定长度记忆（1024 token），读完后覆写更新记忆；记忆只是上下文窗口内的普通 token 序列，不改动基础 LLM 的生成过程与位置编码。推理分解为 Context-Processing 模块（用提示模板迭代更新记忆）与 Answer-Generation 模块（仅用问题与记忆生成最终答案）。训练上提出 Multi-Conv DAPO：把单次查询产生的多个上下文独立对话各自作为优化目标，将损失计算从 (group, token) 扩展到 (group, conversation, token) 维度，用基于规则的最终答案奖励端到端优化记忆读写策略；理论上将记忆建模为隐变量，把对上下文的读写操作形式化为 MDP，以 RL 最大化最终奖励。训练采用两阶段课程（先学基础记忆能力，再迁移到多样上下文），基于 verl 框架实现。

关键结果

8K 上下文训练的模型外推到 3.5M token 的 RULER-HQA QA 任务，性能损失小于 10%

512K NIAH 测试准确率超过 95%，512K 处性能损失小于 5%（该评估涉及超过 100 轮对话）

LongBench-QA 上整体优于 DeepSeek-R1-Distill 系列、Qwen2.5-Instruct-1M、QwenLong-L1 等更大的长上下文/推理模型

LongBench-SUM 上 ROUGE-{1,2,L} 几乎全部指标达到 SOTA，说明记忆能力可泛化到摘要任务

与 RAG Agent（多组 topK/chunk 配置）及 Mem0（GPT-5.1 + text-embedding-3-large）对比，MemAgent 表现更优

消融显示无 RL 训练的 MemAgent 在 LongBench-QA 上仅有边际甚至负向提升，RL 训练是获得可泛化、鲁棒记忆能力的关键

记忆长度消融（256~4096）表明 1024 token 记忆 + 5000 token chunk 是合理甜点，性能对记忆长度较鲁棒

探测实验显示关键信息位于 (0%,100%)、(40%,60%) 等五种位置设置下均无灾难性性能下降，支持端到端优化可缓解信息覆写与 lost-in-the-middle 的假设

计算复杂度从 baseline 的 O(n²) 降为 O(n)（8K~4M 的 FLOP 估算）

创新点

区别于三条已有路线：不依赖位置编码外推或继续预训练、不需要稀疏/线性注意力等架构改动、也不依赖外部记忆模块或检索数据库；MemAgent 通过标准 RL 框架的后训练让 LLM 自身习得记忆能力，记忆是固定长度的普通 token 序列，覆写策略带来线性复杂度与免架构改动。训练方法上提出 Multi-Conv DAPO，把单查询产生的多个上下文独立对话各自作为优化目标，区别于既有工作对 workflow 轨迹的简单拼接或滑动窗口处理；论文还从自回归分解角度将记忆建模为隐变量，论证 RL 形式与长文本建模的内在统一。
