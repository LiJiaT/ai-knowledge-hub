Agent Q-Mix: Selecting the Right Action for LLM Multi-Agent Systems through Reinforcement Learning

Agent Q-Mix：通过强化学习为 LLM 多智能体系统选择正确的动作

简介

LLM 多智能体系统中，Agent 间的通信拓扑直接决定任务性能、token 开销与鲁棒性，但现有方法要么使用固定拓扑，要么依赖集中式生成器一次性产出整图，Agent 在执行时无法自主决策。Agent Q-Mix 将拓扑选择重构为合作式 MARL 问题：每个 Agent 每轮从 6 个离散通信动作（独立处理、广播、定向查询、聚合、验证、辩论）中选择，联合诱导逐轮通信图，用拓扑感知 GNN、GRU 记忆与 QMIX 单调混合网络在 CTDE 范式下训练，奖励同时权衡准确率与 token 成本。在 GPT-OSS:120B 上七个基准平均准确率 72.73%，超过最强自适应拓扑基线 GTD 12.36 分；MMLU-Pro 上 token 用量比其他多 Agent 方法低 4-24 倍；注入对抗 Agent 后准确率仅降 2.86 分。每域仅需 15 个训练样本、单 CPU 30-60 分钟即可训练出可泛化的拓扑策略。对团队而言，这是多 Agent 编排从手工固定流程走向按任务难度自适应的代表性方法。

问题

在 LLM 多智能体系统中，通信拓扑（哪些 Agent 之间交换信息）是决定任务性能、token 效率与鲁棒性的关键因素。静态拓扑（链、星、全连接）无法适应任务难度：简单问题浪费 token，困难问题协作不足。现有自适应方法（G-Designer、TopoDIM、GTD 等）依赖集中式拓扑生成器一次性生成整图，Agent 在执行时不能独立做通信决策，形成集中式瓶颈，且缺乏将联合拓扑目标分解为各 Agent 贡献的机制。论文要解决的是：如何让每个 Agent 在执行过程中去中心化地自主选择通信行为，学到兼顾准确率、token 成本与容错性的通信拓扑。

方法

将通信拓扑学习形式化为 Networked MMDP 上的合作式 MARL 问题并用 QMIX 求解。每个 Agent 每轮从 6 个离散结构动作中选择：solo process、broadcast all、selective query、aggregate refine、execute verify、debate check，联合动作映射为该轮邻接矩阵，拓扑由局部决策组合间接涌现。Agent 网络用 2 层 GNN 编码当前通信图，GRU 维护跨轮时序记忆，MLP 输出各动作 Q 值；QMIX 单调混合网络（超网络生成非负权重）保证 IGM 性质，支持集中训练、去中心化执行。奖励 R = w_acc·acc − w_tok·min(tokens/max_tokens, 1)，显式权衡准确率与 token 成本。训练仅需每域 15 个样本、50 episodes，单 CPU 约 30-60 分钟，主要开销为 LLM API 调用。

关键结果

GPT-OSS:120B 上七个基准平均准确率 72.73%，比最强自适应拓扑基线 GTD（60.37%）高 12.36 分，比最强商业框架基线 AutoGen（68.60%）高 4.13 分

HLE（前 250 道 MCQ，Gemini-3.1-Flash-Lite）准确率 20.8%，超过 Microsoft Agent Framework（19.2%）与 LangGraph（19.2%），且 token 用量显著更低

GPT-OSS:120B 上 LiveCodeBench (v6) 100.00%、HumanEval 97.56%、MMLU-Pro 92.86%；HMMT 2025 达 53.33%（比此前最好方法高 10.00 分）、Beyond-AIME 42.00%（GTD 35.00%、AutoGen 37.00%）

对抗 Agent 注入下（MMLU-Pro），准确率仅从 92.86% 降至 90.00%（-2.86），优于 LLM-Debate（-8.57）、GPTSwarm 与 AutoGen（-10.00）；学到的策略会显著削减对抗 Agent 的出边

token 效率：MMLU-Pro 用 112K tokens，仅比单 Agent Lobster 基线（97K）高 15%，比其他多 Agent 方法（471K-2.71M）低 4-24 倍；Beyond-AIME 用 708K vs 基线 1.00M-2.68M

样本效率：每域仅 15 个训练样本即达 95.73% 聚合准确率，接近 50-100 样本的水平（96.95-97.56%）；训练每域约 30-60 分钟（单 CPU）

消融：Agent 数从 1 到 4，Beyond-AIME 从 18.00% 升至 38.00%，10 个 Agent 时 41.00% 饱和；通信轮数 T=3 时 96.95% vs T=1 时 84.28%；数学任务学到的策略偏好 broadcast all，简单代码任务偏好 solo process

创新点

与 G-Designer、TopoDIM、GTD 等依赖集中式生成器一次性产出整图的自适应拓扑方法不同，Agent Q-Mix 把拓扑学习建模为每个 Agent 的局部离散通信动作选择，通过 QMIX 值分解（单调混合保证 IGM）实现去中心化执行，拓扑在多轮执行中逐轮涌现而非预先确定，且奖励显式纳入 token 成本。相比 MARL 中已有的可微消息传递与注意力通信研究，本文关注通信结构本身如何由局部决策形成，而非信息如何传输。
