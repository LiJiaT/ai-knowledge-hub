Hierarchical Alignment: Enforcing Hierarchical Instruction-Following in LLMs through Logical Consistency

层级对齐：通过逻辑一致性在 LLM 中强制层级化指令遵循

简介

LLM 应用常在同一上下文窗口中同时接收来自 system 提示、用户请求、工具输出与检索文档的多源指令，既有 instruction hierarchy 研究多聚焦对抗攻击，忽视了良性但常见的指令冲突。论文提出神经符号框架 NSHA：推理时将上下文原子化为带权限等级的原子指令，用 NLI/GPT-5-mini 检测语义冲突，再以 Z3 MaxSMT 求解器求出最大一致且层级合规的可用指令集来重构提示并引导生成；训练时用求解器自动构造 43,380 条偏好数据，经 SFT/DPO/HCAL 把层级决策蒸馏进模型参数。在 IHEval 的规则遵循、任务执行、工具调用与安全四类评测中，NSHA 显著提升冲突场景表现（如 Qwen3-4B-it 语言检测从 4.5 恢复到 70.7），并揭示多轮持续冲突下的 hierarchy drift：仅靠强化 system prompt 无法保证层级一致性。

问题

LLM 在生产应用中同时接收来自 system、user、assistant、tool 输出与检索文档等多来源、不同权限等级的指令，指令间存在良性但常见的部分或隐式冲突（如 system 要求 JSON 输出而用户要求纯文本）。现有 instruction hierarchy 研究主要针对 prompt injection、prompt extraction 等对抗场景，缺乏在遵循指令优先级的同时保持任务效用与行为一致性的方法，且强指令微调模型在冲突下仍频繁违反层级优先级。

方法

提出神经符号框架 NSHA，含两条路线：(1) 推理时 solver-guided reasoning：用轻量规则解析器将多角色上下文原子化为带权限等级（system=0、user=1、tool/document=2）的原子指令；用交叉编码器 NLI 或 GPT-5-mini 对指令两两判定 Entailment/Neutral/Contradiction 构建冲突矩阵；将冲突硬约束与按权限等级加权的 lexicographic 目标编码为 MaxSMT 优化问题，用 Z3 求解器求出最大一致且层级合规的可用指令子集，据此重构 refined prompt（含对被否决指令的显式拒绝说明）引导生成。(2) 训练时蒸馏：基于 Alpaca 用 GPT-5-mini 合成对齐/冲突上下文并经冲突扫描验证，构造 43,380 条偏好对，提出层级一致对齐损失 HCAL（长度归一化偏好排序损失 + semantic loss + 可选 KL 正则），得到 NSHA-SFT、NSHA-DPO、NSHA-HCAL 三个变体，使模型推理时无需外部求解器。

关键结果

Rule Following：Qwen3-4B-it 在多轮/单轮冲突下降至 26.6/33.5，Llama3.1-8B 降至 20.3/13.8；NSHA-DPO 将冲突分数提升至 36.6/47.6（Qwen）与 38.7/41.9（Llama），取得最佳平均分 72.6 与 64.2

Task Execution：语言检测在冲突下 Qwen3-4B-it 从 95.8 跌至 4.5、Llama3.1-8B 从 100.0 跌至 0.6；NSHA-DPO 分别恢复至 70.7 与 15.2；翻译任务上 NSHA-SFT 与 NSHA-DPO 取得最佳 Qwen 成绩 25.7 与 23.9

Tool Use：神经符号推理（NS）在 Qwen3-4B-it 上将 Get Webpage 冲突从 1.9 提升至 36.2、Slack User 冲突从 1.0 提升至 77.0；CoT 在 Qwen 上达 39.8/80.0 但无法迁移到 Llama3.1-8B；NSHA-HCAL 在 Llama 上工具调用最佳

Safety：Qwen3-4B-it 的 prompt extraction 准确率从参考设置约 96 跌至冲突下低于 26；NSHA-SFT 恢复至 59.6（extraction 冲突）与 45.0（hijack 冲突）但参考分降至 69.2/65.7；Llama3.1-8B 上 NSHA-DPO 保持参考分 94.7/92.7 并取得最佳 hijack 冲突分 30.6；最佳平均安全分 Qwen 59.9、Llama 66.9

多轮鲁棒性：Default 提示下多数基线与 CoT 变体在 2-Turn 设置准确率低于 0.15，NSHA-DPO 在所有设置中取得最高准确率；语言检测鲁棒性实验中 NSHA-DPO 在用户指令占优时仍达 0.84

冲突检测模块对比：GPT-5-Mini 精度 90.7%、准确率 89.5%，优于 NLI-Deberta-v3-Base（精度 80.5%、准确率 87.5%、召回 99.0%）

训练数据规模：共 43,380 条样本，其中 30,594 条冲突样本、12,786 条对齐样本

创新点

区别于以往 instruction hierarchy 工作聚焦对抗攻击（prompt injection/jailbreak）并以防御成功率衡量，本文面向良性日常指令冲突，将层级指令解析形式化为约束满足问题：用神经符号方法（NLI 冲突检测 + Z3 MaxSMT 求解）实现可验证的层级合规，且权限顺序不作为硬逻辑约束而是在优化层执行，以最大化保留非冲突信息；进一步通过求解器自动构造监督数据把层级推理蒸馏进模型参数，摆脱推理时对外部求解器的依赖。同时强调冲突下保持任务效用，而非仅安全防御。
