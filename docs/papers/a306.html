The Attack and Defense Landscape of Agentic AI: A Comprehensive Survey

简介

这篇 SoK 综述首次从整体系统视角系统化梳理了 AI Agent 的安全攻击面与防御体系。作者将 Agent 定义为 LLM 与传统软件组件混合的系统，提出七个设计灵活性维度（输入信任、工作流、访问敏感性、动作、工具、记忆、用户界面），并归纳出六类攻击向量（V1-V6，含间接/直接 prompt injection、工具投毒、记忆投毒等）与七类安全风险（R1-R7）。防御侧按纵深防御原则将 60 种防御方法组织为 Runtime Protection、Secure by Design、Identity and Access Management、Component Hardening 四大类，并提出 Contextual Security 这一新安全目标。对 Codex、Gemini CLI、OpenHands、Browser-use 等六个开源 Agent 及 AutoGPT 五个 CVE 的案例分析表明：现有防御多为部分覆盖，补丁只治下游后果而不治 prompt injection 上游根源。对团队而言，这是构建生产级 Agent 系统时的安全设计手册与上线检查清单。

问题

现有 Agent 安全研究大多聚焦单一攻击向量（主要是 prompt injection）或个别组件，缺乏将 Agent 视为 LLM 与传统软件混合系统的整体安全视角；论文旨在建立首个系统化框架，刻画 Agent 设计空间、攻击向量与风险分类、防御机制全景，并通过真实开源 Agent 案例指出当前防御的缺口与开放挑战。

方法

系统性文献综述（SoK）：参照 OWASP Top 10 for LLM Applications 与 MITRE ATLAS 设计四维检索关键词，系统回顾 2023 年至 2025 年 10 月的 128 篇文献；将 Agent 建模为 LLM、Memory、Tools、外部环境四类组件与 planner/actor 结构，提出七个设计灵活性维度并映射到安全风险；按 CIA 三元组加 Contextual Security 定义安全目标；以纵深防御原则把防御组织为 Runtime Protection（输入/输出 guardrail、IFC 与污点追踪、监控、人工审批）、Secure by Design（权限分离、形式化验证）、Identity and Access Management（身份、访问控制、凭证管理）、Component Hardening（模型与工具/MCP 加固）四大类并逐一分析设计维度与开放挑战；最后对六个开源 Agent 与 AutoGPT 的五个 CVE 做防御覆盖案例研究。

关键结果

文献综述共纳入 128 篇论文，其中 51 种攻击方法、60 种防御方法（2023 年至 2025 年 10 月）

提出 6 类攻击向量（V1-V6）与 7 类安全风险（R1-R7）的分类体系，并给出设计维度到风险的映射关系

案例研究覆盖 6 个开源 Agent（Codex、Gemini CLI、OpenHands、Browser-use、Nanobrowser、Skyvern）及 AutoGPT 自 2023 年以来的 5 个 CVE

AutoGPT 案例结论：所有已部署补丁均只针对下游后果（访问控制与输出清洗），间接 prompt injection（R2）与不安全数据流（R3）的上游根源仍未解决

创新点

区别于已有聚焦模型层威胁、单一攻击向量、特定 Agent 类型或单组件的综述，本文首次提供覆盖所有 Agent 组件及其交互的统一风险分类，并将模型层与系统层防御整合进统一的纵深防御框架；同时提出七维设计灵活性-安全权衡分析与 Contextual Security 新安全目标，并用真实开源 Agent 的防御覆盖矩阵与 CVE 分析提供可操作指引。
