Does Structured Intent Representation Generalize? A Cross-Language, Cross-Model Empirical Study of 5W3H Prompting

结构化意图表示能否泛化？5W3H 提示的跨语言、跨模型实证研究

简介

论文针对非结构化自然语言提示造成的 intent transmission loss（用户意图与模型产出之间的落差）问题，验证其先前提出的 PPS（Prompt Protocol Specification，基于 5W3H 的结构化意图框架）能否跨语言、跨模型泛化。实验覆盖 2,160 条模型输出（3 语言 × 4 条件 × 3 个 LLM × 60 任务），四个条件分别为简单提示、raw JSON 直传、PPS 自然语言渲染与 AI 辅助扩写，评测采用 LLM-as-Judge 并引入跨模型标准差作为协议级一致性指标。关键结论有三：AI 辅助扩写（Condition D）与专家人工撰写 5W3H（Condition C）在 goal alignment 上三语言均无显著差异，用户只需一句话输入；raw JSON 直传显著更差，渲染层必不可少；非结构化基线存在综合分虚高、跨模型方差虚低的双重膨胀偏差，作为评测基线不可靠。

问题

非结构化自然语言提示存在 intent transmission loss：用户意图与模型产出之间存在落差，表现为输出质量不可预测、跨会话不一致、高度依赖用户的提示工程技能。本文在先前中文单语言研究基础上追问三个问题：PPS 5W3H 结构化意图表示的效果能否跨语言（中/英/日）泛化；AI 辅助扩写能否在消除专家门槛的同时达到人工结构化的质量；结构化表示能否降低跨模型输出方差（作为协议级可靠性指标）。

方法

PPS 将用户意图组织为 5W3H 八个维度（What 任务与 KPI、Why 目标与约束、Who 角色与受众、When 时机、Where 上下文与平台、How-to-do 方法与步骤、How-much 量化要求、How-feel 语气与风格）。设计四个实验条件：A 简单提示基线（temperature=0.7）、B raw JSON 直传、C PPS 渲染为带标签的自然语言、D 用户一句话经 DeepSeek-V3 驱动的 AI 创作接口自动扩写为完整 5W3H（temperature=0）。60 个任务覆盖旅行/商务/技术三域并翻译适配为中英日三语。评测采用 LLM-as-Judge 五维综合分（task_completion、structure、specificity、constraint_adherence、overall_quality）+ 独立的 goal alignment 意图对齐分 + 跨模型标准差 σ；统计检验使用 Mann-Whitney U、Kruskal-Wallis H 与 Cohen's d。

关键结果

AI 扩写（Condition D）与人工撰写（Condition C）在 goal alignment 上三语言均无统计显著差异（中文 p=0.812、英文 p=0.633、日文 p>0.05），用户仅需一句话输入

C 与 D 在 goal alignment 上显著优于 raw JSON（Condition B），三语言均 p<0.001，多数比较 Cohen's d>1.0，证明渲染层必不可少

非结构化 Condition A 在三语言中综合分最高，但存在双重膨胀：constraint_adherence 因无显式约束而无法扣分造成天花板效应；中/日文中 A 最低的跨模型综合分 σ 是无约束生成收敛的伪一致性（如中文 A 的 σ_GA=0.655 远高于 σ_composite=0.160）

跨模型方差在条件间差异显著（Kruskal-Wallis）：中文 H=104.689（p<0.001）、英文 H=8.545（p=0.036）、日文 H=67.771（p<0.001）

中文 C 在 GA 上优于 A（4.606 vs 4.344, p=0.013）；英文出现 composite-GA 分离：C 的 GA=4.228 但综合分仅 2.899，且 D 综合分（3.482）显著高于 C（p<0.001）而 GA 无差异

真实部署单例：化学研究者一句话经 AI 扩写为 PPS 指令提交 MANUS Agent，一次性产出 14 页研发方案；第二轮 Agent 自发复用 PPS Instruction ID（acf1387681f4）实现跨会话溯源

创新点

与 CoT 等优化'AI 如何推理'的提示技术不同，PPS 结构化'用户如何表达意图'，两者正交互补；相比 ICIO、CO-STAR 等非正式框架，PPS 提供机器可读格式、SHA-256 完整性校验、跨会话可追溯的持久 Instruction ID 及渲染层。据作者所述，此前没有工作系统评估结构化意图表示框架的跨语言泛化性与跨模型方差降低效果；本文还引入 goal alignment 用户中心评测维度与跨模型标准差指标，并首次系统揭示非结构化基线的双重膨胀偏差对评测有效性的影响。
