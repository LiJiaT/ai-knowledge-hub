Contrastive Decoding Improves Reasoning in Large Language Models

对比解码（Contrastive Decoding）提升大型语言模型的推理能力

mediumarXiv思维链与推理成本与效率可靠性与安全基于arXiv版本
下载原文 PDF

简介

该论文验证了 training-free 的解码方法 Contrastive Decoding（CD）能在推理任务上大幅超越 greedy decoding。CD 让一个强 expert 模型与一个弱 amateur 模型同时打分，搜索最大化两者似然加权差的输出序列；作者将其简化为 logit 空间的三行 PyTorch 实现，仅引入 α 掩码与 β 惩罚两个超参，实验中以 untuned LLaMA-65B 为 expert、1.5B LLaMA 架构模型为 amateur，配合 8-shot CoT 提示。关键结论：GSM8K 上 LLaMA 系列最高提升 8 个绝对百分点，65B 模型达 57.7，超过 LLaMA-2、GPT-3.5 与 PaLM-540B；HellaSwag 上达 88.0，超过除 GPT-4 外的所有已有模型；总 FLOP 开销仅增加约 3.25%，远低于 self-consistency。机制分析显示 CD 减少了对 prompt 的表面复制与推理步骤缺失，但会带来更多算术错误，且在事实回忆任务上略有损害、必须配合 CoT 提示才有效。

问题

LLM 在不同任务上采用割裂的解码策略：开放生成用截断采样、推理任务用 greedy decoding，这种二分法不理想（例如开放生成中更容易出现推理错误）；同时 greedy 解码在思维链推理中会出现抽象推理错误、复制输入片段等失败模式。论文要验证 Contrastive Decoding 这一无需训练、计算开销小的解码方法能否在推理任务上开箱即用地超越 greedy decoding，从而统一不同任务的生成方法。

方法

Contrastive Decoding：同时运行一个强 expert 模型与一个弱 amateur 模型，在每步解码中搜索最大化两者似然加权差的 token 序列，以规避 expert 分布中不良的共享模式（如过短、通用或复制输入的输出）。论文将原公式简化为直接在 logit 空间线性组合：(1+β)·expert logits − β·amateur logits，并用 α 阈值掩掉 expert 认为低概率的 token，实现仅需三行 PyTorch 代码。实验设置：untuned LLaMA-65B 作 expert、同数据训练的 1.5B LLaMA 架构模型作 amateur，默认 α=0.1、β=0.5，8-shot chain-of-thought 提示；CD 还可与温度采样结合生成多条推理链用于 self-consistency（取多数答案）。

关键结果

GSM8K 上 CD 使 LLaMA 系列模型最高提升 8 个绝对百分点；LLaMA-65B 在 β=0.25 时达 57.7，超过 PaLM-540B（56.5）、LLaMA-2（56.8）与 GPT-3.5（57.1）

HellaSwag 上用 CD 目标做答案排序使 LLaMA-65B 达 88.0，超过 LLaMA-2（85.3）、GPT-3.5（85.5）与 PaLM 2-Large（86.8），仅次于 GPT-4

以 1.5B amateur + 65.2B expert 计，CD 仅增加约 3.25% 总 FLOPs，显著低于需要多次完整生成循环的 self-consistency，且达到相近或更好性能

对 100 道 GSM8K 题的人工错误分析：CD 相比 greedy 产生更多算术错误，但语义误解与缺失步骤更少；对 26,000 条生成样本的分析显示 CD 系统性降低对 prompt 的 token 级复制

消融：仅 α-masking 无显著收益，对比目标才是主要收益来源；去掉 CoT 提示后 CD 不再有一致提升；CD 在 FLAN-T5-XXL（11B expert + 80M amateur）上同样有效

负面结果：CD 在 OpenBookQA/TriviaQA 等事实回忆任务上轻微降低性能；在 CommonsenseQA/StrategyQA 上损害较小模型的表现；在 MATH 数据集上无帮助

创新点

相对 Li et al. (2022) 最初为开放式长文本生成质量提出的 Contrastive Decoding，本文的差异在于：首次将其系统应用于标准推理基准并证明可超越 greedy decoding；引入更可解释的 β 超参重构（logit 空间线性组合，形式上对应 DExperts 的特例）；系统消融不同 amateur 类型（发现 1.5B 小模型优于 7B、部分训练 checkpoint 优于完全训练模型、'负提示'不如小 amateur）；并仔细分析 CD 与 chain-of-thought 提示、self-consistency 的组合及 FLOP 效率。作者称其为首个在推理与文本生成两类任务上均达到 SOTA 的生成算法。
