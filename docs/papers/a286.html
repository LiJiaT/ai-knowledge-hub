Competition and Cooperation of LLM Agents in Games

博弈中 LLM Agent 的竞争与合作

下载原文 PDF

简介

论文研究 LLM Agent 在两类经典博弈——网络资源分配（Kelly 机制）与 Cournot 竞争——中是否会收敛到 Nash 均衡、其策略行为能否被刻画。方法上，作者用 Gemini Pro 驱动部署在隔离会话中的多个 Agent，由中心协调器组织多轮同步博弈并反馈市场状态，系统对比短视、多轮与协作式三种系统提示，并从 Chain-of-Thought 逆向拟合出带协作权重 θ 与稳定性权重 γ 的合成收益函数及离散时间更新方程。关键结论之一：在多轮目标与非零和框架的提示下，Agent 倾向于合作而非走向 Nash 均衡，收益逐步逼近 Pareto 前沿与社会最优，CoT 分析显示公平感推理是核心驱动。关键结论之二：θ 随相互让步逐步建立、对手偏离时骤降、终局衰减为 0；当只可见聚合行动时协作失稳，估值不对称过大时出现合作—自私的突然相变。

问题

LLM Agent 在竞争性多智能体环境中是否收敛到均衡、其策略行为如何刻画；特别是在既非完全合作也非零和的重复博弈中，提示与上下文如何决定 Agent 走向自私（Nash 均衡）还是隐式合作（社会最优/Pareto 前沿）。

方法

在 Kelly 机制资源分配博弈与线性 Cournot 博弈两个环境中，用 Gemini Pro 驱动 N 个部署在隔离独立会话中的 LLM Agent（防止上下文泄漏），由中心环境协调器组织 T 轮同步行动并反馈聚合市场状态。通过三组系统提示操纵行为：短视提示（单轮最大化）、多轮提示（累计净收益）与协作式提示（多轮目标+非零和框架+嵌入'Key Insight'式数学洞察与 Theory of Mind scaffolding）。随后对 Agent 的 Chain-of-Thought 做逆向工程，构造含自身收益、他人收益估计（启发式镜像，假设 b_j ≈ b_i）与行动距离惩罚的合成收益函数，参数 θ（协作/社会福利权重）与 γ（稳定性/公平权重）随可观测性指标 I、剩余轮数 τ/T、对手偏离 E(t)、平价成本 Δπ 等信号按拟合的方程动态演化。

关键结果

协作式提示下，2-Agent 资源分配博弈中三次顺序实验的 Agent 按比例降低出价并最终收敛到社会福利最大化解（落在 Pareto 前沿上），而 Nash 均衡位于远离 Pareto 前沿的低效内部（论文引用先前结果：自私价格预期行为效率至多损失到社会最优的 3/4）

CoT 案例：Agent 1 将出价降至 0.1 后，尽管资源份额变小，单轮净收益从 Round 1 僵持时的 0.50 升至 0.566，并推算若对手跟进到 0.1 双方各得 0.90，因而选择'Hold the Line'而非报复

对称 Cournot 博弈（b=15）中提取的协作权重 θ 通过相互让步逐步升至 1.0（社会最优）；Round 9 对手轻微偏离到 4.5 后 θ 降为 0.6，最后一轮 Agent 执行精确最优反应（5.25），θ=0、γ=0

当只提供行动总和（数学上的充分统计量）时，Agent 无法内化、行为失稳且不再逼近 Pareto 前沿；估值不对称 Δb 增大时实验中出现合作与自私行为之间的突然相变（phase change）

线性 Cournot 中自私价格预期行为在最坏情形导致至少 33% 的聚合剩余效率损失（论文引用先前文献作为实验动机）

创新点

不同于以往零散报告 LLM Agent 市场行为（有的收敛到高于竞争均衡的价格、有的行为近似随机）的工作，本文不止于观察'是否合作'，而是从 CoT 逆向工程出一个可解释的合成收益函数（θ/γ 参数化）与离散时间状态空间更新方程，把 LLM 的推理动态映射为可分析的参数演化，从而统一解释信任建立、终局背叛、可观测性依赖与不对称相变等现象，并提供了一个可推广到更多博弈与工程场景的分析框架。
