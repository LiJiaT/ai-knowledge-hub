LensVLM: Selective Context Expansion for Compressed Visual Representation of Text

LensVLM：面向文本压缩视觉表示的选择性上下文扩展

简介

论文研究如何用 VLM 把长文本渲染成图像来压缩上下文 token，并解决压缩加深后字符低于视觉编码器有效分辨率、准确率骤降且信息不可恢复的问题。方法是 LensVLM：模型先扫描压缩图像做全局定位，再通过可学习的 Expand 工具按需把相关图像恢复为未压缩文本或高分辨率图像；训练上用基于 ground-truth 证据合成的工具使用轨迹做 SFT + DAPO RL，同时给出无需训练、纯提示即可用的推理框架。关键结论：在七个文本 QA 基准上，4.3× 有效压缩率下保持接近全文上限的准确率、最高 10.1× 下优于检索与压缩基线，KV cache 减少 78-84%（代价是约 2× 延迟）；分析证明瓶颈是信息获取而非推理（无工具的 CoT 无增益），工具返回原文优于 OCR 与图像放大。对团队而言，这是上下文压缩与工具化上下文管理方向的高价值参考。

问题

VLM 可将文本渲染为图像，用远少于文本 token 的视觉 token 表示长上下文，且压缩率可通过渲染分辨率连续调节、无需改 tokenizer 或重训模型；但随压缩增大，字符缩小到视觉编码器有效分辨率以下而不可辨认，准确率迅速下降。现有视觉压缩方法让模型从固定压缩视图作答，准确率受限于该压缩率下仍可读的内容，丢失的信息无法恢复。论文要解决的是：如何在保持高压缩率的同时，让模型能按需恢复压缩造成的精度损失。

方法

提出 LensVLM 推理框架与后训练配方：文本经确定性渲染器（PIL，可配置字体/宽度/行距）转为压缩图像输入 VLM；模型在多轮轨迹中交替推理与调用 Expand(k) 工具，把选中图像恢复为未压缩形式（源文本/OCR 文本/高分辨率图像），每轮展开一张、基于已展开内容顺序选择。训练流程：按 base 模型能否直接作答划分 easy/hard 样本，用 Qwen3.5-397B 基于 ground-truth 证据合成多轮工具使用轨迹，先 SFT（仅 hard 子集，冻结视觉编码器与 projector）再用 DAPO 做 RL（答案正确性 + 答案门控的工具使用奖励，T=6 轮上限）。另提出 ECR（有效压缩率）指标公平比较各方法 reader 实际处理的 token 量，并系统分析检索 vs 压缩两种范式的适用条件。

关键结果

七个文本 QA 基准上，LensVLM 在 4.3× 有效压缩率（ECR）下保持与全文上限相当的准确率，并在最高 10.1× ECR 下优于检索类、文本与视觉压缩基线

5× 压缩下，直接读压缩图像的基线准确率仅 31.3%（全文上限 72.4%），LensVLM 达 68.9%；SFT 单独将准确率从 31.3% 提到 63.7%，RL 后图像选择准确率达 76.8%/71.0%/52.1%（5×/10×/15×）

训练消除渲染配置敏感性：匹配压缩下三种渲染配置的准确率差距从 18.0 点缩至 0.5 点

效率：20 张输入图像时 KV cache 较 Text 基线减少 78.6%（334 MiB→71 MiB），100 张时减少 84.2%；代价是延迟约 2×（~17s vs ~8s，batch size 1）

无需训练的推理框架：未训练 9B 模型增益 +7.9~+10.2 pp，Sonnet 4.6 增益 +4.8~+9.0 pp

文档理解：15× 压缩下 zoom 工具 41.9% vs 基础模型 31.1%；代码理解零样本迁移：RepoQA 5× 下 63.4%，10×/15× 下超 Glyph +20/+17 pp

工具调用预算：单次 Expand 调用即获得大部分收益（60.8%），第二次 +6.1pp，实际平均每条轨迹仅 1.3 次调用

模型规模消融：可靠的工具使用行为仅在 9B 规模涌现（2B/4B/9B 对比）；在 pre-training cutoff 后构建的无污染数据上增益保持（三档 ICR 平均 +39.7 点）

创新点

与已有视觉-文本压缩方法（Glyph、VIST、VTC-R1、AgentOCR 等）让模型从固定压缩视图作答不同，LensVLM 引入可学习的 Expand 工具，把压缩从单向有损变换变为模型可按需撤销的能力：压缩视图用于全局选择，相关区域在推理时动态恢复为未压缩形式。与检索式方法相比，无需离线索引与先验 top-k 承诺，选择基于多轮演化的上下文在推理时进行；论文还提出 ECR 指标以公平比较不同压缩机制，并给出检索与压缩各自适用条件的系统分析。
