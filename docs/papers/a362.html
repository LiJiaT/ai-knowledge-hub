Agentic-MME: What Agentic Capability Really Brings to Multimodal Intelligence?

Agentic-MME：Agentic 能力究竟为多模态智能带来了什么？

简介

论文指出现有多模态 Agent 评测的三大缺陷：工具集成缺乏统一灵活的框架、Visual Expansion 与 Knowledge Expansion 被割裂测试、只看最终答案而无法验证工具是否被真正调用、正确使用与高效使用。为此作者构建过程可验证基准 Agentic-MME：418 个真实任务覆盖 6 个领域、3 级难度，配备 2000+ 人工逐步 checkpoint 与参考轨迹，并提供统一执行 harness，同时支持沙箱代码执行（Gen）与结构化 function-calling（Atm）两种工具接口，沿 S 轴（搜索策略）与 V 轴（视觉证据）审计中间状态，用 Overthink 指标度量相对人类轨迹的冗余调用。关键结论：最佳模型 Gemini 3 Pro 总体准确率仅 56.3%，Level-3 上远低于人类的 82.3%；结构化 API 普遍优于代码生成；约 50% 错误源于'不愿行动'，且模型普遍存在 overthinking 循环。其过程级评测协议、双接口对比发现与七类错误分类法可直接迁移到团队内部 Agent 的评测体系与工具接口设计中。

问题

现有多模态 Agent 评测存在三大缺陷：(1) 工具集成缺乏灵活性与全面性，缺少让 Agent 在任意视觉工具与搜索工具间自由切换的统一框架；(2) Visual Expansion（主动图像操作）与 Knowledge Expansion（开放网络搜索）被当作独立模块分别测试，二者在深度耦合工作流中的协同未被探索；(3) 评测主要以最终答案正确性为准，无法验证工具是否真的被调用、是否正确使用、是否高效使用，导致感知不足、跳过工具调用、执行错误（如裁剪错区域）与冗余试错等失败模式被混淆。论文要回答的核心问题是：Agentic 能力究竟为多模态智能带来了什么。

方法

构建 process-verified 基准 Agentic-MME：(1) 418 个真实任务、6 领域、35 子类、3 个按交互复杂度划分的难度等级，通过 model-in-the-loop backward drafting 机制设计任务，使主动视觉操作成为解题前提；(2) 每个任务配 2000+ 人工逐步 checkpoint 与参考轨迹，S 轴审计搜索策略（每跳搜索的人工验证关键词、参考 URL、期望中间答案），V 轴拆分为 Vtool（是否在正确步骤发起工具调用）与 Vtrue（中间视觉产物是否真含所需证据），并采用 any-pass 机制；(3) 统一执行 harness 归一化沙箱代码执行（Gen）与 function-calling（Atm）两种异构接口，含 13 种视觉操作与 4 种检索工具（Serper.dev Google 搜索/Lens、Jina Reader 网页抓取、图片下载），对代码型 Agent 用 AST-based tracer 从执行轨迹提取规范视觉操作；(4) Overthink 效率指标 = max(0, C_agent - C_human)/(C_human + 1)；(5) 中间产物用 MLLM-as-a-Judge（gpt-4o-mini）验证，最终答案通过提示层约束输出格式实现确定性正则匹配，并做 step-wise oracle testing 保证任务在正确轨迹下可解。

关键结果

最佳模型 Gemini 3 Pro（Atm）总体准确率 56.3%；摘要报告其在 Level-3 降至 23.0%，正文 Finding 1 报告 Level-3 为 33.3%；人类求解者总体 93.8%、Level-3 为 82.3%

无工具的 Gemini 3 Pro 在 Level-1 为 42.9%、Level-3 为 7.5%；开放全部工具后 Level-3 升至 33.3%，相对提升 4.4×

开源模型在 Level-3 大幅落后：Qwen3 VL-235B 降至 10.1%、Thyme-rl 仅 2.5%；Thyme-rl 与 Deepeyesv2 的 S 轴得分低于 5%，检索规划近乎完全失败

所有模型上 Atm 模式持平或优于 Gen 模式：GPT 5.2 在 Gen 模式 Vtool ≤ 7.6%、V 仅 10.4，切换 Atm 后 Vtool > 70%、V 达 58.1

工具调用积极但产物错误：Thyme-rl（Gen, L1）Vtool=63.3 而 Vtrue 仅 13.0；Qwen3 VL-32B-think（Gen, L1）Vtool=66.4 vs Vtrue=9.7；Qwen3 VL-235B（Atm, L3）两者接近（48.8 vs 48.4）

去除全部图像后准确率接近零（Gemini 3 Flash 2.63%、GPT-5-mini 1.44%），验证无数据泄漏且任务确需视觉证据

Qwen3 VL-235B 在 Level-3：仅加图像工具反而下降（7.41%→6.25%），仅搜索升至 11.11%，两者结合达 19.23%，呈超加性协同

效率：人类参考平均每任务 2.15 次调用；GPT-5-mini 平均 12.13 次调用但准确率仅 33.5%；DeepeyesV2 OT=0 但准确率仅 22.5%；Gemini 3 Pro 以平衡取得最高 56.3%

错误分析：约 50% 错误为'不愿行动'（默认被动猜测而非主动操作图像）；注入 stepwise guidance 后各模型性能一致提升且强模型受益更大，但 Level-3 仍不饱和，说明逐步验证与自主执行存在差距

创新点

针对已有基准的三大不足提出改进：(1) 将 13 种视觉操作工具与 4 种开放网络检索工具统一到同一 harness，并专门设计测试二者协同的 intertwined 任务（已有工作将视觉工具与搜索解耦，或搜索仅占边缘地位）；(2) 以 2000+ 人工逐步 checkpoint 沿 S 轴/V 轴做过程级验证，超越只看最终答案的评测——借鉴 CodeV 的思路但扩展到中间视觉产物的真实性验证；(3) 用严格 artifact 协议与 AST-based tracer 归一化代码执行与 function-calling 两种异构接口，使跨实现公平对比成为可能；(4) 提出相对人类最小参考轨迹的 Overthink 冗余调用惩罚指标，并给出七类失败模式的错误分类法。
