Enhancing Zero-Shot Chain-of-Thought Reasoning in Large Language Models through Logic

通过逻辑增强大语言模型（LLM）的 Zero-Shot Chain-of-Thought 推理

简介

LLM 在多步推理中常因推理过程不受逻辑原则约束而产生幻觉，自回归生成使某一步的错误沿推理链传播，导致最终结论不可信；现有 zero-shot-CoT 只鼓励逐步思考，缺乏对每步忠实性的监督。论文提出 LoT（Logical Thoughts）提示框架：先用 zero-shot-CoT 生成带编号的推理链，再进入 think-verify-revise 循环——依据符号逻辑的 Reductio ad Absurdum 原则，为每个推理步骤及其否定各生成 post hoc 解释，让模型在两个对立观点中做偏好判别，未通过验证的步骤被修正并重新生成后续链条。在算术、常识、符号、因果推断等多领域 zero-shot 实验中，LoT 普遍提升 CoT 准确率，模型越大（>7B，如 GPT-4）收益越明显，且修正后推理链更短。对团队而言，这是一种无需训练、可直接叠加在现有 CoT 流程上的逐步验证提示模式，可用于提升代码审查、测试推理等场景的产出可靠性。

问题

LLM 在需要多步推理的场景中推理能力不足：推理过程不受逻辑原则约束，常以自信口吻产生幻觉；由于自回归生成，某一步 T_i 的错误会传播并影响后续所有步骤，使最终结论不可信。现有 zero-shot-CoT 只鼓励模型给出具体的推理步骤，但缺乏对每步推理忠实性的监督与验证机制。

方法

提出 LoT（Logical Thoughts）全自动 zero-shot 提示框架：先用 zero-shot-CoT（'Let's think step by step.' 配合 '# NUM.' 编号格式，便于正则切分为原子步骤）生成初始推理链，随后进入 think-verify-revise 循环：对每一步 T_i，依据 Reductio ad Absurdum 检验'前提+已验证步骤是否蕴含 T_i'。核心做法（Adpt-LoT）是为 T_i 与其否定 ¬T_i 分别生成 post hoc 解释 E_i 与 E_¬i，让 LLM 在两个对立 review 之间做偏好判别（转化为偏好判别任务）；若采纳 ¬T_i，则以 E_¬i 作为'为什么错'的具体反馈修正该步，并基于已验证前缀重新生成后续链条，直到最终结论通过验证。另设简化变体 Cmps-LoT（仅组合 ¬T_i 的解释并检查矛盾）。链条只在必要时增长，避免对无争议步骤的重复生成。全程零样本、无需训练、任务无关。

创新点

与 Self-Consistency 等 N 次采样集成方法相比，LoT 不做盲目多数投票，而是有引导地只验证、修正可疑步骤，链条仅在必要时增长，避免集成的额外成本与低效；与 Self-Check（仅提示'再检查一遍'）和直接组合式验证（Cmps-LoT）相比，LoT 将 LLM 自检难题转化为'在两个对立 post hoc 解释间做偏好判别'，利用模型'被提示认为某陈述为假时会努力找错'的强制性行为提升错误检出率；与需要符号化的神经符号方法不同，LoT 只借用 Reductio ad Absurdum 等逻辑原则组织提示，无需将问题转成符号表达式，保持 zero-shot 与任务无关。
