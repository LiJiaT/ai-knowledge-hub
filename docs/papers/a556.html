An Empirical Evaluation of Prompting Strategies for Large Language Models in Zero-Shot Clinical Natural Language Processing

面向零样本临床自然语言处理的大语言模型提示策略实证评估

简介

该论文研究在标注数据稀缺的临床场景下，如何通过提示工程让 LLM 在零样本条件下完成临床 NLP 任务。作者在 GPT-3.5、BARD、LLAMA2 三个模型上，对五个临床 NLP 任务（词义消歧、证据抽取、共指消解、用药状态与属性抽取）系统评估了 prefix、cloze、CoT、anticipatory 等提示类型，并提出 heuristic（规则式）与 ensemble（多数投票）两类新提示，同时对比 zero-shot 与 2-shot。关键结论：提示需按任务类型定制，分类类任务适合 heuristic/prefix，抽取与共指消解适合 CoT；GPT-3.5 综合最强，多任务准确率达 0.94-0.96；few-shot 在多数任务上有提升但并非总优于好的零样本提示；ensemble 未在任何任务上成为最优。论文还给出按任务类型选择提示与模型的工程指南，并指出输出随机性与潜在数据污染对可靠性评估的影响。

问题

临床 NLP 面临标注数据稀缺、昂贵、分散于不同机构且受数据使用协议限制的困境，而现有提示工程研究多针对通用或生物医学 NLP，缺乏对不同提示类型在真实临床任务上相对有效性的系统比较。论文要解决的问题是：如何为临床 NLP 任务系统地设计、选择与评估提示，使 LLM 在零样本/少样本条件下无需微调即可完成信息抽取类任务，并形成可复用的提示选择指南。

方法

在五个临床 NLP 任务（临床词义消歧-文本分类、生物医学证据抽取-NER、共指消解、用药状态抽取-NER+分类、用药属性抽取-NER+RE）上，系统评估 prefix、cloze、CoT、anticipatory 等已有提示类型，并提出两类新提示：heuristic 提示（将规则式 NLP 的领域知识与语言模式编码为预定义规则来引导模型，不同于 CoT 的解释推理）与 ensemble 提示（五种提示的输出经多数投票聚合）。采用'采样-提示设计-部署'三步迭代式提示创建流程，由医疗领域专家参与设计与验证；以 accuracy 为统一指标（用 resolver 将模型输出映射到标签空间），在 GPT-3.5、BARD、LLAMA2 上对比 zero-shot 与 2-shot，并总结按任务类型（分类/抽取/消解）选择提示与模型的四步指南。

关键结果

临床词义消歧：heuristic 与 prefix 提示在所有模型上表现最好，GPT-3.5 准确率达 0.96

生物医学证据抽取：heuristic 与 CoT 提示在零样本下最优，GPT-3.5 准确率 0.94

共指消解：CoT 提示在 GPT-3.5 与 LLAMA2 上最佳，GPT-3.5 准确率 0.94；BARD 用 simple cloze 达 0.81，LLAMA2 用 simple prefix 达 0.8

用药状态抽取：simple prefix 与 heuristic 提示最佳，GPT-3.5 准确率分别为 0.76 与 0.74

用药属性抽取：CoT 与 heuristic 提示有效，GPT-3.5 准确率 0.96；BARD 上 anticipatory 提示最佳

few-shot（2-shot）在除临床词义消歧与用药属性抽取外的所有任务-模型组合上均提升准确率；heuristic 提示在这两个任务上零样本即优于 few-shot

ensemble（多数投票）未在任何任务上成为最优策略：临床词义消歧 GPT-3.5 达 0.9（次优），用药属性抽取 GPT-3.5 达 0.9、BARD 达 0.76；在共指消解等需精确输出的任务上甚至降低准确率

GPT-3.5 在多数任务上整体优于 BARD 与 LLAMA2，但 BARD 与 LLAMA2 在特定任务与提示类型组合上有优势

创新点

据作者所述，这是生成式 AI 时代首批针对临床 NLP 的提示工程系统实证研究之一。区别于已有工作（多用固定模板或仅做综述），本文横向比较了七类提示在多任务、多模型上的表现，首创将规则式 NLP 的领域知识编码为 heuristic 提示，以及用多数投票聚合多提示输出的 ensemble 提示，并产出'任务类型→提示类型→模型'的可操作选择指南，同时系统对比了 zero-shot 与 few-shot 的适用边界。
