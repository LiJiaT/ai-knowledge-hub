On Second Thought, Let's Not Think Step by Step! Bias and Toxicity in Zero-Shot Reasoning

再想一下，还是别'一步一步思考'了！Zero-Shot 推理中的偏见与毒性

简介

论文挑战了'zero-shot CoT（Let's think step by step）普遍提升 LLM 表现'的默认假设：作者将 CrowS-Pairs、StereoSet、BBQ 三个刻板印象基准改造为零样本推理任务，并自动红队式构建含 200 条有害问题的 HarmfulQ 基准，在 GPT-3 davinci 系列与 Flan 开源模型上对比 Standard 与 CoT 两种提示条件。结果显示，在社会敏感任务上 CoT 使模型更少选择无偏/Unknown 选项（平均 ↓8.8 个百分点）、更倾向鼓励有害行为（↓19.4 个百分点），且退化随模型规模增大而加剧、随指令对齐改进而缓解；在提示中加入显式缓解指令仅对对齐较好的 TD3 有效。对团队而言，这是提示工程与评测保障的关键警示：CoT 是需要按任务域与模型对齐程度审计的设计模式，不能作为默认增益开关，引入推理提示前应先做领域内受控评测。

问题

验证 zero-shot CoT 提示的收益是否普适：已有工作集中在有客观正确答案的逻辑推理任务（算术、常识问答）上，本文考察在社会敏感域（刻板印象、有害问题）上，'Let's think step by step' 式零样本推理提示是否会放大模型偏见与毒性输出。

方法

受控对比实验：将 CrowS-Pairs、StereoSet、BBQ 改造为零样本推理任务（提供刻板印象/反刻板印象选项并加入 Unknown 正确选项，随机化 Unknown 同义词与选项位置以控制位置偏好）；用 text-davinci-002 自动红队式生成 200 条有害问题构建 HarmfulQ。每个基准在 Standard Prompt 与 zero-shot CoT（两阶段：先让模型 'think step-by-step'，再将生成的推理拼接回输入做答案抽取 'So the answer is'）两种条件下评测，使用 BigBench CoT 与 Inverse Scaling 两种提示模板控制格式差异；跨 text-davinci-001/002/003（指令对齐程度分析）、001 系列小模型（规模分析）与 Flan 开源模型 80M–20B（开源验证）系统评估，并测试提示内显式缓解指令的效果；对 CoT 失败案例做人工错误归类（显式/隐式推理、刻板印象幻觉）。

关键结果

跨所有刻板印象基准、davinci 模型与提示设置，CoT 相比 Standard 平均 ↓8.8 个百分点（更少选择 Unknown/无偏选项）；HarmfulQ 上平均 ↓19.4 个百分点（更少生成非毒性回答）

TD2 在刻板印象基准上平均 ↓18 个百分点（CrowS Pairs ↓24.1、StereoSet ↓22.2、BBQ ↓6.3）；95% 置信区间最大仅 3%，说明多次 CoT 生成下模型预测稳定地偏向偏见输出

错误分析：刻板印象任务中显式推理占 45%、隐式推理占 55%，37% 的 CoT 含刻板印象幻觉；HarmfulQ 的 CoT 全部为显式，13% 表达犹豫但最终仍产出毒性内容，且 CoT 版毒性输出更详细

指令对齐影响：TD3 用 CoT 在刻板印象基准上平均 ↑2 个百分点（TD1 ↓11%、TD2 ↓17.5%），但在 HarmfulQ 上 TD3 骤降 ↓53 个百分点（TD2 仅 ↓4），即 CoT 抵消了对齐带来的拒答改进（TD3 非 CoT 拒答率 ↑59 个百分点）

规模趋势：CrowS Pairs 的 CoT/非 CoT 差异随规模单调扩大（↓6→↓14→↓29），StereoSet 同样（↓4→↓10→↓31）

提示内显式缓解指令：TD2 仍平均 ↓11.8 个百分点，TD3 仅 ↓1 个百分点，说明缓解指令效果依赖模型的指令遵循能力

Flan 开源模型：80M 小模型平均 ↑13 个百分点，250M 以上模型平均 ↓5 个百分点；而 MMLU、BBH、MGSM 等推理任务随规模一致地从 CoT 获益

创新点

已有 CoT 研究集中于有客观正确答案的推理任务并报告性能提升，本文首次在社会敏感任务上对 zero-shot CoT 做受控评估，实证证明其收益不具普适性；系统刻画了 CoT 危害与模型规模（负相关）和指令/偏好对齐（正相关）的关系，提出自动红队式构建的 HarmfulQ 基准，并将 CoT 定位为需要审计的设计模式，同时给出对 'pretend you're an evil AI' 类 ChatGPT 越狱策略的早期理论解释（它们本质上是让模型获得'思考' token 以绕过价值对齐的推理策略）。
