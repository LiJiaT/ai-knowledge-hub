Larger language models do in-context learning differently

更大的语言模型以不同方式进行 in-context learning

higharXiv提示技术评测基准可靠性与安全基于arXiv版本
下载原文 PDF

简介

论文研究 LLM 的 in-context learning（ICL）究竟依赖预训练形成的语义先验，还是真正从 prompt 中 exemplar 学习 input-label 映射。作者在 GPT-3、InstructGPT、Codex、PaLM、Flan-PaLM 五个模型家族与七个 NLP 分类任务上，设计了翻转标签（flipped-label）与语义无关标签（SUL-ICL）两类对照实验。关键结论：覆盖语义先验、在无语义线索下学习标签映射都是随模型规模涌现的能力——小模型主要依赖语义先验，大模型（如 PaLM-540B、text-davinci-002、code-davinci-002）能真正从示例学习映射，甚至完成高维线性分类；instruction tuning 同时增强两种能力，但更强化语义先验，使模型更不愿跟随翻转标签。对团队的直接启示是：few-shot 示例的真实作用随模型规模与是否 instruction-tuned 而不同，标签命名、示例数量与模板格式的取舍应据此差异化设计。

问题

厘清 LLM 做 in-context learning 的性能来源：是主要利用预训练获得的语义先验（semantic priors），还是真正从 prompt 中给出的 input-label 映射中学习；并考察模型规模与 instruction tuning 如何影响这两种机制的权衡。

方法

设计两类对照实验：flipped-label ICL（按比例翻转 in-context exemplar 的标签，检验模型能否覆盖语义先验）与 SUL-ICL（用 foo/bar 等与任务语义无关的标签替换自然语言标签，迫使模型只能从示例学习映射）；在 GPT-3、InstructGPT、Codex、PaLM、Flan-PaLM 五个家族、七个 NLP 分类任务上系统比较不同规模模型，并扩展到 N 维线性分类、输入词重映射、多种标签类型与 prompt 模板、OOD 数据集等消融实验。

关键结果

text-davinci-002 在 0% 翻转标签时平均准确率 90.3%，100% 翻转时降至 22.5%（远低于随机）；小模型性能基本持平、通常不降至随机以下

Flan-PaLM-8B 在 SUL-ICL 设置下比 PaLM-8B 高 9.6%，几乎追平 PaLM-62B，说明 instruction tuning 增强标签映射学习能力

100% 翻转标签下，标准 PaLM 可低至 31% 准确率，而 Flan-PaLM 各模型均无法低于随机猜测，说明 instruction tuning 更强化语义先验

16 维线性分类：最大 Codex 模型超出随机 19%，小模型超出不超过 9%；Codex 最大模型可做到 N=64 维，小模型约 N=16 即达随机水平，但均不及 SVM baseline

RTE 与 ETHOS 在 SUL-ICL 下随规模涌现：code-davinci-002 达 80%+，而 code-cushman-001 与 code-davinci-001 接近随机；部分数据集仅 PaLM-540B 超过随机

各 prompt 模板在 SUL-ICL 下平均准确率介于 77.9%–87.7%（均值 84.2%，±6.3%），无显著差异

SUL-ICL 下 OOD 数据集鲁棒性随规模涌现：小模型准确率最多下降 36%，text-curie-001 仅降 4%

中等规模模型在 flipped-label 与 SUL-ICL 两种设置下性能差异最高达 74%（text-curie-001 on SST-2）

SST-2 上 Flan-PaLM-8B 比 PaLM-8B 高 28%，甚至比 PaLM-62B 高 2%

创新点

此前工作（如 Min et al. 2022b）显示随机标签几乎不影响 ICL 性能，暗示模型主要依赖语义先验；本文通过跨五个模型家族的规模对比指出该结论仅适用于较小模型，学习 input-label 映射的能力是随规模涌现的；并系统揭示 instruction tuning 对"学习映射"与"强化语义先验"的不对称影响；与需要在微调或 prompt-tuning 中学习的研究（Webson & Pavlick）不同，本文观察的是冻结的预训练模型。
