Skill-Based Few-Shot Selection for In-Context Learning

基于技能的少样本示例选择方法（SKILL-KNN）用于 In-Context Learning

简介

论文解决 in-context learning 中少样本示例选择的问题：基于原始输入 embedding 的检索容易被与任务无关的表层语言特征（如相似实体而非所需操作）误导，而微调 embedding 模型的方法难以适应频繁扩充或变更的示例库。SKILL-KNN 提出 rewrite-then-retrieve 方案：仅用 16 条人工标注的技能描述作为 few-shot demonstration，提示冻结的 gpt-3.5-turbo 把每个输入改写成描述所需任务技能的自然语言，再用现成 embedding 模型（SBERT/OpenAI Ada）对改写结果做 KNN 检索，并以 consistency 与 distinctiveness 两个变体缓解对 demonstration 顺序的敏感性。在 Spider、Dr. Spider、KaggleDBQA、BIRD、COGS 五个语义解析数据集与六个 backbone 模型上，SKILL-KNN 在非 oracle 方法中始终最优，例如 text-chat-davinci-002 在 Spider 上达 78.3% execution accuracy（最佳 raw-input 方法为 74.6%），可比肩甚至超过部分 oracle 方法，且全程无需训练或微调任何模型。

问题

In-context learning 的性能对所选 few-shot 示例高度敏感，而受限于模型上下文长度，prompt 中只能放少量示例。现有基于原始输入 embedding 的示例选择容易被与目标任务无关的表层自然语言特征误导（例如在语义解析任务中只找到实体相似的示例，而非包含所需可执行操作的示例）；基于微调 embedding 模型的方法则需要为每个任务训练并保存模型，难以应用于频繁更新的动态示例库。论文要回答的核心问题是：如何在不训练或微调任何模型的前提下，从大示例库中为每个测试样例选出真正包含所需任务技能（task-specific skills）的示例。

方法

SKILL-KNN 采用 rewrite-then-retrieve 两阶段流程：(1) 提示式改写——人工标注 16 个示例的技能描述（用自然语言而非规则约束，以对齐预训练在自然语言上的现成 embedding 模型），用这些 demonstration 提示冻结的 gpt-3.5-turbo 为示例库中其余示例及每个测试输入生成 skill-based description，从而消除无关表层特征；(2) 技能化检索——将生成的描述喂给现成 embedding 模型（SBERT all-mpnet-base-v2 或 OpenAI Ada）做 KNN 检索，相似度高的示例在 prompt 中更靠近测试输入，k=4。为缓解生成结果对 demonstration 顺序的敏感性，通过打乱顺序为每个输入生成 m=5 个候选描述，并设计两个变体：consistency（取候选描述的中心 embedding，类似 embedding 层面的多数投票，适合零均值白噪声）与 distinctiveness（取候选集间最大相似度/最小距离，适合尖峰噪声）。

关键结果

text-chat-davinci-002 在 Spider 上：SKILL-KNN 达 78.3% execution accuracy，最佳 raw-input-based 方法为 74.6%，oracle 方法 Target-KNN 为 78.6%

在 5 个语义解析数据集 × 6 个 backbone 模型（text-chat-davinci-002、code-davinci-002、text-davinci-003、code-cushman-002、gpt-35-turbo、gpt-4）上，SKILL-KNN 在所有非 oracle 选择方法中始终最佳，有时可比肩甚至超过部分 oracle 方法

与微调式选择方法（EPR、CEIL、TST）相比，SKILL-KNN 表现相当甚至更好（Spider dev，Table 4）

distinctiveness 变体比 consistency 变体赢的次数更多（19 vs 15）；不同 backbone 偏好不同变体（text-chat-davinci-002/code-davinci-002 偏好 distinctiveness，text-davinci-003/code-cushman-002 偏好 consistency）

扰动鲁棒性：text-chat-davinci-002 下 KNN with SBERT 在 Dr. Spider 三类扰动中两类低于 random 基线，而三个版本的 SKILL-KNN 在全部三类扰动上均超过 random 基线

标注 demonstration 从 16 减至 4 仍保持对 raw-input-based selection 的优势；约束操作覆盖或数据库多样性仅带来轻微性能下降

案例研究：100 个生成的技能描述中 86 个完全正确、12 个基本正确但需部分修改、2 个完全错误

Recall@N 评估（Spider dev，text-chat-davinci-002，温度 0.7）：N=10 时召回率超过 90%，top1 为 80.3%，高于 greedy decoding 的 78.3%

创新点

与已有工作相比：(1) 区别于 raw-input-based selection，核心洞察是优化喂入 embedding 模型的输入而非微调模型本身，通过提示 LLM 将输入改写为技能描述来消除表层特征偏差；(2) 区别于 EPR、CEIL、TST 等微调式方法，全程 training-free，适合频繁扩充或变更的示例库；(3) 提出'提示超大模型来辅助 few-shot 选择'的新视角，并针对提示顺序敏感性设计 consistency/distinctiveness 两个变体（分别对应零均值白噪声与尖峰噪声两种噪声模型）。
