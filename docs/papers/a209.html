Achilles Heel of Distributed Multi-Agent Systems

分布式多智能体系统（Distributed Multi-Agent Systems）的阿喀琉斯之踵

简介

论文研究分布式多智能体系统（DMAS）的可信性短板：当异构第三方 Agent 作为服务提供者、经 API 由中央服务器远程管理时，会面临 free riding（供应商偷换更弱模型）、恶意攻击、通信延迟与连接不稳定四类威胁。作者在 AutoGen、CrewAI、AgentVerse、MAD、Reflexion、ChatDev、Camel 七个框架与代码生成、数学/通用推理、创意写作四类任务上系统评测，攻击可导致性能最高下降 80%，free riding 与恶意攻击成功率可达 100%。关键发现：替换承担核心职能的角色（如 coding）危害最大；缺少代码校验时隐私泄露与 DoS 攻击 ASR 达 100%；异常重试机制是断连恢复的关键，重试次数超过最大断连间隔后完成率可恢复至 100%。论文建议未来 DMAS 引入代码校验流程、优化 Agent 间通信频率并完善异常处理，并可将这些攻击策略作为评测多智能体系统的 red-teaming 工具。

问题

现有 LLM 多智能体系统假设所有 agent 本地托管、统一控制，难以扩展规模并灵活集成异构 agent。论文提出分布式多智能体系统（DMAS）设定：异构第三方 agent 作为服务提供者，经预定义 API 接口由中央控制系统远程管理。在此设定下系统控制者失去对 agent 内部运作的直接控制，论文要系统识别并量化 DMAS 固有的四类可信性问题——free riding、恶意攻击、通信低效、连接不稳定——对系统性能与可靠性的影响。

方法

提出 DMAS 框架并设计四类攻击/压力测试：(1) free ride：用 LLaMA-3.1-70B-Instruct、LLaMA-3-8B-Instruct、LLaMA-2-7B-chat-hf 替换 GPT-4o 模拟供应商偷换模型，并系统变化被替换的角色与数量；(2) 恶意攻击：通过修改 agent system prompt 实现噪声注入与 jailbreak（注入 dark characters），并在 agent 响应中注入恶意代码实现隐私泄露与 DoS；(3) 通信延迟：人为设置 agent API 调用延迟模拟高峰时段；(4) 不稳定连接：变化 agent 断连与重连时机（以 API 调用次数量化）。在 7 个框架（AutoGen、Camel、AgentVerse、MAD、Reflexion、ChatDev、CrewAI）与 4 个数据集（HumanEval、MMLU、MATH、Trivia Creative Writing）上评测，指标包括 Pass@1、准确率、攻击成功率（ASR）、任务完成时间与完成率。

关键结果

攻击策略可导致性能下降最高达 80%，free riding 与恶意攻击执行成功率达 100%

Free ride 下 AgentVerse 与 CrewAI 最具韧性（math 任务分别最多下降 40% 与 34%），部分框架某些任务降至 10% 以下，Camel 甚至无法完成整个任务；替换为 LLaMA2-7B 时性能下降超过 60%，而替换为 LLaMA3.1-70B 时下降一般小于 10%

替换核心 coding 角色时 AgentVerse、Reflexion、MAD 分别下降 20%、78%、79%，替换其他角色则基本不变；MAD 仅 free riding moderator 时下降 80%，额外引入其他角色再降 8%；AgentVerse 中替换 solver+critic 与替换 assigner/evaluator 存在 50% 性能差距

噪声注入攻击下 AgentVerse 性能下降 90.52%，MAD 下降 79.36%，其他框架下降 30%–45%

隐私泄露与 DoS 代码执行攻击中 Reflexion 与 AutoGen 在所有场景 ASR 达 100%；jailbreak 攻击 ASR 为 10%–43%（AutoGen 与 Camel 最高 43%，AgentVerse 最低 11%）

通信延迟实验中所有框架任务完成时间随 API 调用延迟线性增长，API 调用频率高的 Camel 与 AgentVerse 斜率更陡、对延迟更敏感

不稳定连接下三个框架性能严重退化，多数情况降至 0%；ChatDev 与 AgentVerse 的最大重试次数超过最大断连间隔后任务完成率达 100%

创新点

已有 MAS 可信性研究均假设集中式（agent 同机托管、用户统一控制），本文首次系统研究分布式 MAS 的可信性，将第三方 agent 作为服务提供者带来的新威胁（如供应商 free riding 偷换模型）纳入分析；与 Huang et al. (2024) 只攻击 debate member 不同，本文还攻击更高层 agent（moderator），发现层级结构 MAS 不一定比线性结构更鲁棒；并将攻击策略定位为评测未来多智能体系统的 red-teaming 工具。
