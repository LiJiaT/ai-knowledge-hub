Exploring Effectiveness of GPT-3 in Grammatical Error Correction: A Study on Performance and Controllability in Prompt-Based Methods

探索 GPT-3 在语法纠错（GEC）中的有效性：基于 Prompt 方法的性能与可控性研究

简介

论文研究 GPT-3 能否仅靠 prompt（zero-shot 与 few-shot）完成语法纠错（GEC）任务，以及能否用自然语言指令控制纠错行为（最小修改 vs 流畅度修改、按学习者水平纠错）。方法上基于 text-davinci-003 API，系统变化任务指令类型（Instructive/Misleading/Irrelevant）、few-shot 示例数量（2~64）与示例集，并用 GLEU/F0.5、编辑距离分布和 Jensen-Shannon 距离做量化评估。关键结论：GPT-3 zero-shot 即超过用约 60 万句对训练的监督 Transformer 与已有无监督方法；指令类型显著影响性能（Instructive 平均 65.54 vs Irrelevant 17.05）；性能随示例数增加而提升但不严格线性（64 个示例最高 69.25）；控制输出行为时示例集的作用大于任务指令措辞。对团队而言，这是一份关于"指令设计 + 示例选择"如何决定 LLM 输出性能与可控性的系统性实证参考，其评测方法可迁移到团队 prompt 资产的回归评测。

问题

GEC 的监督方法依赖大规模标注/伪数据，难以针对不同纠错设置（最小修改、流畅度修改、学习者水平）扩展；而 prompt-based 方法在 GEC 上的应用与可控性此前缺乏系统分析。论文回答两个问题：1) 基于 prompt 的 PLM 能在多大程度上解决 GEC 任务；2) 能否用自然语言 prompt 控制 GEC 的纠错设置。

方法

使用 OpenAI API 的 GPT-3（text-davinci-003）：zero-shot 采用 "{task instruction}: {input text}; output:___" 模板，few-shot 采用 in-context learning 模板（从训练/验证集随机采样示例对）。系统实验包括：1) 三类任务指令（Instructive/Misleading/Irrelevant，各 10 个候选）对性能的影响；2) 示例数量（2~64，受模型最大输入长度限制）的影响；3) 通过指令控制 minimal edits 与 fluency edits，并按 CEFR 学习者水平（A/B/C/N）在指令中加入 Positive/Negative Info 控制纠错强度；4) VIFE（变指令固定示例）与 FIVE（固定指令变示例）对照实验，用 Jensen-Shannon 距离衡量输出编辑分布与示例集的对齐程度。评测基于 JFLEG（GLEU）、CoNLL2014 与 W&I+LOCNESS（F0.5），并与监督 Transformer (big)（约 600K 句对）、无监督方法及 ChatGPT zero-shot + CoT 对比。

关键结果

zero-shot GPT-3 全面超过用约 600K 句对训练的监督 Transformer (big)，在 JFLEG、CoNLL2014、W&I+LOCNESS 上分别领先约 11、5、2 个百分点

GPT-3 在所有测试集上持续超过已有无监督方法，并在三个测试集上均超过 ChatGPT zero-shot + CoT（Fang et al., 2023 报告的结果）

zero-shot 下指令类型影响显著：Instructive 指令平均分 65.54，Misleading 43.45，Irrelevant 仅 17.05（JFLEG 验证集）

JFLEG 上 few-shot 性能随示例数增加而提升但不严格线性：64 个示例最高 69.25，示例从 16 增至 32 时分数由 67.11 降至 66.67；示例增多时分数标准差下降、性能更稳定

few-shot 下使用与测试集对应的指令（minimal/fluency）取得更高分；而使用 special token 的监督控制方法尽管训练数据更多，仍未能有效控制设置

学习者水平控制：zero-shot 下 Positive Info 提升性能、Negative Info 在多数水平上降低输出；few-shot 下 No Info 优于 Positive Info，Negative Info 在多数水平上仍最差

VIFE/FIVE 对照显示：改变示例集造成的性能差距大于改变任务指令；Jensen-Shannon 距离在对角线（输出与对应示例集）上更低，说明示例集对输出编辑分布的引导作用更强

创新点

此前工作（Coyne and Sakaguchi, 2023; Fang et al., 2023）仅在部分 GEC 基准上评估过 prompt 方法，缺乏对可控性的系统分析。本文深入分析 prompt-based GEC 的可控性（minimal vs fluency edits、按学习者水平纠错），并通过 VIFE/FIVE 消融定量拆分任务指令与示例的相对影响（结论是示例集更关键），同时与基于 special token 的监督控制方法对比，证明 prompt 控制在无需额外训练的情况下更有效。
