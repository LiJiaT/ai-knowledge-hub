Large Language Model Instruction Following: A Survey of Progresses and Challenges

大语言模型（LLM）指令遵循：进展与挑战综述

简介

该综述系统梳理了 LLM 指令遵循（instruction following）这一监督范式：传统 NLP 依赖大量任务标注样本，而指令遵循用文本指令表达任务语义，实现 few/zero-shot 跨任务泛化。论文提出统一的"间接监督"视角，将指令分为 NLI-oriented、LLM-oriented（即 prompt）与 Human-oriented 三类，并总结四种建模策略（semantic parser、flatten-and-concatenation、hypernetwork、RLHF）、两类数据集构建方式（人工标注 vs LLM 合成）与评测方案（自动指标、人工评测、LLM-as-judge，以及 task-centric 与 human-centric 两大分支）。关键结论包括：模型规模与任务规模的"双轨扩展"是性能核心因素；指令工程存在"可解释性换性能"的权衡；LLM 评审器存在偏好偏差；negation 指令失效与对抗性指令攻击是突出风险。对不训练模型、专注"用好模型"的团队而言，这是一份提示工程与评测体系设计的系统性知识地图。

问题

传统 NLP 依赖大规模任务特定标注样本，标注成本高、无法即时应对新任务且对终端用户不友好；论文要系统回答指令遵循领域的五个问题：什么是任务指令及有哪些指令类型、如何建模指令、有哪些数据集与评测指标、哪些因素影响指令遵循性能、还剩哪些挑战与未来方向。

方法

综述型方法：提出统一的"间接监督"视角，将任务指令归为三类（NLI-oriented I=T+Y、LLM-oriented/prompt I=T+X、Human-oriented I=T+可选示例）；归纳四种建模策略（semantic parser、flatten-and-concatenation、hypernetwork、RLHF 及其 KL 预测偏移惩罚与奖励模型机制）；梳理人工标注与 LLM 合成两类指令数据集；总结自动指标/人工评测/LLM 评测器三种评测方案与 task-centric、human-centric 两大评测分支；从模型、指令、示例、模型-指令对齐、数据五个维度分析影响因素，涵盖 instruction engineering（人工与自动）、instruction consistency 与 diversity、demonstration 的选择与排序、CoT 及 Auto-CoT/Self-Ask/Least-to-Most/ToT/GoT 等推理提示变体、symbol tuning、任务规模等。

关键结果

本综述自身未开展实验；其汇总的关键量化观察：模型规模足够大时，未调优的 vanilla LLM 可显著超过在大量任务上调优的小模型（Flan-PaLM：vanilla 540B > 8B + 1836 tasks），即模型规模扩展的收益可能超过数据集扩展

任务规模是 instruction following 的关键因素，而固定任务数、仅增加每任务实例数只能带来有限性能提升（Wang et al., 2022b）；任务规模收益受模型规模制约（如 0.08B Flan-T5 上提升不稳定）

SUPER-NATURAL INSTRUCTIONS 由 88 位 NLP 专家贡献、覆盖 1.6k 跨语言任务；LLM 合成数据集（SELF-INSTRUCT、WIZARDLM、DYNOSAUR、MUFFIN 等）虽含噪声，但可使小模型达到与人工标注数据相当甚至更好的泛化，且人机数据混合效果更好

创新点

据作者所称是首篇全面覆盖 instruction following 的综述：不同于只聚焦 prompt、few-shot demonstrations 或 CoT 推理等单一 in-context 指令子领域的已有综述，本文将 prompt 视为指令的特例，提出统一的间接监督视角与三分类法，把指令遵循追溯至早期 semantic parsing 时代的机器学习，并首次系统覆盖指令分类学、建模策略、数据集、评测方案、影响因素与挑战的完整故事线。
