Red Teaming Language Model Detectors with Language Models

用语言模型对语言模型检测器进行 Red Teaming（红队测试）

简介

该论文系统评估了 LLM 生成文本检测器在对抗攻击下的可靠性，覆盖 classifier-based（OpenAI AI Text Classifier、RoBERTa）、watermarking 和 likelihood-based（DetectGPT）三类检测器。作者提出两种黑盒攻击：一是用另一个同样受检测器保护的辅助 LLM 生成上下文兼容的同义词替换，配合 query-free 随机替换或 query-based 进化搜索改写输出；二是在小规模训练子集上自动搜索一段固定的 instructional prompt，引导 ChatGPT 切换写作风格以绕过检测。与同期工作不同，本文设定攻击者 LLM 自身也被检测器保护，证明即使所有强 LLM 都被保护，现有检测器仍会失效。实验中 DetectGPT 的 AUROC 在 XSum 上从 84.4% 跌至 3.9%，OpenAI AI Text Classifier 的 AUROC 最多下降 55.6 个百分点，而人工评估显示攻击后文本质量仅轻微下降。结论是现有 LLM 文本检测手段尚不够可靠，需要更鲁棒的检测方案。

问题

现有 LLM 生成文本检测器（classifier-based、watermarking、likelihood-based 三类）在面对对抗性文本操纵时是否可靠；尤其在比以往工作更难的设定下——攻击者可用的辅助 LLM 本身也被检测器保护——检测器是否仍会被绕过。

方法

两类黑盒攻击（检测器仅可见输出分数）：1) 词替换攻击：用受保护的辅助 LLM G' 针对上下文生成候选替换词（对 ChatGPT 用指令式提示、对 LLaMA 用补全式提示），再以 query-free 随机替换或 query-based 进化搜索（遗传算法，每例约 70 次检测器查询）选择替换，替换预算为非停用词的 20%；针对 watermarking 另设计两阶段 query-free 攻击，先用语言模型预测熵排序 token、优先替换 greenlist token 以破坏统计特征。2) instructional prompt 攻击：面向能遵循指令的 LLM 与 classifier-based 检测器，在 50 个训练样本上迭代搜索一段固定的附加指令 [X_ins, X_ref]（引导模型模仿参考文风），测试时完全 query-free；搜索中用词重叠匹配分数阻止模型直接抄写参考文本。

关键结果

DetectGPT：XSum 上 GPT-2-XL 的 AUROC 从 84.4% 降至 25.9%（query-free 替换），query-based 进化搜索后进一步降至 3.9%；ChatGPT 与 LLaMA-65B 分别从 56.0%/59.3% 降至 25.6%/25.5%，query-based 后降至 4.5%/9.9%

OpenAI AI Text Classifier：query-free 攻击使 AUROC 在 XSum/ELI5 上分别下降 18.9/28.1 个百分点，query-based 攻击进一步下降 45.4/55.6 个百分点至低于随机水平

watermarking 检测器：在 δ=1.0/1.5 两种设置下，query-free 词替换使检测率（阈值设为人类文本 1% 误报率）显著下降，且优于 Dipper paraphrasing 而无需单独的未保护改写模型；具体数值在论文表格中，正文未逐条列出

对专门针对 GPT-2 文本训练的 RoBERTa-Large 检测器，paraphrasing 与 query-free 替换的 Attack Success Rate 接近 0，query-based 进化搜索取得明显更高的 ASR

instructional prompt 攻击（n=50 训练样本、T=5 轮迭代、每轮 K=5 候选）显著降低 AUROC 与检测率，效果优于用 ChatGPT 直接改写，且测试时无需多次查询

MTurk 人工评估（每数据集 20 例、3 名标注者、1-3 分制）显示攻击后文本的 fluency 与 plausibility 仅轻微下降，质量仍可接受

创新点

与同期用未受保护的改写模型攻击检测器的研究（如 Dipper paraphrase）不同，本文首次系统考虑辅助攻击 LLM 自身也被检测器保护的设定，证明即使未来所有强 LLM 都被保护，现有检测器仍可被攻破；同时用 LLM（而非同义词表或 BERT 类模型）生成上下文兼容的高质量替换词，并提出测试时 query-free、可跨输入复用的 instructional prompt 自动搜索方法。
