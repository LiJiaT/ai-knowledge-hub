PRCA: Fitting Black-Box Large Language Models for Retrieval Question Answering via Pluggable Reward-Driven Contextual Adapter

PRCA：通过可插拔的奖励驱动上下文适配器让黑盒大语言模型适配检索问答任务

简介

该论文针对检索问答（ReQA）中黑盒 LLM 难以微调的问题：GPT-4 等闭源模型只能通过 API 调用、开源大模型微调成本过高，而已有方法要么依赖模型 logits、要么频繁调用昂贵 LLM。方法是在 retriever 与 generator 之间插入可训练的可插拔适配器 PRCA（约 0.4B 参数，BART-Large 初始化），先用摘要任务做监督训练，再以生成器为奖励模型、以答案与标注的 ROUGE-L 为奖励，用改进的 PPO 做强化学习，把检索文档蒸馏成更精炼的上下文。在 SQuAD、HotpotQA、TopiOCQA 三个数据集、75 种 retriever-generator 组合中 71 种获得提升，平均提升 3%/6%/9%，最高 20%；生成器用约 1/4 的 token 即可答对，奖励模型调用降为原来的 1/K。对团队而言，这是 RAG 上下文压缩与质量优化的直接参考，其 GPT-4 评测方法（与人工一致率 92%-96%）也可借鉴。

问题

在检索问答（ReQA）框架中，将 LLM 作为生成器虽能提升 QA 能力，但 LLM 参数量巨大，在有限算力预算内难以微调，且 GPT-4 等闭源模型只能通过 API 访问、无法微调；已有整合方法要么依赖 LLM 最后一层 logits（API 模型不可得），要么频繁调用昂贵的 LLM 且忽略输入 token 长度对准确性的影响。论文希望在不微调 retriever 和 generator 的前提下提升检索增强问答性能。

方法

提出 PRCA（Pluggable Reward-driven Context Adapter），一个位于 retriever 与 generator 之间的可插拔适配器（由 BART-Large 初始化，约 0.4B 参数），对 Top-K 检索文档做自回归式信息蒸馏，向生成器输出更精炼的上下文。采用两阶段训练：(1) Contextual Extraction Stage，在 CNN Daily Mail 摘要任务上以监督学习训练上下文抽取能力；(2) Reward-Driven Stage，将黑盒生成器作为奖励模型，以生成答案与 ground truth 的 ROUGE-L 分数为奖励，用 PPO 优化 PRCA；针对黑盒奖励模型无法计算每步回报 R_t 的问题，提出以 token 生成概率加权的奖励估计方法，使每次上下文生成只需调用一次奖励模型（降为原来的 1/K）。retriever 与 generator 全程冻结。

关键结果

75 种 retriever-generator 配置中 71 种在加入 PRCA 后性能提升；SQuAD、HotpotQA、TopiOCQA 上平均提升分别为 3%、6%、9%

TopiOCQA 上 generator Vicuna 在 5 种 retriever 下平均提升 14%；当 SimCSE 作为 retriever 时提升达 20%

PRCA 约 0.4B 参数，使平均约 7B 参数的生成器在三个数据集上分别提升 12.0%、27.1%、64.5%，对比约 1.75T 参数的 GPT-3.5

加入 PRCA 后，生成器可用约 4 倍更少的 token 得到正确答案；奖励模型调用次数降为原 PPO 的 1/K

GPT-4 评测与人工判断在三个数据集上的一致率（正确率）分别为 96%、93%、92%

消融实验显示去掉 reward-driven 阶段后 PRCA 反而产生负面影响，说明该阶段是性能提升的关键

例外情况：PRCA 对 T5 在 SQuAD 上产生负面影响，原因是 T5 倾向直接抽取答案，而蒸馏改变了文本结构导致错误

创新点

与需要访问 LLM logits 的方法（Shi et al., 2023）和频繁调用昂贵 LLM 的方法（Ma et al., 2023）不同，PRCA 将生成器完全视为黑盒，仅通过最终答案的 ROUGE-L 奖励以强化学习方式训练一个可插拔的中间适配器，兼容 API-only 的闭源模型；并提出针对黑盒奖励模型的 PPO 奖励估计方法（token 概率加权、单次调用奖励模型），且 retriever 与 generator 均保持冻结，可适配多种检索器与生成器组合。
