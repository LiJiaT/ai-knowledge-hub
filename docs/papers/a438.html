Fairness-guided Few-shot Prompting for Large Language Models

公平性引导的大语言模型少样本提示（Fairness-guided Few-shot Prompting for Large Language Models）

简介

论文针对 in-context learning (ICL) 对示例选择与排列顺序高度敏感、性能不稳定的问题，提出从预测偏置（predictive bias）视角评估与优化 prompt。方法上，作者将给定 prompt 拼接 content-free 输入（如 [N/A]），用模型预测分布的熵作为公平性指标，单次前向、无需开发集即可评估 prompt 质量，并实证验证了公平性与任务精度的强相关性。在此基础上提出两种搜索策略：T-fair-Prompting 以 Θ(N) 复杂度选取个体偏置最小的 top-k 示例；G-fair-Prompting 以 O(N²) 复杂度做贪心搜索，同时优化示例选择与排序。在 BLOOM (176B)、LLaMA (65B) 等模型与 SST-2、AGNews 等分类任务上，G-fair-Prompting 在多数情况下优于随机选例+后校准，且发现后校准在不少场景反而损害性能。对团队而言，公平性探针可作为无标注开发集的 prompt 质量评估手段，直接服务于提示工程与上下文组织。

问题

in-context learning (ICL) 的性能对示例（demonstration）的选择、数量与排列顺序高度不稳定，且即使做后校准仍敏感。梯度式 prompt tuning 需要修改模型推理过程，对 GPT-3、ChatGPT 等黑盒 LM 服务不可行且计算/存储开销大。论文要解决的问题是：在不修改模型推理的前提下，如何高效地从带标注训练集中搜索近最优的 prompt（示例组合与排序），以提升 ICL 的性能与稳定性。

方法

以预测偏置作为 prompt 质量的代理指标：将给定 prompt 与 content-free 测试输入（如 [N/A]）拼接，理想情况下模型应输出均匀预测分布，用该分布的熵衡量 prompt 的偏置/公平性（fairness），单次前向即可完成评估、无需额外开发集。基于该指标提出两种局部到全局的搜索策略：(1) T-fair-Prompting：先以 one-shot 方式计算每个示例的个体偏置，选取 top-k 最公平的示例构成 prompt（较公平的示例靠后放置），复杂度 Θ(N)，但依赖 k 的选择、可能次优；(2) G-fair-Prompting：贪心搜索，每步向当前上下文开头插入能使公平性得分提升最大的示例，同时覆盖示例选择与排序两个维度，复杂度 O(N²)，更接近 oracle 解。论文固定 prompt 模板，仅优化示例维度。

关键结果

公平性与精度高度一致：枚举全部 prompt 候选并按公平性排序后，fairer prompts yield better performance，按公平性取的 Oracle 始终对应更高平均精度（Fig. 2，多模型多数据集验证）

复杂度对比：全枚举候选数为 ∑C(N,k)·k!（N=8 时超过 10^6），T-fair-Prompting 降至 Θ(N)，G-fair-Prompting 降至 O(N²)；基线全枚举在 BLOOM 上对 RTE 的 4 示例组合需超过 120 NVIDIA A100 GPU 小时

G-fair-Prompting 在多数情况下优于随机选择+后校准（Table 3）；同时发现 post-calibration 在许多场景会损害模型性能，有时又能显著提升（BLOOM-TREC 上提升 10%）

校准前后性能的 Pearson 相关系数随模型规模增大而增强，LLaMA 系列上从 0 增至 0.7，说明选出的好 prompt 校准后更可能保持优势

创新点

与 Calibration-before-use [18] 使用相同的 content-free 偏置指标，但 [18] 只在固定 prompt 下做输出校准，本文首次实证验证预测偏置与任务性能的相关性，并将该指标用于在原始文本空间自动搜索近最优 prompt，无需对输出做事后调整；相比只优化单一维度（示例选择或排序）的启发式方法（如 KATE 的相似度引导、diversity 引导搜索），本文用统一的偏置指标同时覆盖选择与排序，并自然支持从局部视角到全局视角的过渡（local-to-global）。
