Context-faithful Prompting for Large Language Models

面向 LLM 的上下文忠实提示（Context-faithful Prompting）

简介

LLM 在 RAG 式上下文增强任务中常被参数化记忆带偏：上下文与预训练知识冲突时返回记忆中的旧答案，上下文不含答案时也不肯弃答。论文提出两种免微调的提示策略：opinion-based prompts 把上下文改写为叙述者（Bob）的陈述、将事实性问题转为询问其观点的问题；counterfactual demonstrations 用含错误事实的样本（经 KATE 检索）做 few-shot 示例，并配合 APE 自动生成的指令提示。在 MRC 与关系抽取三个数据集上，OPIN+INSTR 组合将 text-davinci-003 在 natural questions 上的 memorization ratio 从 35.2% 降至 3.0%，RealTime QA 的 NoAns 弃答准确率最高提升 57.2%，Brier score 同步下降。论文还发现原始（事实性）示例反而可能损害忠实性，且模型越大记忆倾向越强。这些结论可直接指导团队 RAG 问答的提示模板设计与上下文忠实性评测。

问题

LLM 过度依赖参数化知识，在上下文特定的知识获取任务（机器阅读理解 MRC、关系抽取 RE）中会忽略给定上下文：当上下文事实与预训练知识冲突（knowledge conflict）时，返回记忆中的全局事实而非上下文中局部描述的事实；当上下文不包含答案信息时无法弃答（prediction with abstention），给出基于记忆的猜测。这两个问题直接影响 LLM 在上下文增强（如检索增强）场景中的可靠性。

方法

纯提示层面、免微调的方案。核心技术：(1) opinion-based prompts——将上下文改写为叙述者（Bob）的陈述，把事实性问题改写为询问叙述者观点的问题，利用'观点因人而异、必须依据陈述作答'的认知先验迫使模型关注上下文，并促进无答案时的选择性弃答；(2) counterfactual demonstrations——用含错误事实的反事实样本作为 few-shot 示例，通过 KATE（RoBERTa-nli+sts-b 编码、余弦相似度）检索最相关示例。另比较 attributed prompt（问题后加 'based on the given text'）与 instruction-based prompt（用 APE 自动生成并按 dev 集筛选指令），OPIN+INSTR 组合效果最佳。

关键结果

text-davinci-003 在 natural questions 上的 memorization ratio 从 35.2% 降至 3.0%

相比 zero-shot base prompt，OPIN+INSTR 配合反事实示例在 GPT-3.5 上使 MRC 的 MR 降低 32.2%、RE 降低 10.9%；在 LLaMA-2-7B-chat 上 MRC 降低 39.4%、RE 降低 57.3%

RealTime QA 上 OPIN+INSTR 在 GPT-3.5 的 NoAns 子集准确率比 base prompt 高 57.2%（zero-shot）与 16.3%（few-shot），LLaMA-2 上高 22.4%；Brier score 在 GPT-3.5 上分别降低 24.2% 与 7.8%，LLaMA-2 上降低 2.6% 与 1.9%

使用原始（事实性）实例做演示效果有限、甚至损害 MRC 忠实性；反事实示例带来进一步提升

更大模型更善于依据上下文更新记忆答案，但在完整（未过滤）评测集上记忆更严重

在无知识冲突的原始数据集上，所提方法不损害性能（opinion-based prompts 结果相当或更好）

创新点

先前工作多用微调（在反事实上下文上 finetune、answerability augmentation）或置信度校准（需白盒访问模型）来提升上下文利用与弃答能力；本文证明仅靠提示设计（opinion-based prompts + counterfactual demonstrations）即可免训练、免白盒地显著提升上下文忠实性，更通用且成本更低。此外给出与直觉相反的发现：在知识冲突场景，反事实示例优于事实性示例，后者有时甚至不如 zero-shot 推理。
