Agent-Pro: Learning to Evolve via Policy-Level Reflection and Optimization

Agent-Pro：通过策略级反思与优化实现学习与进化

简介

论文针对现有 LLM Agent 多为依赖人工精调提示的特定任务求解器、无法从交互中学习进化的问题，提出 Agent-Pro：一个通过策略级反思与优化实现自我进化的 LLM Agent。方法上，它受 Theory of Mind 启发，先在每轮决策前生成并更新 self-belief 与 world-belief 以支撑动态决策；在失败轨迹上进行策略级（而非动作级）反思，将经验蒸馏为 Behavioral Guideline 与 World Modeling 两类提示指令，并经 Verification 与基于 DFS 的策略搜索保证新策略收益持续提升。整个学习过程无需参数微调，本质上是把策略学习转化为自动提示优化。在 Blackjack 与 Limit Texas Hold'em 两个零和博弈中，Agent-Pro 平均超过基线 +4% 胜率，在 GPT-4 上以 +3.2 chips 优势超过专用 RL 模型 DMC。对团队而言，其'反思→蒸馏为结构化提示→验证→搜索'的闭环方法论可直接借鉴到 Agent 提示自优化、经验沉淀与上下文组织流程中。

问题

现有 LLM-based Agent 多是依赖人工精心设计提示的特定任务求解器，无法从与环境的交互中学习和进化行为策略，难以应对具有不完美信息与动态交互的复杂场景（如多人博弈）；同时已有的 action-level 自我纠错策略（如 Reflexion）在长程、延迟反馈的交互任务中并不适用。

方法

Agent-Pro 包含三个组件：(1) Belief-Aware Decision-Making：受 Theory of Mind 启发，每轮决策前先用自然语言生成/更新 self-belief 与 world-belief，再基于最新信念输出动作；(2) Policy-Level Reflection：对失败轨迹的信念序列按 Correctness/Consistency/Rationality/Reasons 四个维度反思，将结论蒸馏为 Behavioral Guideline（Goal、Strategy、Demonstration）与 World Modeling（Rule、Opponent 建模）两类提示指令，并通过重放同一局（相同对手与初始条件）做 Verification，三次未通过则丢弃该轨迹；(3) DFS-based Policy Evolution：通过交换各玩家手牌与出牌顺序生成 (K+1)^2 种组合以消除随机性，计算相对最强对手的收益 Δ 评估新策略，再用深度优先搜索在 B 个候选策略分支中迭代寻找更优 policy。整体是 gradient-free 的'探索-学习'策略，把策略学习转化为 prompt 优化，不涉及参数训练。

关键结果

Blackjack（900 局）：Agent-Pro 平均超过基线 Agent +4% 胜率；在 Qwen-72B 与 Llama2-70B 上分别超过 Reflexion +3.9% 与 +11%

Limit Texas Hold'em：在 GPT-3.5、GPT-4、Llama2-70B 上相对 Vanilla LLM 平均提升 +2 chips；在 GPT-4 上超过专用 RL 模型 DMC +3.2 chips，超过其他 LLM-based Agent 2.0 chips 以上

仅保留 Belief-Aware Decision-Making（不做学习）即可比 Vanilla LLM 提升 +0.9 chips（GPT-3.5 上 +1、GPT-4 上 +1.3）

消融实验：去掉动态信念后 chips 从 4.3 降到 2.5（仍比 Vanilla LLM 高 +1.1），且生成的指令变得模糊冗长

Few-shot 对照：加入获胜轨迹示范无效果（-0.5），失败轨迹示范仅 +0.6，均不如进化策略

学习曲线：GPT-4 与 GPT-3.5 版 Agent-Pro 早期最大提升 +2.1 与 +2.3 chips，Llama2-70B 版后半段提升 +0.6 chips

中等强度手牌场景性能提升超过 80%

创新点

区别于 Reflexion 等 action-level 自我纠错（针对单步动作、依赖即时反馈），Agent-Pro 面向长程任务做 policy-level 反思：输入是动作序列与延迟反馈，输出是优化后的策略而非具体动作；并将以往以文本形式堆砌的长期记忆进一步蒸馏为可优化的 Behavioral Guidelines 与 World Models（结构化提示指令），再用 Verification + DFS 搜索保证提示更新带来收益提升，从而把 RL 式策略学习转化为无梯度的 prompt 优化过程。
