TimeSeek: Temporal Reliability of Agentic Forecasters

TimeSeek：Agentic 预测器的时间维度可靠性

简介

现有 LLM 预测类基准大多只在单一时间快照上评测，掩盖了 Agent 预测器在事件生命周期不同阶段的可靠性差异。TimeSeek 基于 150 个 CFTC 监管的 Kalshi 二元市场，在 Open+1、25%、50%、75%、Close-1 五个时间检查点，对 10 个前沿模型在'带/不带 web search'两种条件下共产生 15,000 次预测，并以同期市场价格为基线用 Brier Skill Score (BSS) 打分。关键结论：模型在市场早期与高不确定性（toss-up）市场最有竞争力（Claude 在 toss-up 上 BSS +0.301），但临近结算与强共识市场全面落后；web search 平均提升所有模型 BSS（+0.14~0.59），却在 12% 的模型-检查点组合中反而有害，且按类别剧烈分化（Macro/Sports 全体受益，Politics/Sci-Tech 多数受损）。论文据此主张把工具使用从统一的 always-search 改为'何时搜索、何时依赖参数知识、何时 defer 到市场'的选择性策略，并配合搜索预算与停止规则，这一方法论对团队的 Agent 工具调用与评测体系建设有直接借鉴价值。

问题

现有 LLM 预测基准（如 KalshiBench、ForecastBench）通常对每个市场只做单一快照评测，无法刻画 agentic forecaster 的可靠性如何随预测市场生命周期变化，也无法回答'何时该信任 Agent 的预测、何时该 defer 到市场'，以及'web search 等工具访问是否均匀有益'。

方法

构建 TimeSeek 基准：150 个 CFTC 监管的 Kalshi 二元市场（要求结算晚于 2025 年 10 月以避免训练数据污染），每个市场在生命周期 5 个检查点采样；agentic forecaster 实现为 4 节点状态机（research → agent → tools → forecast），agent 在 tools 间循环直到产出结构化预测；web search 开启时带日期过滤防止未来信息泄漏，关闭时隔离参数知识，预测期间隐藏市场价格防止锚定；用 Brier Score 与以市场价为基线的 BSS 评测，并做时间退化、工具消融、难度分层、类别异质性与两模型集成的描述性分析。

关键结果

10 个前沿模型 × 150 个市场 × 5 个检查点 × 2 种条件，共 15,000 次预测

Open+1 时 4 个模型跑赢市场（Claude +0.167、Kimi-k2.5 +0.118、GPT +0.085、Kimi-k2 +0.011），但到 Close-1 全部落后（BSS < -0.7）；10 个模型中 9 个性能随生命周期单调下降

web search 使所有模型的 pooled BSS 提升 0.14-0.59，但 50 个模型-检查点组合中 6 个（12%）ΔBSS 为负，如 GPT-5.2 在 Open+1 从基线 +0.125 降到 agentic +0.085

toss-up 市场上 10 个模型中 7 个 BSS 为正（Claude 最高 +0.301），easy 市场上所有模型 BSS 强烈为负（-0.692 至 -1.680）

Claude 与市场强分歧（|p̂-p_m|>0.20，n=303）时：toss-up 胜率 80.9%（BSS +0.476）、hard 65.4%（+0.166）、easy 仅 19.8%（BSS -0.720）

按类别：搜索使 10 个模型在 Macro（平均 ΔBSS +0.96）和 Sports（+0.39）全部受益，但在 Politics（7/10 受损，平均 -0.08）和 Sci/Tech（6/10 受损，平均 -0.03）多为有害；GPT-5.2 在 Politics 从基线 -0.005 恶化到 -0.484

Claude 的搜索次数与 BSS 呈非单调关系，最佳区间为 4-7 次查询（+0.109）

模型与市场误差相关性 r=0.19-0.41；最佳两模型集成（Claude+Kimi-k2.5）将 Claude 的 pooled BSS 损失降低 40%（-0.068→-0.041），但没有任何组合整体跑赢市场

创新点

与 KalshiBench（固定快照）、ForecastBench/Prophet Arena（动态但未控工具）、TruthTensor（市场漂移但未控制工具访问、未分析市场内生命周期动态）不同，TimeSeek 的主要区别是在同一基准内做了受控的工具使用消融（带/不带 web search）× 时间检查点 × 难度分层的交叉分析，并把'LLM vs 市场'重新表述为 defer/predict/search 的选择性决策（gating）问题，而非单一聚合比较。
