Hypothesis Generation with Large Language Models

基于大语言模型（LLM）的假设生成

简介

论文研究如何让 LLM 基于带标注样本自动生成高质量、可解释的假设（hypothesis），解决 LLM 难以在单个长 prompt 中有效利用大量样本、且生成过程缺乏质量度量来过滤坏假设的问题。方法上提出 HypoGeniC 算法：先从少量样本生成初始假设库，再迭代更新——对每个训练样本用 top-k 高 reward 假设做预测并按正确性更新 reward（借鉴 multi-armed bandit 的 UCB 思想平衡 exploration 与 exploitation），同时维护 wrong example bank 记录当前假设解释不了的样本，攒满后用其生成新假设填补知识缺口。在 4 个分类任务上，假设推理显著超过 few-shot ICL（最高提升 31.7%），在两个真实数据集上超过 fine-tuned RoBERTa 与 Llama-2-7B；假设可跨模型迁移、在 OOD 数据上保持稳健，且既印证已有文献也发现新洞见。对团队而言，这是一套'从标注数据自动蒸馏自然语言规则并用 reward 信号迭代优化'的可复用工程模式。

问题

如何让 LLM 基于数据（带标注样本）生成高质量假设：一方面 LLM 难以在单个长 prompt 中有效利用大量输入示例；另一方面生成过程需要质量度量，以便过滤坏假设并产生更好的假设。论文将假设质量用其在训练/留存样本上的预测准确率来度量，类似监督学习的设定。

方法

提出 HypoGeniC 算法：1) 从少量初始样本（num_init=10）prompt LLM 生成初始假设库；2) 更新阶段对每个训练样本选取 top-k 高 reward 假设逐一推理，按预测正确性更新 reward——reward 采用 UCB 形式（历史准确率项 + 探索项），把每个假设视为一个 arm、每个训练样本视为一次 pull，且假设库是动态变化的；3) 若错误预测某样本的假设数超过阈值 w_hyp（随训练线性增长），则将该样本加入 wrong example bank，攒满 w_max=10 后用这些难例生成新假设以填补假设池的知识缺口，并按 reward 保留 top-k 假设；4) 推理阶段提供多种策略：best-accuracy hypothesis、filter and weighted vote、single-step / two-step adaptive inference。本质是把自然语言假设当作可用 reward 信号迭代优化的提示资产，并通过逐条迭代处理样本绕开上下文窗口限制。

关键结果

相比 few-shot ICL，准确率提升：SHOE SALES 31.7%、DECEPTIVE REVIEWS 13.9%、HEADLINE POPULARITY 3.3%、TWEET POPULARITY 24.9%

200 训练样本下，在 HEADLINE POPULARITY 与 TWEET POPULARITY 上分别比 fine-tuned RoBERTa 高 12.8%/11.2%，比 Llama-2-7B 高 12.1%/11.6%；将微调样本增至 1000 后，HypoGeniC 最佳结果仍分别高 3.7%/0.7% 与 3.7%/11.4%（DECEPTIVE REVIEWS 为例外，微调模型更优）

假设库更新相比不更新（no updates）平均提升：SHOE SALES 0.7%、DECEPTIVE REVIEWS 5.8%、HEADLINE POPULARITY 8.1%、TWEET POPULARITY 7%

跨模型泛化：GPT-3.5-turbo 生成的假设换用 Claude-2.1/Mixtral 推理性能保持甚至提升；Claude-2.1 换 Mixtral 仅降 2.3%（DECEPTIVE REVIEWS）与 2.7%（TWEET POPULARITY）

OOD deceptive reviews 数据集上超过 few-shot 平均 19.1%，且 HypoGeniC+Claude-2.1 比 RoBERTa 高 1.7%（RoBERTa 性能下降 11%）

oracle inference（回溯选最优假设）下平均准确率：DECEPTIVE REVIEWS 88.6%、HEADLINE POPULARITY 84.1%、TWEET POPULARITY 88%

成本：GPT-3.5-turbo 在 76 次实验中平均每次 $2.05、约 1.5 小时

创新点

与已有 LLM 假设生成工作不同：Qiu et al. (2024) 关注人类式归纳推理评测，Zhong et al. (2023) 支持开放式探索，Qi/Wang/Baek 等从已有文献生成假设，而本文聚焦真实世界挑战性任务上输入与标签之间的假设生成，并引入 UCB 式 reward 设计出自动化算法；与 CoT 推理不同，本文没有预定义推理结构，需同时提出并验证假设以发现未知知识；wrong example bank 与动态假设库把假设生成组织成类似监督学习的迭代过程，并以跨模型推理与 OOD 泛化作为假设质量的证据（反驳了 Qiu et al. 关于 LLM 无法可靠解释假设的结论）。
