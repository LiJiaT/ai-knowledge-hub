Larimar: Large Language Models with Episodic Memory Control

Larimar：具有情景记忆控制的大语言模型

简介

LLM 部署后知识需持续更新，微调有过拟合与灾难性遗忘风险，locate-then-edit 类编辑方法在序列/批量编辑下速度慢、难扩展，且难以在同一框架内同时支持编辑与遗忘。Larimar 受大脑互补学习系统（CLS）理论启发，为 LLM 外挂一个分布式情景记忆模块（基于 Kanerva Machine/GPM，记忆读写被形式化为最小二乘/伪逆求解），新知识一次写入即可生效，记忆读出向量作为 KV cache 注入解码器各层实现 memory-conditioned decoding，全程无需对编辑样本做梯度更新；同一机制还支持选择性遗忘与防信息泄露，并通过递归分层记忆读取泛化到长上下文。实验显示其编辑精度与 ROME/GRACE 相当但快 4-10 倍，1000 次序列编辑后 ERR=0.98，K=512 内批量编辑准确率近 100%，防泄露攻击成功率 17.6% 优于 ROME（29%）与 MEMIT（49%）。局限是仅支持短事实、训练限于句子补全任务，且记忆模块需与解码器端到端联合训练。

问题

预训练 LLM 的知识在部署后需要持续更新（纠正过时/错误事实、保护隐私、消除偏见与幻觉），直接微调存在过拟合与灾难性遗忘风险；现有模型编辑方法（训练超网络、locate-then-edit 参数修改）在序列与批量编辑场景下面临速度慢、内存开销高、扩展性差的问题，且难以在同一方法框架内同时实现事实编辑与选择性遗忘；此外还有长输入上下文泛化难题。

方法

提出 brain-inspired 架构：BERT-large 编码器 + LLM 解码器（GPT2-large 或 GPT-J-6B）+ 固定大小外部情景记忆矩阵（512×768），遵循 CLS 理论将记忆作为快学习系统、LLM 作为慢学习系统。基于 Generative Pseudo-inverse Memory（GPM），将记忆读/写/生成操作形式化为贝叶斯推断并用矩阵伪逆求最小二乘解，实现 one-shot 写入；序列写入与遗忘通过 α=±1 的增量更新保持最小二乘最优。记忆读出向量经线性投影后作为跨层 KV cache 注入解码器，实现 memory-conditioned decoding。可选 scope detector（外部 MiniLM 句向量 1-NN 或内部编码训练的二分类器）判断查询是否命中记忆内容，in-scope 走记忆条件解码、否则走无条件解码。长上下文通过将输入分块写入多个记忆、在 latent 空间递归读取汇总成高层记忆来处理。训练时编码器、记忆、解码器端到端联合优化（重建损失+KL 散度+预训练数据正则项）。

关键结果

编辑速度：比 ROME 与 GRACE 快 4-10 倍（摘要称依基座 LLM 不同为 8-10 倍），在 EasyEdit 框架单张 A100 上测得

序列编辑（ZsRE，1000 次编辑后）：edit retention rate（ERR）Larimar=0.98，GRACE=0.96，SERAC=0.31；且比 GRACE 快约 10 倍以上（GPT-2 XL）

CounterFact 单事实编辑：精度与 ROME 等最强基线相当；向记忆写入 1-2 条改写后 paraphrase 泛化从 88.4 提升到 93.6（Larimar-6B）；ZsRE 上从 70.4% 提升到 82.2%

批量编辑：N≤K=512 时 rewrite accuracy 接近 100%，N=1024 时降至 82%

防信息泄露：rephrase 攻击成功率 Larimar 17.6% vs ROME 29% vs MEMIT 49%（单提示模式）

长上下文（CNN Fast Facts）：随输入上下文变长 recall 退化小；记忆读取平均耗时 0.36s vs Mistral-7b 基线 1.44s

加记忆后语言能力基本不受损：WikiText 困惑度 Larimar-1.3B=14.6、Larimar-6B=15.9；外部 scope detector 检测 EER=2.9%、F1=0.974

创新点

据论文所述是首个将在线分布式写入分层条件记忆模型用于 LLM 测试时新知识适配的工作。与需要梯度更新的微调/超网络方法（FT、KE、MEND）和 locate-then-edit 方法（ROME、MEMIT）不同，Larimar 编辑无需对编辑样本做任何梯度更新；与 IKE/PROMPT 等 in-context 方法不同，无需在上下文中堆叠多条演示、不增加上下文长度；并在同一记忆更新机制下统一了编辑、选择性遗忘（无需负例微调）与信息泄露防护，且架构 LLM-agnostic、可泛化。
