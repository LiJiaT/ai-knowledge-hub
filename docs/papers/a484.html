Ignore Previous Prompt: Attack Techniques For Language Models

Ignore Previous Prompt：针对语言模型的攻击技术

简介

该论文是 prompt injection 的早期系统性实证研究：基于字符串替换构建的 GPT-3 应用中，恶意用户可通过应用接口注入对抗性指令，使模型偏离原定任务。作者提出 PROMPTINJECT 框架，以模块化方式组装 base prompt（初始指令、n-shot 示例、含敏感信息的 private value）与 attack prompt，量化评估两类攻击：goal hijacking（诱导模型输出指定目标串）与 prompt leaking（诱导模型泄露原始 prompt）。在 35 个 OpenAI Examples 官方示例 prompt 上，goal hijacking 成功率达 58.6%±1.6，prompt leaking 达 23.6%±2.7；分隔符、措辞、模型参数等因素均显著影响攻击效果，且能力最强的 text-davinci-002 反而最易被攻击（inverse scaling 现象）。论文指出 stop sequences、后置文本、输出后处理等缓解手段效果有限，在当前开放式 LLM 范式下完全防御可能几乎不可能。

问题

基于字符串替换方式构建的 GPT-3 应用中，恶意用户可以轻易通过应用接口注入对抗性指令，使模型偏离原定目标，而针对此类 prompt injection 现象的系统性研究稀缺。论文旨在定义并量化评估两类攻击——goal hijacking（使模型输出恶意目标字符串）与 prompt leaking（使模型泄露原始 prompt，可能包含应用最核心的提示资产）——的可行性与有效性，并探索影响攻击效果的因素与可能的缓解手段。

方法

提出 PROMPTINJECT 框架，以模块化（mask-based iterative adversarial prompt composition）方式组装 prompt：base prompt 包含初始指令、n-shot 示例、指代用户/模型的 labels、以及含敏感信息的 secret 子提示；attack prompt 依攻击策略构造 rogue string（诱导输出特定字符串）或窃取 private value，并可附加恶意转义/分隔字符以混淆模型。实验在 35 个从 OpenAI Examples 页面收集的 base prompt 上以 text-davinci-002 运行，每个实验重复 4 次以应对 GPT-3 输出的随机性；goal hijacking 以输出精确等于目标串判定成功，prompt leaking 以输出包含原始指令判定成功。

关键结果

在 35 个 base prompt 上，goal hijacking 攻击成功率为 58.6% ± 1.6，prompt leaking 为 23.6% ± 2.7（每个实验重复 4 次）

prompt leaking 中，用 spell check 作为代理任务比直接要求模型打印原始 prompt 成功率更高（12.1 ± 1.4 vs. 2.9 ± 0.0）；在攻击 prompt 中加入 instead 一词将成功率提升至 23.6 ± 2.7

对比 OpenAI API 上的公开模型，能力最强的 text-davinci-002 最易受攻击，呈现 inverse scaling 现象

使用分隔符在指令间做清晰分隔对攻击特别有效（F2）；rogue string 越有害，攻击效果越差（F4），可能是对齐训练的结果

高 temperature 略微降低攻击成功率，但代价是模型输出更不可预测（F3）

创新点

相对已有工作（如 Branch et al. 仅演示 prompt injection 可改变 GPT-3 分类任务结果），本文首次提出系统化、可量化的 prompt injection 评测框架，明确区分并定义 goal hijacking 与 prompt leaking 两类攻击，系统考察分隔符、rogue string、模型参数、stop sequences、后置文本等因素对攻击成功率的影响，并发现最强模型最易受攻击的 inverse scaling 现象。
