EpiBench: Benchmarking Multi-turn Research Workflows for Multimodal Agents

EpiBench：面向多模态 Agent 多轮科研工作流的基准测试

简介

现有 Agent 评测基准大多从明确指定的目标论文出发、以单轮单图问答为主，既无法考察 Agent 主动检索文献、跨论文对齐图表证据的多轮科研工作流，也缺乏对证据复用与证据正确性的过程级度量。EpiBench 构建了 102 个情景式多轮任务（Easy 39/Hard 63），要求 Agent 从引用线索与间接提示出发主动搜索论文、抽取图表证据、在记忆池中积累，并在最终轮禁用工具、仅凭记忆完成跨论文多证据融合作答；配套提出证据正确性（EC）、工具调用最小性差距（MG）与五类错误归因的过程级评测框架。实验显示最强模型 GPT-5.2 在 Hard split 上 ESR 仅 29.23%，多个闭源模型非最终轮准确率较高但最终轮与整集成功率骤降，表明基于记忆的多证据融合复用是主要瓶颈；消融显示放开最终轮工具可显著提升成绩，而移除文本 RAG 影响较小，步数预算从 5 提到 10 有收益、到 15 已饱和。其过程级评测方法与错误归因体系可直接迁移到团队自研 Agent 的质量诊断与记忆设计。

问题

现有基准对科研 Agent 的评测不忠实于真实工作流：任务多从明确指定的目标论文或直接标识符出发，不要求基于引用线索的主动检索，问题常可由单图单表回答，缺少需要跨论文、跨图表多模态证据融合与跨轮证据复用的多轮情景；同时评测协议不完整，允许反复重浏览导致无法度量证据复用，也不校验中间证据是否正确落地，使证据归因错误与融合失败难以诊断。

方法

提出 EpiBench：以情景式多轮任务实例化短科研工作流，任务描述不给出目标论文，要求 Agent 用引用线索与间接提示主动搜索、从图表区域抽取结构化证据、跨轮整合作答。构建流程为 68 篇种子论文经 Connected Papers 扩展为 485 篇语料，GPT-5.2 起草问题链后由 5 位计算机博士标注者精修校验，得到 102 个 episode（Easy 39/Hard 63）。评测框架包含 ESR/Acc_final/Acc_pre、按论文与图表 ID 标注必需证据单元的证据正确性（EC）、相对最小可行工具调用清单的最小性差距（MG），以及基于 trace 最早失败点的五类错误归因；最终轮禁用工具强制记忆复用。Agent 实现基于 smolagents，采用 ReAct 式 function-calling 循环，配 Web Search、PDF Extractor、PDF Extractor RAG、Content Extractor 四个工具与按时间序追加的 episode 级记忆存储，答案由 GPT-5.2 LLM-as-a-Judge 评分。

关键结果

最强模型 GPT-5.2 在 Hard split 上 ESR 仅 29.23%，为全部 8 个 LMM 中最佳

多个闭源模型 Acc_pre 较高但 Acc_final 与 ESR 骤降，多证据融合与记忆复用是主要瓶颈；两位博士人类专家成绩显著更高（正文未给出具体数值）

允许最终轮使用工具可显著提升 ESR 与 Acc_final；移除 PDF 文本 RAG 工具影响较小且因模型而异

步数预算从 5 增至 10 一致提升 ESR，增至 15 几乎无额外收益，进入饱和区

人类专家完成基准需 14.04×10^4 秒，模型为 2.64–9.45×10^4 秒；Qwen3-VL-235B-Instruct 总 token 达 5.67×10^7

基准构建中仅 8% episode 保留原稿、6% 轻度编辑，27% 重写最终问题、33% 重写全部问题、26% 整体重建；Hard split 中 94% 经大幅重写或重建

Others 类错误仅占约 3%，被从主分析中排除

创新点

与 SciVQA、CharXiv、SPIQA、LiveXiv、SIN-Bench、PaperArena 等单文档或单图问答基准不同，EpiBench 强调工作流忠实性：不指定目标论文的主动引用引导检索、跨论文多图多表证据融合、多轮证据积累与复用；与 MemoryQA、EMP 等记忆基准不同，它以论文为中心且要求跨论文多模态整合。核心新意在过程级评测：按论文/图表 ID 标注必需证据单元实现自动 provenance 打分、以最小可行工具路径度量冗余、基于 trace 的最早失败点错误归因，以及最终轮禁用工具的 memory-only 协议。
