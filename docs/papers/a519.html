Making Pre-trained Language Models Better Few-shot Learners

让预训练语言模型成为更好的 Few-shot 学习器（LM-BFF）

简介

论文研究如何让 RoBERTa 等中等规模预训练模型在仅有少量标注样本时获得接近 GPT-3 的 few-shot 能力，提出 LM-BFF 方法组合。方法包括三部分：将任务改写为 masked language modeling 填空形式的 prompt-based fine-tuning；利用 T5 的 span-filling 能力自动生成模板、用剪枝搜索自动选择 label words，减少人工提示设计；在每步训练中为每个输入从各类别采样示例拼入上下文，并用 SBERT 相似度选择性采样语义相近的 demonstrations。在 15 个 NLP 任务上，相比标准 fine-tuning 最高提升 30%（平均 11%），仅用 32 个样本即在多数二分类任务达到约 90% 准确率。对团队的核心启示：提示措辞对效果影响巨大（模板或 label word 的小改动可导致 >10% 波动），且基于相似度检索的示例选择能显著提升上下文利用效率，这两点可直接迁移到团队的提示设计与上下文组织实践。

问题

GPT-3 展示了仅靠自然语言提示与少量示例的 few-shot 能力，但其 175B 参数规模难以在实际应用中部署；同时人工设计提示（模板与 label words）依赖领域知识和反复试错且容易次优，GPT-3 式随机拼接 demonstrations 的 in-context learning 对中等规模模型也不一定有效。论文研究更实际的场景：仅有每类 K 个标注样本时，如何对中等规模语言模型做高效 few-shot 微调，并减少对人工提示设计的依赖。

方法

提出 LM-BFF，一套互补的 few-shot 微调技术：(1) prompt-based fine-tuning——用任务模板将分类/回归任务改写为 masked language modeling 填空问题，用 label words 映射标签，复用预训练 MLM 头、不引入新参数；回归任务建模为两个极值词之间的插值混合模型。(2) 自动提示生成——对 label words 做基于条件似然剪枝的暴力搜索并用 dev set 重排；用 T5 的 span-filling 能力以 beam search 自动解码生成多样模板候选，再逐个微调筛选或集成。(3) 带 demonstrations 的微调——每个输入从每个类别各采样一个示例构成最小 demonstration 集拼入上下文，训练与推理时采样多组并集成预测；并用 SBERT 句向量做选择性采样，只从与输入语义最相近的前 50% 示例中采样。

关键结果

在 15 个 NLP 任务（8 个单句、7 个句对）上，相比标准 fine-tuning 最高取得 30% 绝对提升，平均提升 11%；其中 SNLI 上提升 30%

仅用 32 个训练样本，RoBERTa-large 在多数二分类句子分类任务上达到约 90% 准确率

提示选择影响显著：SNLI 上将 [MASK] 移到末尾或交换句序会导致 >10% 的准确率下降；label words 与语义类别匹配越好效果越好

自动生成模板（Auto T）在多数任务上达到或超过人工模板，且是各自动变体中始终最优的；多模板集成进一步提升性能，同等数量下自动模板集成达到或超过 PET 人工模板集成

基于 SBERT 的选择性示例采样在两种句向量设置下均优于均匀采样

样本效率：SST-2 等简单任务上 LM-BFF 用 32 个样本已接近饱和、与全量数据标准微调相当；SNLI 上优势保持到 K=256 两者收敛

创新点

与 GPT-3 不同，将 few-shot 能力迁移到可高效微调的中等规模模型；与 PET 的半监督设置不同，仅用少量标注样本，并新增自动模板生成与自动 label word 搜索（此前自动搜索方法未能超过人工提示），以及微调阶段 demonstrations 的动态拼接与相似度选择性采样；并首次在该设置下覆盖回归任务。评测上提出更严格的协议：多个随机 split 取平均以估计方差、dev set 与训练集同规模、超参在各自 dev set 上选择。
