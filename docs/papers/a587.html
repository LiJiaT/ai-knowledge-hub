Strategic Reasoning with Language Models

基于语言模型的策略推理

简介

论文研究如何让预训练 LLM 在不训练、不微调的前提下进行可靠且可泛化的策略推理。作者提出自动 'prompt compiler'，把博弈求解过程分解为 search、value assignment、belief tracking 三类推理步骤，系统化生成 few-shot CoT 演示提示；当博弈复杂度超出上下文窗口时，通过 'search'/'calculate' 等工具调用把子推理派发到独立的 LM 上下文。在 35 个单阶段与 30 个两阶段矩阵博弈、新目标、部分可观测及 Deal or No Deal 谈判任务上，结构化提示几乎完美泛化到新规则、新目标与隐藏信息，明显优于 0-shot/CoT 基线；11 人参与的人机谈判用户研究中平均奖励 7.6，高于无 belief 版本的 6.7 与 few-shot 基线的 4.8，且被评为更像人、攻击性更低。对团队的价值在于其'结构化推理提示 + 工具分解 + 上下文分治'的方法论，可迁移到 Agent 可靠性与提示工程实践中。

问题

现有博弈 AI（Chess、Go、Poker、Diplomacy 等）依赖大量训练，策略无法在换规则、换目标或新博弈时泛化，需重新训练；LLM 虽有灵活推理潜力，但在涉及其他 Agent、社会情境与规划的推理上脆弱且不可靠。论文要解决的问题是：如何在不做任何训练或微调的情况下，让 LLM 进行可靠、灵活、可泛化的策略推理，即在状态与动作空间中搜索、为状态-动作赋值、并对部分可观测信息形成信念。

方法

提出 'prompt compiler'：从示例博弈自动生成结构化推理演示，将推理分解为三个组件——search（遍历博弈树与对手动作，含穷举搜索与'提议-评估-修订'的迭代搜索）、value assignment（为每个状态-动作对赋值并给出自然语言解释以泛化到新目标）、belief tracking（对隐藏状态、对手价值观测与通信真实性形成信念并随交互更新）。这些演示以 few-shot CoT 提示注入。面对大博弈树超出上下文窗口的问题，通过 'search'/'calculate'/'compare' 等工具调用把子推理派发到新的 LM 上下文；用 Synchromesh 把输出约束到合法动作空间；对 level-2 对手用 LM cascade 实现递归推理。实验使用 code-davinci-002、curie-001、davinci-002/003，temperature 0 贪心解码。

关键结果

在 35 个单阶段（7 类博弈 × 5 种收益）与 30 个两阶段矩阵博弈上，结构化策略提示成功泛化到新收益结构，显著优于 0-shot、2-shot 与 0-shot CoT 基线；消融掉 search 或 value assignment 组件后性能变得不可靠（准确率具体数值见表1，正文未列出百分比）

通过 factored reasoning（'search'/'calculate' 工具分解），模型在更大动作空间（3×3、4×3、5×5、6×6）与更多玩家（3、4、5 人）的新博弈结构上'完美泛化'，而未分解的推理随博弈规模增大而失效（图2）

零样本泛化到从未见过的新目标（对手帮忙、最大化总福利、自定义目标 'daxity' 等），结构化推理提示优于基线（表2）

公平 broker 任务中，迭代式'提议-评估-修订'推理结构使提议与最优交易的差距'降低超过一半'（more than halving the error rate，表3）

Deal or No Deal 人机谈判用户研究（11 名参与者、每人 3 局 × 3 种方法）：本方法平均奖励 7.6，高于无 belief 版本的 6.7 与 few-shot 基线的 4.8；人类对手与本方法谈判也获得更高奖励（6.30 vs 6.21）；问卷（7 点 Likert）显示该 Agent 更像人、更合理、更愿妥协、攻击性更低

对 level-2 对手，LM cascade 结合推理提示可成功泛化；无 cascade 的单上下文方式也表现不错，但作者预期更高阶推理时会退化（表5）

创新点

与既有博弈 AI 依赖大量训练、换场景需重训不同，本文不训练任何参数，仅靠自动生成的结构化 CoT 提示让 LLM 本身充当灵活的策略规划器。与 Cicero 采用独立策略规划器、LLM 只负责把预测转成对话不同，本文把搜索、赋值、信念建模全部以语言推理形式注入提示，并通过工具调用把推理分解到多个 LM 上下文以突破上下文窗口限制；'prompt compiler' 自动生成演示、以及用 LM cascade 做任意层级递归推理也是其区别于已有 prompting 工作的特点。
