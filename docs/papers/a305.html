简介

这篇综述系统梳理了针对 LLM 与 VLM 的越狱攻击与防御，指出越狱源于训练数据不完整、语言歧义、生成不确定性等结构性因素，并强调需与幻觉区分。论文提出攻击—防御—评测三维框架：攻击侧覆盖模板/编码、ICL 操纵、对抗与强化学习、LLM 辅助与微调攻击，以及 VLM 的提示-图像注入、跨模态扰动与代理模型迁移；防御侧归纳为提示级、输出评估、模型级三类；评测侧给出 ASR、Toxicity Score、Clean Accuracy、OASR 等指标，并汇总 JailBreakV-28K、AdvBench、JailbreakBench 等基准。关键结论包括：ICL 依赖与多轮上下文构成真实攻击面；幻觉输出会高估攻击成功率，需用 BABYBLUE 式三阶段评估区分真实威胁；统一防御原则为感知层变体一致性/梯度敏感性检测、生成层安全解码与输出审查、参数层对抗增强偏好对齐。对团队而言，其防御分类与评测指标可直接用于自建 LLM 应用的安全评测与提示加固。

问题

LLM 与 VLM 的安全对齐可被越狱攻击绕过而产生有害内容；现有研究分散于纯文本与多模态、攻击与防御各自为政，缺乏统一的机制梳理与标准化评测；同时幻觉与越狱常被混淆，导致攻击成功率被高估、防御研究偏离真实威胁。

方法

系统性文献综述，提出三维调查框架。攻击维度：模板/编码类（嵌套虚构场景、prompt 重写、加密编码、ASCII art）、ICL 操纵（advICL、Crescendo、DrAttack、CFA）、对抗优化（GCG、AutoDAN、I-GCG）、强化学习攻击、LLM 辅助攻击（GUARD、PAP、TAP）与微调攻击，以及 VLM 侧的提示-图像注入（FigStep、AutoJailbreak）、文本+图像联合扰动（Co-Attack、CroPA）与代理模型迁移。防御维度：提示级（变体扰动一致性检测、SMEA 的 system prompt 进化优化、defense prompt 自动精炼如 AdaShield）、输出评估类（如 ECSO、Llama Guard 类审查）、模型级（安全微调、RLHF）。评测维度：定义 ASR、Toxicity Score、query/time cost、Clean Metric、OASR 等指标并汇总多模态安全基准。最后提出感知层 variant-consistency/gradient-sensitivity 检测、生成层 safety-aware decoding 与输出审查、参数层对抗增强偏好对齐的统一防御原则，并引入 BABYBLUE 框架（分类—文本—功能三阶段）区分越狱与幻觉。

关键结果

I-GCG（基于 GCG 改进）在多个 LLM 上取得接近 100% 的攻击成功率，优于现有越狱攻击方法

Lermen 等用 LoRA 微调 Llama 2-Chat，仅少量算力与数据即将 AdvBench 与 RefusalBench 上的拒绝率降至 1% 以下

Zhan 等用弱模型生成的有害数据微调 GPT-4 后，攻击成功率高达 95%

Tu 等收集 12,974 条 knowledge-jailbreak 攻击对训练 Jailbreak Generator，具备较强的跨域与跨模型泛化能力

JailGuard 采用 19 种变体生成器对多模态输入做扰动一致性检测，在多模态越狱数据集上优于现有主流防御方法

在三个主流 VLM 及其对应 LLM 上的实验表明，视觉指令微调会诱发“遗忘效应”，削弱底座 LLM 的安全对齐

创新点

相比此前分别聚焦文本域或单模态的综述（Das et al.、Yi et al.、Jin et al.），本文将范围扩展到从纯文本到多模态的完整谱系，统一归纳攻击的共享机制，提出攻击—防御—评测三维框架与感知层/生成层/参数层三层统一防御原则；并系统区分幻觉与越狱，指出当前评测器难以判断内容是否真正“恶意”、幻觉导致 ASR 高估的问题，提出以 BABYBLUE 式框架和标准化基准改进评测。
