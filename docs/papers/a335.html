明智行动：培养 Agentic 多模态模型的元认知工具使用能力

简介

论文针对多模态 Agent 的“盲工具调用”问题：现有模型即使原始视觉上下文足以作答，也会反射性调用外部工具，导致严重延迟瓶颈，且冗余工具交互注入噪声、破坏原本正确的推理链。作者先论证现有 RL 将准确率与工具惩罚标量化耦合会造成梯度纠缠与效率信号被方差淹没，随后提出 HDPO，把两者解耦为正交优化通道：准确率通道用标准 GRPO 全局优化，效率通道仅在答对的 rollout 内做条件优势估计，并配合剔除幻觉环境反馈、过滤非必要工具样本的数据清洗流程。基于 Qwen3-VL-8B-Instruct 训练的 Metis 将工具调用率从 98% 降至 2%，同时在 HRBench、CharXiv、WeMath 等基准上达到开源多模态 Agent 的最优或可比精度。对团队的核心启示是：工具调用并非越多越好，“何时不用工具”的元认知仲裁应成为 Agent 设计与评测的一等公民。

问题

Agentic 多模态模型存在元认知缺陷：无法在依赖内部参数知识与查询外部工具之间做仲裁，即使原始视觉输入足以解题也会反射性调用工具（blind tool invocation），造成严重延迟瓶颈，且冗余工具交互注入环境噪声、破坏原本正确的推理。现有 RL 缓解方案把任务正确性与工具使用惩罚标量化为单一奖励，形成不可调和的优化困境：惩罚过强会抑制困难任务上的必要工具使用，惩罚过弱则在优势归一化（如 GRPO）中被准确率奖励的方差完全淹没，无法遏制工具滥用。

方法

提出 HDPO（Hierarchical Decoupled Policy Optimization）：不做奖励标量化，而是维护两个正交优化通道——准确率通道（正确性 0.9 + 格式 0.1，标准 GRPO 在全部 rollout 上估计优势）与效率通道（工具奖励为随调用次数递减的反比惩罚，T=0→1.0、T=1→0.5，答错 rollout 记 0），效率优势仅在“合格集”（答对的 rollout）内做条件优势估计，|Q|<2 时置 0；两通道各自归一化后再线性组合 clipped surrogate loss（w_acc=1.0、w_tool=0.15），消除协方差梯度纠缠，并自然形成“先学会做对、再学会做省”的隐式认知课程。配套元认知数据清洗：沙箱执行剔除幻觉环境动态、以基模型 pass@8=1 过滤无需工具的 SFT 样本、用 Gemini-3.1-Pro 多维评审并显式惩罚盲调用；RL 阶段仅保留 pass@8∈(0,1) 的方差感知 prompt。最终模型 Metis 以 Qwen3-VL-8B-Instruct 为骨干，配备代码执行、文本搜索与图像搜索工具，系统提示规定 <reason>/<tool_call>/<answer> 结构并鼓励尽量直接作答。

关键结果

工具调用率从标准 GRPO 的 98% 降至 2%（数量级下降），同时推理精度提升

HRBench-4K 83.5%、HRBench-8K 82.0%，超过包括 30B 参数 Skywork-R1V4 在内的现有 agentic 模型

CharXiv 推理题 54.1%，显著超过此前最佳 agentic 模型 DeepEyesV2 的 48.9%

数学与逻辑推理五个数据集平均 66.9%；WeMath 65.2%，较骨干 Qwen3-VL-8B（38.8%）绝对提升 +26.4%

消融：HDPO（w_tool=0.15）相对标准 GRPO 在 V*Bench、HRBench8K、CharXiv(RQ) 分别 +2.4%、+2.8%、+3.1%

w_tool 呈倒 U 型敏感：0.10 次优、0.15 最优、0.20 在所有基准上性能退化

创新点

以往工作把工具效率作为标量化奖励中的惩罚项与准确率耦合，本文论证该耦合在优势归一化下因协方差纠缠而数学性失效，并首次将工具效率重构为“严格以答对为条件”的独立优化通道（conditional advantage estimation），无需手工奖励调度即隐式产生认知课程；同时指出并系统清洗现有工具增强数据集中“幻觉环境动态”与“过时工具依赖”两类病灶。核心主张从“教模型如何执行工具”转向“培养模型何时不使用工具”的元认知仲裁。
