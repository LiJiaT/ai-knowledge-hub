Mindstorms in Natural Language-Based Societies of Mind

基于自然语言的'心智社会'（NLSOM）中的 Mindstorms

简介

论文提出 NLSOM（Natural Language-Based Society of Mind）框架，以自然语言作为通用通信接口，把多个预训练 LLM 与 VLM 等专家模型组织成可模块化扩展的多智能体社会，通过多轮 'mindstorm'（提问-回答-汇总）协作解决单模型难以完成的任务。方法上为每个 Agent 分配角色与目标，并用'君主制'（Organizer/Leader 层级汇总）或'民主制'（RTK/RTC/RTE 投票）等组织结构控制通信与决策流程，构建了最多 129 个成员的 Artist-Critic 层级 NLSOM。在 VQA、图像描述、文生图提示生成、3D 生成、第一视角视频检索、具身智能与通用语言任务上做了实验：VQA 零样本达 67.42%，超过微调单模型最佳的 60.3%；Ego4D 检索中单 Agent 不如随机基线，组队后显著超越。关键结论：增加 Agent 数与讨论轮数通常有收益但存在任务差异，君主制与民主制孰优取决于任务与成员能力，提示设计对整体系统性能影响极大。对团队而言，这是多 Agent 编排结构选型与角色化提示设计的早期系统性参考。

问题

单个 LLM 在多模态零样本推理上能力有限。论文研究如何将多个预训练模型（LLM、VLM 等）通过自然语言接口组织成'心智社会'（NLSOM），使整体能力超越任何单一成员，并探讨何种社会结构（君主制/民主制）、通信方式与规模能最有效地完成各类任务。

方法

提出 NLSOM 框架：由多个各有目标的 Agent 加上规定通信连接与信息传递路径的组织结构组成，通过多轮自然语言 mindstorm 协作；典型流程分四阶段：Mission Initialization、Task-Oriented Mindstorm、Opinion Gathering、Execution。用角色化提示赋予 Agent 身份（Organizer、Leader、Critic、Artist 等），对比君主制（层级汇总）与民主制（知情权/改答权/执行投票权）两种结构；构建 26 个 Artist（各含 Questioner-Answerer-Leader 三个 LLM）+ 50 个 Critic + 1 个 Collector 的 129 成员层级 NLSOM 做文生图提示优化；通用任务采用 CAMEL 角色扮演框架；展望部分提出用 RL 与'货币/合同'机制实现 Economy of Minds（EOM）的信用分配。

关键结果

VQA（A-OKVQA val）：零样本君主制 NLSOM 准确率 67.42%，超过微调单模型最佳 GPV-2 的 60.3%；VQA Agent 从 1 增到 3 性能逐步提升；民主制 NLSOM 表现差于君主制

图像描述（TARA）：10 轮 mindstorm 后 NLSOM 的 Sentence-BERT 相似度为 20.6，BLIP2 为 11.3

3D 生成：NLSOM 在几乎所有任务上的平均 Clip score 优于 Imagine3D；但 mindstorm 超过两轮迭代后无显著提升

Ego4D 第一视角检索（NLQ val 的 5%，192 个查询）：单 Agent 无法超过随机基线，组成 NLSOM 后一致超过启发式基线与单 Agent；该设定下民主制略优于君主制

成本数据：在 A-OKVQA 1.1K 样本上运行 10 轮 mindstorm 需 3-13 小时（视 VQA Agent 数量而定）

文生图与具身智能实验主要为定性结果：NLSOM 生成的图像更具艺术性；环境探索覆盖率高于均匀随机策略

创新点

把 Minsky 的 Society of Mind 与 Schmidhuber 的 'learning to think' 中'NN 互相访谈'的思想推广到以自然语言为通用通信接口的预训练 LLM/VLM 社会：接口标准化带来模块化即插即用、可解释性与人类专家可直接加入。相比此前把 LLM 嵌入程序或与专用网络组合的工作，NLSOM 强调大量主动 Agent 之间的多轮 mindstorm，系统对比君主制/民主制等社会结构，并提出 Economy of Minds（以货币与自然语言合同做 RL 信用分配）的研究议程。
