$k$NN Prompting: Beyond-Context Learning with Calibration-Free Nearest Neighbor Inference

kNN Prompting：基于免校准最近邻推理的超越上下文学习（Beyond-Context Learning）

简介

该论文指出 In-Context Learning (ICL) 这一 LLM 主流使用方式的两大实际困境：受 1024/2048 tokens 上下文长度限制无法随训练数据扩展，以及输出分布存在偏差、需要精细校准而现有方法只能部分缓解。方法上提出 kNN Prompting：将训练数据分为 demonstration set 与 anchor set，用 demonstration 前缀逐条查询 LLM，不把输出映射回标签空间，而是将完整的语言建模概率分布缓存为表征、golden label 作为 value 存入本地 datastore；推理时对测试实例获取同样分布，用 KL 散度在 datastore 中检索 k 近邻（k=3）并聚合标签预测，全程 training-free、calibration-free。实验显示 few-shot 下超过 SOTA 校准方法最高 +7.07，32 shots 时较 ICL 平均分最高 +13.58，且在 2 到 1024 shots、0.8B 到 30B 模型规模上持续有效扩展，方差（3.83）显著低于 ICL（9.14）。对团队而言，这是'用缓存分布表征 + 近邻检索突破上下文窗口限制、同时缩短线上 prompt 降低按 token 计费成本'的代表性方法参考。

问题

In-Context Learning (ICL) 作为 LLM 的典型使用方式存在两个问题：一是受固定上下文长度（1024 或 2048 tokens）限制，无法利用更多训练数据，数据 scaling law 被截断；二是 LLM 输出分布存在严重偏差与不稳定，现有 calibration 方法（如 ContextualCalibration）只能部分缓解，因为 LLM 补全虚构 prompt 的能力与下游任务标签空间本质上不对齐。

方法

将训练数据 T 划分为 demonstration set D（作为 prompt 前缀的上下文示例）与 anchor set A。Meta test 阶段：对每条 anchor 样本，用相同 demonstration 前缀拼接后查询 LLM，将整个 next-token 语言建模概率分布缓存为 key、golden label 作为 value，构建本地 datastore。Formal test 阶段：对测试实例构造相同 prompt 获取分布，用 KL 散度在 datastore 中度量距离，取 k 近邻（固定 k=3）聚合其标签作为预测。框架 training-free、无校准步骤、除 k 外无其他超参；anchor 只需查询一次并本地缓存，从而支持任意多训练数据参与推理（beyond-context）。

关键结果

Few-shot 场景（m≤8，严格可比设置）：超过 SOTA 校准方法，4-shot 提升 +3.56，8-shot 提升最高 +7.07

低资源场景（m=128，0.8B 模型）：平均分较 ICL 与 ICL Ensemble 分别提升 +16.96 与 +16.08；LLM 规模大于 6B 时（82.73）超过 finetuning 基线，而 ICL Ensemble 需 30B（82.45）才可比

数据扩展：从 2 shots 到 1024 shots、模型规模 0.8B–30B 持续有效扩展；仅 32 shots 时较 ICL 平均分最高提升 +13.58（0.8B），fully supervised 设定下绝对提升最高 +18.84；OPT 30B 取得最佳成绩 86.02

对比 demonstration selection（BM25、Sentence-BERT、SimCSE、Trans-Encoder）：kNN Prompting 明显更优，且与搜索 1000 个 prompt 得到的上界近似（PromptCompose upper-bound）相当或更优

稳定性：10 个任务上标准差为 3.83，显著小于 ICL 的 9.14；对先验分布错配鲁棒，三个不平衡设定下 MaxDrop 仅为 -1.3/-2.6/+0.05

消融：KL 散度距离优于基于上下文表征的欧氏距离；k=3 在 [3, |A|/2-1] 宽范围内稳健；使用完整 LM 分布优于仅用 label words（Partial）

类别不平衡场景下方法脆弱（多数类 anchor 淹没近邻），提出按类平均表征生成类中心的归一化 trick 后，在平衡设定下也无性能损失

创新点

与 demonstration selection 类工作（Liu et al., 2022b; Rubin et al., 2022，检索相似样本拼 prompt，推理时仍只使用上下文内样本、丢弃大部分训练数据且依赖外部 retriever）不同，kNN Prompting 用整个 LM 分布（而非仅 label words）作为样本表征，在缓存 datastore 上做 kNN 推理，从而免校准、免训练，并把任意多训练数据纳入推理过程。与 kNN-LM 等用无监督语料做 datastore 并插值当前步概率的方法不同，它定位于 gradient-free 的 LLM 部署范式，用规模可控的有标注训练数据构建 datastore，避免检索模型效率问题，实现数据 scaling 与模型 scaling 的桥接。
