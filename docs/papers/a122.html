IAG: Induction-Augmented Generation Framework for Answering Reasoning Questions

IAG：面向推理型问答的归纳增强生成框架

简介

针对隐式推理类开放域问答中 RAG 检索文档覆盖不足、纯提示方法易幻觉的问题，论文提出 IAG 框架：在常规 RAG 之上增加 inductor，用基于归纳推理（类比+泛化）的两步提示模板从 GPT-3 引出归纳性知识语句，与检索文档一起作为证据喂给生成器。IAG-GPT 直接调用 GPT-3 API 生成知识；IAGStudent 通过置信度加权蒸馏与 TAILBACK（可微 beam search 回传生成器反馈）训练 T5-Large 学生 inductor，摆脱推理期对 GPT 服务的依赖。结果显示 IAG 在 CSQA2.0 与 StrategyQA 上超越 SOTA 与 ChatGPT，并登顶两个官方榜单；知识融合优于 self-consistency 投票，5-7 条知识语句效果最佳。对团队而言，'检索证据+LLM 生成知识'的上下文组织方式与归纳提示模式可直接借鉴到知识库问答场景。

问题

开放域问答中的隐式推理问题（如 'can you catch a jellyfish in the dumpster?'）答案通常不以明文形式存在于网页或知识库：RAG 受限于知识库覆盖不足与噪声，检索文档难以提供有效证据；纯提示方法则受幻觉困扰，且 LLM 能力受参数规模限制，难以应对训练语料之外的领域问题。论文寻求结合检索与提示两类方法优势的新范式。

方法

提出 IAG 框架：在常规 RAG 之上增加 inductor 模块，针对每个问题生成归纳式知识语句。核心提示方法基于归纳推理的两个认知工具（类比 analogy 与泛化 generalization）构造两步推理路径：先用两个类比物将目标归入其上位概念（hypernym），再陈述与该上位概念相关的事实；模板含 5 个 in-context demonstrations。IAG-GPT 直接调用 GPT-3（text-davinci-003，temperature 0.7）采样 M 条知识语句，与 N 篇检索文档一起按 FiD 方式喂给 T5-11B 生成器（让生成器隐式推理全部证据的知识融合，而非显式投票）。IAGStudent 用 T5-Large 学生 inductor 替代 GPT-3：第一步用 GPT-3 语句作伪标签、按生成器置信度加权蒸馏（Q Max / Q Weight 两种策略）；第二步用 TAILBACK 方案——可微 beam search 保留 beam score 计算图，使生成器反馈经 beam score 回传更新 inductor（生成器参数 stop gradient）。

关键结果

IAG 超越当时 SOTA：CSQA2.0 从 74.1 提升到 78.2，StrategyQA 从 69.4 提升到 72.9

登上 CSQA2.0 与 StrategyQA 官方榜单第一：CSQA2.0 78.08（10 篇检索文档+5 条知识语句+集成方法），StrategyQA 单模型 72.86（5 篇检索文档+5 条知识语句）

在两个任务各 50 例的随机 held-out 子集上，IAG-GPT 显著优于 ChatGPT（截至 2023-01-29 版本）

StrategyQA dev 上提示方法对比：CoT 71.5，CoT+self-consistency 73.3，仅用 GPT-3 知识的 IAG 消融版 75.6，含检索的 IAG 76.2

蒸馏策略对比：Q All 仅 64.5（RAG 基线 64.3），Q Weight 表现最佳并被后续实验采用

TAILBACK 在蒸馏基础上带来一致提升：CSQA2.0 60.5→61.9，StrategyQA 65.7→66.6

知识语句数量在 5-7 条时 IAGStudent 表现最佳，过多引入噪声、过少易受随机错误影响

知识融合机制明显优于基于多数投票的 self-consistency（Table 4）

创新点

区别于纯 RAG 或纯提示方法：1) 提出归纳提示（analogy+generalization 两步推理路径）提升 LLM 引出知识的事实性，可通用用于开放域知识引出，而 SI/LAMBADA 依赖有限上下文空间中的启发式搜索、难以适配开放域；2) 用'生成器隐式推理全部采样语句'的知识融合替代 self-consistency 的显式投票；3) 提出按生成器置信度加权蒸馏（Q Weight）与 TAILBACK（可微 beam score 回传生成器反馈）训练学生 inductor，使小模型在推理期摆脱对 GPT 服务的依赖。
