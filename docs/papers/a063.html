Beyond the Limits: A Survey of Techniques to Extend the Context Length in Large Language Models

突破极限：扩展 LLM 上下文长度的技术综述

简介

该综述系统梳理了扩展 LLM 上下文长度的技术全景：自注意力的计算与内存开销随序列长度二次增长，制约多轮对话、文档摘要等长输入场景。论文将方法分为五类——长度外推（位置编码修改、上下文窗口分割与滑动、prompt 压缩）、注意力近似、attention-free 架构（SSM/Mamba、RWKV）、模型压缩（量化、剪枝、MQA/GQA）与硬件感知 Transformer（FlashAttention、PagedAttention 等），并标注各方法适用于训练、微调还是推理阶段。关键结论包括：LLMLingua 可达 20 倍 prompt 压缩且性能几乎不降，LongLLMLingua 仅用 1/4 token 使 RAG 性能提升最高 21.4%，MemGPT 通过 function call 自管理分层记忆以模拟无限上下文。论文指出计算成本、可解释性与外部知识集成仍是开放挑战，并呼吁建立长上下文评测基准。对本团队而言，prompt 压缩与上下文窗口管理部分可直接借鉴，架构类内容主要提供模型侧约束的背景认知。

问题

Transformer 自注意力的计算与内存需求随序列长度呈 O(n²) 增长，内存需求常超出先进 GPU 容量，导致 LLM 难以高效处理多轮对话、文档摘要等场景中远超训练长度的输入序列；论文旨在系统综述提升 LLM 长序列/长上下文处理能力的各类技术。

方法

按五类 taxonomy 组织并关联训练/微调/推理三个应用阶段：1) Length Extrapolation：位置编码外推与插值（ALiBi、xPOS、CLEX、PI、YaRN）、上下文窗口分割与滑动（structured prompting、PCW、StreamingLLM）、prompt 压缩（LLMLingua、LongLLMLingua、Selective Context、MemGPT）；2) Attention Approximation：低秩分解（Linformer）、稀疏注意力（Longformer、LongNet、Routing Transformer）、softmax-free 注意力（Performer、RetNet）；3) Attention-free Transformers：SSM（S4、H3、Hyena、Mamba）与位置依赖注意力（AFT、RWKV）；4) Model Compression：量化（LLM.int8()、OPTQ、AWQ、OWQ）、剪枝（LLM-Pruner、Sheared LLaMA、SparseGPT、Wanda）、MQA/GQA；5) Hardware-aware Transformers：IO 感知与资源管理（FlashAttention、BPT、FlashConv）、多设备分布式注意力（Ring Attention）、内存管理（PagedAttention、Flash-Decoding、LLM-in-Flash）。

关键结果

综述引用：LLMLingua 实现最高 20 倍 prompt 压缩，性能仅有极小下降

综述引用：LongLLMLingua 仅使用 1/4 的 token，使 RAG 性能提升最高 21.4%

综述引用：LogSparse 将 transformer 内存占用降至 O(n(log n)²)；LongNet 达到线性计算复杂度 O(n)；Routing Transformer 计算复杂度为 O(n^1.5)

综述引用：LLM.int8() 推理时内存减半且保持全精度性能；OPTQ 可量化至每权重 3 或 4 bit 且精度损失可忽略；SparseGPT 将数十亿参数模型压缩多达 60% 几乎不影响性能

综述引用：BPT 可处理比 FlashAttention 长 4 倍的序列；Flash-Decoding 对超长序列实现最高 8× 生成加速；基于 MQA 的分区优化模型支持最高 32× 上下文长度；LLM-in-Flash 可加载最大至可用 DRAM 两倍大小的模型

创新点

区别于通用 LLM 综述与高效 Transformer 综述，本文专门聚焦长序列/上下文扩展这一垂直主题，提出五分类法（length extrapolation、attention approximation、attention-free transformers、model compression、hardware-aware transformers），并将各方法与训练、微调、推理三个应用阶段建立映射，同时讨论局限与未来方向。
