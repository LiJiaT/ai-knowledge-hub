G-Retriever: Retrieval-Augmented Generation for Textual Graph Understanding and Question Answering

G-Retriever：面向文本图理解与问答的检索增强生成（RAG）

简介

论文解决"让用户通过对话界面与带文本属性的图（textual graph）问答"的问题：现有 LLM+GNN 工作多局限于传统图任务或小型/合成图上的简单查询，把大图展平成文本会超出 LLM 上下文窗口，而把整图压缩为单一嵌入又容易产生幻觉。方法上提出 G-Retriever，即首个面向通用文本图的 RAG 框架：用 SentenceBert 对节点/边建向量索引并做 kNN 检索，将子图检索形式化为 Prize-Collecting Steiner Tree（PCST）优化以获得连通且相关的子图，再由 GNN 编码器生成 graph token 作为 soft prompt，与文本化子图一起输入冻结的 Llama2-7b 生成答案；同时构建了覆盖 ExplaGraphs、SceneGraphs、WebQSP 的 GraphQA 基准。关键结论：三种配置下均超越基线（prompt tuning 设置下较传统 prompt tuning 平均提升 40.6%、较 GraphToken 提升 30.8%），WebQSP 上 token 与节点数减少 99%、训练时间缩短 67%，引用节点/边的有效率从基线的 31%/12% 提升到 77%/76%，幻觉减少 54%。

问题

让用户能通过统一对话界面就真实世界的文本图提问并获得文本回答、同时高亮图中相关部分（"chat with your graph"）。现有工作要么聚焦节点/边/图分类等传统图任务，要么只在小型或合成图上回答简单问题；将大图文本化会产生过量 token 超出 LLM 输入上限，截断则损失信息与回答质量；用单一图嵌入表示整图会导致模型生成不存在的节点或边（幻觉）。此外，此前缺乏针对图模态、面向真实复杂应用的综合 GraphQA 基准。

方法

G-Retriever 融合 GNN、LLM 与 RAG，包含四步：1) Indexing：用预训练 LM（SentenceBert）编码节点/边文本属性，存入最近邻数据结构；2) Retrieval：对查询用同一编码方式，按 cosine 相似度做 kNN 检索最相关的节点/边；3) Subgraph Construction：把子图检索形式化为 Prize-Collecting Steiner Tree（PCST）优化问题，按与查询的相似度给节点/边赋 prize、按边数计 cost，并通过"虚拟节点"技巧支持边 prize，用近线性时间算法求解，得到连通、规模可控且尽量覆盖高相关元素的子图；4) Generation：用 GAT/Graph Transformer 编码检索到的子图，经 MLP 投影为 graph token 作为 soft prompt，与文本化子图及问题拼接后输入冻结 LLM（Llama2-7b），仅对图编码器与投影层做反向传播训练。另将 ExplaGraphs、SceneGraphs、WebQSP 三个数据集标准化为统一格式的 GraphQA 基准。

关键结果

在 ExplaGraphs、SceneGraphs、WebQSP 三个数据集上，G-Retriever 在 inference-only、frozen LLM+prompt tuning、LoRA 微调三种配置下均优于基线；frozen LLM+prompt tuning 设置下较传统 prompt tuning 平均提升 40.6%，较 GraphToken 提升 30.8%

效率：SceneGraphs 上 token 减少 83%、节点减少 74%、训练时间减少 29%；WebQSP 上 token 与节点均减少 99%、训练时间减少 67%（从 18.7 min/epoch 降至 6.2 min/epoch）

幻觉缓解：与 LLM+Graph Prompt Tuning 基线相比幻觉减少 54%；人工核验 100 条回复中，引用节点有效率 77% vs 31%，边 76% vs 12%，节点边整体完全有效 62% vs 8%

消融实验（WebQSP）：去掉图编码器性能下降 22.51%，去掉文本化图下降 19.19%，说明文本与嵌入两种图表示互补；PCST 子图检索的检索成功率高于 KAPING 的三元组检索

对图编码器选择稳健（WebQSP 上 GCN/GAT/GraphTransformer 的 Hit@1 分别为 70.70/70.27/70.49）；更大 LLM（Llama2-13b）进一步提升效果

创新点

相对已有工作的区别：1) 现有 GraphRAG 方法多针对知识图谱、按与图结构隔离的 top-k 三元组检索，本文是首个面向通用文本图（不限于知识图谱）的 RAG 方法，检索时考虑邻域/图结构信息并返回连通子图，同时提升可解释性；2) 相比把整图编码为单一 soft prompt 的 GraphToken 类方法，通过 RAG 直接从真实图取材来抑制幻觉，并支持远超 LLM 上下文窗口的大图；3) 提出统一数据格式的 GraphQA 基准，覆盖常识推理、场景理解与知识图谱推理等真实任务，而非节点度、边存在性等基础推理。
