Efficient Reasoning with Balanced Thinking

基于平衡思考的高效推理（REBALANCE）

简介

大型推理模型（LRM）存在 overthinking（对简单问题生成冗余推理步骤、推高 token 成本与延迟）与 underthinking（探索不足导致能做对却做错）两类失衡，而现有抑制 overthinking 的手段（关键词抑制、prompt 压缩、外部 early-exit）往往连带削减有价值推理、反而诱发 underthinking。论文提出 training-free 的 REBALANCE 框架：以步骤级 confidence 及其滑动窗口方差作为推理状态的连续指标，从约 500 道题的一次前向中聚合深层 hidden states 得到两种推理模式的 prototype 并构造 steering vector，再用基于模型行为自动拟合的动态控制函数按实时 confidence 调节注入的方向与强度——overthinking 时剪冗余、underthinking 时促探索。在 0.5B–32B 多个模型与九个数学/科学/常识/代码基准上，Pass@1 最高提升 10.0 分、平均生成 token 最多减少 35.4%，跨域无需调参仍有效。对团队而言，这是在自托管推理模型上同时降本与提准的 plug-and-play 手段，但需能干预 hidden states，不适用于纯 API 调用场景。

问题

LRM 常出现 overthinking——对简单问题分配冗余推理步骤，带来大量计算成本却收益甚微，甚至引入幻觉，限制在资源受限环境中的部署；同时也存在 underthinking——模型本有能力解题却因探索不足而过早承诺错误路径。现有缓解 overthinking 的方法（抑制反思关键词如 NoWait/SEAL、按难度调整推理长度的 SFT/RL、外部验证模型 early-exit 如 TrimR/FlashThink）会无差别影响冗余与有价值的推理，或惩罚长推理导致决策边界坍缩，从而诱发 underthinking。论文要解决的核心问题是：如何在抑制 overthinking 的同时不引发 underthinking，实现 balanced thinking 的高效推理。

方法

REBALANCE 是 training-free 的推理时隐空间控制框架，含三个组件：(1) 显式建模：将 <think> 轨迹按 \n\n 切分为步骤，定义 stepwise confidence（步骤内 token 最大预测概率的几何平均）与滑动窗口 confidence variance，用带答案的小规模数据集（500 道 MATH 题）按分位数阈值把步骤标注为 overthinking（低置信、高方差）或 underthinking（持续高置信、低方差）；(2) steering vector 提取：一次离线前向收集各步骤首 token 的深层 hidden states，按标签平均得到两种模式的 prototype µ_O 与 µ_U，其差向量即 steering vector，并通过线性 probing 的 R² 自动选择可分性最好的中后层作为注入层；(3) 动态控制函数：推理时在每个步骤首 token 注入 α·v，α=g(c_s,v_s) 由按模型行为自动拟合的 sigmoid 形控制面加方差感知门控实时决定方向（δ=±1）与强度，overthinking 时反向压冗余、underthinking 时正向促探索。无额外前向、无辅助验证模型，已在 Hugging Face Transformers 与 vLLM 实现，并适配 Ascend 910B NPU。

关键结果

六个数学推理基准（MATH-500、AIME24、AIME25、AMC23、GSM8K、OlympiadBench）上，不引入辅助模型或额外推理阶段，Pass@1 最高提升 10.0 分，平均生成 token 数最多减少 35.4%

跨域固定 steering vector 与控制面时，在 GPQA Diamond、LiveCodeBench、StrategyQA 上推理长度最多减少 29.9% 且保持 Pass@1

在 Ascend 910B NPU 上的 openPangu-Embedded-7B-V1.1 slow-thinking 模式下，相对 baseline 一致提升推理准确率与效率

MATH-500 上响应词数与最低步骤置信度呈负相关（Spearman ρ 约 -0.62~-0.80）、与步骤置信度方差呈正相关（ρ 约 0.46~0.70），95% bootstrap CI 不含 0（p<0.001）

消融：固定 steering 权重 α=+3 使 QwQ-32B token 增加 147%，α 为负则省 token 但降准确率，验证动态双向调节的必要性；confidence 状态满足一阶 Markov 持续性，故窗口大小 |W|=2 已足够

Pass@20 设定下在 AMC23/AIME24/AIME25 上显著缩短推理长度且准确率无退化；Creative Writing v3 上各模型 65%~100% 的写作指标不低于原模型（Qwen3-14B 全部指标提升）

创新点

相对已有工作的区别：(1) 现有 anti-overthinking 方法——关键词抑制（NoWait、SEAL）、prompt 压缩（NoThinking、CoD）、外部验证 early-exit（TrimR、FlashThink）、内部信号 early-exit（DEER、Dynasor-CoT）与 SFT/RL 长度控制——只针对 overthinking，且以二值、粗粒度方式丢弃或压制整段推理，容易诱发 underthinking；REBALANCE 用 confidence（水平+方差）作为连续细粒度指标，显式建模并双向控制两种失衡。(2) 相比静态 steering（SEAL、Manifold Steering）与单向调幅的动态 steering（Controlling Thinking Speed），其方向与强度均随实时 confidence 双向动态调节。(3) 不丢弃推理路径，而是在隐空间连续微调、保留有价值中间步骤。(4) 控制面参数由模型行为自动拟合、无需人工调参，并论证关键词法本质上是 confidence 控制的不完整近似。
