S-Agent: Spatial Tool-Use Elicits Reasoning for Spatial Intelligence

S-Agent：以空间工具使用激发空间智能推理

简介

现有 VLM 与工具增强 Agent 的空间推理大多停留在静态、无状态的孤立帧级预测，难以应对连续多视角图像与视频。论文提出 S-AGENT：让 VLM 充当语义规划器决定'需要什么证据'，通过三级工具体系（2D 感知 grounding、2D-to-3D 几何提升、空间专家聚合）按需获取证据，并以 Scene Memory（演化场景状态）与 Agent Memory（推理轨迹）双记忆实现跨帧、跨步骤的有状态推理。零样本免训练即可提升 GPT-5.4 等模型（MMSI-Bench 上超 GPT-5.4 4.5%）；其轨迹蒸馏出的 S-AGENT-8B 在 MMSI-Bench 上较 Qwen3-VL-8B 直接推理提升 10.5%（31.1%→41.6%），可比肩闭源先进模型。消融给出对团队很有价值的结论：原始 3D 数值证据直接进上下文收益有限甚至干扰规划器，经专家结构化解读后收益显著，双记忆再叠加增益。

问题

现有 VLM 与工具增强 Agent 的空间推理大多依赖静态、无状态的孤立视觉观测：真实 3D 世界持续演化并投影为 2D 观测流，仅从孤立 2D 视角推理难以维持持久的物体状态、跨视角与跨时间整合证据、并形成对 3D 场景的连贯理解。论文要将空间推理从孤立的帧级预测重塑为时空证据积累的场景级理解过程。

方法

S-AGENT 将 VLM 作为 tool-calling 语义规划器，把'决定需要什么证据'与'获取空间证据'解耦。空间维度采用三级工具层次：Level 1 用 GroundingDINO 开放词表检测、VLM 多帧 grounding、深度估计、关键帧选择等获取 2D 证据；Level 2 用基于 Depth-Anything-3 的 metric_depth3d_tool 将 2D 证据提升为度量 3D 几何（深度、3D 坐标、相机位姿）；Level 3 由计数、相对方向、朝向、度量测量等空间专家把几何信号聚合为结构化高层空间知识。时间维度维护双记忆：Scene Memory 以实体为中心合并可复用场景证据（别名、支持帧、几何属性、派生事实），Agent Memory 记录工具调用、观测、失败信息与中间结论等推理轨迹；每次证据请求都条件于问题与当前记忆状态，输出可跨步骤复用。训练侧用 GPT-5.4 规划器在 SenseNova-SI-800K 上生成零样本轨迹，经执行有效性与答案正确性过滤后分解为 final-answer、turn-level、expert/tool 三种粒度，构成 S-300K（292,391 条 SFT 样本），SFT Qwen3-VL-8B 得到 S-AGENT-8B。

关键结果

零样本免训练下，S-AGENT（GPT-5.4 规划器）在 MMSI-Bench 平均 46.4%，超 Gemini 3 Pro 1.2%、超 GPT-5.4 4.5%

ViewSpatial-Bench 平均 60.0%，超 GPT-5.4 14.4%；更难的 P-SSRD 分项超 GPT-5.4 20.5%

ReVSI 平均 58.8，总排名第二，超过所有开源通用模型与空间专用基线

S-AGENT-8B 在 MMSI-Bench 上较直接 Qwen3-VL-8B 推理提升 10.5%（31.1%→41.6%），与 GPT-5.4、Gemini 3 Pro 相当

消融（ViewSpatial，GPT-5.4 规划器）：VLM-only 45.6% → +Level-1 49.0% → 直接加 Level-2 收益有限 → +Level-3 专家 56.7% → +Scene Memory 58.2% / +Agent Memory 57.6% → 双记忆全量 60.0%

VSI-SUPER 的 VSR 子集在 240 分钟长视频设定下超最强基线 Cambrian-S-7B-LFP 37.2 个百分点

S-300K 构建：100K 原始轨迹中 51,596 条通过过滤，分解为 51,596 final-answer + 154,590 turn-level + 86,205 tool/expert 样本，共 292,391 条

创新点

相对 VADAR、SpaceTools、Think3D 等已有 agentic 空间推理方法（多针对静态图像或孤立观测），S-AGENT 面向连续多视角图像与视频，把空间推理形式化为对场景状态与 Agent 状态的迭代更新：每次证据请求都条件于问题与演化中的双记忆，工具输出可跨步骤复用，而非把每次工具调用当作孤立动作；Scene Memory 以实体为中心绑定跨帧重复观测、抑制重复证据。训练侧将每条教师轨迹分解为 final-answer、turn-level、expert/tool 三种粒度监督，而非仅用作最终答案样本。
