Self-Knowledge Guided Retrieval Augmentation for Large Language Models

基于自我知识（Self-Knowledge）引导的大语言模型检索增强

简介

该论文针对“检索增强并不总是有益、检索到的段落有时反而干扰 LLM 原本正确的回答”这一问题，提出 SKR（Self-Knowledge guided Retrieval augmentation）方法：先在训练问题上分别用 LLM 直接作答与检索增强作答，依据与标准答案的对比把问题划分为“模型已知”与“模型未知”两类，沉淀为自我知识样本；对新问题，通过直接提示、in-context learning、训练 BERT-base 分类器或 kNN 近邻搜索四种策略判断是否需要外部知识，仅对“模型未知”的问题自适应调用检索器。在 TemporalQA、CommonsenseQA、TabularQA、StrategyQA、TruthfulQA 五个问答数据集上，SKR（尤其 kNN 版本）平均优于 CoT 类与全量检索类基线，InstructGPT 与 ChatGPT 上分别提升 4.08%/2.91% 与 4.02%/4.20%；同时发现直接问模型“是否需要额外信息”效果差，约 30% 的问题属于 'unknown unknowns'。对团队而言，这是“何时该检索、何时不该检索”的自适应 RAG 决策的代表性工作。

问题

检索增强并不总是有益：检索到的段落可能干扰 LLM 原本已能正确回答的问题，甚至导致错误答案；同时 LLM 自身的“自我知识”（self-knowledge，即识别自己知道什么、不知道什么）能力有限，难以预先判断一次检索是否比模型已有知识更有用。论文要解决的是如何让 LLM 自适应地决定何时调用检索器、何时直接回答，从而更好地结合内部知识与外部知识。

方法

SKR 采用三段式流水线：(1) 收集自知识——对训练问题分别用 LLM 直接作答与检索增强作答（检索器为 DPR，语料为 Wikipedia 段落），依据与标准答案的对比将问题划分为“模型已知”子集 D+ 与“模型未知”子集 D-（两者都答错的丢弃）；(2) 引发自知识——对新问题用四种策略判断其属于 D+ 还是 D-：直接提示（问模型是否需要额外信息）、in-context learning（用 D+/D- 样本作演示）、显式训练 BERT-base 二分类器、基于 SimCSE 句向量的 kNN 近邻搜索（按 top-k 近邻中正负样本比例投票）；(3) 使用自知识——仅对判定为“模型未知”的问题调用检索器做增强，“模型已知”问题由 LLM 直接回答。

关键结果

SKR 在五个数据集上平均优于 CoT 类与全量检索类方法：InstructGPT 上分别提升 4.08%/2.91%，ChatGPT 上分别提升 4.02%/4.20%

SKRknn 取得五个数据集上的最佳平均结果

直接提示策略效果较差：模型对自认为可直接回答的问题仅达到约 70%~73% 准确率，即约 30% 的问题属于 'unknown unknowns'

SKRknn 在各数据集上带来 55%（StrategyQA）到 78%（TruthfulQA）的“有益引导”比例

训练数据量从 10% 增至 50% 时性能逐步提升，说明自知识样本可从既有问题持续积累并用于后续任务

对比 Wikipedia、MS MARCO、SciFact 三种外部语料，Wikipedia 取得最佳平均结果

创新点

与已有工作的区别：(1) 已有检索增强方法（如 IRCoT、CoT-RR）致力于为每次推理整合充分的外部知识，而 SKR 关注内部与外部知识的互补，按需自适应检索；(2) 已有 self-knowledge 研究侧重设计专门指标或数据集来评测模型自我认知，而 SKR 通过“有/无检索的表现差异”从数据中实证地收集模型知识边界，并通过参照已有案例（kNN/分类器）而非逐题独立判断来引发自知识；(3) 与教 LLM 使用外部工具的工作相比，本文以自知识为依据更灵活地决定是否调用检索器。
