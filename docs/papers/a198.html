MDTeamGPT: A Self-Evolving LLM-based Multi-Agent Framework for Multi-Disciplinary Team Medical Consultation

MDTeamGPT：面向多学科团队会诊的自进化 LLM 多智能体框架

简介

论文针对 LLM 多智能体多学科会诊（MDT）中多角色对话历史过长导致模型认知负担加重、效率与精度下降，以及已有方法只存历史、不提炼经验也不反思错误的问题，提出自进化多智能体框架 MDTeamGPT。方法上由 Primary Care Doctor 基于 few-shot 模板分诊选择专科 Agent，多轮讨论中 Lead Physician 将各方发言结构化为 Consistency/Conflict/Independence/Integration 四类存入 Historical Shared Pool，并采用残差讨论结构（每轮仅参考前两轮结构化摘要）控制上下文膨胀；结论经 Safety and Ethics Reviewer 审查后，按对错由 Chain-of-Thought Reviewer 分别写入 CorrectKB 与 ChainKB，新病例通过 cosine 相似度检索 top-5 相似案例增强 prompt。在 MedQA/PubMedQA 上分别取得 90.1%/83.9% 准确率，消融显示残差结构+Lead Physician 组合带来 5.8%/3.6% 提升，知识库可跨数据集迁移。人工评估显示多轮讨论导致 Efficiency 得分最低，是框架的主要代价。

问题

LLM 多智能体 MDT 会诊中，多角色协作产生过长的对话历史，随上下文累积模型认知负担增加，降低响应效率与准确性；同时已有方法仅简单存储诊断历史，未有效整合正确诊断经验、也未对错误进行反思，限制知识泛化与系统自进化。

方法

构建专科医生 Agent（8 类）与辅助 Agent（Primary Care Doctor、Lead Physician、Chain-of-Thought Reviewer、Safety and Ethics Reviewer）的会诊框架，分三阶段：(1) 分诊：Primary Care Doctor 用 few-shot 示例按病情选择专科 Agent 组合，避免无关专家造成信息污染；(2) 多轮会诊：首轮各专科独立作答，Lead Physician 将发言归为 Consistency/Conflict/Independence/Integration 四类存入 Historical Shared Pool；采用残差讨论结构，第 i+1 轮 Agent 只能读取第 i 与 i-1 轮的结构化摘要，直至共识或 10 轮上限（未达共识按多数决）；(3) 总结输出：Safety and Ethics Reviewer 过滤有害建议后输出最终结论；按结果对错，CoT Reviewer 将正确经验（问题+答案+末轮结构化摘要）存入 CorrectKB，将错误案例（初始假设/分析过程/最终结论/错误反思）存入 ChainKB；新病例用 text-embedding-3-small 做 cosine 相似度检索 top-5（K=5）案例增强专科 Agent 的 prompt（首轮不引用以保持独立推理，第二轮起尤其冲突时引用）。

关键结果

gpt-4-turbo 骨干下，MDTeamGPT 在 MedQA 与 PubMedQA 测试集上分别达到 90.1% 与 83.9% 准确率；MedQA 上略低于 Medprompt（作者归因于 Medprompt 仅在四选项场景评估），PubMedQA 与整体平均上优于 Medprompt

消融实验：同时使用残差讨论模式与 Lead Physician，相比无策略联合讨论在 MedQA/PubMedQA 上分别提升 5.8% 与 3.6%

知识库消融：仅用 CorrectKB 比仅用 ChainKB 在 MedQA/PubMedQA 上分别高 2.1%/5.4%、整体高 3.8%；两者结合优于任一单独使用

自进化实验：无论使用何种 LLM，准确率随会诊样本增加而提升并在约 600 例后趋于稳定；基础能力较弱的模型（如 LLaMA3-8B）随经验积累的提升斜率更陡

跨数据集泛化：用 PubMedQA 构建的知识库测 MedQA 提升 3.6%，用 MedQA 构建的知识库测 PubMedQA 提升 2.1%

人工评估（5 名临床医学背景志愿者、10 题、10 个维度）：Efficiency 得分最低（多轮讨论比 Single-Agent 更耗时），Diversity 平均分低于 3，其余维度均高于 3

创新点

相比 MedAgents 等仅用共识投票（作者指出其缺乏稳健策略、存在集体幻觉风险）与 Agent Hospital 等仅存病历/经验库、缺乏对错误案例抽象与反思的工作：(1) 提出残差讨论结构，限制每个专科 Agent 只能读取前两轮结构化摘要而非全部历史，降低信息污染与认知负载；(2) Lead Physician 将每轮发言归为 Consistency/Conflict/Independence/Integration 四类的结构化聚合机制；(3) 将正确经验与错误反思分库（CorrectKB/ChainKB）并以 CoT 形式抽象存储，实验证明推理模式可跨数据集迁移，实现自进化。
