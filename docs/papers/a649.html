Prompting and Evaluating Large Language Models for Proactive Dialogues: Clarification, Target-guided, and Non-collaboration

面向主动对话的 LLM 提示与评测：澄清、目标引导与非协作对话

简介

论文首次系统评估 LLM 对话系统在三类"主动对话"上的能力：对模糊提问主动澄清、把对话引导至指定目标、在利益冲突的谈判中达成共识，实验覆盖 ChatGPT 与 Vicuna-13B 及五个数据集。方法上提出 ProCoT（Proactive Chain-of-Thought）提示方案：先让模型输出面向对话目标的推理与规划描述，再决定对话动作，最后生成回复，并与 standard、proactive 两种提示在 zero/one-shot 设置下对比。关键结论：标准提示下 LLM 几乎不会主动澄清，ProCoT 使 ChatGPT 在 Abg-CoQA 的澄清需求预测上接近微调 SOTA，但在金融领域 PACIFIC 上仍明显落后；目标引导任务中 LLM 达成率接近完美但话题转移过于激进，ProCoT 让转移更平滑；非协作谈判中策略学习是最大短板。对团队而言，这是"用提示激发模型主动规划"与"主动性能力评测方法"的直接参考。

问题

LLM 对话系统（如 ChatGPT）虽擅长上下文理解与回复生成，但缺乏"主动性"：不会对模糊提问追问澄清、难以拒绝不合理请求、无法主动控制对话以达成会话目标。论文要回答：LLM 对话系统是否具备处理主动对话（澄清、目标引导、非协作）的能力，以及如何通过提示方案激发这种能力。

方法

提出三种提示方案并系统对比：standard prompting（直接生成回复）、proactive prompting（提供候选对话动作让模型先选择再生成）、ProCoT（先让模型生成面向对话目标的中间推理与规划描述，再决定下一步动作，最后生成回复）。在三类任务上评测：澄清对话（分解为 Clarification Need Prediction 与 Clarification Question Generation）、目标引导对话（下一话题选择 + 转移回复生成，含 self-play 多轮模拟）、非协作谈判（策略预测 + 动作预测 + 回复生成）。使用 ChatGPT（gpt-3.5-turbo-0301，temperature=0）与 Vicuna-13B，在 Abg-CoQA、PACIFIC、OTTers、TGConv、CraigslistBargain 五个数据集上结合自动指标、人工评测与错误分析。

关键结果

标准提示下 Vicuna 与 ChatGPT 均无法对模糊提问提出澄清问题（人工 Help. 评分失败）；proactive 提示下 Vicuna 选择澄清动作的 F1 接近 0，ChatGPT 在 Abg-CoQA 上 F1 与 Help. 均有提升

ProCoT 显著提升澄清能力：ChatGPT 零样本 ProCoT 在 Abg-CoQA 的 CNP 任务 F1 上与微调 SOTA 方法相当，one-shot ICL 进一步大幅提升；但在领域任务 PACIFIC（金融）上仍远落后微调方法（SOTA 达 86.9 F1 / 80.1 Help.）

目标引导对话：ChatGPT 在 TGConv 上成功率（Succ.）接近完美，基本在约 3 轮内达成目标话题，但全局连贯性（G-Coh.）低、话题转移激进；ProCoT 使 Vicuna 的转移更平滑（更高 Coh.、更多 Turns），ChatGPT 的平滑转移仍有挑战

非协作谈判：LLM 的策略/动作预测与回复生成显著落后微调方法；以参考策略为条件生成时，人工评测 Win Rates、Persuasive 与 Sale-to-List Ratio 均更优，说明策略学习是关键瓶颈；ChatGPT 倾向保守让步策略（hedge 词、致谢、反报价）

错误分析：每数据集随机抽取 100 个澄清问题生成失败案例，PACIFIC 中 Wrong Aspect 与 Under-specified Clarification 占比高于 Abg-CoQA，指向领域知识缺失；全部 ChatGPT 实验 API 成本约 $120

创新点

已有主动对话研究多针对单一任务微调专用模型；本文是首个对 LLM 对话系统在澄清、目标引导、非协作三类主动对话上的统一评测，并提出 ProCoT——将 CoT 从通用推理扩展为"面向对话目标的规划式推理"（先描述达成目标的中间推理与规划，再决定动作、再生成回复），同时系统对比三种提示方案与 zero/one-shot 设置的效果边界，并给出错误类型分析与策略分布分析。
