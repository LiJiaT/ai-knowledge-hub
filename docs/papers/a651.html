The Knowledge Alignment Problem: Bridging Human and External Knowledge for Large Language Models

知识对齐问题：为 LLM 桥接人类知识与外部知识

简介

论文研究 RAG 场景下的'知识对齐问题'：即使用户问题检索到了正确证据，由于用户不了解知识库中存储的信息，问题中的条件/约束常与证据错位，导致 LLM 忽略正确 grounding、依赖自身偏见知识产生幻觉。作者提出 MIXALIGN 框架，先用 LLM 自动抽取并匹配用户问题与表格知识库中的属性-值约束（显式知识对齐），匹配不确定时自动生成澄清问题向用户求证（人工辅助对齐），再过滤无关候选证据并选择可区分性强的属性继续澄清（隐式知识对齐），最后将澄清信息并入 prompt 生成答案，全部步骤通过 prompt LLM 实现。在基于 OTT-QA 构建的 FuzzyQA 数据集上，79.54% 的样本存在知识错位；oracle 澄清可带来最高 22.2% 的 coverage 提升与 27.1% 的幻觉下降；MIXALIGN 显著优于 Direct-Ask 与 Knowledge-Ask 基线，平均只需约 1 个澄清问题，并可将需要人工澄清的比例降低 14.2%-22.5%。该工作对团队的知识库问答、RAG 上下文组织与人机协作澄清流程有直接参考价值。

问题

RAG 场景中，即检索证据正确，LLM 仍可能生成含无关信息、完全忽略证据甚至与证据矛盾的内容。论文将其根因归结为'人类知识与 grounding 知识的错位'：用户不了解外部数据库内容，提问时可能不一致地表述或遗漏证据中的条件与约束，模型于是跟随伪相关和偏见知识产生幻觉。论文将错位分为 semantic、contextual、structural、logical 四种类型，研究如何通过获取澄清信息 C 将 LLM(A|Q,K) 改进为 LLM(A|Q,K,C)。

方法

MIXALIGN 框架，面向表格型知识库，分两个阶段：(1) Explicit Knowledge Alignment——先用 LLM 从用户问题中按知识库属性抽取约束值（约束抽取），再将抽取的约束与知识库中的值做匹配（显式约束匹配），模型不确定时生成澄清问题请用户确认（澄清问题生成）；(2) Implicit Knowledge Alignment——利用已获得的澄清过滤无关候选 grounding（无关候选过滤），再选择区分度强且用户可回答的属性生成澄清问题继续向用户提问（可区分属性选择）。最终将显式与隐式澄清信息并入 prompt 生成答案。所有步骤均通过 prompt LLM 实现，并配有基于 Structural Causal Model 的分析说明对齐如何促进 front-door adjustment。论文还讨论了用更强 LLM（如 GPT-4）做信息抽取以适配其他知识形式的 strong-to-weak 思路。

关键结果

FuzzyQA 数据集（基于 OTT-QA 演化，1,173 个有效样本，GPT-4 评估协议）中 79.54% 的样本存在知识错位

使用 oracle 澄清时，不同对齐类型间 gold answer coverage 差距为 15%-32%，hallucination 差距为 16%-37%

引入无关 grounding 后，coverage 下降 25.7%-39.4%，hallucination 上升 28.1%-39.8%，且无关 grounding 越多性能越差

oracle 澄清带来 coverage 提升 9.6%-22.2%、hallucination 改善 16.2%-27.1%

对比 Direct-Ask 基线，MIXALIGN 在 coverage 上高 8.1%-11.7%、hallucination 上低 9%-11.8%；对比 Knowledge-Ask，coverage 高 4.6%-8.9%、hallucination 低 6.3%-9.2%

无关 grounding 较少时 MIXALIGN 接近 oracle 澄清性能；候选增多时与 oracle 差距扩大至 coverage 7.7%、hallucination 9.8%

MIXALIGN 将需要用户澄清的比例降低 14.2%-22.5%，平均澄清问题数为 1.08-1.19，最多提出 4 个问题

计算成本：平均每例 3.7 次 LLM 推理，额外延迟 4.87 秒（Text-DaVinci-003）

在原始 OTT-QA 问题上，coverage 与 hallucination 相对 FuzzyQA 结果提升 5%，说明问题简化确实增加难度

消融：去掉人工辅助（w/o Human）性能显著下降且随无关 grounding 增多而加剧；去掉隐式对齐（w/o Implicit）性能一致下降

创新点

区别于以 RLHF 为代表的 value alignment（对齐人类价值观），论文提出并形式化 knowledge alignment（对齐人类知识与外部领域知识）。区别于已有 clarifying question generation 工作（主要解决用户查询自身的歧义），MIXALIGN 针对'用户问题与存储知识之间的关系'寻求澄清，且采用 feedback-driven 方式：先由 LLM 做约束抽取与匹配，仅在模型无法自信建立对齐时才向用户提问，并引导用户针对特定约束补充信息，而非泛泛要求用户提供更多上下文。同时将模型自动对齐与人工辅助澄清结合，并给出因果视角（SCM/front-door adjustment）的解释。
