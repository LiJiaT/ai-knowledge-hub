AriGraph: Learning Knowledge Graph World Models with Episodic Memory for LLM Agents

AriGraph：面向 LLM Agent 的知识图谱世界模型与情节记忆学习

简介

当前 LLM Agent 普遍用完整历史、迭代摘要或 RAG 向量检索来处理过往经验，但这些非结构化记忆难以支撑复杂决策所需的推理与规划。论文提出 AriGraph：Agent 在探索环境时用 LLM 从观察中抽取语义三元组构建知识图谱，并用 episodic 边把每步观察挂接到图谱上，形成语义记忆与情节记忆统一、可动态更新（含过时知识替换）的记忆图；检索采用两阶段方案，先做基于 Contriever 嵌入与图结构扩展的语义搜索，再做情节搜索。在此之上构建了带规划模块与 ReAct 决策的 Ariadne Agent。在 TextWorld 文本游戏、NetHack 与多跳问答基准上，AriGraph 显著优于 full history、summarization、RAG、Reflexion、Simulacra 等记忆方案，超过 RL 基线并接近顶尖人类玩家；在 Musique/HotpotQA 上与 GraphRAG 等专用方法相当且成本低 10 倍以上，是'结构化记忆替代纯向量 RAG'的代表性工作。

问题

LLM Agent 在部分可观察的动态环境中执行长程任务时，现有记忆方案（完整历史、迭代摘要、RAG 向量检索）都是非结构化的：持有全部历史成本高且难以处理海量信息中隐藏的复杂逻辑，纯向量检索难以召回分散在记忆各处的相关信息，无法有效支撑推理、规划与探索。论文要解决如何为 LLM Agent 构建能随交互动态更新、同时整合结构化语义知识（semantic memory）与情节经验（episodic memory）的长时记忆/世界模型。

方法

AriGraph 记忆图由语义部分（LLM 从文本观察抽取的 (object1, relation, object2) 三元组作为顶点和边）与情节部分（存储原始观察的 episodic 顶点，用 episodic 边连接同一步抽取的所有三元组）构成。更新时先筛出与新观察相关实体的既有边，用专门提示词检测并替换过时三元组，再写入新知识。检索分两阶段：(1) 语义搜索用预训练 Contriever 模型对查询与边做嵌入相似度检索，并沿图做深度 d、宽度 w 可控的类 BFS 扩展；(2) 情节搜索按 episodic 顶点关联到的输入三元组数量（含 log 加权、单三元组观察零权重）打分取 top-k。Ariadne Agent 在此之上采用工作记忆 + 规划模块（生成/修订子目标序列并根据环境反馈调整）+ 遵循 ReAct 框架的决策模块的分工架构，并利用语义图中的空间关系扩展 'go to location' 导航动作与未探索出口检测（探索模式）。

关键结果

TextWorld 三类游戏（Treasure Hunt/Cleaning/Cooking）中，Ariadne 全面优于 full history、summarization、RAG、RAG+Reflexion、Simulacra 等记忆基线；基线无法解开 Treasure Hunt，Hardest 版本连第二把钥匙都找不到，而 Ariadne 约 50 步解开基础版，并能在 36 房间/7 钥匙加干扰物品的 Hardest 版本完成任务

在 Cooking RL 对比基准的 4 个难度级别上，Ariadne 全部超过 GATA、LTL-GATA、EXPLORER 等 RL 基线；GPT-4 full history 只解出前两级

人类对比：Ariadne 在所有任务上超过样本中的普通人类玩家，在 Cooking 与 Treasure Hunt 上接近最好人类成绩，Cleaning 上低于最好人类

NetHack 中，仅接收当前房间观察的 Ariadne [Room obs] 成绩与拥有整层记忆 oracle 的 NetPlay [Level obs] 相当

多跳问答（Musique/HotpotQA 各 200 随机样本）：GPT-4 版优于 ReadAgent (GPT4)、GPT-4 RAG、GPT-4 full context、GraphReader (GPT4)，与最优的 HOLMES 相当；GPT-4o-mini 版在 HotpotQA 上超过 GraphRAG、Musique 上略弱，且成本比 GraphRAG 低 10 倍以上

图谱增长率随 LLM 骨干模型质量提升而下降；图谱在探索期快速增长、熟悉环境后趋于饱和

创新点

与向量 RAG、Generative Agents/Simulacra（recency+importance+relevance 打分）、Reflexion（跨 trial 反思）、Voyager 等依赖技能库/摘要的记忆方案不同，AriGraph 把语义知识图谱与情节记忆统一在一张图中，用 episodic 边把观察挂接到语义三元组上，实现结构化与非结构化记忆的互联；与 GraphRAG、HOLMES、GraphReader 等面向静态文档的 KG-QA 方法不同，它面向交互式环境，支持基于新观察的三元组更新与过时知识替换，这是那些方法所缺乏的机制。
