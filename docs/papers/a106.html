Large Language Models Can Be Easily Distracted by Irrelevant Context

大语言模型（LLM）容易被无关上下文干扰

简介

论文研究 LLM 的'易分心'问题：现有评测基准中输入信息通常全部与解题相关，而真实任务的上下文往往混有无关内容。作者构建 GSM-IC 基准，在 GSM8K 小学数学题上用模板追加一条经人工验证不影响标准答案的无关句子（按主题相关性、角色名重叠、数值范围三个正交因子组合生成），共 58,052 例，并提出 micro/macro accuracy 两个指标，系统评测 COT、0-COT、LTM、PROGRAM 等主流提示技术。关键结论：仅加一条无关句子就使各技术性能大幅下降，多数基础题无法在干扰下稳定解出；LTM 最稳健，self-consistency、在示例中加入带干扰样例、以及添加'忽略无关信息'的指令均能显著缓解，且不损害干净数据集上的精度。对团队而言，这是上下文噪声鲁棒性评测与提示层抗干扰设计的直接参考。

问题

现有 LLM 评测基准中的问题描述通常只包含与解题相关的信息，与真实场景中上下文混有无关信息的情况不符；论文要量化 LLM 的 distractibility（被无关上下文干扰的程度），即无关信息如何影响模型解题准确率，并寻找无需训练或微调的缓解策略。

方法

构建 GSM-IC 数据集：从 GSM8K 选取 100 道基础题（2-7 步推理），用模板法为每题追加一条经人工验证不影响标准答案的无关句子，按主题（in-topic/off-topic）、角色名是否与原题词汇重叠、数字是否在合理范围三个正交因子组合生成，全量 58,052 例，采样 4,000 例（GSM-IC-4K）评测；提出 micro accuracy 与 macro accuracy 两个指标；系统评测 COT、0-COT、LTM、PROGRAM 及 self-consistency（SC），并对比三种提示层缓解手段：在 few-shot 示例中加入带无关上下文的样例、在提示前加入 'Solve grade school math problems. Feel free to ignore irrelevant information given in the questions.' 的 instructed prompting、以及 SC 多数投票；另在 DROP 数据集上验证指令的泛化性。

关键结果

在 GSM-IC-4K 上，所有被测提示技术（COT、0-COT、LTM、PROGRAM，含/不含 SC）相比原始 GSM8K 均出现显著性能下降；macro accuracy 降幅尤其大，少于 30% 的基础题在加入干扰后仍能被稳定解出

self-consistency（20 样本多数投票）将整体 micro accuracy 提升超过 11 个百分点，其中 0-COT 提升 35.5 个百分点；COT 与 LTM 的 20 个采样中含正确答案的比例为 99.7%，0-COT 为 96.5%，但所有技术中最佳 macro accuracy 仅为 45%

LTM 是对无关上下文最稳健的技术：使用 code-davinci-002 时 macro accuracy 约为 COT 的两倍，且在不同推理步数下表现一致；COT 与 PROGRAM 在 4 步以上题目上降幅显著

在 few-shot 示例中加入带无关上下文的样例一致优于无干扰原始示例，且在原始 GSM8K 与 SVAMP 上不造成精度下降（PROGRAM 提示在 SVAMP 上甚至有提升）

加入指令 'Feel free to ignore irrelevant information given in the questions.' 一致提升 COT、LTM、PROGRAM 性能；仅加 'Solve grade school math problems.' 无显著效果；instructed prompting 配原始示例可达到甚至超过带干扰示例的无指令提示

4-exemplar COT 提示在原始 GSM8K 开发集上更优，但在 GSM-IC 上比 1-exemplar 提示更易被干扰，尤其在超过 2 步推理的题目上；使用指令后两者在 2 步题上几乎无差别（79.0 vs 79.2）

无关句子为 in-topic、角色名与原题词汇重叠、数字在合理范围内时最具干扰性；在 DROP football split 上，抗干扰指令一致提升 COT 与 LTM 性能

创新点

与以往通过改写/替换原题句子构造扰动基准的工作不同，GSM-IC 保留原题全部句子、只追加一条确保不改变标准答案的无关句子，从而纯粹度量'分心'而非语义改变；与需要微调才能抗噪的先前方案（如 knowledge-aware finetuning）不同，本文证明仅靠提示层手段（带干扰示例、忽略无关信息的指令、self-consistency）即可显著缓解，且不损害干净数据集上的精度；此外还揭示了示例数量增多可能降低提示鲁棒性这一反直觉发现。
