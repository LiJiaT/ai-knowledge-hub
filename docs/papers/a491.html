Language Models Are Greedy Reasoners: A Systematic Formal Analysis of Chain-of-Thought

语言模型是贪婪的推理者：对 Chain-of-Thought 的系统性形式化分析

简介

论文针对现有基准只能通过数学推理等下游任务的答案准确率间接衡量 LLM 推理能力、无法判断模型是否真正依赖所生成的思维链（CoT）这一问题，构建了由一阶逻辑世界模型生成的合成问答数据集 PRONTOQA，使模型预测的 CoT 可被语义解析为符号化证明并逐步形式化检验。作者在 INSTRUCTGPT 与 GPT-3 上系统控制本体类型（true/false/fictional）、证明跳数与遍历方向等变量，共开展 48 组实验。关键结论：最大模型能高质量完成单步演绎（fictional 本体 5-hop 实验中 93.2% 的步骤为 canonical），但在多条有效推理路径可选时缺乏 proof planning 能力，misleading step 是错误的主要来源；self-consistency 与 DFS 式示例提示均无法显著改善（0.56/0.55 vs 0.545）。此外，label accuracy 与 strict proof accuracy 相关性差，最宽松的 valid proof accuracy 才与标签准确率最相关，为 CoT 评测指标选择提供了直接依据。

问题

现有基准通过数学推理等下游任务的答案准确率间接衡量 LLM 推理能力，无法确定模型是真正依据生成的 chain-of-thought 逐步推理，还是依赖预训练知识检索或启发式捷径猜出答案；需要一种能对预测 CoT 逐步形式化检验的系统方法来直接度量推理能力。

方法

构建合成 QA 数据集 PRONTOQA：先从一阶逻辑本体生成证明，再用简单语法将本体与证明翻译为自然语言问题与 CoT，使预测的 CoT 可通过递归下降解析还原为符号逻辑形式并逐步对照 gold proof 检验；将每个证明步骤按 valid/invalid、atomic/non-atomic、misleading/correct 三个维度分类，并提出 strict/skip/broad/valid proof accuracy 等指标；通过控制 hop 数（1/3/5）、本体遍历方向（top-down/bottom-up）与本体类型（true/false/fictional）等变量，在 INSTRUCTGPT 与 GPT-3 系列模型上以 8-shot CoT prompting 加 greedy decoding 系统实验，并附加 self-consistency prompting 与含 DFS 搜索轨迹示例的提示做泛化验证。

关键结果

只有最大的模型 text-davinci-002 能显著优于随机水平；模型规模从 350M 增至 1.3B、6.7B 时 proof accuracy 明显提升，invalid 步骤频率随规模增大而下降

fictional 本体 5-hop 实验中，canonical（严格有效且原子的）步骤占全部预测步骤的 93.2%

5-hop top-down 场景下模型准确率降至随机水平，1-hop 与 3-hop 表现较好

true 本体（符合现实世界知识）下模型表现显著更好，且 hop 数从 3 增至 5 性能不下降，说明推理高度依赖预训练世界知识

label accuracy 与 strict proof accuracy 相关性差，与最宽松的 valid proof accuracy 相关性最高

错误证明中第一个非 canonical 步骤最常为 strictly-valid atomic misleading step，是最强模型推理错误的主要来源

self-consistency prompting（40 个采样、temperature 0.7）valid proof accuracy 为 0.56，DFS 示例提示为 0.55，相比基线 0.545 均无显著差异

正确证明中也含 misleading/invalid 步骤，模型有时能返回 gold proof；偏离正确路径越久，返回可能性越低

创新点

与 PROOFWRITER、FOLIO 等仅按预测标签评测的数据集不同，本文直接将预测的 CoT 解析为符号证明并逐步形式化检验（同时度量 local 与 global correctness），并系统控制 true/false/fictional 本体、hop 数、遍历方向等既有数据集中不可控的变量；首次指出 misleading step（而非 invalid step）是强模型推理错误的主因，并证明 label accuracy 并非可靠的推理能力度量。
