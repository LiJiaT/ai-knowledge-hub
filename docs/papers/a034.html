MemoryBank: Enhancing Large Language Models with Long-Term Memory

MemoryBank：以长期记忆增强大语言模型

简介

LLM 本身缺乏跨会话的长期记忆，在个人陪伴、心理咨询、秘书助理等需要持续交互的场景中无法召回历史对话、也难以随时间理解与适应用户个性。论文提出 MemoryBank，一种外挂式长期记忆机制，包含三部分：带时间戳的对话存储与分层事件摘要/用户画像（记忆存储）、基于双塔稠密检索与 FAISS 的记忆检索，以及受 Ebbinghaus 遗忘曲线启发的记忆更新机制（按时间衰减、被召回则强化）。作者据此构建 AI 陪伴聊天机器人 SiliconFriend，先用 38k 心理对话数据对开源模型做 LoRA 微调，再接入 MemoryBank，适配 ChatGPT、ChatGLM、BELLE 三种骨干。定量评测用 ChatGPT 模拟 15 个虚拟用户、生成 10 天对话并人工编写 194 个记忆探测问题，按检索准确率、回答正确性、上下文连贯性人工打分；结果显示 SiliconFriend ChatGPT 综合最佳，开源版本检索准确率也高。对团队而言，这是'存储-检索-更新'式 Agent 记忆系统的代表性参考实现。

问题

LLM 缺乏长期记忆机制，在需要持续交互的场景（个人陪伴、心理咨询、秘书助理等）中无法维持长程上下文理解、召回历史交互信息，也无法随时间理解并适应用户个性，限制了性能与用户体验。

方法

MemoryBank 由三大组件构成：(1) 记忆存储：以时间戳记录多轮对话，并用 LLM 提示词将对话压缩为日级事件摘要再合成全局摘要，同时每日推断用户性格与情绪并聚合为全局用户画像，形成多层记忆结构；(2) 记忆检索：采用类 DPR 的双塔稠密检索，将每轮对话与事件摘要预编码为向量并用 FAISS 索引，以当前对话为 query 检索最相关记忆，实践中用 LangChain 编排，英文用 MiniLM、中文用 Text2vec 作为 embedding（可替换）；(3) 记忆更新：受 Ebbinghaus 遗忘曲线 R=e^(-t/S) 启发，记忆强度 S 初始为 1，记忆被召回时 S 加 1 且 t 归零，从而按时间流逝与召回次数实现选择性遗忘与强化。基于此构建 SiliconFriend：第一阶段用 38k 心理对话数据以 LoRA（rank=16，3 epochs，A100）微调开源模型 ChatGLM 与 BELLE；第二阶段接入 MemoryBank，检索到的相关记忆、全局用户画像与全局事件摘要被组织进对话 prompt 生成回复。

关键结果

定量评测构建了 10 天、15 个虚拟用户（由 ChatGPT 扮演）的模拟对话记忆存储，人工编写 194 个记忆探测问题（英文 97、中文 97）

SiliconFriend ChatGPT 在记忆检索准确率、回答正确性、上下文连贯性等所有指标上综合表现最佳

SiliconFriend BELLE 与 SiliconFriend ChatGLM 在检索准确率上同样表现较高，验证 MemoryBank 对开源与闭源 LLM 的通用性，但其余指标不及 ChatGPT 版本

模型表现因语言而异：ChatGLM 与 ChatGPT 版本在英文上更好，BELLE 版本在中文上更优

创新点

区别于此前的记忆增强网络（如 Neural Turing Machines 等外部记忆矩阵方法）与多会话长程对话数据集工作，MemoryBank 是面向闭源与开源 LLM 的外挂式记忆机制：将 Ebbinghaus 遗忘曲线理论引入 LLM 记忆更新，实现基于时间与召回次数的拟人化选择性遗忘与强化；同时以分层事件摘要与动态用户画像构建多层记忆结构，并兼容 ChatGPT/ChatGLM/BELLE 等可互换的模型骨干与 embedding 模型。
