Thought Propagation: An Analogical Approach to Complex Reasoning with Large Language Models

Thought Propagation：一种基于类比的 LLM 复杂推理方法

简介

现有 prompting 方法（IO、CoT、ToT）都让 LLM 从零开始推理，既无法复用解决相似问题的经验，也会在多步推理中累积中间错误。论文提出 Thought Propagation（TP）：先让 LLM 提出并求解一组与输入问题相关的 analogous problems，再由聚合模块复用这些解——或直接生成新解并与初始解择优，或提炼知识密集型 plan 供 Agent 在每轮决策中携带执行；框架由 LLM Propose、LLM Solve、LLM Aggregate 三个模块构成，可即插即用叠加在 IO/CoT/ReAct 之上，无需微调、不依赖外部知识库。在 Shortest-path Reasoning、Creative Writing 与 ALFWorld LLM-Agent Planning 三个任务上，TP 分别取得最优解率平均 12% 绝对提升、人类偏好 13% 提升、任务完成率 15% 提升；1 层 TP 即可以与 ToT 相近的 token 开销取得强结果，2 层收益边际但开销增加。

问题

现有 prompting 方法（IO、CoT、ToT 等）均让 LLM 从零开始（reason from scratch）推理，存在两个问题：一是无法复用解决相似问题的洞察与经验作为先验知识；二是在多步推理任务中对中间步骤的错误敏感，误差会累积并误导后续搜索与规划，最终导致无效的推理结果（论文展示在最短路任务中 IO/CoT/ToT 均找不到最优路径，ToT 甚至反向搜索、重复访问节点）。

方法

提出 Thought Propagation（TP）类比推理框架，包含三个模块：LLM Propose 用 few-shot 示例或 zero-shot 提示让 LLM 生成与输入问题相关、解可复用的 analogous problems；LLM Solve 用现有 prompting 方法（IO、CoT，Agent 场景用 ReAct）求解输入问题与类比问题，得到初始解；LLM Aggregate 聚合类比问题的解，通过两条路径增强：一是基于类比解直接生成输入问题的新解并与初始解评估择优，二是对比输入问题与类比问题、提炼知识密集型高层 plan，供 LLM 在长程规划的每轮决策中携带执行。支持 K 层堆叠做层级化修正（K=0 即退化为 IO/CoT/ToT），即插即用、无需微调、不依赖外部知识库。

关键结果

Shortest-path Reasoning（100 个生成图，PaLM 2/GPT-3.5/GPT-4 三后端）：相比 IO/CoT/BaG/ToT 基线，找到最优路径的平均绝对提升 12%，且可行路径最接近最优（Over-Length Rate 最低）

Creative Writing（100 个测试实例）：在 GPT-3.5 与 GPT-4 上 coherent score（GPT-4 打分）最高，用户研究中人类偏好提升 13%

LLM-Agent Planning（ALFWorld 134 个环境）：任务完成率提升 15%；无记忆模块的 TP-SE/TP-SM 也取得大幅领先；6 轮试验成本约 300-400 美元，与 Reflexion 相当

复杂度分析：1 层 TP 以与 ToT 相近的 token 开销取得有竞争力的性能；2 层 TP 相比 1 层收益边际但 token 开销明显增加

即插即用性：TP+CoT（1/2 层）在 GPT-3.5 上显著优于 CoT；换用 Edge Description / Graph Modeling Language 图编码时仍有超过 10% 的最优路径绝对提升

创新点

据作者所述，这是首个面向 LLM 复杂推理的通用问题类比框架（此前类比推理方法依赖参数化网络或大规模外部知识库）。与三类相关工作的区别：(1) IO/CoT/ToT 等均从零推理，不能复用相似问题的解；(2) 检索增强 LLM 需查询十亿级 token 的外部数据库，TP 不依赖外部库、由 LLM 在推理过程中自行提出类比问题；(3) Reflexion 等 self-refinement 方法只反思同一任务的失败经验，TP 则聚合其他相似任务的成功经验来制定 plan，且无需记忆模块也能取得大幅提升。
