Combining Knowledge Graphs and Large Language Models

简介

这篇综述收集并系统分析了 28 篇 Knowledge Graph（KG）与 LLM 结合的研究，回答三个研究问题：KG 如何增强 LLM、LLM 如何支持 KG、二者更联合的结合是否带来更多优势。作者将方法分为三类：KG 赋能 LLM（把检索到的 KG 事实注入 prompt、用 GNN 提供推理路径以提升可解释性、注入实体语义表示）、LLM 赋能 KG（时序知识图谱预测、LLM 辅助 KG 构建与校验）、以及融合文本与知识 embedding 的混合架构（ERNIE、KnowBERT 等），并提出 Add-ons 与 Joint 两种交互模式的主题分析框架。关键结论是：现有工作大多把 KG 或 LLM 当作附加组件使用，更联合的结合在语义理解类任务上收益更大；KG 接地可缓解幻觉并增强可解释性，但存在 KG 领域覆盖有限、参数规模与运行时间增大、知识易过时、知识整合效率低等局限。对团队而言，其中 KG-RAG 式知识注入与 LLM 辅助 KG 构建两条线与知识库问答场景和可靠性保障直接相关。

问题

LLM 的知识冻结在训练参数中，存在幻觉、缺乏领域特定知识、决策过程不透明等问题；另一侧 KG 的构建困难、昂贵、耗时（涉及实体抽取、知识融合、指代消解等步骤），且领域专用、易随知识演化而过时。论文要系统梳理 KG 与 LLM 如何相互弥补：KG 如何增强 LLM（RQ1）、LLM 如何支持与增强 KG（RQ2）、更联合的结合方式是否带来更多优势（RQ3），并总结关键趋势、创新技术与共性挑战。

方法

对 arXiv 近五年相关文献做 quick review（检索窗口为 2024 年 2 月至 5 月），筛选 28 篇同时涉及 LLM 与 KG 的原创研究，按三大类组织并比较：(1) KG 赋能 LLM——知识注入（KAPING、KICGPT、DRAK 等将检索到的 KG 事实加入 prompt；Knowledge Solver 教 LLM 多跳遍历 KG 进行推理）、提升可解释性（QA-GNN、LMExplainer 用 GNN/图注意力给出推理路径）、语义理解（LUKE 实体感知自注意力、R3 树状搜索使推理可验证）；(2) LLM 赋能 KG——时序知识图谱预测（Chain-of-History、基于 ICL 的少样本预测）、KG 构建（BertNet 从 LLM 抽取任意关系 KG、Kommineni 等基于 ChatGPT-3.5 的半自动 pipeline、AutoRD、TKGCon）与 KG 校验（事实核查、不一致检测）；(3) 混合方法——文本与知识 embedding 融合（ERNIE、CokeBERT、KnowBERT、KRISP）。最后提出 Add-ons vs Joint 的主题分类并讨论优势与局限。

创新点

与以往综述不同：早期综述只关注 KG 作为知识源注入 LLM，或把 LLM 仅当作 KG 构建中的信息抽取器；本文双向覆盖 KG→LLM 与 LLM→KG 的互补收益，并首次提出 Add-ons 与 Joint 两种交互模式的主题分析框架（作者称此角度此前未被其他论文探讨），系统比较三类结合方式的优势与局限。
