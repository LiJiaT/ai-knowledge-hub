Improving Language Model Negotiation with Self-Play and In-Context Learning from AI Feedback

通过自我博弈与 AI 反馈的 In-Context Learning 提升语言模型谈判能力

简介

论文研究多个 LLM 能否在最少人工干预下通过自我博弈相互改进：两个 Agent 分别扮演买卖双方议价，第三个 LLM 充当 critic 在每轮后给出自然语言改进建议，玩家把历史对话与 AI 反馈作为 in-context demonstrations 迭代优化策略（ICL-AIF），另由 moderator LLM 判定 ON-GOING/DEAL/NO DEAL 状态。关键结论：只有 gpt-3.5-turbo、gpt-4、claude-v1.3 能多轮持续改进，弱模型要么不理解规则要么无法吸收反馈；买方比卖方更难改进；成交价提升伴随成交率下降的 tradeoff；AI 反馈效果与人工反馈相当但更可扩展。对团队而言，critic-player 反思回路、失败案例驱动的提示优化技巧、以及'规则理解-反馈吸收-持续改进'三能力的模型分层评测思路，都可直接迁移到 Agent 自动化流程的构建与评测中。

问题

研究多个 LLM 能否在类似 AlphaGo Zero 的自我博弈中以最少人工干预相互改进：具体设定为两个 LLM 分别扮演买方与卖方进行议价博弈，第三个 LLM 充当 critic 提供自然语言反馈，考察哪些模型具备理解博弈规则、响应 AI 反馈、跨多轮持续改进策略的能力，并以成交价衡量改进效果。

方法

提出 ICL-AIF（In-Context Learning from AI Feedback）：买卖双方以固定开场价（卖方 $20、买方 $10）开始议价，成交价限定在 [$10, $20] 区间；每轮结束后由与玩家同引擎的 critic 给出 3 条自然语言改进建议，玩家将全部历史对话与收到的反馈作为 in-context demonstrations 拼入下一轮提示，对手则清空历史重新开始；另设第四个 LLM（gpt-3.5-turbo）作为 moderator，基于最近 4 轮对话与 few-shot 示例分类 ON-GOING/DEAL/NO DEAL 状态，并把误判案例修正后持续追加为示例；除 moderator 外不做提示工程，以成交价与成交率为指标，基础实验 500 次、多轮实验 200 次 × 最多 5 轮。

关键结果

能力分层：仅 gpt-3.5-turbo、gpt-4、claude-v1.3 能多轮持续改进；cohere-command 不理解议价规则（作为卖方拒绝 $10 却接受 $8），j2-jumbo-instruct 不响应 AI 反馈，claude-instant-v1.0 最多改进一轮

AI 反馈与人工反馈提升幅度相当（各 500 次运行对比），但 AI 反馈更可扩展

角色差异：claude-instant-v1.0 与 gpt-3.5-turbo 作为卖方可改进、作为买方平均成交价不改进，买方更难改进

多轮设置（200 次 × 最多 5 轮）：只有 gpt-4 能改进满 5 轮，其他模型约 3 轮饱和

tradeoff：卖方提价伴随成交成功率持续下降；gpt-4 作为买方取得最低成交价与最高成交率的最佳平衡

策略性：gpt-4 比 claude-v1.3 用词更少但成交价与成交率更优，说明其冗长更具策略性

成本：gpt-4 跑 500 轮约 $120，gpt-3.5-turbo 约 $10

moderator 通过追加修正后的误判案例作 few-shot 示例，状态分类准确率达约 90+（人工检查）

创新点

相对 AlphaGo Zero 引入了第三个合作型 critic Agent，且反馈为自然语言而非标量奖励；相对 RLHF 无需训练/微调，通过 in-context learning 实现改进且反馈是自然语言；相对 Generative Agents、CAMEL 等并发多 Agent 工作，具有明确可量化的优化目标（成交价）；将 Lewis et al. 基于 RNN 的议价工作升级到 LLM 引擎，并系统刻画了不同模型在规则理解、反馈吸收、持续改进上的能力分层。
