Agent psychometrics: Task-level performance prediction in agentic coding benchmarks

简介

论文针对 agentic coding 评测的痛点：总体 pass rate 掩盖了基准内任务的多样性，且任务级评测数据昂贵（SWE-bench Verified 单次评测约 $350-$500），提出基于 Item Response Theory (IRT) 的任务级成功概率预测框架。方法上将任务难度参数化为从 problem statement、repository state、test cases、gold patch 提取的特征向量（embedding 与 LLM-as-a-judge 两种编码），并把 Agent 能力分解为 LLM 与 scaffold 两个可加分量，从而聚合异构 leaderboard 数据，泛化到未见任务与未见 LLM-scaffold 组合。在 SWE-bench Verified/Pro、Terminal-Bench 2.0、GSO 四个基准上，各泛化设置均显著优于 baseline，New Agents 设置接近 oracle；结合 computerized adaptive testing (CAT) 自适应选题，IRT-Agent 先验使新 Agent 在约 10 个任务内即达到随机选题需积累的初始估计精度。对团队而言，这是'评测保障'方向的直接方法参考，可用于内部 Agent 评测集难度校准、新模型/新 harness 的低成本评估与 scaffold 能力量化。

问题

当前 Agent 评测通常只报告基准上的总体 pass rate，掩盖了基准内任务的多样性；而任务级成败数据的获取昂贵（SWE-bench Verified 单次评测 $350-$500），且最需要任务级理解的场景——新发布、尚未在任何基准上测试的 Agent，以及尚无 Agent 尝试过的草稿基准——恰恰没有任何评测数据。论文要解决的核心问题是：如何在 agentic coding 基准中高效预测 Agent 在单个任务上的成败，包括对没有评测数据的任务和 LLM-scaffold 组合进行泛化预测。

方法

扩展 Item Response Theory (IRT)：标准 IRT 把任务和 Agent 当作 one-hot ID，无法泛化到未见对象。本文将任务难度 β 参数化为任务特征向量的线性函数，特征来自两类编码——用 DeepSeek-R1-Distill-Qwen-32B 提取的 embedding，以及用 Claude Opus 4.6 按固定 rubric 打分的 15 个 LLM-as-a-judge 特征（repository state 特征由 GPT-5.4 扮演 auditor agent、以 ReAct 式 bash/Python scaffold 在 InspectAI 框架中探索任务沙箱后提取）；训练采用两阶段流程：先用 SVI（带 hierarchical priors）拟合标准 IRT，冻结难度后用 ridge regression 从特征预测难度。Agent 侧将能力分解为 LLM 能力与 scaffold 能力之和（无交互项），使多个基准的 leaderboard 可以'拼接'训练多基准 IRT 模型。应用上结合 computerized adaptive testing (CAT)：用 Fisher 信息选择下一个任务，以 IRT-Agent 预测能力作为 Gaussian 先验，通过 MAP 估计迭代更新，实现小样本高效评测。

关键结果

New Tasks 设置：四个基准上，embedding、LLM-as-a-judge 及二者拼接三类特征预测器的 AUC-ROC 均显著优于 baseline（5 折 CV、20 seeds，经 Holm-Bonferroni 校正后仍显著）

特征源消融：完整特征集在所有基准上显著优于仅用 problem statement 的预测器；GSO 上加入 solution 使 AUC 从 0.728 升至 0.774，SWE-bench Verified 上加入 test cases 使 AUC 从 0.797 升至 0.833

New Responses 设置：IRT-Agent 与 standard IRT 差异很小，在 Terminal-Bench 2.0 上统计不可区分，同时具备 standard IRT 不具备的对 held-out Agent 的泛化能力

New Agents 设置：对 held-out LLM-scaffold 组合的预测性能很强、接近 oracle；New Benchmarks 设置：优于 baseline 但距 oracle 仍远，只能作为粗略初估

CAT 应用：IRT-Agent 先验在未做任何任务前的平均绝对误差为 0.79，随机选题需约 10 个任务才能达到该精度；约 40 个任务后各方法收敛

分解验证：固定 scaffold (Terminus 2) 下学到的 agent 能力与分解出的 LLM 能力高度相关（Pearson r = 0.974）

多基准 IRT 学到的难度符合预期：SWE-bench Pro (mean β=0.407) 难于 SWE-bench Verified (mean β=-0.867)，GSO (mean β=2.907) 最难

创新点

相比 Truong et al. (2025)、Chen et al. (2025) 等仅用 problem statement embedding 线性预测 IRT 难度、且面向问答类任务的工作，本文首次针对 agentic coding 引入 repository state、test cases、gold patch 等任务工件特征，证明其提供 problem statement 之外的预测能力；并首次将 Agent 能力分解为 LLM 与 scaffold 的可加分量，使跨异构 leaderboard 的数据聚合与对新 LLM-scaffold 组合的泛化成为可能；训练上用两阶段（先 IRT 后 ridge regression）替代联合似然最大化并验证更优；还将 CAT 自适应评测扩展到 agentic coding 基准。
