Discrete Prompt Optimization via Constrained Generation for Zero-shot Re-ranker

基于约束生成的离散提示优化：面向零样本 Re-ranker

简介

LLM 作为零样本 re-ranker 对提示高度敏感，但此前针对 re-ranking 这类需要连续相关性分数输出的任务缺乏自动提示优化方法，人工搜索提示成本高且迁移性差。论文提出 Co-Prompt：把最优提示搜索转化为带约束的从左到右离散提示生成，用零样本 re-ranker 本身作 discriminator 计算提示最优性似然度量（采样文档-查询对上相关性分数的期望），用 decoder-only PLM 作 generator 采样高先验提示 token，经 beam search 迭代完成候选生成与评估，全程无需参数更新。在 T0/OPT 两种 LLM、MS-MARCO/NQ 两个数据集、BM25/DPR 两种检索器的全部组合中，Co-Prompt 一致优于 Manual Prompt、RL-Prompt、P-Tuning 等基线，且生成的提示人类可读、包含任务关键词 'question'。对团队而言，这是'用任务度量驱动的免训练自动提示优化'的可直接借鉴范式，尤其适用于 RAG 重排环节的提示调优与提示词资产管理。

问题

LLM 作为零样本 re-ranker（按与 query 的相关性分数对检索文档重排）性能高度依赖提示，但针对零样本 re-ranker 的提示影响与优化此前未被研究；人工搜索离散提示既昂贵又在迁移性上次优；已有自动离散提示优化方法主要面向文本分类或 mask-filling 任务，无法直接适用于 re-ranking 这类需要连续相关性分数的开放生成任务。

方法

提出 Co-Prompt，将最优提示搜索形式化为基于 discriminator 的约束生成（依据 Bayes 规则），包含两个模块：(1) discriminator——复用零样本 re-ranker 本身，计算提示序列的最优性度量，即在采样出的文档-查询对数据集 D_s 上相关性分数的期望似然 P_M(D_s|ρ)；(2) generator——任意 decoder-only PLM，以零样本方式采样具有高先验概率的提示 token，从而限制 discriminator 需评估的候选空间。两模块迭代执行候选生成与评估，采用 beam search 解码（beam width=10、最大提示长度=10、起始 token 为 'Please'），全程不更新任何模型参数。另探讨了对比式度量作为可选似然。

关键结果

在 T0 与 OPT 两种 LLM、MS-MARCO 与 NQ 两个数据集、BM25 与 DPR 两种检索器的全部组合上，Co-Prompt 在 ACC@20/ACC@100 等指标上一致优于 Null Prompt、P-Tuning、RL-Prompt、Manual Prompt 四个基线（正文称在所有场景均取得稳健提升，具体数值见表格、正文未列出）

在 Top-20 与 Top-100 的详细评测中，Co-Prompt 在所有实验的全部指标上均排名第 1 或第 2；针对 NQ 优化的 Manual Prompt 在 MS-MARCO 上表现较差，RL-Prompt 与 P-Tuning 在所有实验中均未取得最优

无论起始 token 取 'Please'、'Score' 还是 'This'，Co-Prompt 都能一致生成高效提示，但为数据集找到合适的起始 token 对取得更好结果很重要

基础度量在各数据集与 LLM 上均有稳定表现，而对比式度量在 MS-MARCO 上表现较差

Co-Prompt 生成的提示包含描述任务的关键词 'question'，比 RL-Prompt 产出的不可读乱码提示更符合人类语言模式、更可解释

创新点

与已有工作的区别：(1) 已有离散提示优化方法（如 RL-Prompt）需通过强化学习训练策略网络且产出不可读的乱码提示，P-Tuning 产出连续 soft prompt；Co-Prompt 无需任何参数更新或训练，通过 discriminator 引导的约束生成直接搜索离散提示；(2) 已有优化方法主要考虑文本分类或 mask-filling 任务，本文首次针对 re-ranking 这类需要连续相关性分数的任务定义了提示最优性度量（文档-查询相关性分数期望）；(3) 生成的提示符合人类语言模式，可作为理解黑盒模型的自然用户界面。
