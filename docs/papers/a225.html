aiXiv: A Next-Generation Open Access Ecosystem for Scientific Discovery Generated by AI Scientists

简介

论文针对 AI 生成的科研提案与论文缺乏合适发表渠道、传统人工同行评审难以扩展且普遍排斥 AI 内容的问题，构建了 aiXiv——一个面向人类与 AI 科学家的开放获取平台。平台采用多智能体架构，通过 API 与 MCP 接口接入异构 Agent，实现投稿、评审与迭代修订的闭环流程；评审框架包含 Single Review、Meta Review（动态创建领域评审 Agent 并由 Chair 汇总）与 Pairwise Review，评审 Agent 通过 RAG（Semantic Scholar API）做有据评估，并配套五阶段 Prompt Injection 检测防御管线和五个高性能 LLM 投票的录用机制。实验显示 GPT-4.1+RAG 的提案成对评估准确率达 77%（超过基线 71%）、论文级达 81%，注入检测准确率 84.8%~87.9%；修订后提案录用率从 0% 升至 45.2%，论文从 10% 升至 70%。对本团队而言，其闭环 review-refine 流水线、RAG 有据评审、多模型投票降偏、结构化 JSON 评审提示与注入防御等做法可直接迁移到 AI 代码审查、文档质量评估等工程场景。

问题

AI Agent 已能自主生成科研提案、开展实验、撰写论文并进行评审，但 AI 生成研究内容面临发表生态割裂的困境：传统期刊会议依赖人工同行评审、难以扩展且不愿接受 AI 生成内容，arXiv 等预印本服务器缺乏严格质量控制，导致大量高质量 AI 生成研究缺乏传播渠道；同时现有 LLM 评审系统存在幻觉反馈、易受 prompt injection 攻击、缺乏有据评估与闭环迭代机制等缺陷。

方法

构建 aiXiv 多智能体开放平台：(1) 通过 API 与 MCP（Model Control Protocol）层编排作者、评审、meta-reviewer 等异构 Agent， accepted 提交分配 DOI 并记录 IP 归属；(2) 评审框架含 Single Review（四维度结构化反馈）、Meta Review（Area Chair/Editor Agent 先识别子领域并动态创建 3-5 个领域评审 Agent，再汇总冲突产出 meta review）与可选的 Pairwise Review（对比修订前后版本），评审 Agent 通过 RAG 接入 Semantic Scholar API 做有据评估；(3) 五阶段 Prompt Injection 检测与防御管线：PDF 内容与版面元数据提取、规则粗筛（关键词/白色文字/零宽字符）、LLM 语义细查与多语言交叉验证、攻击分类、风险打分与阈值决策；(4) 五个高性能 LLM 独立评审并多数投票（3 票以上 accept）决定录用，先标记 Provisionally Accepted，待外部评审充分后升级为 Accepted。

关键结果

提案级成对评估：GPT-4.1+RAG 在 ICLR 2024 数据集上达到 77% 准确率，显著优于基线方法（Si, Yang, and Hashimoto 2024）的 71%

论文级成对评估：在 ICLR 数据集上达到 81% 准确率

Prompt injection 检测：合成对抗数据集上准确率 84.8%，真实可疑样本集上 87.9%

评审-修订闭环效果：超过 90% 的修订版提案经成对比较被评为优于原版，附 response letter 时接近 100%；10 篇修订论文中超过 90% 被偏好，附 response letter 时达 100%

多模型投票录用率：提案从修订前 0% 提升至修订后平均 45.2%；论文从 10% 提升至 70%

创新点

与现有工作相比：传统期刊/会议依赖人工评审且多拒绝 AI 作者身份，arXiv 等预印本服务器缺乏质量控制；Agents4Science 让 AI 同时担任作者与评审但缺少修订/rebuttal 环节；DeepReview、CycleResearcher 等评审系统多为一次性流程，存在幻觉反馈、易受 prompt injection 攻击、缺乏有据评估的问题。aiXiv 的区别在于首次将闭环 review-refine 迭代、RAG 有据评审、prompt injection 检测防御、五模型投票录用与 MCP/API Agent 接入整合为统一开放生态，并同时覆盖提案与论文两类投稿。
