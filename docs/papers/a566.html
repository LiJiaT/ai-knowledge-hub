Large Language Models Vote: Prompting for Rare Disease Identification

Large Language Models 投票：面向罕见病识别的提示方法

简介

罕见病数据稀缺，从临床笔记（Clinical Notes）中识别罕见病天然是 Few-Shot Learning 场景，而现有提示方法（IP、CoT、SC）都只依赖单一模型。论文提出 Models-Vote Prompting（MVP）：按各模型预训练格式分别校准并融入 CoT 的提示，并行查询多个 13B 开源 LLM（Llama 2、MedAlpaca、Stable Platypus 2、Vicuna），再对输出做多数投票，思路类似 Random Forest 集成，区别于 SC 对同一模型重复采样。同时基于 MIMIC-IV 构建了含 4 种罕见病、256 篇两轮人工标注（Cohen's kappa 0.839）的可复现数据集，并用 JSON 增强提示让模型输出可解析结构以支持自动化评测。结果显示 MVP 在 32/64/128/256 词四种上下文的识别任务上全面最佳且统计显著（p<0.05），分类任务与 SC prompting 相当互有胜负；约 85.9% 的输出无需人工标注即可自动评测；消融发现移除弱模型 MedAlpaca 后性能不降反略升，说明集成成员选择本身是超参数。

问题

罕见病数据稀缺且人工收集标注昂贵，从临床笔记中识别罕见病天然需要 Few-Shot Learning 技术；现有提示方法（IP、CoT、SC）均基于单一模型，缺乏结合多个 LLM 知识的提示方法；同时面向 NLP 的罕见病数据集稀缺，且生成式 LLM 输出的评测依赖昂贵耗时的人工标注。

方法

提出 Models-Vote Prompting（MVP）：用 m 个不同 LLM 对同一任务各自生成回答，再对输出做多数投票选取最频繁答案，类似 Random Forest 的多学习器集成；与 SC 对同一模型多次采样不同，MVP 聚合的是在不同数据集上预训练的多个模型的知识。提示按各模型预训练格式分别设计并融入 CoT（如 Llama 2 使用其专属标签）。数据集方面，用 SPARQL 从 Orphanet ORDO 抽取罕见病术语，用 Rust+rayon 并行术语匹配 MIMIC-IV 的 331,794 份出院小结，叠加弱监督规则（词长≥4、出现率≤0.5%）过滤，最终选取 4 种罕见病并进行两轮人工标注。另提出 JSON 增强提示，使模型输出可解析 JSON 字符串，从而自动化评测并减少人工标注。

关键结果

罕见病识别任务：MVP 在全部四个上下文长度上取得最佳 APRF——32 词 (0.66, 0.66, 0.65, 0.65)、64 词 (0.70, 0.72, 0.69, 0.69)、128 词 (0.62, 0.62, 0.61, 0.60)、256 词 (0.68, 0.67, 0.67, 0.67)，且在所有上下文规模上超过 Llama 2 (SC Prompting)

识别任务中 MVP 与次优模型的配对 t 检验均统计显著（p 值分别约为 7.437e-9、1.600e-2、2.928e-7、7.979e-13，均小于 0.05）

罕见病分类任务：MVP 与 Llama 2 (SC Prompting) 总体最佳；MVP 在 64 词上下文最佳 APRF (0.81, 0.75, 0.65, 0.69)，但 32 词与 256 词上下文分别被 Llama 2 (SC)（APRF (0.84, 0.78, 0.67, 0.72)）和 Stable Platypus 2（APRF (0.66, 0.76, 0.53, 0.61)）反超

JSON 增强提示使约 85.9% 的 4096 条模型输出无需人工标注即可自动评测；Llama 2 仅 33 条 JSON 格式错误，MedAlpaca 最差达 197 条

消融实验：从 ensemble 中移除单个模型通常降低性能，但移除表现最差的 MedAlpaca 后性能与原四模型 ensemble 相当或略有提升

两个任务中增大上下文规模（32→256 词）均导致性能下降，论文假设是更大上下文包含更多医学术语、歧义增加所致，但表示需进一步研究

标注质量：首轮 64 篇临床笔记标注的 Cohen's kappa 达 0.839

创新点

此前 IP/CoT/SC 等提示方法均只使用单一模型（SC 是对同一模型重复采样），本文首次提出跨多个 LLM 的集成投票提示方法，以 Random Forest 式多数投票聚合不同预训练数据背景的模型知识，并声称可在低算力硬件上用多个小模型逼近大模型效果；同时贡献了一个可复现的罕见病 FSL 标注数据集，并验证 JSON 结构化提示可实现生成式 LLM 的自动化评测。
