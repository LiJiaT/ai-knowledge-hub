Lift Yourself Up: Retrieval-augmented Text Generation with Self Memory

自我提升：基于 Self-Memory 的检索增强文本生成

简介

检索增强生成（RAG）通常从固定语料库检索记忆（memory）来辅助生成，但记忆质量受限于语料库本身，这种"有界记忆"限制了模型潜力。论文提出 Selfmem 框架，利用"更好的生成也能带来更好的记忆"这一对偶性：让检索增强生成器迭代生成无界记忆池，再由记忆选择器依据 BLEU/ROUGE 等无模型指标（而非生成器概率，以避免落入其置信区域、无信息增益）挑出一条输出作为下一轮生成的记忆，即用模型自身输出（self-memory）提升自身。方法同时覆盖微调小模型（Joint-Encoder/Dual-Encoder）与 few-shot 提示黑盒 LLM（XGLM）两种范式，检索采用 BM25。实验在机器翻译（JRC-Acquis 四个方向）、摘要（XSum 50.3 ROUGE-1、BigPatent 62.9 ROUGE-1）与对话生成上取得 SOTA，摘要任务上 BRIO 提升 +1.2 R1、BART 提升 +18.5 R1。进一步分析表明固定参数的生成器已能区分好坏记忆、当前瓶颈在记忆选择器；对 LLM 而言，更相似的 ICL 示例在所有模型规模上均显著提升少样本性能，但跨语言 LLM 仍不及监督基线。

问题

以往检索增强生成的记忆均从固定语料库中检索，受限于语料库质量（有界记忆），限制了记忆增强生成模型的潜力。论文定义"原问题"为更好的记忆带来更好的生成，并探索其对偶性——更好的生成也能带来更好的记忆——从而让模型利用自身输出作为记忆（self-memory）来迭代提升生成质量。

方法

提出 Selfmem 框架，含两个组件：(1) 检索增强生成器 Gξ，支持两种范式——微调小模型（Joint-Encoder 将 x 与 m 拼接输入，或 Dual-Encoder 双编码器双交叉注意力）或 few-shot 提示固定黑盒 LLM（以检索到的 (x, y) 作为 in-context 示例）；(2) 记忆选择器 Sθ，以源文本与候选的拼接为输入，用 KL 散度训练以拟合 BLEU/ROUGE 等无模型质量指标 Δ（刻意不用生成器概率 p(y|x)，因为 beam 记忆落在生成器置信区域内、无信息增益），从 beam search（宽度 50）产生的候选池中选出一条作为下一轮生成的记忆。检索用 BM25，迭代次数由验证集确定；选择器骨干为 XLM-R base（翻译）与 RoBERTa base（摘要/对话），并可通过更换 Δ 指标（如对话用 Distinct）直接优化目标属性。

关键结果

在 JRC-Acquis 四个翻译方向（Es↔En、De↔En）取得 SOTA；XSum 达 50.3 ROUGE-1，BigPatent 达 62.9 ROUGE-1

摘要任务上 self-memory 使 BRIO 提升 +1.2 R1、BART 提升 +18.5 R1，两个数据集均达 SOTA

对话生成（DailyDialog）上 self-memory 相比检索记忆在 BARTjoint 上提升 3.08 B-1 与 0.6 B-2；改用 D-1/2 作为 Δ 训练选择器可优化多样性

JRC-Acquis En→De 上检索记忆与参考的 n-gram 重叠为 38.89 BLEU，而模型自身输出达 58.58 BLEU；但直接把 beam 输出回填为记忆无提升，需经指标驱动的选择器筛选

增强的 memory selector 使两种生成器架构均显著超过当时 SOTA（60.11 BLEU），且 oracle 选择器下候选池的 oracle/四分位/平均/最低分随迭代持续改善

LLM 实验（XGLM 1.7B–7.5B）显示更相似的 ICL 示例在所有模型规模上均显著提升少样本翻译性能，但跨语言 LLM 仍不及监督基线

token 级频率分析显示含 self-memory 的检索增强模型在长尾输入上表现更优

创新点

与以往 reranking 工作的单向过程（选出的候选即最终输出）不同，Selfmem 将选出的候选作为下一轮检索增强生成的记忆，形成"生成→选择→更好生成"的迭代自提升闭环，且被选候选不必优于 beam 假设。论文首次指出检索增强文献中有界记忆的根本局限，用模型自身输出构建无界记忆池；记忆选择器采用无模型指标而非生成器概率，以保证记忆带来信息增益。
