Large Language Models Can be Lazy Learners: Analyze Shortcuts in In-Context Learning

大语言模型可能是'懒惰的学习者'：分析 In-Context Learning 中的捷径利用行为

简介

论文研究 in-context learning 的鲁棒性：LLM 在不更新参数、仅靠 prompt 中 few-shot 示例的条件下，是否会走'捷径'，利用示例中的表面相关性（shortcut-label 映射）而非语义理解做推理。方法上，作者向 prompt 示例注入与标签强相关的触发器（常见词、罕见词、符号、中性句子、Shakespeare/Bible 风格等），并构造 anti-shortcut 测试集，以性能下降幅度量化模型对捷径的依赖。关键结论：LLM 是'懒惰的学习者'，会系统性利用 prompt 中的捷径，且存在 reverse scaling 现象——模型越大性能下降越严重（GPT2-large 平均降 33.71% vs GPT2-base 1.04%）；触发器放在 prompt 末尾最易被捕获，仅出现一次即可被模型利用，而提高示例质量与更换模板均无法缓解。对团队而言，这提示 few-shot 示例中的格式伪影可能被模型当作判据，提示设计与评测都需主动防范。

问题

理解 in-context learning 的鲁棒性与泛化：LLM 在不更新参数、仅依赖 prompt 中 few-shot 示例的条件下，是否会利用 prompt 中的捷径/伪相关（shortcut-label 映射）而非语义理解来完成下游任务，以及哪些触发器与 prompt 因素会影响这种依赖。

方法

提出向 prompt 中的 few-shot 示例注入与目标标签强相关的触发器（字符级符号、常见/罕见词、中性句子、文本风格如 Shakespeare/Bible 风格），构造 anti-shortcut 测试集（对标签不同于触发器目标标签的测试样本注入触发器），用性能下降幅度量化模型对 shortcut 的依赖；通过消融实验系统分析触发器位置/格式/注入率/长度、shot 数量、示例质量与模板的影响；并采用 LIME 的 token 掩码重要性分析检测 prompt 中的 shortcut。

关键结果

GPT2-large 在 MR 数据集上，常见词 shortcut 导致 41.45% 性能下降（从 63.46% 降至 22.01%），低于 50% 的随机猜测水平

reverse scaling 现象：GPT2-large 在三个数据集上平均性能下降 33.71%，远大于 GPT2-base 的 1.04%；OPT 系列也随模型规模增大而下降加剧

消融实验：向 prompt 注入触发器后在原始测试集上性能变化小于 5%；原始 prompt 在 anti-shortcut 样本上性能差异小于 4%，证明性能下降主因是模型依赖 shortcut 而非触发器破坏语义

注入率 12.5%（触发器仅在 1 个示例中出现一次）造成的性能下降反而高于 50% 注入率，说明模型极少几次即可识别潜在 shortcut

增加 shot 数（2/4/6/8）可降低性能下降；OPT-1.3B/2.7B/6.7B 的最高下降出现在 2 shots，OPT-13B 出现在 4 shots

风格触发器（Bible、Shakespeare 风格）同样导致 anti-stereotype 测试集上明显性能下降，说明更隐蔽、贴近真实场景的 shortcut 也会被利用

信息抽取任务（ATIS-D、MIT-D）上 shortcut 触发器导致一致的性能下降，但幅度显著低于分类任务（作者归因于触发器位置不固定）

创新点

据作者所述，这是首个在非训练（无参数更新）设定下研究 shortcut learning 的工作，此前文献主要关注 fine-tuning 过程中的捷径学习；并首次揭示 in-context learning 中的 reverse scaling 现象，以及高质量 prompt 示例无法缓解 shortcut 影响这一与直觉相反的结论。
