Maieutic Prompting: Logically Consistent Reasoning with Recursive Explanations

Maieutic Prompting：基于递归解释实现逻辑一致的推理

简介

论文针对 LLM 解释式提示的固有缺陷：模型生成的解释常与推断答案矛盾，甚至对陈述及其否定给出相同标签，导致推理不可靠。Maieutic Prompting 让模型对 True/False 两个候选答案分别做 abductive 解释，并递归地把自身生成的解释当作新问题继续追问，构建一棵解释树；以 logical integrity（对陈述与否定的判断是否一致）筛选可信命题，用 belief/consistency 权重刻画命题间关系，再把最终答案推断转化为 weighted MAX-SAT 问题，由符号求解器给出全局一致的真值分配，可选接入小型 NLI 模型补充跨分支约束。在 Com2Sense、CSQA 2.0、CREAK 上，该方法较 CoT、Self-Consistency 等提示基线最高提升 20% 准确率，完全无监督即可比肩有监督模型，且对语义扰动和 few-shot 示例选择更稳健。对团队而言，它是'不信任单次生成、用结构化自检加符号校验换取可靠性'的代表性提示工程与可靠性方法。

问题

LLM 在解释式提示下推理缺乏逻辑一致性：模型生成的解释本身常是噪声且不可靠——解释推不出所推断的答案、对同一陈述及其否定给出相同标签、甚至自我推翻生成的解释——而已有方法把推断质量建立在单条解释的正确性之上。论文要解决的问题是：即使模型生成不可靠、自相矛盾，也能从中推断出正确且逻辑一致的答案。

方法

提出 Maieutic Prompting，一种无监督 few-shot 推理方法：(1) Abductive 解释生成——对同一问题分别以 True/False 为给定答案让模型事后合理化，生成双向解释而非单条解释；(2) 递归深度扩展——把生成的解释作为新问题递归提示模型，构建 maieutic 树，宽度上用 nucleus sampling 采样多条解释增加覆盖；(3) logical integrity 检验——检查模型对命题与其否定 ¬Q 的真值判断是否一致，到达 integral 命题即停止该分支，并剪枝非 integral 的叶子；(4) 关系量化——用 belief（模型对命题为真的置信）与 consistency（解释与答案标签的似然一致性）定义一元/二元逻辑约束，可选引入 NLI verifier（RoBERTa 在 MNLI 上微调，dev 准确率 90.2%）补充跨分支的蕴含/矛盾关系；(5) 符号推理——将所有命题的真值分配形式化为 weighted MAX-SAT（RC2 求解器），全局求解最满足约束的答案。实验使用 GPT-3（text-davinci-001）与 6 个示例，树最大深度 2、至多 18 个节点。

关键结果

在 Com2Sense、CSQA 2.0、CREAK 三个常识推理与事实校验基准上超过所有 few-shot 提示基线（Standard、CoT、Self-Consistency、GKP），最高提升 20% 准确率

是唯一在 Com2Sense 和 CREAK 上超过最小有监督基线 RoBERTa-large 的提示方法，整体与 billion 级有监督模型（T5、UnifiedQA、Unicorn）相当或更好

消融实验：去掉 abductive 生成准确率下降 4%（降至 68.4）；用 likelihood-based consistency 替代 NLI verifier 下降约 7%（降至 65.6）

鲁棒性：在 pairwise accuracy 与 contrast set accuracy 上与基线差距进一步拉大；在不同 few-shot 示例集合与示例排列下方差更小、更稳定

人工评测（Krippendorff's alpha=0.64）：超过 99% 的 true 解释语法完美；在答错的样本中，42% 的 true 解释完全符合事实、23% 完全有助于得出正确答案

树规模消融：深度/宽度增大后准确率在某个阈值后饱和，归因于生成的话题漂移与解释重叠；对比 GKP 与 Self-Consistency 采样 20 条解释，本方法用更少生成（至多 18 节点）取得更好效果

StrategyQA 多跳实验：加入问题分解后，Maieutic Prompting 仍优于 Standard 与 C-o-T 提示

创新点

与既有解释式提示（CoT、Self-Consistency、GKP）把解释'按原样'使用、或在答案层做多数投票不同，该方法不假设解释正确，而是显式建模解释之间的逻辑关系，并用符号求解器（weighted MAX-SAT）做全局一致的联合推断；双向 abductive 生成与递归自验证（depth-wise knowledge spanning）是对单跳解释采样的推广。相比此前需要人工标注的神经符号方法，它在完全无监督设定下泛化了 neuro-symbolic 路线，且解释本身作为内在（intrinsic）成分直接参与推断而非事后解释。
