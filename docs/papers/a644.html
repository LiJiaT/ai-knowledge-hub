Two Failures of Self-Consistency in the Multi-Step Reasoning of LLMs

LLM 多步推理中 Self-Consistency 的两类失败

下载原文 PDF

简介

论文指出，评价 LLM 多步推理不能只看正确率，还要看自洽性（self-consistency），并提出两类此前未被研究过的自洽性：hypothetical consistency（模型能否预测自己在另一上下文中的输出）与 compositional consistency（把中间子步骤替换为模型自身输出后，最终答案是否保持一致）。作者在文本补全预测、合成算术与 GeoQuery 语义解析任务上，对 GPT-3 各规格与 GPT-4 进行了系统评测。关键结论：小于 davinci-003 的模型在 hypothetical 一致性上接近随机；davinci-003 与 gpt4 在算术任务上的 compositional 一致率不足 50%，语义解析不足 65%；增加模型规模与 in-context 示例数量可改善一致性。对团队而言，这意味着多步 prompt 链或 Agent 流程中回填中间结果可能使最终输出漂移，评测体系中应加入一致性检验。

问题

LLM 在多步推理任务上的成功通常只以正确性（correctness）衡量，而缺乏对自洽性（self-consistency）的考察。论文要解决的问题是：定义并形式化对多步推理有效性至关重要的两类自洽性——hypothetical consistency 与 compositional consistency——并实证测量 GPT-3/GPT-4 系列模型在这两类一致性上的表现，以揭示 LLM 在组合式任务上泛化差的原因，为'是否可信任 LLM 在复杂组合任务上的输出'提供依据。

方法

论文基于语义等价关系 ∼ 与 prompt 模板替换算子 f 形式化定义两类一致性。Hypothetical 一致性：设计 4 个'预测自己输出'的 prompt 模板，将来自 Wikipedia 与 DailyDialog 的 prompt 转为假设性问题，用多选题方式（选项包含模型自身 greedy 解码补全、其他模型的补全与数据集原文续写）测量模型能否识别自己的补全，k-shot 取 1–10 并随机化选项顺序。Compositional 一致性：将复合 prompt 中的子表达式/子树替换为模型对该子步骤的输出，构造 compositional consistency prompts，在 400 个随机嵌套的合成算术表达式（最大嵌套深度 5）与 GeoQuery（400 条 FunQL 语义解析样本）上，对 ada-001/babbage-001/curie-001/davinci-001/davinci-003/gpt4 六个模型以 k=3–10 的 few-shot 提示测量一致率，并分析不一致来源及正确率与一致率的关系。

关键结果

hypothetical 一致性：所有小于 davinci-003 的 GPT-3 规格表现接近随机；davinci-003 是唯一持续高于随机的模型，但准确率仅 Wikipedia 26%–31%、DailyDialog 30%–37%

gpt4 在 DailyDialog 上需区分 6 个词时达到 59.9% 的 hypothetical 一致率，但在 Wikipedia 上仅 17.9%–27.4%

compositional 一致性：davinci-003 与 gpt4 表现最好，但在算术任务上一致率低于 50%，在 GeoQuery 语义解析任务上低于 65%

算术任务中 90% 的 compositional 不一致源于子表达式答案正确但最终答案与替换后 prompt 的答案不匹配；GeoQuery 约 59% 的不一致源于子树 parse 未被包含在父树 parse 中，约 41% 源于子节点 parse 本身错误

正确率与 compositional 一致率呈明显线性关系（除 davinci-001 外所有模型都略更正确而非一致）；随 in-context 示例数增加各模型在 GeoQuery 上一致性提升，gpt4 在算术任务上显著比 davinci-003 更一致

创新点

区别于已有工作将一致性定义为 paraphrase 等语义保持变换下的不变性（Elazar et al., 2021）或否定/对称/传递/可加等逻辑一致性（Jang et al., 2022），论文首次形式化并提出 hypothetical 与 compositional 两类新的逻辑一致性变换，指出其对多步推理有效性至关重要且此前未被研究过；并结合 Dziri et al. (2023) 关于 Transformer 在组合任务上误差随平均并行度指数增长的讨论，进一步解释了 LLM 在组合任务上泛化差的原因。
