Dynamic Prompt Learning via Policy Gradient for Semi-structured Mathematical Reasoning

基于策略梯度的动态提示学习：面向半结构化数学推理

简介

论文针对两个问题：一是缺少需要在表格上下文上做数学推理的基准，二是 few-shot GPT-3 的表现高度依赖 in-context 示例的选择，随机选取时性能不稳定甚至接近随机。作者构建了包含 38,431 道带表格上下文的年级数学题数据集 TabMWP（含 free-text 与 multi-choice 两类问题，每题附多步推理 gold solution），并提出 PromptPG：用固定参数的 BERT 加一层可学习线性层构成策略网络，以 REINFORCE 策略梯度训练，从候选池中为每道测试题自动选择 in-context 示例并构造提示。结果显示 PromptPG 总体准确率 68.23%，超过最强 baseline 5.31%，并显著降低随机选择带来的预测方差；在 1,000 个开发样本上仅用 2 个示例即达 70.9%。对团队而言，这是用强化学习自动做示例选择与提示优化的代表性早期工作，其数据集构建流程与稳定性分析对内部评测建设也有直接参考价值。

问题

现有数学应用题数据集只覆盖纯文本，缺少需要对表格等异构信息做推理的基准；同时 few-shot GPT-3 的性能高度依赖 in-context 示例的选择与排列，随机选择时表现不稳定、可能退化到接近随机水平，在问题类型与表格布局多样的 TabMWP 上该不稳定问题更严重，而基于语义相似度的检索式选例又无法度量表格等结构化信息的相似性。

方法

提出 TabMWP 数据集与 PromptPG 方法。PromptPG 将示例选择建模为强化学习问题：策略网络（固定参数的 BERT [CLS] 编码加一层可学习线性层）根据当前题目从 20 个候选示例中选择 2 个作为 in-context 示例，与测试题一起构造提示交给 GPT-3；以生成答案的对错作为 +1/-1 奖励，用 REINFORCE 策略梯度（蒙特卡洛采样估计期望奖励）只更新线性层参数，从而在与 GPT-3 API 交互中学习选择策略，无需人工启发式、暴力搜索或检索式选择。

关键结果

PromptPG 在 TabMWP 上总体准确率 68.23%，超过最强 baseline few-shot-CoT GPT-3（62.92%）5.31%

相比随机选择，PromptPG 显著降低预测方差（选择不稳定性）

zero-shot GPT-3 准确率与最佳 fine-tuned baseline（UnifiedQA LARGE、TAPEX LARGE）相当；few-shot 仅提升 0.17%

人类平均准确率比 PromptPG 高 21.99%；multi-choice 问题的启发式猜测准确率为 39.81%

消融：训练样本数约 160 时准确率达到峰值，之后下降且方差增大；候选示例数过多或过少都会降低性能

在 1,000 个开发样本上，PromptPG 仅用 2 个 in-context 示例即达到 70.9% 准确率；few-shot-CoT 随机选择从 2 shots 增至 4 shots 提升 2.5%，5 shots 无进一步收益

选择策略对比：按问题/答案类型选例可提升准确率并降低方差，manual selection 方差为 0 但仅比随机选择高 1.7%，PromptPG 在各策略中最优

创新点

据论文所述，这是首个将强化学习（策略梯度）用于为 few-shot GPT-3 选择 in-context 示例的工作，区别于随机选择、暴力排列搜索和基于语义相似度的检索式选择；同时 TabMWP 是首个要求在文本问题与表格上下文之间做数学推理的数据集，每题带多步 gold solution，且表格以图像、半结构化文本、结构化表格三种格式呈现。
