Agent Capability Negotiation and Binding Protocol (ACNBP)

Agent 能力协商与绑定协议（ACNBP）

简介

随着多 Agent 系统日益异构化，传统通信协议（如 Contract Net Protocol、FIPA）假设环境同构、能力描述静态且默认可信，难以支撑开放动态场景下的安全协作。论文提出 Agent Capability Negotiation and Binding Protocol（ACNBP），通过与 Agent Name Service（ANS）分布式注册服务集成实现基于能力的 Agent 发现，并设计覆盖能力发现、候选预筛、安全协商、绑定承诺到执行的 10 步协议流程，内置数字签名、Zero-Knowledge Proof 能力证明、防重放与 DoS 防护等安全机制，protocolExtension 机制则支持协议向后兼容演进。作者以 MAESTRO 威胁建模框架完成七层安全分析，并给出法律合同翻译场景的执行示例与开源参考实现。论文未提供量化实验结果，核心贡献是协议形式化规范与安全设计。对团队而言，其价值在于为多 Agent 间能力发现、协商与调用提供协议层设计参考，可与 MCP、A2A 等现有协议对照借鉴。

问题

异构多 Agent 系统中，各 Agent 的能力、接口、安全需求与运行上下文差异巨大且动态演化，而传统 Agent 通信协议（CNP、FIPA 等）假设同构 Agent 群体、静态能力描述与可信环境，新兴协议（A2A、MCP、ACP）也缺乏完整的能力协商机制与集成安全特性，导致开放环境下 Agent 间难以进行安全、可验证的能力发现、协商与绑定。

方法

提出 ACNBP 协议：与 Agent Name Service（ANS）分布式目录集成，通过 ANRI 记录实现基于能力的 Agent 发现；设计 10 步协议流程（能力发现 CD、候选预筛与选择 CPS、安全会话请求/建立、协商与拒绝、绑定承诺 BC、执行、Commit/Abort 决策、分布式承诺更新 DCU）；以五元组形式化定义 Capability，并做语法/语义/操作/安全/时间五维一致性检查；CPS 阶段进行兼容性评估、安全凭证验证、信誉分析、成本收益与风险评估。安全上采用 ECC 数字签名、Zero-Knowledge Proof 能力证明、X.509 证书链、nonce+时间戳防重放、速率限制与 proof-of-work 防 DoS，并用 MAESTRO 框架做七层威胁建模；protocolExtension 机制支持向后兼容的协议演进，配套 JSON schema 与开源参考实现。

创新点

区别于只解决单一环节的已有工作：CNP/FIPA 假设同构环境且安全能力薄弱，A2A 侧重消息路由、MCP 侧重模型交互的上下文共享、ACP 侧重消息格式，均缺乏完整能力协商与集成安全；ACNBP 将 ANS 能力发现、结构化 10 步协商流程、能力一致性检查、密码学绑定承诺与 MAESTRO 威胁建模整合为统一协议，并以 protocolExtension 实现向后兼容的协议演进，论文将其列为核心创新点。
