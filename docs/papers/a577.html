Layout and Task Aware Instruction Prompt for Zero-shot Document Image Question Answering

面向零样本文档图像问答的版面与任务感知指令提示（LATIN-Prompt）

简介

文档图像问答此前依赖 LayoutLM 等布局感知预训练模型，需要在语言模型上外挂可学习模块并在大规模文档图像上预训练，因而无法直接利用 Claude、ChatGPT 等现成 instruction-tuning 模型。本文发现这类模型仅凭空格和换行即可理解版面，据此提出 LATIN-Prompt：将 OCR 坐标按规则转译为空格与换行以重构版面文本，再套用带答案格式要求的任务指令模板。在 DocVQA 上该方法使 Claude 与 ChatGPT 的 zero-shot 性能分别提升 263% 与 20%，达到与微调 SOTA 相当的水平；配套的 LATIN-Tuning 用 Pandas 与 Claude 从 CSV 表格合成数据微调 Alpaca，使其在 DocVQA 上提升 87.7%。对团队而言，这是'用提示与上下文组织替代训练'的典型实证范例，其版面文本化与指令模板设计可直接迁移到文档型知识库问答等场景。

问题

布局感知预训练模型（LayoutLM 系列、ERNIE-Layout 等）需在语言模型上引入额外可学习模块，并从 OCR bounding box 坐标出发在大规模文档图像上预训练才能捕捉版面信息；这使其无法直接利用现成 instruction-tuning 大模型——闭源的 Claude/ChatGPT 无法继续预训练，开源的 Alpaca（7B）在千万页文档上预训练成本过高。论文要解决的问题是：如何让 instruction-tuning 语言模型不做额外预训练即可零样本完成文档图像问答，并让小模型也具备版面理解能力。

方法

核心是 LATIN-Prompt，由两部分组成：(1) 版面感知文档内容——五步规则法把 OCR 坐标'翻译'为纯文本排版：按从上到下、从左到右重排文本段，按行分组并计算行宽与字符宽度，同一行内相邻文本段之间插入与水平距离成比例数量的空格，行间用换行连接，从而把坐标中的版面信息转译为空格与换行；(2) 任务感知指令——为每个任务手工设计提示模板，包含任务要求说明、文档与问题占位符，并在模板末尾重申任务要求以防止模型因长文档内容干扰而遗忘任务，约束答案符合格式要求。多页场景 MP-DocVQA 采用 MaxConf 设置：每页抽取一个答案并给出置信度，取置信度最高者。针对小模型提出 LATIN-Tuning：用 Pandas 把 CSV 表格转为含空格与换行的文档字符串，由 Claude 生成问答对构造指令微调数据（5000 条，来自 WikiTableQuestions），对 Alpaca 微调 3 epochs（AdamW，batch size 64，lr 2e-5）。

关键结果

LATIN-Prompt 使 Claude 与 ChatGPT 在 DocVQA 上相对 Plain Prompt 分别提升 263% 与 20%；Claude 与 ChatGPT-3.5 的 zero-shot 性能显著超过微调后的 LayoutLM，并与微调后的布局感知多模态预训练模型（SOTA）相当

在 InfographicVQA 上，LATIN-Prompt 使 Claude 与 GPT-3.5 的 zero-shot 性能超过除 TILT 外的所有微调基线

在 MP-DocVQA 上，Claude 的 zero-shot 性能超过为长序列设计的 Longformer 与 Big Bird 的微调性能，并与多页布局感知模型 Hi-VT5 的微调性能相当

LATIN-Tuning 使 Alpaca 在 DocVQA 上提升 87.7%、在 InfographicVQA 上提升 113%，但仍落后于 Claude

消融实验表明版面感知文档内容与任务指令均能显著提升 zero-shot 性能；对 Claude 而言任务指令带来的提升更显著（保证答案格式正确），版面内容在此基础上进一步提升

GPT-4 的 zero-shot 性能与最佳微调性能持平（未结合 LATIN-Prompt，因 API 权限限制留作未来工作）

LATIN-Tuning 性能随样本数增加而提升，样本数超过 2000 后提升速率放缓

创新点

与已有工作通过 bounding box 坐标 + 额外可学习模块 + 大规模文档预训练来捕捉版面不同，本文发现 instruction-tuning 模型可直接通过空格与换行理解版面，从而把坐标信息转译为纯文本排版，无需任何额外预训练即实现零样本文档图像问答；同时用任务指令模板约束答案格式，并用强模型（Claude）合成的空格/换行文本数据微调小模型（LATIN-Tuning）。与并行的 ICL-D3IE 不同，本文聚焦 zero-shot 问答而非 few-shot 信息抽取。
