Prompt-Based Monte-Carlo Tree Search for Goal-Oriented Dialogue Policy Planning

基于 Prompt 的蒙特卡洛树搜索（MCTS）用于目标导向对话策略规划

简介

目标导向对话（如说服用户捐款）的策略规划通常需要训练神经网络来执行 A* 或 MCTS 等前瞻搜索，但训练依赖大量标注数据，在标注噪声大或低资源场景下难以奏效。论文提出 GDP-ZERO：用 Open-Loop MCTS 在决策时做规划，全程零模型训练，通过 prompt 让同一个 LLM 分别充当策略先验、价值函数、用户模拟器与系统模型；树节点只保存对话动作序列，遍历时重新生成具体话语，以缓解模拟误差的复合累积。在 PersuasionForGood 任务上，其回复在静态评测中最多 59.32% 的对比中优于直接 prompt ChatGPT，在 MTurk 交互式人工评测中说服力相关指标全面超过 ChatGPT 与当时 SOTA 系统 RAP。消融显示 Open-Loop 变体与 response selection 贡献最大；主要代价是每轮约 35 秒的模拟延迟。对团队而言，它是'用多角色 prompt 替代训练模块、用搜索式规划提升 Agent 决策质量'的代表性方法参考。

问题

目标导向对话（如说服、谈判）的策略规划需要模拟未来对话交互并估计任务进展；已有方法依赖训练专用神经网络（策略分类器、价值函数、用户模拟器）来执行 A*/MCTS 等前瞻搜索，需要大量高质量标注数据，在标注噪声大或低资源场景下表现差。论文实验显示，监督/强化学习多分类器预测下一对话动作最高仅 18-25% 准确率，转为二分类（是否提议捐款）也仅 74%。

方法

GDP-ZERO：零训练的 Open-Loop MCTS 决策时规划。将规划建模为随机 MDP，树节点只存对话动作序列而非具体话语，遍历时用 LLM 重新生成系统/用户话语（每节点缓存 k 条）以减少复合模拟误差。通过 prompt 让同一个 LLM 充当四种角色：策略先验（温度 1.0 采样 15 次估计下一动作分布）、价值函数（追加捐款询问后采样 10 次估计用户倾向并映射为 -1.0~1.0 分）、用户模拟器与系统模型（one-shot 条件生成）。搜索按 PUCT 选择、扩展、评估、回传更新统计量，最终按访问次数选出最优动作，并从缓存中选估计价值最高的系统回复（response selection）。

关键结果

静态评测（P4G 前 20 段对话、154 轮，ChatGPT 作 backbone 与裁判）：GDP-ZERO 规划后的回复在最多 59.32% 的对比中优于直接 prompt ChatGPT；ChatGPT 类生成方法在约 90% 的对比中优于人工 ground truth，其中 GDP-ZERO 得分最高

交互式人工评测（MTurk，有效问卷 GDP-ZERO 40 / ChatGPT 35 / RAP 36）：GDP-ZERO 在所有说服力相关指标上最佳，超过 ChatGPT 与当时 SOTA 的 RAP

消融实验：Open-Loop MCTS 对提升说服力贡献最大，response selection 进一步提升；对 ChatGPT 与 Codex 两种 backbone 均有效

分析：上一轮用户表现负面情绪时 GDP-ZERO 被判更有说服力的比例为 70.59%，正面情绪时为 59.26%

运行时：受 OpenAI API 限速与推理速度限制，动作空间限 7 个对话动作，n=10、k=3 时每轮模拟约 35 秒

评测偏差分析：回复词数与 ChatGPT 裁判偏好呈正相关（r=0.29, p<0.001）

创新点

据论文所述，prompting 此前主要用于对话回复生成、对话合成与对话理解，尚未被用于策略规划；本文首次在树搜索的每个环节（策略先验、价值估计、用户/系统模拟）都用 prompt 完成、无需任何模型训练。与'神经网络+搜索'的已有方法不同，GDP-ZERO 将对话规划建模为随机 MDP 并采用 Open-Loop MCTS（节点存动作序列、遍历时重新生成话语），以缓解闭环搜索中单次低概率模拟在子树中复合放大的问题。
