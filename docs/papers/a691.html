Temporal Knowledge Graph Forecasting Without Knowledge Using In-Context Learning

无需知识、仅凭 In-Context Learning 的时序知识图谱（TKG）预测

简介

论文研究时序知识图谱（TKG）预测任务：给定历史事实预测未来缺失的四元组，传统方法依赖 GNN、强化学习、逻辑规则等监督模型，需要大量训练数据且逐数据集选型成本高。作者将任务转化为 LLM 的 in-context learning（ICL）问题，设计三阶段流水线：从 TKG 检索相关历史事实作为上下文、用 Index/Lexical 两种模板构造结构化 prompt、并通过把候选实体映射为数字标签作为 indirect logit，将输出 token 概率解析为实体排名。关键结论：无需任何微调，GPT-NeoX 等基础模型在 WIKI、YAGO、ICEWS 等基准上与 SOTA 监督模型持平（Hits@1 相对中位数差距 -3.6%~+1.5%）；把实体/关系替换为任意编号后性能几乎不变（±0.4%），说明 LLM 主要依赖上下文中的符号模式而非语义先验；性能随历史长度与模型规模呈 scaling 趋势，并显著超过 frequency/recency 启发式基线。对团队而言，这是一份关于'上下文如何组织、prompt 如何消融、输出如何解析'的系统性实证参考。

问题

时序知识图谱（TKG）预测要求根据历史图快照预测未来缺失链接。已有监督方法（GNN、强化学习、逻辑规则）需要大量包含完整实体历史的训练数据，且每个数据集的 SOTA 模型不同、模型选型计算代价高。论文探究：LLM 能否仅通过 in-context learning（ICL）、不做任何训练地完成该预测，以及模型究竟从上下文中学到了什么——是语义先验还是符号模式。

方法

三阶段流水线：(1) History Modeling——按 Entity/Pair 与 Unidirectional/Bidirectional 四种组合，从历史快照中检索与查询实体/关系相关的事实作为上下文（双向时通过交换主宾并替换为逆关系保持语义）；(2) Prompt Construction——用预定义模板将事实线性化，支持 Index（实体/关系映射为唯一编号）与 Lexical（保留词面）两种形式，查询以 't:[s,p,' 形式拼接在末尾；(3) Response Generation——将候选实体映射为数字标签作为 indirect logit，取首个生成 token 的概率排序得到实体排名。评测分 Single Step（用真实历史）与 Multi Step（用自身带噪预测作为历史）两种设置；对 gpt-3.5-turbo 另用人工编写的 system instruction 约束输出格式。

关键结果

GPT-NeoX（history length=100）零训练 ICL 与 SOTA 监督模型持平：Hits@1 相对各数据集中位数差距在 (-3.6%, +1.5%) 内

将实体/关系替换为任意编号（Index prompt）后性能几乎不变（±0.4% Hit@1；GPT-J 上 Index 与 Lexical 平均差 ±4e-3），说明语义先验非必要

在所有数据集上超过最强启发式基线（frequency/recency）(+10%, +28%) Hits@1 相对幅度，说明 ICL 学到了超越频率/时近偏差的模式

gpt-3.5-turbo 上 Lexical prompt 比 Index prompt 高 0.024 Hits@1，instruction-tuned 模型更能利用语义先验

性能随历史长度增加持续提升（history length scaling law），也随模型规模增大而提升

去掉时间戳导致性能下降，打乱历史事件顺序进一步加剧下降，说明模型利用了事件的时序结构

Bidirectional 历史相比 Unidirectional 略有下降（ICEWS 上降幅显著）；Entity 与 Pair 检索的优劣依赖数据集（WIKI/ICEWS18 偏好 Entity，ICEWS14 偏好 Pair）

创新点

将 TKG 预测整体转化为无需训练、无需定制架构的 ICL 任务，并系统消融历史检索策略、prompt 形式与输出解码方式；与已有 ICL 研究通常使用每类均匀采样的 few-shot 示例不同，本文研究模型从历史事实的不规则模式中学习；核心新发现是基础模型在语义被完全移除（纯编号符号）时仍能凭上下文符号模式完成预测，且 ICL 学到的是超越 frequency/recency 偏差的不规则模式；同时用启发式基线揭示了现有 TKG 基准的缺陷（recency 在 YAGO/WIKI 上即可超过所有已有模型）。
