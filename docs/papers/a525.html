Promptor: A Conversational and Autonomous Prompt Generation Agent for Intelligent Text Entry Techniques

Promptor：面向智能文本输入技术的对话式自主 Prompt 生成 Agent

简介

论文针对两个问题：智能文本输入功能传统上依赖数据收集与 GPT-2 微调、开发成本高；而缺乏 prompt 工程经验的设计师难以写出高质量 prompt。方法上提出 Promptor：用一段含 Instructions、Facts、Actions、Examples 四段的 'parent' system prompt 驱动 GPT-4 成为对话式 Agent（Prompt2Prompt 方法），按六步流程（引导设计师、生成中间 prompt、prompt 评估、测试轮次、迭代精炼、产出最终 prompt）与用户交互，最终生成由 Preamble、Few-Shot with CoT 和 Policy 构成的 'child' prompt 供 GPT-3.5 执行句子预测，并配套虚拟测试键盘供设计师实测。关键结论：Prompted GPT-3.5 平均超过 Fine-tuned GPT-2 3.94%，微调 GPT-3.5 无显著增益且调用成本约 8 倍；24 人用户研究中 Promptor 生成的 prompt 比设计师自写的 similarity 高 35%、coherence 高 22%，格式错误率从至少 30% 降至 5% 以下，SUS 得分 83.4；GPT-4 as judge 与人类评委高度一致（Spearman 0.88–0.96），可支撑大规模 AI 评测。

问题

智能文本输入（句子预测等）功能传统上需要在专门采集的数据集上训练并微调模型（如 GPT-2），数据收集、模型开发与训练成本高昂；虽然 GPT-3.5 的 in-context learning 使仅靠 prompt 即可完成任务，但 prompt 的效果高度依赖其质量与结构，缺乏 prompt 工程专长的设计师难以通过大量实验写出稳定、高质量的 prompt。

方法

提出 Promptor：一个对话式、自主的 prompt 生成 Agent。核心是 Prompt2Prompt 方法——用一段 'parent' system prompt（分 Instructions、Facts、Actions、Examples 四段，Facts 来自文献综述，Examples 为理想对话样例）prompt GPT-4，使其成为自动生成 'child' prompt 的 Agent。Agent 遵循六步流程：Engage the User、Derive an Intermediate Prompt、Conduct a Prompt Evaluation（Likert 三指标均分超过 4 才继续）、Conduct Test Rounds（结合虚拟测试键盘实测，将失败对话历史回传给 Promptor 并要求其解释修改理由）、Continue to Refine the Prompt、Derive a Final Prompt。最终 'child' prompt 由 Preamble、Few-Shot with Chain of Thought（固定 4 个示例以平衡效果与上下文窗口长度）和 Policy（输出约束）构成，输入输出均采用 JSON 格式便于解析与集成。配套可配置的虚拟测试键盘用于真实体验与对比评估；评测上用 GPT-4 作为 AI judge（OpenAI Evals），并先验证其与人类评委的一致性再用于大规模 prompt 评测。

关键结果

Prompted GPT-3.5 在句子预测任务上平均超过 Fine-tuned GPT-2 3.94%（人类与 AI 评委平均分），Wilcoxon Signed-Rank Test 的 p 值为 0

Fine-tuned GPT-3.5 相比 Prompted GPT-3.5 无显著性能提升，且 Fine-tuned GPT-3.5 的模型请求成本约为基础模型的 8 倍

通过咨询 Promptor 并配置 GPT-3.5 完成 KWickChat 2 任务全程不到 20 分钟，仅需 API 调用

24 人用户研究（3 个任务）：Promptor 生成的 prompt 相比设计师自写 prompt，similarity 3.93 vs 2.91（+35%）、coherence 4.16 vs 3.41（+22%）

格式正确性：自写 prompt 至少 30% 的预测不符合格式要求，Promptor prompt 的错误率低于 5%

System Usability Scale (SUS) 平均得分 83.4，获 'excellent' 评级

人类评委与 GPT-4 AI judge 的一致性：Spearman 相关 0.88–0.96（合并 0.91），Cohen's Kappa 0.54–0.87（合并 0.75）

KWickChat 2 自身改进：加入标点输入使 BLEU 提升 79.3%；re-ranking 机制（M=50）使平均 keystroke savings 提升 15.9%

创新点

与已有自动提示工作（如 automatic prompt engineer 将指令生成形式化为黑盒优化、gradient-guided search 需梯度微调）不同，Promptor 无需梯度搜索或微调，仅用 'parent' prompt 驱动 GPT-4 以对话方式自主生成并迭代精炼 'child' prompt，面向非 prompt 专家并强调人在回路的交互式评估与测试键盘实测；同时论文以实证系统对比了 Prompted GPT-3.5、Fine-tuned GPT-2 与 Fine-tuned GPT-3.5，并验证 GPT-4 as judge 与人类评委的一致性以支撑大规模 prompt 评测。
