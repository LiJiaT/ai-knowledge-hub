Meta-in-context learning in large language models

大语言模型中的元上下文学习（Meta-in-context learning）

简介

论文研究 LLM 的 in-context learning 能力能否通过 in-context learning 本身递归提升，作者将这一现象命名为 meta-in-context learning。方法上完全不微调参数，只在 prompt 中按顺序呈现多个相关学习任务——一维线性回归、two-armed bandit 和 42 个真实回归数据集——再评估模型在新任务上的表现。结果显示 GPT-3 在任务内与跨任务均显著提升，机制是先验逐步适配真实环境统计，学习策略也随之改变（更贪心、更多 UCB 式决策）；在真实回归基准上，meta-in-context learning 后的 GPT-3 与 Bayesian linear regression 相当、略逊于 random forest，且与先前任务相似度越高收益越大。对团队的启示是：与其追求完美 prompt，在上下文中组织若干相关任务示例即可让模型在一定程度上自行推断所需信息；但该结论来自理想化任务与 2023 年的 GPT-3/GPT-4，且 prompt 长度增长快，受上下文窗口与调用成本约束。

问题

LLM 通过 in-context learning（few-shot 示例）在单个任务内获得提升，但这种由上下文实现的'学习算法'本身能否在不微调任何参数的前提下被进一步改进？即 in-context learning 能否递归地作用于自身；若能，其机制是什么（先验适配还是学习策略改变），以及能否从理想化任务扩展到真实世界任务。

方法

完全基于 prompt、不更新权重：将 N 个学习任务按顺序拼接进上下文，逐 trial 迭代呈现数据点及其历史，让模型先在多个相关任务上'学习'，再评估其对后续新任务的 in-context learning 表现。实验覆盖三个设置：（1）一维线性回归（5 个任务×5 个数据点，函数参数从特定分布采样，用于覆盖模型对递增正函数的先验偏置）；（2）two-armed bandit（5 个赌场×10 trials，用基于 Kalman filtering 的 probit 回归分析 Boltzmann 探索、UCB、Thompson sampling 等策略权重随任务数的变化）；（3）42 个真实世界多维回归数据集（每任务取 5 个特征、5 个数据点，特征与目标归一化到 [-1,1]）。机制分析通过在任务前探测模型先验（temperature=1 采样）和拟合策略回归模型完成。所有模拟使用 TEXT-DAVINCI-002（GPT-3），temperature 默认为 0。

关键结果

一维回归任务：MSE 上 trial number（β = -30.614 ± 3.08, t = -19.514, p < 0.001）与 task number（β = -13.26 ± 3.08, t = -8.455, p < 0.001）效应均显著，确认 in-context 与 meta-in-context learning 同时存在；单任务上 GPT-3 匹配甚至略优于默认先验的 Bayesian linear regression（BLR）

two-armed bandit：regret 上 in-context learning（β = -0.221 ± 0.012, t = -35.828, p < 0.001）与 meta-in-context learning（β = -0.031 ± 0.012, t = -5.002, p < 0.001）效应均显著；仅经历 4 个任务后性能即匹配 greedy policy，仅略落后于 UCB 算法

先验适配：bandit 中对奖励的先验期望从初始 M = 545.22（SD = 6359）收敛到接近真实分布的 M = 6.49（SD = 4.41）；回归任务中截距先验从 0 附近移向真值 -100

策略重塑：GPT-3 在 meta-in-context learning 过程中变得更贪心（任务数与价值差交互 β = 0.128 ± 0.025, z = 9.633, p < 0.001），UCB 式决策显著增加（β = 0.046 ± 0.010, z = 9.279, p < 0.001）

真实回归基准（42 个数据集）：meta-in-context learning 后 GPT-3 匹配 BLR、仅略逊于 random forest；改进主要来自 zero-shot 阶段——预测落在目标范围外的比例大幅下降；任务相似度对 RMSE 效应显著（β = -0.147 ± 0.020, t = -15.223, p < 0.001）

GPT-4 复现了主要发现（trial: β = -0.133 ± 0.024；task similarity: β = -0.196 ± 0.024，均 p < 0.001），但表现略差于 GPT-3

创新点

与经典 meta-learning 通过更新网络权重来适配任务分布不同，本文完全通过上下文本身（不更新任何权重）实现对任务分布的适配；与以往孤立评测单个任务的做法不同，本文借鉴心理学实验中连续呈现多个学习任务的范式，提出并命名了 meta-in-context learning 现象，并通过先验探测与策略回归分析揭示其双重机制：先验向环境真实统计适配，以及学习策略（如探索-利用权衡）被重塑。
