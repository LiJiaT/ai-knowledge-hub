Boosted Prompt Ensembles for Large Language Models

面向大语言模型的 Boosted Prompt 集成方法

简介

该论文针对 few-shot 场景下 LLM 推理性能高度依赖人工挑选的提示示例、且单 prompt 的 self-consistency 集成存在上限的问题，提出 'boosted prompting'：借鉴经典 boosting 算法，用小规模标注集（仅需最终答案标签，50-300 条）分阶段构造一组 few-shot prompt——每轮用当前 ensemble 对各题采样多条推理路径，以答案间一致度作为难度/信息量代理，选出'至少一次答对但整体不确定'的 hard examples，配以模型自生成的正确 CoT（按复杂度启发式挑选）组成新 prompt 加入集成；测试时对 n 个 prompt × m 条采样做多数投票，另提供用 'sufficient agreement' 的模型自预测替代真值的 test-time 与 online 变体。在 GSM8K、AQuA、MMLU570、SVAMP、CMATH420 上，各标注水平下均超过 self-consistency 与 bagged 基线，AQuA 上 63.5% vs 57%，100 条标注即可见效；但弱模型（curie）上无效，加权投票收益甚微。对团队而言，这是提示工程域中自动构建与迭代 prompt 资产、以一致度定位模型薄弱点的直接方法参考。

问题

few-shot 提示性能对人工挑选的示例敏感，prompt engineering 需要大量人工投入，且示例选择对性能的影响存在不确定性（不同工作甚至给出相互矛盾的建议）；单 prompt 的 self-consistency 输出空间集成存在性能上限。论文要解决的问题是：在不做额外训练的前提下，如何利用小规模标注数据自动构造一组能协同工作、覆盖问题空间困难区域的 few-shot prompt，以提升 LLM 推理准确率并减少人工提示工程量。

方法

借鉴经典 boosting 的分阶段（stagewise）集成方法：每轮用当前 prompt 集合对问题集每题采样 m 条推理路径，以采样答案间的一致度（agreement）作为示例信息量/难度的代理；train-time 版本用真值标签选出'至少有一条推理路径正确但整体一致度低'的 hard examples，test-time 版本用达到 'sufficient agreement' 阈值的模型多数预测替代真值；为每个入选问题按复杂度启发式（推理路径句子数，遵循 Fu et al. 2022）从导致正确/多数答案的 CoT 中挑选，拼成含 8 个示例的新 prompt 加入 ensemble；测试时对 n 个 prompt × m 条采样做多数投票，并可用 'solved set' 剪枝（已达一致度阈值的题不再重复生成）节省计算。提供 train-time（归纳）、test-time（transductive）与 online 三种变体。

关键结果

在 GSM8K、AQuA、MMLU570、SVAMP、CMATH420 五个数据集上，boosted prompting 在所考察的各标注水平下均优于对应的 self-consistency 基线

AQuA：train-time boosting 达 63.5%，单 prompt self-consistency 为 57%（初始 prompt 次优时差距更大）

仅需 50-300 条（少至 100 条）标注样本，train-time boosting 即可超越 bagged 与单 prompt 集成

固定计算预算下改变 ensemble 组成（prompt 数 × 每 prompt 采样数）性能影响较小，所有设置均优于 bagging 与 self-consistency

test-time boosting 的 minimum agreement 阈值过低会大幅降低平均 prompt 准确率与测试性能；主实验中选择题数据集用 0.8、开放题用 0.7

对集成成员施加 Adaboost 式加权仅带来轻微性能差异，与 self-consistency 论文中加权投票收益甚微的发现一致

从最复杂的 5 条模型生成 CoT 中采样优于随机采样，但仍优于各基线

方法对较强模型（code-davinci-002、text-davinci-003、gpt-3.5-turbo）同样有效，但对较弱的 text-curie-001 无效

CMATH420（训练集仅 71 条且存在显著分布偏移）上 test-time 版本优于 train-time 版本，为 test-time boosting 可做在线 'prompt space exploration' 的假设提供部分支持

创新点

首次将经典 boosting 算法适配到 CoT few-shot prompt 集成场景：不同于并发工作 Hou et al. (2022)（面向单 token 分类、随机选例、仅调整 verbalizer 权重），本文以 ensemble 采样一致度作为信息量代理，主动挑选 hard examples 构造新 prompt；相比 self-consistency（单 prompt 输出空间集成）与 bagged prompts（随机多 prompt），boosted prompt 集在问题空间的困难区域形成针对性覆盖；并提出以模型高一致度自预测替代真值标注的 test-time（transductive/online）变体，使算法在无标注场景可用。
