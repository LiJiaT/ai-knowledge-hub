ProAgent: Building Proactive Cooperative Agents with Large Language Models

简介

论文研究零样本协作（zero-shot coordination）问题：传统学习式协作 Agent 的策略泛化依赖训练期队友的多样性，面对陌生队友难以自适应，且计算开销大、缺乏可解释性。作者提出 ProAgent，一个无需训练或微调的 LLM Agent 框架，由 Planner、Verificator、Controller、Memory 四个模块加 Belief Correction 机制组成：先把环境张量状态 grounding 为自然语言，Planner 用 CoT 分析场景、推断队友意图并规划高层技能；Belief Correction 用队友后续实际行为修正意图预测；Verificator 通过多轮提示校验技能前置条件、归因失败并触发重规划；Controller 把技能分解为底层动作；Memory 以持久知识库加 FIFO 轨迹缓冲存储信息。在 Overcooked-AI 上，ProAgent 与 AI 队友协作时优于 SP、PBT、FCP、MEP、COLE 五种方法；与人类代理模型协作时较当时 SOTA 平均提升超 10%。消融显示分析与信念推断把 Cramped Room 得分从 100 提到 204，移除 Verificator 后 100 步成功率降至 20%。

问题

基于学习的方法（self-play、Population-Based Training 等）构建的协作 Agent，其策略泛化严重依赖训练阶段接触的队友多样性，在与陌生队友协作的零样本协作（zero-shot coordination）场景中难以进行策略自适应；这类方法还需要大量计算资源做数据收集与模型优化，且策略缺乏可解释性。论文探索如何利用 LLM 的常识与推理能力，构建能主动推断队友意图、动态调整自身行为的协作 Agent，且无需先验训练或微调。

方法

ProAgent 是一个分层 LLM Agent 流水线，包含五个阶段：(1) Knowledge Library 与 State Grounding——任务开始前将按 Task/Rules/Demos 三部分模板构建的结构化知识库注入 prompt，并把环境的原始张量状态转换为 LLM 可理解的语言化状态描述；(2) 高层技能规划——Planner 模块遵循 CoT，先输出对当前场景与队友意图的 Analysis，再给出一个合法技能作为计划；(3) Belief Correction——将 Memory 中记录的队友意图预测与队友后续实际行为对比，用替换或标注纠错两种方式修正信念；(4) 技能验证与执行——Verificator 通过多轮 prompt（如 Preconditions Check、Double-check、Error Conclusion）分析技能失败原因并触发重规划，通过验证后由 Controller（规则式如 Best-First Search 或 RL 策略）把技能分解为底层动作执行；(5) Memory 存储——由持久 Knowledge Library 与固定长度 FIFO 的 Trajectory 缓冲组成，按 recent-K 策略检索最近轨迹。整体采用去中心化规划（每个玩家一个 Planner），不依赖 Agent 间显式通信。

关键结果

在 Overcooked-AI 上将 SP、PBT、FCP、MEP、COLE、ProAgent 六种算法两两组合成 36 对进行实验：ProAgent 作为 Player 0 时在全部五个布局上优于所有基线；作为 Player 1 时仅在 Cramped Room 布局略低于 FCP、在 Forced Coordination 布局输给 PBT

与人类代理（5 个行为克隆 BC 模型）协作时，ProAgent 在五个环境中的四个优于基线，整体较当时 SOTA 方法平均提升超过 10%，且起始位置左右互换对其性能影响可忽略

消融实验（Cramped Room 布局）：同时使用 analysis 与 belief 得分 204，去掉 belief 为 184，两者都不用、直接规划技能为 100

移除 Verificator 模块、无反馈直接规划时，ProAgent 在 100 步内的成功率显著下降至 20%

创新点

相对已有工作的区别：(1) 据作者所述，在其 camera-ready 时点，LLM Agent 在协作游戏中的应用仍很少被探索，本文将 LLM 引入协作多智能体零样本协调并给出完整框架；(2) 采用去中心化规划（一个玩家一个 Planner），区别于 Li et al. (2023a) 的集中式双玩家规划；(3) 不通过显式通信促成协作，而是通过观察并推断队友意图来协作，区别于 Zhang et al. (2023) 的显式通信方案；(4) 提出 Belief Correction 机制，用队友实际行为持续修正对意图的预测；(5) 无需训练/微调，模块化、可解释，区别于需要大量计算资源且不可解释的 PBT/ToM 类 ZSC 方法。
