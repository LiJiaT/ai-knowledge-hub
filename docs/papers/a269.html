简介

现有 test-time scaling 方法把每个问题孤立处理，不复用先前推理轨迹中的程序性知识（如何重构问题、分解子问题、选择方法、验证与回溯）。论文提出 Reasoning Memory，一个面向推理模型的 RAG 框架：离线把公开推理轨迹语料（Nemotron V1）分解为自包含的 subquestion-subroutine 对，构建约 3200 万条目的程序性知识库；推理时用 thought-hijacking 提示让模型在思维流内自述当前子问题作为查询，经 dense retriever（ReasonIR-8B）检索 top-k 子程序注入思维流，并在多个检索子程序下分别采样候选轨迹，再用基于轨迹长度的不确定性启发式过滤选优。在 AIME 2024/2025、MATH500、GPQA-D、LiveCodeBench 六个基准上，该方法一致优于文档级、轨迹级、模板级 RAG 与 compute-matched 的无检索基线，高推理预算下跨模型与任务平均比无检索提升 19.5%、比 compute-matched 基线提升 8.9%。论文还通过 pilot study 发现标准文档 RAG 对推理模型收益有限甚至为负，而程序性知识注入收益更大；消融表明子问题分解与自述查询是关键设计，且 datastore 生成可用更小的模型完成。

问题

现有 test-time scaling 方法（包括推理模型的长思考）把每个问题孤立处理，不复用跨推理运行的知识，尤其是程序性知识——如何重构问题、分解为子问题、利用结构、选择方法、验证或回溯；同时标准文档级 RAG 检索的是通用背景知识，与推理模型当前推理状态对齐弱，难以提供'下一步该解什么子问题、怎么解'的指导。

方法

提出 Reasoning Memory，分三部分：(1) 离线用两步提示管线（QwQ-32B）把公开推理轨迹（Nemotron V1 的 math/stem/code 子集）分解为自包含的 subquestion-subroutine 对，构建约 3200 万条目的程序性知识库（子问题平均 19.2 tokens，子程序平均 207.9 tokens，每条轨迹贡献 10.5 个子问题）；(2) 推理时用 thought-hijacking 元提示让模型在思维流开头生成一句搜索式查询，用 ReasonIR-8B 以子问题为 key 检索 top-k 子程序，以提示形式直接注入思维流（不插入源轨迹），检索成为推理的轻量延伸；(3) 在每个检索到的子程序下分别采样一组候选轨迹（diversity-first 预算分配），用轨迹长度作为不确定性分数做归一化，过滤低分子程序并按置信度选出最终答案。

关键结果

六个基准（AIME 2024/2025、MATH500、GPQA-D、LiveCodeBench V1-V4/V5-V6）上，Reasoning Memory 一致优于文档级、轨迹级、模板级 RAG 及 compute-matched 的无检索 test-time scaling 基线；跨模型与任务平均达 0.580 vs 无检索 0.500

高推理预算下，跨模型与任务平均比无检索提升 19.5%，比 compute-matched 基线提升 8.9%；m=30 时相对 No RAG 数学提升 0.12（19.0%）、科学 0.05（9.8%）、编程 0.09（28.9%）

diversity-first 预算分配（多用检索子程序、每子程序少采样）随预算 m 增至 100 单调提升并优于 intensity-first；更大更混合的 datastore 性能更好，全量混合语料优于任何单域子集

消融：去掉子问题分解在 AIME 与 GPQA-D 上降幅最大；用原始问题替代自述查询在 LiveCodeBench 降幅最大；datastore 生成模型换成 Qwen3-8B 性能接近全系统

效率：查询生成与检索注入合计不到 1 秒，远小于单条长推理约 10 秒；m=30 端到端约 60 秒

Pilot study：标准文档 RAG 对 instruction-tuned 模型有 modest 收益，但对推理模型常收益有限甚至下降；合成知识注入实验显示程序性知识收益大于事实性知识

创新点

区别于三类已有工作：(1) 面向推理的文档级 RAG（CompactDS、Search-o1、R1-Searcher 等）用检索为推理提供外部事实信息，本文检索的是从推理轨迹蒸馏的紧凑程序性子程序并直接注入思维流；(2) 程序性记忆类工作（Agent Workflow Memory、ReasoningBank、Buffer of Thoughts、Retrieval-of-Thought 等）从交互经验或解题轨迹归纳工作流/策略/模板，本文的贡献是将其操作化为 3200 万条目规模的可检索 datastore、主动 in-thought 检索接口与 compute-matched 的 scaling recipe；(3) 相对 test-time scaling 文献，本文把额外推理算力用于在多样化检索先验下探索，而非单纯更长或更多的采样。
