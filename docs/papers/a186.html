Beyond Self-Talk: A Communication-Centric Survey of LLM-Based Multi-Agent Systems

超越自言自语（Beyond Self-Talk）：以通信为中心的 LLM 多智能体系统综述

简介

现有 LLM-MAS 综述多按应用领域或系统架构分类，忽视了通信在协调 Agent 行为与交互中的核心作用。本文提出通信中心视角的两层分析框架：系统级通信（架构、目标、协议）与系统内部通信（策略、范式、对象、内容），系统梳理了 Flat/Hierarchical/Team/Society/Hybrid 五种架构、合作/竞争/混合三类目标，并详解 MCP、A2A、ANP 三种新兴协议。在系统内部层面，论文比较了 One-by-One、Simultaneous-Talk、Simultaneous-Talk-with-Summarizer 等通信策略与 Message Passing、Speech Act、Blackboard 等范式的优劣与适用场景。核心结论是：通信设计的选择直接决定多 Agent 系统的可扩展性、效率与可靠性；当前主要挑战包括协议功能冗余与互操作缺失、通信安全漏洞、系统级评测基准不足。对团队而言，这是多智能体协作域的全景式参考，可直接支撑多 Agent 系统的架构与协议选型。

问题

现有 LLM-MAS 综述通常按应用领域或系统架构分类，对协调 Agent 行为至关重要的通信与协作工作流覆盖有限；领域特定综述（如软件工程、社会仿真）又缺乏跨任务的通用框架。论文要填补的空白是：缺乏一个以通信为中心、能跨任务/架构/工作流统一分析 LLM-MAS 的结构化分类框架。

方法

提出通信中心的两层分析框架。系统级通信包括：通信架构（Flat、Hierarchical、Team、Society、Hybrid 五种，分析各自在可扩展性、灵活性、效率上的权衡）；通信目标（直接合作、辩论式合作、竞争、混合）；通信协议（详解 MCP 的 JSON-RPC client-server 架构、A2A 的 Agent Cards 能力发现与 HTTP/SSE 异步消息、ANP 的 DIDs 去中心化身份与 JSON-LD 语义通信，并做对比）。系统内部通信包括：通信策略（One-by-One、Simultaneous-Talk、Simultaneous-Talk-with-Summarizer，分析延迟、误差累积、状态陈旧、冲突仲裁等 trade-off）；通信范式（Message Passing、Speech Act、Blackboard）；通信对象（Self、Other Agents、Environment、Human）；通信内容（显式的自然语言/代码与结构化数据，隐式的行为反馈/环境信号）。最后总结系统设计优化、Agent 竞争、统一协议、多模态通信、通信安全、评测基准六大挑战与方向。

创新点

区别于既有按应用领域或架构分类的通用/领域综述，本文首次以通信为中心视角统一分析 LLM-MAS，借鉴传统通信理论（source、channel 概念）将 LLM-MAS 工作流分解为协议约束下的通信过程，提出系统级+系统内部的两层框架；并将 MCP、A2A、ANP 等新兴 Agent 通信协议纳入系统梳理与对比，同时指出当前评测以单 Agent 指标为主、缺少协调效率与通信鲁棒性等系统级指标的空白。
