CoTEVer: Chain of Thought Prompting Annotation Toolkit for Explanation Verification

CoTEVer：用于解释验证的 Chain of Thought（CoT）提示标注工具包

简介

CoT 提示的效果高度依赖所生成解释的事实正确性，而 LLM 幻觉会产生流畅却错误的解释；同时可用于微调的高质量解释数据稀缺，人工从头撰写成本高且需要背景知识。论文提出 CoTEVer，一个人机协作标注工具包：先用 Self-Ask 风格的 few-shot 提示让 GPT-3 生成'子问题-子答案'式解释，再以子问题为查询经 Google Search API 检索文档，切分后用 Sentence-T5 嵌入按余弦相似度重排，标注者对照证据对每步解释做 1-5 星评分、提交修订并标记所用证据文档。对 300 个预测错误样本的分析表明，Wrong Fact（43%）、Out of Date（22%）、Insufficient Knowledge（18%）三类错误合计 83% 可借助证据修订。论文还给出收集数据的三种用途：CoT 微调、以低分解释为 hard negative 的 unlikelihood 训练、构建事实核查与稠密检索训练集。

问题

CoT 提示的性能很大程度上受生成解释事实性的影响；要提升解释正确性需用解释数据微调模型，但此类数据集稀少且缺少收集工具。人工从头撰写解释耗时费力且需要背景知识，而 LLM 幻觉会生成流畅但难以辨别的事实错误解释。论文要回答的问题是：能否以更高效的方式收集解释数据。

方法

三步人机协作流程：S1 Prompting——用 GPT-3（TEXT-DAVINCI-002）配合 Self-Ask 风格 6-shot 提示生成由子问题/子答案组成的解释；S2 Evidence Retrieval——以子问题直接作为查询，用 Google Search API 取回 top-10 文档，切分为最大 512 token 的块后用 Sentence-T5 嵌入按余弦相似度重排；S3 Verification——标注者对照证据文档对每步解释做 1-5 星 Likert 评分、提交修订版解释、勾选所用证据文档，并验证最终答案。收集的数据存入数据库，可用于 CoT 微调、以低分解释为 hard negative 的 unlikelihood 训练、构建 FEVER 式事实核查数据集（SUPPORTED/REFUTED/NOTENOUGHINFO）以及稠密检索训练数据。

关键结果

对 StrategyQA train set 中 300 个预测错误样本的人工分析：Wrong Fact 占 43%、Out of Date 占 22%、Insufficient Knowledge 占 18%，三类合计 83% 的错误可基于检索到的证据文档修订

其余 17% 的错误（GPT-3 反复重复而未给出最终预测，或知识全部正确但推理错误）无法通过证据文档检索辅助修订

在 StrategyQA（question-only set）上，Self-Ask 风格（子问题+子答案）6-shot 提示的 few-shot 准确率优于 Wei et al. (2022b) 的提示；错误解释占比为 29.18%（Table 2 的具体准确率数值未在正文中给出）

创新点

与 Promptsource 等提示标注框架及已有 human-in-the-loop 标注工具相比，CoTEVer 增加了面向解释数据收集的专属功能：证据文档检索与重排、支持多种 CoT 提示、逐步评分与修订收集。与 Self-Ask 原论文用子问题检索并回答问题不同，CoTEVer 用子问题检索证据以辅助人工验证解释。核心新意是把标注者角色从'从头撰写解释'降为'对照证据验证并修订机器生成的解释'，从而降低收集事实正确解释数据的成本。
