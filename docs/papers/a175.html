A Machine with Short-Term, Episodic, and Semantic Memory Systems

具备短期记忆、情景记忆与语义记忆系统的机器

下载原文 PDF

简介

论文针对机器记忆系统难以回答个人化问题（如'某人的物品现在在哪'）的缺陷，受认知科学显性记忆理论启发，构建了同时具备短期、episodic 与 semantic 三种记忆系统的 Agent，每种记忆均以知识图谱四元组存储。作者发布了兼容 OpenAI Gym 的仿真环境 'the Room'，Agent 在部分可观测条件下观察人物放置物品并回答位置问题，用 deep Q-learning 学习短期记忆满时的三选一策略（遗忘/存入情景/存入语义），检索则用基于时间戳与记忆强度的规则算法。关键结论：双长期记忆的 RL Agent 超过仅情景、仅语义与随机基线；用 ConceptNet 预填充语义记忆的 Agent 收敛更快且得分更高（116 vs 109，每回合满分 128）；低容量时优先存语义知识更优。对团队而言，其记忆分层与遗忘/固化策略对 LLM Agent 记忆系统设计有概念借鉴价值，但方法本身依赖 RL 训练而非 LLM。

问题

现有机器学习 Agent 的记忆系统难以回答个人化（episodic）问题，例如'某人的物品现在在哪里'；且记忆容量有限，不可能把每条观察都存为长期记忆。论文要验证的假设是：相比单一记忆系统，同时建模短期、情景与语义三种人类样记忆系统，能让 Agent 在部分可观测环境中更好地回答关于世界状态的问题，并学会在容量受限时决定哪些观察该遗忘、哪些固化为长期记忆。

方法

将三种记忆系统均建模为有容量上限的知识图谱：观察以四元组 (h, r, t, timestamp) 存入短期记忆，满时由 deep Q-learning（LSTM Q-network，输入为三个记忆系统的 KGE 序列表示）学习三选一动作——彻底遗忘、移入情景记忆、移入语义记忆（语义记忆以 strength 替代 timestamp，且 head 去个体化）；情景记忆满时遗忘最旧条目，语义记忆满时遗忘最弱条目；检索采用规则算法（多条情景记忆取时间最新，情景缺失时查语义记忆并取强度最高者）。环境为离散事件仿真 'the Room'（兼容 OpenAI Gym，N_humans=64、N_objects=16、N_object_locations=28、p_commonsense=0.5），部分实验用 ConceptNet 预填充语义记忆作为'预训练'变体。

关键结果

容量 32 时，同时具备情景与语义记忆的 RL Agent 在测试中超过三个基线（总是存情景、总是存语义、随机动作）

语义记忆用 ConceptNet 预填充的 Agent 比从零学习收敛更快，平均测试总奖励 116 vs 109（每回合满分 128）

仅情景记忆的 Agent 性能随容量增长，容量 64 时可答对全部 128 个问题

仅语义记忆的 Agent 在低容量时表现最好，但容量 32 与 64 时均约 92 分，出现平台期

行为分析：预填充 Agent 从不向语义记忆写入新内容（保留初始世界知识），从零学习 Agent 会写入但会犯错（如学到 (train, AtLocation, kitchen) 而非 (train, AtLocation, zoo)）

创新点

与 ACT-R、Soar 等认知架构相比，本文给出了可训练的计算方法（用 RL 学习记忆管理策略）；与 Gorski & Laird 学习情景记忆检索不同，本文学习的是记忆存储（固化/遗忘）策略；与 Tensor Brain 的监督学习关系预测、Episodic Memory Reader 的单一数值嵌入记忆不同，本文的三种记忆均为可解释的知识图谱，并显式区分情景与语义两类长期记忆及其分工。
