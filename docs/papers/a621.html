Augmented Large Language Models with Parametric Knowledge Guiding

基于参数化知识引导（PKG）增强的大语言模型

简介

SOTA LLM 在领域知识密集任务上表现受限，且这类'黑盒'模型只能通过 API 访问、无法用私有数据微调，把数据交给模型方还有隐私风险；检索增强又受制于稠密检索器的浅交互与多源整合能力。论文提出 PKG 框架：将开源'白盒'模型 LLaMa-7B 经 instruction fine-tuning 训练为知识引导模块，运行时为输入生成背景知识，再通过 background-augmented prompting 拼入黑盒 LLM（InstructGPT3.5）的提示，全程不改黑盒参数、无需外部知识库。在 FM2、NQ-Table、MedMC-QA、ScienceQA 四类知识密集任务上分别较直接生成提升 7.9%、11.9%、3.0%、9.1%，并超过 REPLUG、GenRead 等基线，ScienceQA 上还胜过基于 gpt-3.5-turbo 的 Chameleon 工具调用方案。结论是黑盒模型越大收益越大、PKG 模块越大效果越好；但 PKG 可能产生幻觉错误，作者建议未来与检索方法结合。

问题

SOTA LLM 在需要专业领域知识的任务上表现欠佳，因为预训练对相关数据和词汇的覆盖有限；而这类最强模型多为'黑盒'，只能通过 API 访问，无法用领域数据微调，API 微调成本高，且把私有数据交给模型提供方存在泄露与滥用风险。已有检索增强方法则依赖双流稠密检索器，query 与候选文档交互浅、检索模型规模小缺乏世界知识，且难以整合多源/多模态的复杂知识。

方法

提出 PKG（Parametric Knowledge Guiding）框架，遵循 generate-then-read 范式，分两步：(1) 离线知识对齐——收集目标任务/领域的原始数据，转成 (instruction, input, output) 三元组，用 instruction fine-tuning 训练开源'白盒'模型 LLaMa-7B 作为 PKG 模块，使其学会为给定输入生成相关背景知识；(2) 运行时背景增强提示——PKG 先为输入生成背景知识，再通过 background-augmented prompting 把背景与问题拼接后送入黑盒 LLM（InstructGPT3.5 text-davinci-002）作答，全程不改动黑盒模型参数。多模态场景（ScienceQA）为 PKG 加装 CLIP-ViT 提取视觉特征，经单头 cross-attention 与文本特征融合。

关键结果

FM2 事实核查：PKG 较 InstructGPT3.5 直接生成提升 7.9%（67.9% vs. 59.4%），较检索增强 REPLUG 提升 1.4%，较自引导 GenRead 提升 1.8%

NQ-Table 表格问答：PKG 达 28.8%，较 InstructGPT3.5（16.9%）提升 11.9%，较 REPLUG（24.3%）提升 4.5%，较 GenRead（23.5%）提升 5.3%

MedMC-QA 医学问答：PKG 达 47.4%，较 InstructGPT3.5（44.4%）提升 3.0%；CoT 与 GenRead 基线未能带来提升

ScienceQA 多模态：平均准确率 80.76%，较 InstructGPT3.5（71.66%）提升 9.1%，较基于 gpt-3.5-turbo 的模型（含 Chameleon 工具调用，78.31%）高 2.45%

规模分析：黑盒 LM 越大从 PKG 获益越多；PKG 基座从 OPT 1.3B 增至 2.7B 时，FM2/NQ-Table/MedMC-QA/ScienceQA 分别提升 1.4%/1.4%/0.5%/2.5%

创新点

与 retrieve-then-read 范式（BM25/DPR/REPLUG）不同，PKG 用本地可微调的开源白盒模型'生成'而非'检索'背景知识，运行时无需维护外部知识库，私有数据不出本地，也不触碰黑盒 LLM 参数；与 CoT、GenRead 等让黑盒 LLM 自我生成背景的 self-guiding 方法不同，PKG 是用任务数据专门对齐的独立小模块，能提供黑盒模型自身缺乏的领域知识（论文实验显示在医学等任务上 self-guiding 基线无提升而 PKG 有）。另通过 CLIP-ViT 与 cross-attention 把知识引导扩展到多模态输入。
