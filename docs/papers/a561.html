Zero-Resource Hallucination Prevention for Large Language Models

大语言模型的零资源幻觉预防

简介

LLM 在开放对话中会产生幻觉，而已有处理方法几乎都是事后检测：一类依赖外部知识库加 CoT，一类基于困惑度等参数指标，均无法阻止幻觉生成、可解释性差，且性能受指令格式与模型风格影响、跨模型不稳定。论文提出 SELF-FAMILIARITY，一种零资源的事前自评估防幻觉方法：先用 GPT-3.5 做零资源 NER 抽取指令中的概念并做分组与过滤，再让模型解释概念、遮蔽概念词后用 constrained beam search 重建原概念，以最高重建概率作为熟悉度分数，最后按 Wiktionary 词频权重聚合出指令级分数，低于阈值即拒绝作答。在自建 Concept-7 数据集与四个开源模型上，该方法一致优于现有 baseline 且跨模型表现稳定，而 baseline 如 Greedy-Perplexity 在 mpt-7b-instruct 上 F1 为 0。案例研究显示该守门器可与检索结合：检出不熟悉概念后补充背景知识即可纠正回答，适合作为团队问答与 Agent 流程中回答前的幻觉防护与路由开关。

问题

现有开放对话幻觉方法以事后检测为主：一类依赖第三方知识库配合 CoT（如 CRITIC 结合搜索引擎），一类基于模型参数指标（如 SelfCheckGPT 用困惑度与采样一致性）。这些方法只能判断回答是否为幻觉、无法抑制其产生；输出多为自由文本导致分类阈值模糊；且性能深受指令格式与模型风格影响，跨模型表现不一致。论文要解决的是：在 zero-resource（不依赖搜索引擎等外部知识）条件下，在生成之前判断一条指令是否为潜在幻觉指令，若模型对其中概念不熟悉则拒绝作答，把幻觉治理从'事后检测'前移到'事前预防'。

方法

SELF-FAMILIARITY 是生成前的指令级守门器，分三步：(1) Concept Extraction：用 GPT-3.5 作为零资源 NER 抽取指令中的概念实体，再做 Concept Grouping（相邻概念拼接后仍出现在原指令中则融合，如 '2023 United States debt-ceiling crisis'）与 Concept Filtering（用 Wiktionary top 10,000 高频词剔除 'year'、'age' 等常见概念）；(2) Concept Guessing：用解释 prompt 让模型对每个概念生成解释（greedy search），遮蔽解释中的概念词防止模型'抄近路'，再用 constrained beam search（beam size 30）强制模型在回答中重建原概念，取最高响应概率作为该概念的熟悉度分数；(3) Aggregation：基于 Wiktionary 词频排名计算概念频率分（指数变换、归一化因子 H=100），按几何递减权重（r=2）加权平均得到指令级幻觉分数，低于阈值 h（用 192 个基础概念经 bootstrap 95% 区间中点估计、按模型分别校准）则终止响应。整个流程仅用 prompt engineering 与解码控制，不需要任何外部知识。

关键结果

在 Vicuna-13b-v1.3、Falcon-7b-instruct、mpt-7b-instruct、Alpaca-7b 四个模型上，SELF-FAMILIARITY 在幻觉指令分类（AUC/ACC/F1/PEA）上均一致优于全部 baseline，且是唯一跨模型保持稳定表现的方法（具体数值见论文 Table 2）

baseline 跨模型不稳定：Forward-Inference 仅在 Vicuna-13b-v1.3 上表现较好；Greedy-Perplexity 在 mpt-7b-instruct 上未检出任何幻觉指令，F1=0

PEA 相关性表明本方法的评分与基于 gold explanation 的熟悉度标注高度一致

构建 Concept-7 数据集：192 个基础概念/451 条基础指令（用于阈值校准），180 个测试概念/515 条测试指令，覆盖 Medical、Finance、Music、Art、Legal、Physics、History 七个专家领域，其中 74 个为虚构概念

消融实验：去除 Concept Grouping、Concept Filtering 或频率排序均导致性能下降；加权聚合在除 F1 外的指标上整体最优

Amazon Mechanical Turk 人类标注（Vicuna-13b-v1.3）评估中，各方法排名与 GPT-4 自动标注结果一致，本方法在所有指标上仍保持最优

创新点

据作者所述，这是首个在 zero-resource 设定下通过分析指令本身来预防（而非事后检测）开放对话幻觉的工作。技术上融合两条已有路线的优点：像 CoT 方法一样可解释、能定位导致幻觉的具体概念，但只用 prompt engineering 与 constrained beam search，不要求模型具备强 CoT 推理能力；像参数方法一样输出精确分数，但通过'解释-遮蔽-重建'的自评估设计避免直接用困惑度带来的指令风格敏感性。同时提出了首个面向 pre-detection 设定的数据集 Concept-7（真实概念+虚构概念、按模型分别标注熟悉度）。
