Enhancing Few-shot Text-to-SQL Capabilities of Large Language Models: A Study on Prompt Design Strategies

增强大语言模型的 Few-shot Text-to-SQL 能力：提示设计策略研究

简介

该论文系统研究提示设计策略如何提升 LLM 在 few-shot Text-to-SQL 任务上的表现，针对 ICL 方式落后于微调系统、且性能对 demonstration prompt 结构高度敏感的问题展开。方法上提出以 SQL 语法结构的离散向量（而非输入问题的语义向量）作为示例检索依据，在按难度划分的分区上用 k-means 聚类同时兼顾相似性与多样性来选取 demonstrations；并将数据库线性化为 CREATE 代码序列而非文本序列，用 gpt-3.5-turbo 自动生成列语义描述与 Entity-Relationship 摘要来增强 schema 上下文；最后对不同 shot 数的预测经 DBMS 去除执行错误后做 majority vote。最优策略在 Spider 上取得 84.4 的 Execution Accuracy，超过当时 SOTA 系统 2.5 分、最佳微调系统 5.1 分。对团队而言，这是一份关于 few-shot 示例选择、结构化上下文组织与 schema 知识增强的可复用提示工程实证参考。

问题

以 in-context learning 方式驱动 LLM 做 Text-to-SQL 的效果落后于微调系统，且已有研究表明 ICL 性能显著受 demonstration prompt 结构影响。论文要系统回答：在 Text-to-SQL 语义解析任务中，如何选择 demonstration 示例、如何在指令中表示与增强结构化知识（数据库 schema），以最大化 LLM 的 few-shot 表现。

方法

三条核心技术手段：(1) 基于输出结构的示例检索——将示例池中 SQL 解析为离散语法向量（keywords、operators、identifiers 映射为二值特征），推理时先用 preliminary predictor 生成草稿 SQL，按难度类别划入对应分区，再在分区内对语法向量做 k-means 聚类、选取最靠近各质心的 k 个示例，从而同时满足相似性与多样性；(2) 结构化知识的代码风格线性化与增强——用 CREATE 查询序列而非文本序列表示数据库（附带列类型与外键约束），问题与示例数据以注释形式并入代码风格；用 gpt-3.5-turbo 为每列生成自然语言定义（block/inline comment），并构建 Entity-Relationship 摘要枚举表间 join 路径；(3) 集成策略——用不同 shot 数构建多个 prompt 分别预测，经 DBMS 确定性执行剔除错误后做 majority vote 得到最终预测。

关键结果

在 Spider 数据集上取得 84.4 的 Execution Accuracy，比当时 SOTA 系统（Ni et al., 2023）高 2.5 分，比最佳微调系统（Scholak et al., 2021）高 5.1 分

兼顾相似性与多样性的示例选择策略在所有数据集上平均优于 random 选择、纯相似性采样（kNN/KATE）与纯多样性采样（k-means）

将数据库线性化为 CREATE 查询（代码风格）相比文本序列线性化，在 zero-shot 设置下带来明显性能提升

结构增强（ontology/ER 摘要）对 Codex 的 few-shot 设置带来略更大的提升，语义增强（列描述 block comment）对 Codex 的 zero-shot 与 ChatGPT（gpt-3.5-turbo）的 few-shot 更有益

对不同 shot 数模型的预测做 majority vote（剔除执行错误后）带来显著的整体性能提升

preliminary model 的强弱对 similarity-diversity 与 integrated 策略影响较小，仅随模型变强有渐进改善

语法覆盖度（syntax coverage）与语法相似度之和与系统 Execution Accuracy 呈相关性

创新点

区别于已有工作（如 KATE）基于输入问题/数据库的连续语义向量做 kNN 示例检索，本文提出以输出 SQL 的语法结构离散向量作为检索基础，并同时优化相似性与多样性两个采样目标；此外提出用 CREATE 代码序列替代文本序列来线性化数据库，用 LLM 自动生成列语义描述与 Entity-Relationship 摘要增强 schema 上下文，并组合多 shot 多数投票的集成策略。论文还系统比较了多种 embedding（Sentence-BERT、RoBERTa、text-embedding-ada-002、CodeT5、CodeBERT 等）在相似性/多样性检索中的表现。
