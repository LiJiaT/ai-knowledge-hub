Unifying Large Language Models and Knowledge Graphs: A Roadmap

简介

该综述针对 LLM 作为黑盒模型缺乏事实知识、易产生幻觉且缺乏可解释性，而 KG 以三元组结构化方式显式存储准确、可解释知识却难以构建与演化的问题，提出了统一 LLM 与 KG 的路线图。方法上归纳为三大框架：KG-enhanced LLMs（将 KG 注入预训练目标/输入/指令微调，或在推理阶段通过 Retrieval-Augmented Knowledge Fusion 与 KGs Prompting 注入知识，并用 KG 做 LLM probing 与可解释性分析）、LLM-augmented KGs（用 LLM 做 KG embedding、补全、构建、graph-to-text 与 KGQA）、Synergized LLMs + KGs（联合表示与协同推理，含 LLM 作为 Agent 通过 API 接口在 KG 上多步推理）。关键结论：预训练注入适合时不变知识但无法在不重训的情况下更新；推理时检索/提示注入适合频繁更新的开放域知识；对黑盒 LLM 只能靠 prompt 注入知识但受输入 token 长度限制；幻觉检测与知识编辑是重要未来方向。对团队而言，它是知识库问答中结构化知识注入与 Agent 化推理的方法地图。

问题

LLM 是黑盒模型，难以捕获和访问事实知识，存在幻觉、缺乏可解释性、缺少领域特定与新知识；而 KG 虽然显式、结构化、准确且可解释，但构建困难，现有方法难以处理不完整和动态变化的真实世界知识、难以建模 unseen 实体。论文要解决的问题是：如何统一 LLM 与 KG，使二者互补、相互增强，服务于各类下游任务。

方法

提出三框架路线图并做细粒度分类：1) KG-enhanced LLMs——将 KG 融入训练目标（ERNIE、KEPLER 等）、LLM 输入（K-BERT、Colake 等）与 KGs Instruction-tuning（RoG 等）；推理阶段采用 Retrieval-Augmented Knowledge Fusion（RAG、KGLM、REALM、EMAT 等）与 KGs Prompting（将三元组/图结构转为文本上下文，如 Mindmap、ChatRule、CoK）；并用 KG 做 LLM probing（LAMA、LPAQA、Autoprompt、LLM-facteval）与推理过程分析。2) LLM-augmented KGs——LLM 作为文本编码器或生成器服务于 KG embedding、KG completion（PaE/PaG 两条路线）、KG construction（NER/CR/RE 及端到端构建、从 LLM 蒸馏 KG）、KG-to-text、KGQA。3) Synergized LLMs + KGs——联合知识表示（ERNIE、DRAGON 等）与协同推理，包括 LLM-KG Fusion Reasoning，以及 LLMs as Agents Reasoning（KD-CoT、KSL、StructGPT、Think-on-Graph、AgentTuning）。
