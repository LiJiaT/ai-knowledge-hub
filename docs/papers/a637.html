In-Context Probing: Toward Building Robust Classifiers via Probing Large Language Models

In-Context Probing：通过探测大语言模型构建鲁棒分类器

简介

论文针对 in-context learning (ICL) 在下游分类任务中对指令措辞高度敏感、且自回归解码标签存在 miscalibration 与效率问题，提出 In-Context Probing (ICP)：仍用指令对输入做上下文化，但不解码输出，而是在模型最后一层 contextualized representation 上训练 logistic regression 或单层 attention 轻量探针来预测标签。在 MQP、CLIMATE、TWEETEVAL 三个分类任务和多个规模的 FLAN-T5 上实验显示：ICP 对指令变化显著更鲁棒；大模型上与 ICL 及 calibrated ICL 相当或更好，小模型上 ICL 接近随机而 ICP 显著更优；仅约 40 条标注样本即可与 ICL 竞争，且与 finetuning 相当的同时可训练参数少 4-6 个数量级。对团队的价值在于：一方面量化揭示了提示措辞敏感性这一可靠性风险及校准手段的局限，另一方面给出小样本构建稳定分类器的低成本路径。

问题

用 ICL 构建分类器存在三类问题：(1) 下游性能高度依赖指令的具体措辞与演示样本，且这种依赖以不可预测的方式出现（看似更信息丰富的指令可能更差）；(2) 可用演示样本数量受模型最大输入长度限制；(3) 自回归解码标签既不准确（miscalibration、surface form competition）也不高效（O(N²) 解码开销）。论文寻求一种不更新模型权重、比 ICL 更准确鲁棒、比 finetuning 更省资源的分类器构建方式。

方法

提出 In-Context Probing (ICP)：将 instruction 与输入拼接后送入预训练模型（FLAN-T5），取最后一层 contextualized representations，绕过解码步骤，直接在其上训练轻量探针预测分类标签；探针为 logistic regression probe（线性分类）或单头 attentional probe（以 instruction token 的固定表示 r0 作为 query），用交叉熵损失训练。实验对比 ICL、calibrated ICL（用 content-free prompt 估计标签偏置并做概率校准）与 prompt-based finetuning，覆盖 3 个分类任务与 5 个规模的 FLAN-T5 模型。

关键结果

鲁棒性：ICP 对指令变化的敏感性显著低于 ICL 与 calibrated ICL；CLIMATE 任务上指令的微小改写可使 ICL 降至接近随机准确率，而 ICP 保持稳定；calibration 仅在 MQP 上降低指令间方差，在 CLIMATE 与 TWEETEVAL 上无帮助

整体性能：较大模型（如 FLAN-XXL）上 ICP 与 ICL/calibrated ICL 相当或更好且方差更小；较小模型（FLAN-SMALL/FLAN-BASE）上 ICL 通常接近随机预测，ICP 显著优于随机并达到大模型 ICL 的水平

样本效率：TWEETEVAL 上仅用 40 条训练样本训练探针即可与 ICL 竞争；MQP 任务上 ICP 用 40 样本达到解码基线，而不带指令的普通 probing 需 80 样本

与 finetuning 对比（200 训练样本预算）：ICP 在不同模型规模与任务上性能相当或更优，可训练参数少 4-6 个数量级，且两者对训练指令变化的标准差相当

探针架构消融：logistic regression probe 与 attentional probe 的 F1 Macro 性能相当，前者计算更少

创新点

将 probing 从'诊断表示中是否编码了某属性'的研究工具重新定位为构建分类器的替代工作流：与 ICL 共享'用指令上下文化输入'的思想，但引入直接训练信号并绕过标签解码；与 finetuning/PEFT 相比，不需要访问或修改模型权重、不需要了解模型架构，只需最后一层输出表示，且仅需约百条标注样本即可训练。
