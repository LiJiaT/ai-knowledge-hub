Towards Reasoning in Large Language Models: A Survey

迈向大语言模型（LLM）的推理：一篇综述

简介

这篇综述系统梳理了 LLM 推理研究的现状，围绕三个问题展开：什么是推理、如何激发与增强 LLM 的推理、如何评测推理。论文将技术路线分为三类：全监督微调；提示与 in-context learning（涵盖 CoT 及其变体、Rationale Engineering 的示例精炼/探索/验证、least-to-most 等问题分解方法）；以及结合训练的混合方法（推理增强微调与 STaR 式自举自改进），并汇总了 GSM8K、BIG-bench、ROSCOE、FOLIO 等评测基准。关键结论：推理能力似乎是模型规模达到一定水平后的涌现能力；CoT 能显著提升推理任务表现并改善分布外鲁棒性；但 LLM 在复杂推理上仍不可靠，现有评测多只看端到端准确率、缺乏对推理步骤质量的深入分析，因此尚不能断言 LLM 真正具备推理能力。对团队而言，它是一份覆盖提示技术与推理评测方法的基础性索引。

问题

尽管 LLM 在某些推理任务上表现强劲，但学界对 LLM 是否真正具备推理能力、能力边界在哪仍不清楚（不同研究结论相互矛盾），且该领域发展迅速、缺乏系统梳理。论文旨在对 LLM 推理的知识现状做全面综述：澄清推理概念、归纳激发/增强推理的技术、整理评测方法与基准、总结关键发现并指出未来方向。

方法

作为综述，其核心贡献是一套分类框架：1) 概念澄清：区分演绎/归纳/溯因等推理类型与形式化/非正式推理，聚焦 LLM 中的'非正式演绎推理'；2) 技术分类：全监督微调（需含显式推理的数据集）；提示与 in-context learning——CoT 及其变体（Zero-shot-CoT、将推理构造成代码生成、多语言 CoT 等）、Rationale Engineering（rationale refinement 如 complexity-based prompting、algorithmic prompting、Auto-CoT 自动聚类构造示例；rationale exploration 如 self-consistency 采样投票；rationale verification 如训练外部 verifier 或用 LLM 自校验）、问题分解（least-to-most prompting、dynamic least-to-most、decomposed prompting、successive prompting）及其他（selection-inference、backward chaining、推理蒸馏）；混合方法（在含科学/数学/SQL/CoT 数据上继续训练或微调、STaR 自举自改进）；3) 评测方法：端到端任务基准（GSM8K、Math、CSQA、StrategyQA、BIG-bench 等）与推理步骤级分析（ROSCOE、PrOntoQA、FOLIO）；4) 发现综合与批判性讨论。
