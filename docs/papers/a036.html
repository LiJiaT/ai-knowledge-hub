MEM1: Learning to Synergize Memory and Reasoning for Efficient Long-Horizon Agents

MEM1：学习协同记忆与推理以实现高效长程 Agent

简介

长程多轮 Agent 普遍采用 full-context prompting，把所有历史轮次追加进上下文，导致内存无界增长、推理成本上升、超出训练长度后推理退化，且冗余内容稀释注意力。MEM1 用端到端强化学习训练 Agent 在每轮把先前记忆与新观测整合进一个紧凑的内部状态 <IS>，并剪裁上一轮上下文，从而在任意长任务中保持近似恒定的内存占用；训练基于 Qwen2.5-7B Base 与 PPO，用 masked trajectory 和 2D attention mask 保证动态上下文下策略优化正确，并把现有 QA 数据集组合成多目标任务用于训练与评测。关键结论：仅用 2 目标任务训练的 MEM1-7B 在 16 目标 multi-hop QA 上比 Qwen2.5-14B-Instruct 性能提升 3.5×、内存降低 3.7×，峰值 token 仅为后者的 27.1%。对团队而言，其'推理即记忆整合'的上下文管理模式与 prompt/rollout 模板可不训练直接借鉴，但完整方法依赖 RL 训练与可验证奖励环境。

问题

现有 LLM Agent 在长程多轮交互中把全部历史观察、动作与思考追加进上下文，带来三个问题：(1) 推理成本与内存随上下文长度 N 无界增长（O(N²) 计算，KV cache 下 O(N) 内存）；(2) 超出训练数据长度的对话成为 OOD 输入，模型难以管理与推理；(3) 无关冗余内容稀释注意力，即使相关信息仍在 prompt 中也损害推理。此外，现有训练与评测环境多聚焦单目标任务，缺乏支持长程多目标交互的数据集。

方法

MEM1 把记忆整合作为推理的一部分：每轮 Agent 生成新的内部状态 <IS_t>，将上一轮的 (<IS_t>, <query_t>, <info_t>) 整合压缩为新的 <IS_(t+1)>，随后程序化剪裁上一轮全部标签，任意时刻上下文只保留最近两个 <IS>、两个 <query> 和一个 <info>，实现近似恒定内存。训练上从 Qwen2.5-7B Base 出发，用 PPO 与可验证奖励（QA 用 exact match，WebShop 用环境内置奖励）做端到端 RL，并设计 masked trajectory 与 2D attention mask，保证动态上下文下 log-probability ratio、优势、KL 惩罚与价值估计正确。另提出多目标任务构造法，把 HotpotQA、Natural Questions 等单目标 QA 数据交错组合成 N 目标复合任务，并在 <info> 前注入剩余轮数提示（turns-left hint）帮助 Agent 判断终止。

关键结果

16 目标 multi-hop QA 上，MEM1-7B 相比 Qwen2.5-14B-Instruct 性能提升 3.5×、内存占用降低 3.7×，且仅用 2 目标任务训练即泛化到 16 目标（超出训练视野）

16 目标任务上，MEM1 仅需 Qwen2.5-14B-Instruct 27.1% 的峰值 token 与 29.3% 的总推理时间；相对最佳未崩溃基线，峰值内存低 1.27×、推理快 1.78×，准确率超过所有基线

WebShop 网页导航上相对最佳基线 AgentLM：Peak Token Usage 提升 2.8×、Dependency 提升 1.9×、Inference Time 提升 1.5×，并超过参数量翻倍的 AgentLM-13B

单目标 Wikipedia QA 上取得最高 EM，F1 与 Qwen2.5-14B-Instruct 相当且三项效率指标全面占优；零样本迁移到未见过的在线 Web-QA 环境仍保持效率优势与可比效果

RL 训练显著优于 SFT：多目标任务数超过 6 后 SFT 模型性能崩溃，RL 模型保持稳健与可扩展性

格式奖励加速收敛但损害最终性能：2 目标 QA 上 EM 为 0.466，仅用结果奖励的 MEM1 为 0.709；平均峰值 token 分别为 514.9 与 640

创新点

与外部记忆模块（摘要器/检索器，如 A-MEM 的向量库记忆）需单独训练、无法与 Agent 策略端到端联合优化不同，MEM1 把记忆整合统一进推理过程，用单一内部状态表示，无需额外模块或架构改动；与现有 RL Agent 训练（Search-R1、DeepResearcher 等）任由 prompt 无界增长不同，MEM1 在 rollout 中每轮剪裁上下文，并用 masked trajectory + 2D attention mask 解决动态演化上下文下的策略优化问题；同时提出把现有单目标 QA 数据集组合成任意复杂多目标任务序列的可扩展任务增强方法。
