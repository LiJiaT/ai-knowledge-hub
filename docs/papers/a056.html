Extending Context Window of Large Language Models via Positional Interpolation

通过 Position Interpolation（位置插值）扩展大语言模型的上下文窗口

mediumarXiv上下文窗口评测基准基于arXiv版本
下载原文 PDF

简介

LLaMA 等 RoPE-based 预训练 LLM 的上下文窗口固定（2048 tokens），直接外推位置编码会使注意力分数出现灾难性数值（perplexity >10^3），而直接用长窗口微调收敛极慢（10000+ 步仅从 2048 提升到 2560）。论文提出 Position Interpolation（PI）：不外推位置，而是把输入位置索引线性缩放回预训练窗口范围后再计算 RoPE，并从理论上证明插值后的注意力分数上界比外推小约 600 倍，因而稳定且易适配。PI 不引入新参数、不修改模型架构，只需在 the Pile 等语料上微调约 1000 步，即可把 LLaMA 7B–65B 扩展到最高 32768 窗口；passkey retrieval 显示 200 步后有效窗口即达标，长文本 perplexity 随窗口增大持续下降，原 2048 窗口基准最多退化约 2%（8192 情形）。对团队而言这是模型侧技术，不涉及自身训练，但有助于理解长上下文模型的机理与选型，其 passkey retrieval 有效窗口测法可用于验收团队实际使用的长上下文模型。

问题

预训练 LLM（如 LLaMA）带有固定的上下文窗口（2048 tokens），而长对话、长文档摘要、长期规划等应用需要更长窗口；从头训练长窗口模型代价高昂，直接外推 RoPE 位置编码会导致注意力分数爆炸（perplexity >10^3，与未训练模型相当），直接用更长窗口微调原模型又适应极慢。论文要解决的问题是：如何以最小的微调代价，把已有 RoPE-based 预训练 LLM 的上下文窗口大幅扩展，同时尽量保留原窗口内的能力。

方法

提出 Position Interpolation（PI）：不做位置外推，而是将输入位置索引从 [0, L') 线性下采样（down-scale）到 [0, L)（L 为原预训练窗口），使最大相对距离落在训练过的区间内再计算 RoPE，从而缓解窗口扩展对注意力分数计算的影响。理论上（Theorem 2.1）证明插值注意力分数上界比外推上界至少小约 600 倍（LLaMA 7B 设定，2 × 294.73），因此更稳定。方法不引入额外权重、不修改模型架构，可复用既有基础设施与优化；随后用 next token prediction 目标在长文本语料（the Pile / RedPajama）上仅微调约 1000 步（AdamW，PyTorch + FSDP + Flash Attention，32–128 张 A100）即可完成适配。

关键结果

将 LLaMA 7B/13B/33B/65B 从 2048 扩展至最高 32768 上下文窗口，PI 仅需约 1000 步微调；passkey retrieval 中有效窗口 k_max = L' 在仅 200 步微调后即达成，在 7B 与 33B、最高 32768 窗口上一致成立

直接微调基线在 10000+ 步后有效窗口仅从 2048 增至 2560；直接外推在 8192 窗口下 perplexity > 10^3，而 PI 模型未微调（step 0）时即 < 20

语言建模（2048→16384）：LLaMA 7B 在 PG19/proof-pile 上 perplexity 分别降低 0.28/0.5，13B 降低 0.27/0.48，33B 降低 0.14/0.42；65B 扩至 8192 降低 0.12/0.3；7B/13B 在 PG19 上该趋势延续到 32768 无衰减

原 2048 窗口基准：扩展到 8192 的模型性能退化最多约 2%（7B 与 33B）；proof-pile 上原窗口 perplexity 退化 0.01–0.05

GovReport 长文档摘要（16384 窗口，微调 10 epochs）：ROUGE-1 在 SCROLLS 排行榜已有模型中具竞争力

理论结果：插值注意力分数上界比外推上界至少小约 600 倍

创新点

区别于 ALiBi、LeX 等'短窗口训练、长窗口推理'的外推路线（这些方法尚未被 LLaMA、OPT 等使用弱外推位置编码的大模型采用），PI 面向已有预训练模型，通过缩放位置索引而非外推来扩展窗口，并给出插值 vs 外推的注意力分数上界理论对比（约 600 倍）。相比 ViT 中对可学习位置嵌入做插值（Dosovitskiy et al., 2021），PI 插值的是位置索引本身、不新增可训练参数，且把扩展倍数从 4x 推进到 32x；相比并行的 SuperHOT 博客（2K→8K），本文验证了至 65B 的全参数微调并给出理论解释。
