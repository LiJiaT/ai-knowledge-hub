Guiding Large Language Models via Directional Stimulus Prompting

通过 Directional Stimulus Prompting（方向性刺激提示）引导大语言模型

简介

黑盒 LLM 无法直接微调，而通用任务级提示难以引导模型产出符合细粒度、实例级要求的输出。论文提出 Directional Stimulus Prompting（DSP）框架：用一个可训练的小型策略模型（T5-Base/Flan-T5-Large）为每个输入生成'方向性刺激'——摘要关键词、dialogue acts 或 CoT 触发句——插入提示后再调用黑盒 LLM；策略模型先用启发式构造的伪刺激做 SFT，再以下游任务指标为奖励、用 PPO/NLPO 加 KL 惩罚做强化学习，把对 LLM 的对齐问题转化为对小策略模型的优化。实验显示：仅 4,000 条样本训练的策略模型使 ChatGPT 摘要 ROUGE/BLEU 提升 4-13%；仅 80 条对话即使 ChatGPT 在 MultiWOZ 上 Combined 分数提升 41.4%，媲美或超过全量数据训练的 SOTA；实例级 CoT 触发提示优于 14 条人工提示与 APE 自动提示。对团队而言，这是'以小模型自动生成实例级提示'的代表性提示工程方法，其'评测指标作奖励优化提示'的思路可直接借鉴。

问题

黑盒 LLM（ChatGPT、Codex、InstructGPT 等）只能通过 API 访问、参数不可调，直接微调不可行或计算上低效；而标准提示（任务级指令+少量示例）难以在细粒度、实例级层面引导 LLM 生成符合期望的输出，已有标注数据也难以被有效用于引导 LLM。

方法

提出 Directional Stimulus Prompting（DSP）：在提示中额外引入一小段离散 token 的'方向性刺激' z，作为实例级提示与线索引导黑盒 LLM。刺激由一个小型可调策略模型 p_POL(z|x)（220M T5-Base 或 750M Flan-T5-Large）针对每个输入生成，再与原输入 x 一起构造提示调用 LLM。不同任务使用不同刺激形式：摘要用应覆盖的关键词、任务型对话用 dialogue acts、推理用 CoT 触发句。策略模型训练分两步：(1) 监督微调（SFT）——用启发式构造的伪刺激数据（textrank 抽取且出现在参考摘要中的关键词、数据集自带的 dialogue act 标注、能触发正确推理的人工提示）训练；(2) 强化学习——把 LLM 输出质量作为奖励（ROUGE-Avg、SacreBLEU、推理正确率或人类偏好），用 PPO 的 NLPO 变体加 KL 散度惩罚优化策略模型，从而把对黑盒 LLM 的优化转化为对小策略模型的优化。

关键结果

摘要（CNN/Daily Mail）：仅用 4,000 样本训练的策略模型使 ChatGPT 的 ROUGE 与 BLEU 提升 4-13%；用 1,000-4,000 样本训练时，DSP 使 ChatGPT 的 ROUGE、BLEU、Meteor 一致提升 1-2 分

任务型对话（MultiWOZ 2.0/2.1）：仅用 80 条对话（训练集的 1%）训练策略模型，ChatGPT 的 Combined 分数提升最高 41.4%，Success/Inform 超过多个用全量 8,438 条对话训练的模型；用 800 条（10%）时与全量数据训练的 SOTA 方法相当

CoT 推理（MultiArith、AQuA）：策略模型生成的实例级触发提示使 InstructGPT（text-davinci-002）准确率超过 14 条人工提示及 APE 自动发现的提示；仅 SFT 达不到峰值，RL 后进一步提升

GPT-4 评估：500 条测试样本中，DSP 摘要被偏好 255 次（51.0%），标准提示摘要被偏好 222 次（44.4%），平局 23 次（4.6%）

增加 SFT 数据量（80→800 条对话）不保证性能提升，但对策略模型做 RL 微调一致带来额外收益

创新点

相对已有工作的区别：(1) 与 RAG 等外部知识增强不同，刺激仅由输入查询本身生成，不依赖外部检索；(2) 与人工设计或 APE 等任务级提示优化不同，DSP 提供实例级细粒度引导；(3) 与 soft prompt tuning 不同，无需梯度穿过黑盒 API；(4) 与 PPLM、GeDi、DExperts 等可控生成方法不同，不需要模型内部梯度或 logits；(5) 与 InstructGPT 式 RLHF 直接优化 LLM 不同，DSP 优化的是生成刺激的小策略模型，绕开对 LLM 本身的高成本优化。
