简介

论文针对两类提示的取舍问题：硬提示（可读的离散文本 token）依赖人工试错与直觉手工 crafting，软提示（连续向量）虽可梯度优化却不可解释、无法跨模型复用、也难以接入纯文本 API。作者提出 PEZ 算法：优化全程维护连续嵌入作为中间变量，每次前向传播前先投影到词表最近邻 token 并对离散嵌入求梯度，再用梯度更新连续嵌入，从而用梯度法直接搜索可读的硬提示。该方法在文生图场景以 CLIP 相似度为损失自动反演提示驱动 Stable Diffusion，在文本分类场景自动发现可从小模型迁移到大模型的分类提示。关键结论包括：仅 8 个 token 即可接近依赖 77 token 与 BLIP 的 CLIP Interrogator；AGNEWS 上比其他梯度方法高约 2%，提示从 GPT-2 Large 迁移到 OPT-6.7B 可带来约 14% 提升；论文还演示了提示拼接与蒸馏，并警示该技术可绕过关键词级内容过滤。

问题

硬提示由可解释单词/token 组成、可移植可复用，但需人工试错手工 crafting；软提示是连续特征向量，可用梯度优化自动发现，却不可解释、因嵌入空间不同无法跨模型迁移，且无法用于只能控制文本输入的 API 场景。论文希望用高效的梯度离散优化自动生成硬提示，兼得软提示的自动化与硬提示的可读性、可移植性，覆盖 text-to-image 与 text-to-text 两类应用。

方法

提出 PEZ（Hard Prompts made EasY）算法：优化过程中始终维护连续（软）嵌入作为迭代变量；每次前向传播前用投影函数 Proj 将其映射到词表嵌入矩阵的最近邻 token，对投影后的离散嵌入计算任务损失梯度，再用该梯度更新连续嵌入，最终投影回离散 token。相比 AutoPrompt（贪心逐位置评估候选、需大量额外前向）与 FluentPrompt（Langevin 动力学加流畅度惩罚），该方法对学习率与数据噪声更鲁棒、避免嵌入停滞。文生图场景以 CLIP 图文余弦相似度为损失，完全避免对扩散模型求梯度；文本分类场景在任务损失上加 fluency 损失（λ=0.003）。另支持提示拼接（将多个独立优化出的提示连接以组合场景）与提示蒸馏（优化更短提示去匹配长提示的文本编码器嵌入，蒸馏比最低至 0.1）。

关键结果

文生图：在 LAION、MS COCO、Celeb-A、Lexica.art 四个数据集上，PEZ 仅用 8 个 token 在 CLIP score 上优于 AutoPrompt SGD 与 FluentPrompt 等梯度基线，并接近使用 77 token、BLIP 模型与大型关键词库的 CLIP Interrogator（后者在 Celeb-A 上并非最高）

提示长度消融：16 个 token 泛化性最好；更长提示虽降低 CLIP 图像编码器训练损失，但验证 CLIP score 下降，说明长提示过拟合、迁移性差

提示蒸馏：在 0.7/0.5/0.3/0.1 四种蒸馏比下，即使只有 3-4 个 token，提示仍能生成与原长提示概念高度相似的图像

文本分类：在 SST-2 与 Amazon Polarity 上与其他方法相当，在 AGNEWS 上比其他方法高约 2%；软提示基线在 GPT-2 Large 上达 93.35±0.01 但无法跨模型迁移

跨模型迁移：GPT-2 Large 上训练的提示迁移到 GPT-2 XL、T5-LM-XL、OPT-2.7B、OPT-6.7B，带 fluency 约束的方法迁移最好，在 OPT-6.7B 上比空模板基线高约 14%

Few-shot：AGNEWS 上每类 2 或 4 个样本、100 个随机种子下即可取得较高验证精度，每次 few-shot 运行约 5 分钟

安全实验：PEZ 可生成不含被禁词 'Afghan' 的提示，在 Midjourney 上复现被屏蔽的版权图像，且防御方追加屏蔽词后仍可迭代绕过

创新点

区别于以往'每步更新后将嵌入投影回最近邻'的离散提示优化方法（AutoPrompt、FluentPrompt），PEZ 借鉴二值网络领域'维护连续表示而非随机舍入'的经验，把软提示作为优化的中间变量、仅在前向时投影，使梯度信息跨步累积，避免嵌入停滞与大量超参调优；同时将硬提示自动发现统一应用于 CLIP 提示反演（文生图）与 LM 分类提示调优（文本）两类任务，并展示学到的提示可作为可组合、可蒸馏的构建块。
