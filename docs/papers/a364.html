MERRIN: A Benchmark for Multimodal Evidence Retrieval and Reasoning in Noisy Web Environments

MERRIN：嘈杂 Web 环境中的多模态证据检索与推理基准

简介

论文针对真实 Web 搜索中查询不含模态提示、证据多模态且常相互冲突的问题，构建人工标注基准 MERRIN，评测搜索增强 Agent 识别所需模态、检索多模态证据并在嘈杂来源上做多跳推理的能力。基准含 162 题，要求问题无显式模态线索、必须依赖非文本证据、答案唯一可验证，覆盖 text/image/video/table 四类来源，并用对抗性文本搜索排除捷径。作者用 10 个模型在 No Search、Native Search、Agentic Multimodal Search 三种设置下评测，平均准确率仅 22.3%，最佳配置 Gemini-3.1-Pro + Agentic Multimodal Search 也仅 40.1%，而人类达 71.4% 且搜索次数约为 Agent 的三分之一。分析显示强 Agent 易过度探索（超时、超工具调用上限）、检索证据 87.7% 偏向文本，注入 gold 证据也仅提升 7.6%，说明推理是比检索更紧迫的瓶颈。其评测方法（gold 证据消融、失败模式分类、LLM-as-judge）可迁移到团队知识库问答与搜索类 Agent 的内部评测与错误归因。

问题

现有搜索增强 Agent 评测基准存在三大不足：查询常含显式模态提示（如'如下图所示'）、模态覆盖多限于文本与图像（缺少视频/音频）、且未充分刻画真实开放 Web 中嘈杂、冲突、不完整证据对推理的影响。论文要解决的问题是：如何系统评测 Agent 在无模态提示的自然语言查询下，自主判断所需模态、从嘈杂多模态 Web 来源中检索证据并完成多跳推理与冲突消解的能力，并进一步定位失败源于检索还是推理。

方法

构建人工标注诊断基准 MERRIN（162 题，120 题全新构造，部分改编自 SealQA 与 ChartMuseum）：每题须满足无模态线索、必须依赖非文本证据、答案唯一可验证三项要求，并按推理类型（多跳/多模态冲突消解）与多模态角色（答案来源/推理组件）两轴标注；经多轮人工评审与对抗性文本搜索两遍验证做质量控制。评测覆盖 10 个模型（GPT-5.4 系列、Gemini 3/3.1 系列、Gemini Deep Research、Qwen3 系列）× 三种搜索设置（No Search / Native Search / 基于 smolagents 构建的 Agentic Multimodal Search，配备 visit webpage、watch video 等自定义工具），用沿用 BrowseComp 的 LLM-as-judge 自动判分；并通过逐级注入 gold 证据的消融（Gold Sources Injection / Gold Sources Only / Gold Sources Prompting）解耦检索与推理瓶颈，辅以 50 题人类对照实验分析搜索行为与错误类型。

关键结果

全部运行平均准确率 22.3%；最佳为 Gemini-3.1-Pro + Agentic Multimodal Search 的 40.1%；六模型平均下 No Search 17.3%、Native Search 23.1%、Agentic Multimodal Search 33.7%

从开放搜索到提供完美 gold 证据，准确率仅提升 7.6%（40.1% → 47.7%），表明推理是比检索更紧迫的瓶颈

人类在 50 题子集上达 71.4%，平均 2.9 次搜索/2.9 次网页访问（Agentic 系统为 9.1 次搜索），URL 精确率 38.1% vs Agent 的 1.8%；人类 Acc@5min 59.2% 到整体 71.4% 提升 12.2%，而 Agent 仅提升 1.3%~6.1%

最佳 Agent 检索证据中 87.7% 为文本（数据集真实分布为 31.4% 文本、35.9% 图像、28.8% 视频/音频），存在强烈文本模态偏置

Gemini Deep Research 平均 33.1% 题目超时（持续搜索长达 15 分钟无答案）；Gemini Pro Native Search 平均 12.7% 题目触发 TOO MANY TOOL CALLS

为 Native Search 增加视频处理工具平均绝对提升 5.7%（四个 Gemini 模型，+1.0% 至 +8.5%）

GPT-5.4-mini 在 Agentic Multimodal Search 下从无思考到最高 thinking effort 绝对提升 8.6%

两步推理链的错误预测中 57.7% 在第一步失败，早期错误向最终答案传播

开放权重 Qwen 系列从 No Search 到 Agentic Multimodal Search 平均仅提升 6.5%，闭源模型平均提升 16.4%

创新点

相对已有基准的三个独特之处：(1) 查询为自然语言、不含显式模态提示，迫使 Agent 自主判断所需模态，而此前基准多用'如下图所示'类提示；(2) 纳入视频、音频等此前少被覆盖的模态；(3) 显式引入真实开放 Web 的嘈杂、冲突、不完整证据（冲突由真实搜索引擎触发、非合成构造），并要求多跳推理。此外，论文系统解耦检索与推理两类瓶颈，并量化了过度探索、文本模态偏置、多步错误传播等失败模式，以及人机搜索行为对比，这些诊断维度在先前搜索类基准中缺失。

团队参考意义

相关度级别：high

命中能力域：3.1 上下文工程与记忆 | 3.3 Agent 架构与工具使用 | 3.5 评测与可靠使用

理由：直接命中三个能力域：3.5 评测与可靠使用——论文本身即评测搜索增强 Agent 的基准，提供 LLM-as-judge 判分、gold 证据逐级注入解耦检索/推理瓶颈、人机对照等可复用的评测方法，并给出成本（搜索次数、页面访问、超时率）与可靠性（过度探索、错误传播）的量化分析；3.3 Agent 架构与工具使用——对比 No/Native/Agentic 三种搜索设置，分析工具增补（视频工具平均 +5.7%）、工具调用上限与收敛行为对单 Agent 执行可靠性的影响；3.1 上下文工程与记忆——核心研究嘈杂、冲突的检索结果作为上下文对下游推理的干扰（真实 distractors 会主动劣化 Agent 推理），即 RAG 场景的检索质量与噪声管理问题。团队构建知识库问答与搜索类 Agent 时面临同样的'检索噪声导致推理失败'与'Agent 过度探索浪费成本'问题，其 Reasoning/Modality/Retrieval Error 失败模式分类可直接作为内部错误归因框架。需注意其多模态（视频/音频）重心超出团队以文本为主的日常场景，该部分结论需选择性借鉴。
