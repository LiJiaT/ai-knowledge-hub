Autonomous Tree-search Ability of Large Language Models

大语言模型（LLM）的自主树搜索能力

简介

该论文研究如何让 LLM 不借助外部程序、在单次回复内自主完成树搜索。针对 CoT 只能单路径推理、而 ToT 等被动搜索需为每个任务编写搜索代码且要多轮 API 调用、成本高的问题，作者提出 Autonomous Tree-Search（ATS）：用一条跨任务固定的 system prompt 让 GPT-4 直接生成 BFS 或 DFS 结构的搜索轨迹（ATS-BFS/ATS-DFS），并自建四个拼图数据集、以 GPT-4 API 成本为指标系统评测。结果显示 ATS-BFS 平均比 CoT 提升 33% 准确率，达到与 ToT 相当精度时节省 65.6% 或 47.7% 的 API 成本；用 ATS 数据微调的 LLaMA2-7B/13B 分别超过 CoT 微调模型 40.6%/38.5%。对团队而言，这是一篇典型的推理提示技术加成本效率评测论文，其提示模板与评测思路可直接借鉴，但任务均为谜题、未验证工程场景。

问题

CoT 等提示技术使 LLM 具备逐步推理能力，但在需要探索、策略性前瞻和序列决策的任务上表现不足；已有工作（如 Tree of Thoughts）用外部程序定义搜索逻辑、让 LLM 执行被动搜索，存在三大缺陷：求解单个问题需多轮 LLM API 调用导致成本高、需要针对每个任务专门设计程序而不灵活、无法像 CoT 那样在聊天中直接使用。论文要回答：能否不依赖外部程序，让 LLM 自主生成清晰体现树结构搜索过程的回答。

方法

提出 Autonomous Tree-Search（ATS）概念：让 LLM 在单次回复中自行写出树搜索轨迹，按展开方式分为 ATS-BFS（逐层维护多个场景分支）与 ATS-DFS（深入尝试、失败后回溯）。对 GPT-4 采用一条所有任务通用的固定 system prompt（零样本）或少量任务示例（few-shot）激活该能力；对小模型（LLaMA2-7B/13B）用 ATS 增强的 GPT-4 生成的问题-回答对做监督微调（ATS-tuned），并与剪枝成链状的 CoT-tuned、ToT-tuned 对比。作者自建四个拼图数据集（Drop Water、Number Path、Arithmetic、Minimal Grass），以 GPT-4 API token 成本为效率指标，在低成本/高成本两种设置下与 CoT、ToT 基线比较。

关键结果

ATS-BFS 平均准确率比 CoT 提升 33%

达到与 ToT 相当准确率时，所需 GPT API 成本减少 65.6% 或 47.7%

用 ATS 数据微调的 LLaMA2-7B 与 LLaMA2-13B 平均分别超过 CoT 微调模型 40.6% 与 38.5%

零样本设置下 ATS-BFS 综合最有效：成本与 ToT(width=1) 相当却显著优于 CoT 与 ToT(width=1)，并以低得多的成本达到或超过 ToT(width=5) 的性能；ATS-DFS 零样本表现不稳定，有时不如 CoT

few-shot 下 ATS-DFS 在求解型拼图上总体最佳，但在优化型任务 Minimal Grass Puzzle 上表现差；ToT-tuned LLaMA 提升有限且有时失败（如 Drop Water、Minimal Grass）

创新点

与 ToT 等被动搜索需人工为每个任务编写搜索程序、多次调用 LLM 不同，论文提出新概念'自主树搜索'：LLM 通过固定 system prompt 在单次回复内自主完成树搜索，无需外部代码、任务无关，并兼具 CoT 的灵活性与 ToT 的探索能力。相比并行的 Algorithm of Thoughts（仅限 GPT-4 与 few-shot in-context learning），本文还覆盖零样本设置与更小模型的微调蒸馏。
