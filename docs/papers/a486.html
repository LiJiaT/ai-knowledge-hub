Teaching Algorithmic Reasoning via In-context Learning

通过 In-context Learning 教授算法推理

简介

LLM 在 parity、多位数算术等算法推理任务上即使配合 chain-of-thought 也远未解决，答案长度超出提示示例时性能急剧下降。论文提出 algorithmic prompting：把算法当作技能，用同时包含自然语言描述与显式中间计算、无歧义的详细示例，纯靠 in-context learning（不训练模型）教给 Codex，并系统研究技能教学、技能累积、技能组合、技能即工具四个阶段。结果上，长位加法/乘法/减法/parity 相对最优基线错误率分别降低约 9x/5x/2x/10x，加法近乎完美泛化到 19 位。论文还发现同一上下文混用异质技能会相互干扰，提出用 <ALGO>/<NONALGO> 标志引导注意力，并用双模型对话式工具调用绕开上下文长度限制，在 GSM8k-Hard 上准确率翻倍。

问题

LLM 即使借助 chain-of-thought 等 rationale 类提示，在 parity、多位数加减乘等算法推理任务上仍远未解决，尤其在答案长度超出提示示例（OOD/长度泛化）时性能急剧下降。作者认为现有提示方法提供的 rationale 过于模糊，无法充分约束模型对提示信息的解释，导致模型难以学到并真正遵循解题算法。

方法

提出 Algorithmic Prompting：将算法表述为技能，通过 in-context learning（不更新任何权重）教授模型；提示同时包含自然语言描述与显式中间计算步骤，并刻意消除规则歧义（如显式写出进位推导、用复制未处理数字的方式规避变长索引）。围绕四个阶段展开：(1) 单算法技能教学；(2) skill accumulation：同一提示同时教多个算法（加法+减法）；(3) skill composition：在已学技能上组合出更复杂算法（多数相加、乘法转化为加法）；(4) skills as tools：把已学算法作为工具嵌入更大的数学推理问题（GSM8k）。针对上下文长度限制提出 second-pass 策略与双模型对话式工具调用（主模型用特殊 token 触发加载算法提示的子模型执行计算并回传结果），并用 <ALGO>/<NONALGO> 标志引导模型注意力以缓解技能间干扰。实验模型为 OpenAI Codex code-davinci-002（8000 token 上下文），temperature 0。

关键结果

相对最优可用基线，长 parity、加法、乘法、减法的错误率分别降低约 10x、9x、5x、2x

加法：仅用 3 个答案≤5 位的示例，算法化提示在最长 19 位问题上接近完美准确率并实现 OOD 长度泛化；few-shot、CoT、instruction-only 随长度增加性能持续下降

parity：基线在列表长度约 5 时降至随机水平（50%），算法化提示在最长 30 位列表上保持约 80% 准确率

向提示算法步骤注入系统性错误后加法准确率降至接近 0%，不规则错误仅轻微影响，证明模型确实在遵循上下文教授的算法

GSM8k-Hard（纯加法子集加大数值，答案 3-12 位）：调用加载加法算法提示的第二个模型做计算，整体准确率是无算法提示 CoT 基线的两倍

<ALGO>/<NONALGO> 标志引导：86% 的 <ALGO> 测试样本产生算法化输出，0% 的 <NONALGO> 样本产生算法化输出

技能累积：加法+减法组合提示中加法性能几乎无退化；仅 4 个减法示例性能显著下降，补足到 6 shot 纯减法提示可恢复，显示相似技能同时学习有正向迁移

技能组合：组合提示显著优于 few-shot 与 CoT 基线，且不含组件技能（No Comp）的版本性能明显更差

创新点

与 scratchpad/CoT 提供松散 rationale 不同，algorithmic prompting 大幅提高 rationale 的细节与无歧义程度，把算法步骤显式写入提示，并证明自然语言描述与显式计算缺一不可；首次系统化提出'技能教学→技能累积→技能组合→技能即工具'的 in-context 技能习得框架；通过系统性错误注入实验证明模型确实在遵循上下文中的算法（与 Min et al.、Madaan and Yazdanbakhsh 等发现提示内容正确性不实质影响性能的结论形成对照）；识别并命名混用异质技能时的 interference 现象，给出标志引导与双模型对话式工具调用两种缓解/绕行方案。
