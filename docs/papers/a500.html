Toxicity Detection with Generative Prompt-based Inference

基于生成式提示推理的毒性内容检测（Toxicity Detection with Generative Prompt-based Inference）

简介

论文研究零样本毒性内容检测：不微调、不使用标注数据，仅靠提示激发 LLM 预训练中习得的“自我诊断”能力。方法上提出生成式分类——把标签改写成“写一段包含/不包含 X 的文本”的正反提示，通过比较模型在两种条件下生成待测文本的对数似然来判定标签，区别于以往让模型回答 Yes/No 的判别式提示，并可用目标域无标注样本作 task demonstration。在 SBIC、HATEXPLAIN、CIVILITY 三个社交媒体数据集上，生成式分类优于判别式分类及词表/句向量基线，但所有零样本方法都只略好于随机；提示措辞极其敏感，精确指明受害群体（如加入 'ethnic slur'）能大幅提升效果，而判别式提示在 SBIC 上经大量尝试最好仅达 0.55。此外发现生成式分类性能随模型规模正相关，并用 LIME 做了误判归因与伦理影响分析。

问题

如何在完全不依赖毒性检测标注监督（zero-shot、不微调）的条件下，让 LLM 判断一段文本是否含有毒性内容；并解决现有 prompt-based 方法普遍采用判别式方式（让模型对“文本是否含毒性 y”回答 Yes/No）而难以激发模型自我诊断能力、效果接近随机的问题。

方法

提出 prompt-based 生成式分类：将标签 y 转写为一对正/反提示（'Write a text that contains y' / 'Write a text that doesn't contain y'），分别计算 LLM 在该条件下生成待测文本 x 的对数似然得分 s(y)，再由两个得分归一化得到 p(y|x) 完成判定；可选引入 task demonstration——从目标域无标注语料中随机采样 k 条文本加入提示，并类似 ensemble 地聚合不同示例条件下的得分。同时开展系统性 prompt engineering：先分析各数据集的毒性特性（SBIC 涵盖多种攻击性内容、HX 主要是针对特定族群的仇恨言论、CIVILITY 兼有群体与个体攻击），据此为每个数据集定制提示（结论中提到融入了 SOCIAL BIAS FRAME），并与 toxicity lexicon、embedding similarity（SinCSE）、判别式 cloze 提示三类零样本基线对比；评测采用正负类 F1 与 macro-F1，并用 LIME 做词级归因的定性分析。

关键结果

判别式提示分类在 SBIC 上经大量提示尝试后最好仅达到 F1 0.55（ID 8 提示，显式包含 'intend to offend'），多数判别式提示接近随机水平（F1 ~0.5）

所有无监督/零样本方法（toxicity lexicon、embedding similarity、判别式与生成式提示分类）整体仅比随机基线略好；其中 Toxicity Lexicon 仅在 Civility 数据集上取得基线中的最高分（因该数据集构建时本就以关键词匹配爬取）

生成式分类相对 embedding similarity 基线提升显著，尤其在 HX 数据集上；在 HX 的提示中加入 'ethnic slur' 一词可大幅提升性能，而使用 'offensive or toxic content' 或 'hatespeech' 等措辞效果差

生成式分类 + task demonstration（无标注示例）相比原始生成式分类可大幅提升 positive F1

创新点

将 Schick et al. (2021) 等已有的判别式（cloze/Yes-No 问答）零样本毒性检测扩展为生成式变体：不再估计 p(y|x)，而是把标签转写为正/反两条生成指令并比较 p(x|y)，利用更长的预测序列提供更强的对比信号（作者称为 'improved contrastiveness'），且与 GPT 类模型的自回归预训练方式更一致；同时系统分析了提示措辞与数据集特性匹配对零样本分类性能的影响。
