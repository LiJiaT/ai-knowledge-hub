Model evaluation for extreme risks

面向极端风险的模型评估

简介

这是 DeepMind 等机构的一篇立场论文，指出通用 AI 模型可能涌现开发者未预期的危险能力（如网络攻击、操纵人类），而现有评测只覆盖偏见、毒性、真实性等常规属性，无法应对极端规模风险。论文提出两类新评测：识别模型是否具备危险能力的 dangerous capability evaluations，与评估模型是否倾向有害使用自身能力的 alignment evaluations，并给出将评测嵌入治理流程的蓝图：负责任训练（用较弱模型做早期预警与 scaling/inverse scaling 分析、训练中定期评测）、负责任部署（部署前评估、渐进式部署、continuous deployment review）、透明度报告与安全控制。论文还列出极端风险评测的理想属性、五项局限与四类潜在危害，结论是模型评测是必要但不充分的防线。对团队而言，其'能力 vs 倾向'评测二分、评测门禁进入部署决策的思路，可借鉴到 AI 辅助工程工具（尤其代码生成/审查 Agent）的安全评测与上线流程中。

问题

现有模型评测（性别/种族偏见、真实性、毒性、版权内容复述等）无法识别通用 AI 模型因误用或失准可能造成的极端规模风险（如数万人死亡、数千亿美元损失、社会政治秩序严重破坏级别的危害）。论文要论证为何需要面向极端风险的模型评测，定义其两大类别（危险能力评测与对齐评测），并设计将其嵌入模型训练、部署与治理决策的流程。

方法

概念框架与治理蓝图，而非具体技术系统：将极端风险评测分为 dangerous capability evaluations（检测网络攻击、操纵、武器获取、自主复制等能力，见 Table 1）与 alignment evaluations（检测欺骗、权力寻求等行为倾向）；提出评测结果应驱动 responsible training（训练前用历史与实验性较弱模型做预警和 scaling/inverse scaling 分析、训练中定期评测、必要时暂停训练）、responsible deployment（部署前评估、渐进式部署、continuous deployment review）、transparency（对外报告评测结果）与 appropriate security 四个环节；给出评测组合的理想属性清单（覆盖多样设置、对模型鲁棒、难以被针对性规避等），并讨论 mechanistic analysis 与 agency/goal-directedness 评估作为补充手段。

创新点

将模型评测从常规属性（偏见、毒性、真实性）扩展到'极端规模风险'，系统提出 dangerous capability evaluations 与 alignment evaluations 的'能力 vs 倾向'二分框架，并给出评测结果嵌入训练决策、部署决策、外部审计与安全控制的完整治理流程蓝图。论文指出当时几乎不存在针对该规模风险的评测，并较少见地讨论了评测工作自身的五项局限与四类潜在危害（如评测内容泄露、对评测优化导致 deceptive alignment 的选择压力）。
