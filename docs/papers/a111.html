RAGCache: Efficient Knowledge Caching for Retrieval-Augmented Generation

RAGCache：面向检索增强生成（RAG）的高效知识缓存

简介

论文针对 RAG 将检索文档注入请求后序列大幅变长、prefill 计算与显存开销剧增导致 TTFT 过高的问题，提出面向 RAG 的多级动态缓存系统 RAGCache。系统刻画发现检索文档在请求间高度重复且分布高度倾斜（MMLU 中 top 3% 文档覆盖 60% 请求），据此用基于文档 ID 的前缀树 knowledge tree 在 GPU 与 host memory 层级组织文档 KV cache，配合感知前缀顺序的 PGDSF 替换策略、cache-aware 请求重排序，以及重叠检索与推理的 dynamic speculative pipelining。系统基于 vLLM+Faiss 实现约 5000 行代码，实验显示 TTFT 最高降低 4×、吞吐最高提升 2.1×，优于 SGLang（TTFT 3.5×、吞吐 1.8×）。对团队而言，这是 RAG 生产服务成本与延迟优化的代表性系统工作，其刻画结论与缓存思路可直接指导知识库问答场景的推理引擎选型与上下文组织方式。

问题

RAG 将检索到的外部知识文档注入原始请求，使增强请求的序列远长于原始请求（论文示例中额外计算与内存开销超过 10×），以 prefill 为主的生成步骤成为端到端性能瓶颈；现有 LLM 推理优化（vLLM、SGLang）只在容量有限的 GPU 显存中缓存中间状态，未考虑 RAG 的检索模式特性，导致性能次优。

方法

RAGCache 是首个缓存检索文档（外部知识）中间状态并跨请求共享的多级动态缓存系统：(1) 用基于文档 ID 的前缀树 knowledge tree 组织文档 KV cache，适配 LLM 对文档顺序的敏感性，节点按访问热度分布在 GPU 与 host memory 层级，并采用 swap-out-only-once 策略减少 PCIe 传输；(2) 提出 prefix-aware Greedy-Dual-Size-Frequency（PGDSF）替换策略，综合频率、KV 大小、访问时间与前缀感知的重计算代价（离线 profiling prefill 时间并用双线性插值估计）；(3) cache-aware reordering 依据缓存命中收益对请求重排序以提升命中率、避免 thrashing，并用时间窗口防止饥饿；(4) dynamic speculative pipelining 在向量检索过程中分阶段投机启动 LLM 生成，依据系统负载（max_prefill_bs 阈值）动态启停，重叠检索与推理。另含 GPU 故障与请求失败的容错机制。

关键结果

相比 vLLM+Faiss，TTFT 最高降低 4×，吞吐最高提升 2.1×

相比 SGLang，TTFT 最高降低 3.5×，吞吐最高提升 1.8×

刻画发现检索模式高度倾斜：MMLU 中 top 3% 文档被 60% 的请求引用，比均匀分布少 20×，且该结论在不同 embedding 模型与 ANN 索引下均成立

缓存前缀与全量 prefill 的延迟差距最高达 11.5×；即使计入 GPU-host 间 KV 传输开销，cache hit 延迟仍比全量 prefill 最高低 3.9×

PGDSF 命中率比 GDSF 高 1.02-1.32×、比 LRU 高 1.06-1.62×、比 LFU 高 1.06-1.75×，平均 TTFT 比基线策略低 1.05-1.29×

cache-aware reordering 在高请求率下将平均 TTFT 降低 1.2-2.1×

dynamic speculative pipelining 最多降低 TTFT 1.6×，非重叠向量检索时间减少 1.5-4.3×

top-k 取 1/3/5 时，RAGCache 平均 TTFT 比 vLLM 好 1.7-3.1×、比 SGLang 好 1.2-2.5×

大模型（Mixtral-8×7B、LLaMA2-70B）下比 vLLM 低 1.4-2.1× TTFT、比 SGLang 低 1.2-2.6×；vLLM 分别在 2 和 1.5 req/s 以上无法满足 SLO，RAGCache 在各请求率下保持 TTFT 低于 1.4 秒

调度开销（知识树查找/更新、请求重排序、投机决策）在所有请求率下低于 1 毫秒

创新点

首个缓存检索文档中间状态并跨请求共享的系统：不同于 vLLM（单请求内的分页 KV 管理）与 SGLang（仅在 GPU 显存中复用跨请求中间状态），RAGCache 针对 RAG 检索模式设计 GPU+host memory 多级缓存、感知文档顺序的前缀树与 PGDSF 替换策略，并将向量检索与 LLM 推理通过投机流水线重叠；与 Prompt Cache、CacheGen 等可能引入近似误差的方法不同，RAGCache 保留精确 KV cache，不改变生成结果。
