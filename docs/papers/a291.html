简介

现有递归自改进系统（如 Darwin Gödel Machine）依赖固定、手工设计的元层机制，且只在'评估任务与自我修改同为编码'的对齐假设下有效。论文提出 hyperagents：把 task agent 与 meta agent 融合为单一可编辑程序，使改进机制本身也可被修改（metacognitive self-modification），并在 DGM 的开放式探索（archive、parent selection、分阶段评估）之上实现 DGM-H。在 Polyglot 编码、论文评审、机器人奖励设计、奥数评分四个域上，DGM-H 持续提升性能并超越无自改进/无开放式探索的消融版本与原 DGM，接近甚至超过人工定制的 DGM-custom；学到的元层能力（持久记忆、性能追踪、结构化提示流程）可跨域迁移并在多次运行间累积。论文同时给出 imp@k 评测指标、约 88.6M tokens/100 迭代的成本核算，以及沙箱、人类监督与评估作弊（Goodhart）等安全讨论。对团队而言，其涌现出的提示结构化、记忆与性能追踪等工程模式，以及评估驱动自动迭代 Agent 的框架，均有直接借鉴价值。

问题

现有递归自我改进系统（如 Darwin Gödel Machine）依赖固定、手工设计的元层机制来生成自我改进指令，既限制了改进速度，也使系统只在'任务求解技能与自我修改技能对齐'（即编码域）的假设下有效；论文要构建不受初始实现约束、可对任意可计算任务同时改进任务能力与改进能力本身的自指式 Agent。

方法

提出 hyperagents：将 task agent（解决目标任务）与 meta agent（修改 Agent 并生成新 Agent）融合为单一可编辑的 Python 程序，使元层修改过程本身可被修改（metacognitive self-modification）。在 DGM 基础上实现 DGM-H：保留开放式探索结构（维护 Agent archive、按性能与已编译子代数加权进行 parent selection、staged evaluation），初始 hyperagent 由冻结 FM 加 bash 与文件编辑两个工具构成，meta agent 可修改代码库任意部分。提出 imp@k 指标量化 meta agent 在固定预算内生成更优 task agent 的能力，并在编码、论文评审、机器人奖励设计、奥数评分四个域上以训练/验证/测试划分进行实验。

关键结果

Polyglot 编码基准：训练 50 任务子集从 0.140 提升至 0.340（CI: 0.300-0.380），完整基准从 0.084 提升至 0.267（CI: 0.231-0.280），与原 DGM（0.140→0.380 / 0.142→0.307）相当，尽管 DGM-H 并非为编码专门手工设计

论文评审测试集：从初始 Agent 的 0.0 提升至 0.710（CI: 0.590-0.750），超过开源静态基线 AI-Scientist-v2 reviewer 的 0.630

机器人奖励设计测试集：从 0.060 提升至 0.372（CI: 0.355-0.436），超过直接优化评估指标的默认奖励函数（0.348）

跨域迁移（imp@50，奥数评分域）：DGM-H 学到的 transfer hyperagents 达 0.630（CI: 0.540-0.630），而初始 meta agent 与 DGM-custom 的 transfer agents 均约为 0.0

跨运行累积：DGM-H + transfer 在奥数评分达 0.640（CI: 0.550-0.720），高于从初始 Agent 开始的 0.610（CI: 0.510-0.680），但差异不具统计显著性（p > 0.05）

在完整 IMO-GradingBench 上，DGM-H 将 ProofAutoGrader 准确率从 0.561 提升至 0.601，平均绝对误差从 0.178 降至 0.175

消融实验：去掉 meta agent 自我改进后论文评审 0.0、机器人 0.213；去掉开放式探索后分别为 0.0 与 0.116，均显著低于完整 DGM-H（p < 0.05）

成本：100 次迭代总计约 88.6M tokens（自修改约 33M + 评估 0.506M×100）；可修改 parent selection 的初步实验中 modifiable（0.491）优于 random（0.428）但仍不及手工设计的 score-child-prop（0.532），差异均不显著

创新点

与 DGM 及其后续工作依赖固定、手工设计的指令生成机制不同，hyperagents 将元层改进机制本身纳入可修改范围，去除了'任务技能与自我修改技能对齐'的领域假设，从而原则上可泛化到任意可计算任务；论文还实证了元层改进（持久记忆、性能追踪、评估分析等）可跨域迁移并在多次运行间累积，这是先前自改进系统不具备的性质。
