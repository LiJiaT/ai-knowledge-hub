Don't Forget to Connect! Improving RAG with Graph-based Reranking

别忘了建立连接！用基于图的重排（Graph-based Reranking）改进 RAG

简介

论文解决 RAG 中的一个痛点：与问题仅有弱关联、但可经由其他文档间接关联到答案的 positive documents 常被 reranker 忽略，且现有方法完全不考虑文档之间的连接。方法上提出 G-RAG，在 retriever 与 reader 之间用 GNN 重排 top-100 检索文档：以文档为节点、以两文档 AMR 图存在公共概念为边构建文档图，节点特征由预训练 LM 的文档 embedding 与 AMR 图中从 'question' 节点出发的最短路径概念序列拼接而成，边特征编码文档间共享概念，并用 pairwise ranking loss 训练。在 NQ 与 TQA 上，G-RAG（尤其配 Ember embedding 的 G-RAG-RL）超过 BART-GST 等 SOTA 且计算开销更小；同时实证发现 PaLM 2 zero-shot 做 reranker 显著落后于 G-RAG（差距最高 7 个百分点），并提出 MTRR 与 TMHits@10 两个处理并列分数的评测指标。核心结论：即便在 LLM 时代，为 RAG 专门设计 reranker 仍然关键。

问题

RAG 检索到的文档中，包含答案但与问题上下文关联不明显的 positive documents 容易被模型忽略；现有 reranker 不利用检索文档之间的连接信息；将全部 AMR 语义信息融入预训练语言模型会带来计算时间与 GPU 开销上升及过拟合风险；此外，LLM 不做微调直接充当 reranker 的效果此前未被系统探索。

方法

提出 G-RAG：对每个问题用 DPR 检索 top-100 文档，用 AMRBART 将 'question:<question text><document text>' 解析为 AMR 图；以文档为节点建图，若两文档的 AMR 图有公共概念节点则连边。节点特征为预训练 LM（BERT/GTE/BGE/Ember）编码的文档 embedding，拼接从 AMR 图 'question' 节点出发的最短单源路径（SSSP）上的概念序列，从而只引入关键 AMR 信息而非全部 token；边特征为 2 维共享概念信息并做归一化。用 2 层 GCN（mean aggregator）做消息传递更新表示，问题 embedding 与节点表示计算重排分数；训练时用 pairwise ranking loss 替代 cross-entropy（即 G-RAG-RL）以应对正负文档不平衡。另提出 MTRR 与 TMHits@10 两个指标，公平评估 LLM 打分中大量并列排名的场景。

关键结果

G-RAG 在 NQ 与 TQA 上超过 state-of-the-art 方法（如 BART-GST），同时计算开销更小，实验在单张 Tesla A100 40GB GPU 上完成

利用跨文档连接信息相比对比方法带来最高 7 个百分点的提升（up to 7 percentage points）

PaLM 2 各版本 zero-shot 做 reranker 显著落后于 G-RAG；其打分为 0-100 间可被 5 整除的整数，产生大量并列排名，小尺寸 LLM 并列更多

Embedding 模型对比中 Ember 表现最佳，其次为 GTE 与 BGE；超参调优后的 Ember (HPs-T) 在所有测试集取得最高分

GNN 对比中 GCN 在大多数情况下优于 GAT、GraphSage 与 GIN，作者归因于文档图规模很小

pairwise ranking loss（G-RAG-RL）优于 cross-entropy loss

创新点

首次在 RAG 重排过程中利用跨文档连接（document graph），且不依赖需要大量存储与实体映射的外部知识图谱；与将全部 AMR token 融入 LM 的 BART-GST 不同，只提取 AMR 中从 'question' 节点出发的最短路径概念作为节点特征，降低计算与过拟合风险；提出处理并列分数的 MTRR/TMHits@10 评测指标；并系统评估了 PaLM 2 各版本 zero-shot 做 reranker 的表现。
