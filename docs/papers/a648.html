Element-aware Summarization with Large Language Models: Expert-aligned Evaluation and Chain-of-Thought Method

基于大语言模型（LLM）的要素感知摘要：专家对齐评测与思维链（Chain-of-Thought）方法

简介

该论文针对 CNN/DailyMail 与 BBC XSum 等主流新闻摘要数据集参考摘要存在事实幻觉与信息冗余、导致自动评测与人类偏好不一致的问题，邀请三位新闻专家按 'Lasswell Communication Model'（5W1H）协议重写参考摘要，构建了各含 200 条样本的 Element-aware 测试集。基于新测试集，作者发现 zero-shot GPT-3 的摘要能力与强 fine-tuned PLM 相当甚至在 BBC XSum 上大幅领先，解释了此前 GPT-3 人类偏好高但自动指标低的矛盾。进一步提出 Summary Chain-of-Thought（SumCoT）两阶段提示方法：先用人工设定的引导问题抽取 Entity、Date、Event、Result 四类核心要素，再整合要素与原文细节逐步生成摘要。实验显示 SumCoT 在两个数据集上 ROUGE-L 分别超过此前 SOTA +4.33/+4.77，且该能力是模型规模的涌现能力，仅在最大模型上有效。

问题

主流新闻摘要数据集（CNN/DailyMail、BBC XSum）的参考摘要存在事实幻觉与信息冗余等噪声，导致 LLM zero-shot 摘要的人类偏好与自动评测指标结果不一致（如 Goyal et al. (2022) 观察到的 GPT-3 现象），且缺乏能客观、全面评估 LLM 细粒度摘要写作能力的可靠评测基准。

方法

两条主线：(1) 评测基准构建——依据 'Lasswell Communication Model'（5W1H）让三位新闻专家为两个数据集各 200 篇文档重写参考摘要，写作协议包含微观要求（摘要必须忠实覆盖 Entity、Date、Event、Result 四要素）与宏观要求（Fluency、Coherence、Consistency、Relevance 四维度），并用 Precision/Recall/F1 度量测试集的要素覆盖特性；(2) SumCoT 两阶段提示流水线——Stage 1 通过人工设定的引导问题让 LLM 逐项抽取四类核心要素，Stage 2 将引导问题与 LLM 输出的答案打包，引导 LLM 聚焦关键细节、按要素感知的写作模式逐步生成最终摘要。

关键结果

在 Element-aware 测试集上，zero-shot GPT-3（175B text-davinci-002）与 fine-tuned PLM（BART、T5、PEGASUS）竞争力相当，并在 BBC XSum 上以明显优势领先；相比 dataset-specific 测试集，GPT-3 的 ROUGE-1/2/L 在 CNN/DailyMail 提升 +7.65/+6.22/+6.74，在 BBC XSum 提升 +11.75/+7.26/+9.56，而 fine-tuned PLM 性能下降

SumCoT 相比标准 GPT-3 与此前 SOTA，ROUGE-1/2/L 在 CNN/DailyMail 提升 +5.05/+1.35/+4.33，在 BBC XSum 提升 +3.96/+4.36/+4.77；以 ROUGE-L 计超过 SOTA +4.33/+4.77

人类评估（7 点 Likert 量表，Fluency/Coherence/Consistency/Relevance 四维度）显示 GPT-3 摘要几乎在所有维度优于数据集原生与其他模型生成摘要；SumCoT 进一步在所有维度提升，尤其是 coherence 与 relevance

要素抽取质量：除 Date 外各要素抽取 F1 表现优异；错误分析归纳出 Date 幻觉（为原文不存在的日期强行抽取）与要素冗余两类主要问题，且 Date 的 coverage 显著偏低

SumCoT 是模型规模的涌现能力：小尺寸 GPT-3 版本上要素抽取几乎无效，仅最大版本（text-davinci-002）的抽取达到人类认可水平

创新点

据作者所述，这是首个将 chain-of-thought prompting 引入自动摘要（开放式生成任务）的工作；区别于以往直接在含噪标准数据集上评测，论文通过专家按 5W1H 协议重写参考摘要，构建与专家判断对齐的测试集，并据此解释了 GPT-3 人类偏好与自动指标不一致的成因（测试域噪声），同时提出'先要素抽取、后整合生成'的两阶段 CoT 提示流水线。
