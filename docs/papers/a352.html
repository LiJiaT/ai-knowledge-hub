Deconstructing Instruction-Following: A New Benchmark for Granular Evaluation of Large Language Model Instruction Compliance Abilities

解构指令遵循：一个用于细粒度评估 LLM 指令合规能力的新基准

简介

现有 LLM 指令遵循评测基准常把任务成败与指令合规混在一起，且约束数量少、脱离真实应用场景。Capital One 团队提出 MOSAIC（MOdular Synthetic Assessment of Instruction Compliance），一个模块化合成基准：将 21 条面向应用的生成约束（格式、词汇、句法、语义、业务/法律五类）以模块化列表形式动态拼接到 32 种文本生成任务变体上，每条提示最多 20 条约束、平均 10.5 条，经分层抽样得到 4,000 条在约束数量、位置、任务与产品维度均衡的评测集，并可动态生成以防数据泄漏。评测采用规则函数（NLTK/textstat）与 GPT-4o-mini LLM-as-a-judge（与人工标注一致性 0.82-0.83），提出 SCC、PCC、位置合规率、Prompt following Accuracy 等指标。对 Llama 3.1/3.3、Qwen3、Deepseek-R1、Claude 3.7 Sonnet、Gemini Flash 2.5、Mixtral 的评估表明：指令遵循不是单一能力，存在模型特定弱点（如列表结构约束 Deepseek-R1 仅 0.07）、约束间协同/冲突关系，以及 primacy/recency 位置偏置；超过 15 条约束时几乎所有模型合规率明显下降。这些细粒度结论可直接指导提示中输出约束的编写、排序与数量控制。

问题

现有指令遵循评测存在三个缺口：(1) 约束虽易测量但脱离真实应用（如 IFEval 的大写词频约束）；(2) 约束与具体提示任务耦合（如 InFoBench），无法把模型'遵循指令的内在能力'与'解决任务本身的能力'分开评估；(3) 评测通常只用少量约束（ComplexBench 也仅 4-5 条），忽略约束间相互依赖、数量与排列顺序对合规的影响。论文目标是提供一个能对指令合规做细粒度、独立、可诊断分析的基准与指标体系。

方法

提出 MOSAIC 框架。数据生成：将文本生成任务（32 种变体）× 产品/服务描述（8 种）× 约束列表（从 21 条约束池中抽取 1-20 条并控制排列顺序，动态填充 <SelectedTone>、关键词等占位符）拼接成提示，共生成 765,472 条，再通过分层抽样得到 4,000 条在约束数量、位置、任务、产品维度均衡的子集。评测指标：Single Constraint Compliance (SCC)、Pairwise Constraint Compliance (PCC)、Position-based Constraint Compliance、Prompt following Accuracy (PA)。验证策略：格式/词汇/句法约束用基于 NLTK 与 textstat 的规则函数打分（0.0-1.0），语义与业务/法律约束用 GPT-4o-mini 做 LLM-as-a-judge（0-10 分、JSON 输出、按约束逐条判定），并用 250 条响应的双人人工标注验证 judge 可靠性。

关键结果

综合数据集含 765,472 条提示，均衡评测子集 4,000 条；每条提示平均 10.5 条约束，为次高竞品的两倍以上

LLM-as-a-judge 与两位人工标注者的一致性分别为 0.82 和 0.83，人与人一致性为 0.94

'Structure body into lists using dashes' 约束呈显著模型差异：Llama 3 系列达 0.97-0.99，Qwen3 仅 0.34，Deepseek-R1 仅 0.07

Flesch reading ease 70-80 约束普遍困难，SCC 从 0.80 到 Deepseek-R1 的 0.42；Avoid unsubstantiated superlatives 也是普遍难题

约束间存在协同与冲突：Clear purpose 与 Use unambiguous language 正相关（Mixtral r=0.575，Deepseek-R1 r=0.866）；Flesch reading ease 与 Use given keywords 负相关（Llama 3.3 70B r=-0.278，Mixtral r=-0.320）；Qwen3 中 Include <BOC> token 与 Respond in JSON 强负相关（r=-0.531）

位置偏置：Llama、Qwen3、Deepseek 呈 primacy effect，Mixtral、Gemini、Claude 呈 recency effect；Claude 与 Gemini 在约束位置 19 出现合规峰值、到位置 20 骤降

约束数 1-6 时 Qwen3 平均合规最高；7-15 条时各模型表现波动大；超过 15 条时几乎所有模型合规率明显下降，推理型模型（Deepseek-R1 8B、Qwen3）退化更明显

商业模型 Gemini 2.5 Flash 与 Claude 3.7 Sonnet 的表现与较小的开源模型相当

创新点

与 IFEval、InFoBench、CELLO、FollowBench、ComplexBench 等相比：(1) 用模块化约束列表把指令合规与任务能力解耦，同一约束集可配任意任务，实现'纯'指令遵循评估；(2) 动态合成生成防止数据泄漏；(3) 系统探索最多 20 条约束下数量、排列顺序与两两交互的影响，并提出 PCC 与位置合规率等新指标，首次形式化揭示 primacy/recency 位置偏置与约束冲突；(4) 规模与约束密度为现有基准中最大（4,000 条提示、平均 10.5 条约束/条）。
