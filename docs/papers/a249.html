Think Deep, Not Just Long: Measuring LLM Reasoning Effort via Deep-Thinking Tokens

深度思考，而非仅仅更长：通过 Deep-Thinking Tokens 度量 LLM 推理努力

简介

该论文针对'用生成 token 数衡量 LLM 推理努力不可靠'的问题：更长 CoT 并不对应更高准确率，甚至可能反映 overthinking 并导致性能下降。方法上，论文将中间层 hidden states 用 unembedding matrix 投影到词表空间，以 JSD 度量每层预测分布与最终层分布的距离，把直到深层才收敛的 token 标记为 deep-thinking token，其在序列中的占比即 deep-thinking ratio（DTR）。在 AIME 24/25、HMMT 25、GPQA-diamond 与 GPT-OSS、DeepSeek-R1、Qwen3 等模型上，DTR 与准确率平均相关 r=0.687，显著优于长度类（r=-0.59）与置信度类基线。基于此提出 Think@n 测试时扩展策略：用 50 token 前缀估计 DTR 选取高分组做多数投票，在匹配或超过 self-consistency 精度的同时将推理成本降低约 50%。对团队而言，这为推理质量评测与重复采样成本优化提供了可落地的内部信号方法。

问题

现有工作普遍以生成 token 数等表面特征作为推理努力/质量的代理，但长度与准确率的相关性不可靠甚至呈负相关（overthinking 现象），而基于 CoT 语义结构的方法又依赖昂贵的辅助解析或外部标注。论文要解决的问题是：如何用更原则性、高效的方式度量 LLM 推理时的真实思考努力，以区分有效推理与无信息生成，并据此降低推理成本。

方法

提出 deep-thinking token 概念与 DTR 度量：对每个生成 token，将各中间层 hidden states 通过 unembedding matrix 投影到词表空间得到逐层预测分布，计算其与最终层分布的 Jensen-Shannon divergence（JSD）；分布首次降至阈值 g 以下的层为 settling depth，落在深度区间（depth fraction ρ=0.85）内的 token 记为 deep-thinking token，序列中其占比即 DTR。进一步提出 Think@n 测试时扩展策略：仅用 50 token 前缀估计各候选的 DTR 并排序，对 top η%（50%）样本做多数投票并早停其余生成，从而在保持 self-consistency 精度的同时约减半推理成本。

关键结果

DTR 与任务准确率的平均 Pearson 相关达 r=0.687（32 个模型-基准设置中仅 2 个为负），显著优于 token count（平均 r=-0.59）、reverse token count 及置信度类基线（log probability、negative perplexity、negative entropy、Self-Certainty，r=0.219~0.605）

在 GPT-OSS-120B medium 上，DTR 与准确率平均相关 r=0.828，而输出 token 数呈中等负相关（平均 r=-0.544）

Think@n（n=48、η=50%）在 AIME 24/25、HMMT 25、GPQA-diamond 上匹配或超过 Cons@n，同时推理成本降低约 50%，取得最优 accuracy-cost Pareto 前沿

仅用 50 token 前缀估计 DTR 即可在 AIME 25 上取得高于更长前缀的准确率并与全序列相当，同时显著降低推理成本

距离度量消融：JSD-based DTR 在 AIME 25 上 r=0.869、HMMT 25 上 r=0.895，优于 KLD（r=-0.698 / 0.409）与 cosine similarity（r=0.633 / 0.172）

定性示例：同一 AIME 25 题目上，错误输出长达 27,724 tokens、DTR 仅 13.9%，正确输出仅 3,725 tokens、DTR 达 19.0%

超参分析表明 (g, ρ)=(0.5, 0.85) 在稳定性与相关性之间取得最佳平衡

创新点

区别于以 token 长度（含 reverse token count、最短/最长投票）或置信度（log probability、perplexity、entropy、Self-Certainty）为代理的表面方法，DTR 是基于模型内部逐层预测分布演化的机制性信号，无需任务特定启发式或外部结构标注；区别于将 CoT 建模为图的语义结构分析（需昂贵解析或外部标注），DTR 直接利用未修改的内部表示；区别于关注隐状态序列维度演化的已有工作（Vilas et al., 2025），本文聚焦单个 token 预测在深度方向上的收敛过程，并将其转化为可操作的测试时样本选择与早停机制。
