Post Hoc Explanations of Language Models Can Improve Language Models

语言模型的 Post Hoc 解释可以改进语言模型

简介

该论文解决人工标注 rationale（如 Chain-of-Thought prompting）虽能提升 LLM in-context learning 表现、但依赖大量人工难以扩展，且在部分复杂语言理解任务上反而导致性能下降的问题。作者提出 AMPLIFY 框架：先用 GPT-2/BERT 等小代理模型（约 1-2 亿参数）从验证集中筛选 LLM 误分类且代理模型高置信的样本，再用梯度类 post hoc 解释方法提取 top-k 关键词，按固定模板自动生成纠正性 rationale，嵌入 few-shot prompt 供大模型使用。在 BigBench-Hard 等 7 个数据集上，AMPLIFY 相比 Answer-Only 与 CoT 基线带来约 10-25% 的准确率提升，且代理模型无需微调即可接近最优，显著降低计算成本。对团队而言，这是一条无需人工标注即可自动构造高质量提示上下文的路径，其关于样本选择、模板设计与超参的消融结论对提示优化实践有直接参考价值。

问题

人工标注 rationale（如 Chain-of-Thought prompting）能显著提升 LLM 在推理与语言理解任务上的 in-context learning 表现，但依赖大量人工介入、不可扩展，且先前工作表明其在某些复杂语言理解任务上可能引起性能下降；论文寻求一种无需人工介入、可自动生成纠正性 rationale 来改进 LLM 的方法。

方法

AMPLIFY 四步框架：(1) 选择计算上可行的小代理模型（GPT-2 约 125M 或 BERT 约 110M 参数，可选微调）；(2) 从验证集中找出被 LLM 误分类的样本，按新提出的 Misclassification Confidence Score（MCS，代理模型对错误标签与真实标签的概率差）排序，选出最具纠正信号的 s 个样本；(3) 用梯度类 post hoc 解释方法（Vanilla Gradients、Gradient x Input、对比梯度）计算 token 归因分数，聚合到词级并取 top-k 关键词；(4) 用模板“The key words: word1...wordk are important clues to predict [Label] as the correct answer”构造 [Input][Rationale][Label] 的 s-shot prompt，与测试输入拼接后交给 LLM 预测。

关键结果

在 7 个数据集（Snarks、Causal Judgment、Ruin Names、Formal Fallacies、Salient Translation Error Detection、CommonsenseQA、Coin Flip）上，AMPLIFY 相比 AO 与 CoT 基线带来约 10-25% 的准确率提升

GPT-3.5 在 Snarks 上达 91.6% 准确率，比 AO 高 16%、比 CoT 高 20% 以上；Causal Judgment 上达 76.3%，显著超过 CoT（63.1%）与 AO（57.8%）

GPT-3 在 Ruin Names 上取得最高的 78.6%；GPT-3.5 在 Salient Translation Error Detection 上达 60.8%

代理模型无需微调（E=0）即接近最优：GPT-3.5 在 Snarks 上用未微调 GPT-2 达 88.8%，已显著优于 CoT 最佳表现，可进一步降低计算成本

样本选择策略消融：按最高 MCS（H-MCS）选择样本效果最好，Random 最差；仅按解释忠实度选择（F-EXP）在多数数据集上劣于 L-MCS

解释方法消融：Gradient x Input 及其对比变体总体最佳，但各梯度类方法间差异不大（GPT-3.5 在 Snarks 上稳定在 88.8-91.6%）

针对任务定制 rationale 模板带来小幅提升：Causal Judgment 上 GPT-3 从 60.5% 升至 63.1%；超参 (k=7, s=10) 在多数数据集上最佳

GSM8k 上 AMPLIFY 优于 AO 但低于 CoT，多步推理超出 post hoc 解释的设计能力范围

创新点

据论文所述，这是首次探索将 post hoc 解释方法用于提升 LLM 性能：以往 post hoc 解释仅用于理解模型行为与定位错误根因，本文将其转化为自动 rationale 注入 few-shot prompt，替代依赖人工标注的 CoT；同时提出 Misclassification Confidence Score (MCS) 筛选最具纠正信号的样本，并用小代理模型（约 1-2 亿参数）规避对千亿级 LLM 计算梯度的不可行性。
