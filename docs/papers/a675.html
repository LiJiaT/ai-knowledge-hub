Evaluation of medium-large Language Models at zero-shot closed book generative question answering

中等规模语言模型在零样本闭卷生成式问答上的评估

higharXiv评测基准可靠性与安全成本与效率基于arXiv版本
下载原文 PDF

简介

论文指出开放式生成式问答难以用 ROUGE/BLEU 等自动指标可靠评估，且'大模型'边界模糊，因此定义了 6B–100B 参数的中等规模语言模型（MLM），自建 110 题测试集（含 trick questions、数学应用题、符号推理、基础物理等），以人工评估方式系统测评数十个开源 MLM 的零样本 closed-book 问答能力，并招募 87 人建立人类基线。结果显示 MLM 平均正确率仅 35.3%，但最佳模型 Airoboros 33B 达 71.8%，超过 ChatGPT 的 60.9% 与人类基线 70.1%；组合不同模型的最佳答案可覆盖 82.7%（摘要）至 91.8%（正文）的问题。核心结论是微调数据质量比参数规模更关键，30B 级模型普遍欠训练，4bit GPTQ 量化几乎无损。对团队的价值主要在于其对开放式生成输出的人工评估方法论，以及模型选型与量化部署的实证结论。

问题

开放式长答案问答（long-form QA）的模型回答难以用 ROUGE/BLEU 等自动指标评估：正确答案可用不同措辞表达，甚至出现人类认为更优的答案；同时 LLM 中'large'缺乏清晰定义。论文要回答：参数量在 6B–100B 之间的中等规模语言模型（MLM）在零样本、无外部检索的 closed-book 生成式问答上究竟能做到多好，与 ChatGPT 等真正 LLM 及人类相比差距如何。

方法

自建 110 题评测集（含常识、trick questions、数学应用题、抽象与符号推理、基础物理等类别，并通过改变高度/材质/措辞等变体检验模型是否真正理解而非模式复述）；从 HuggingFace 选取数十个 6B–66B 开源模型（OPT、LLaMA、Alpaca、Vicuna、WizardLM、Flan-T5、Falcon、MPT 等），以 ChatGPT 与 GLM 130B 作 LLM 参照；在本地 A100 80GB 上以 FP16、temperature 0.1 运行，明确不使用 prompt engineering 与 CoT；因自动指标失效而采用人工评估，先按模型评、再按题跨模型交叉核对以控制主观性；另以 87 名人类被试建立人类基线。

关键结果

最佳模型 Airoboros 33B 正确率 71.8%，超过 ChatGPT（60.9%）并略高于人类基线（70.1%）；Airoboros 65B 4bit 为 65.5%

组合所有 MLM 的最佳答案：摘要报告总体正确率 82.7%，正文讨论与结论处报告 91.8%（论文内部数字不一致），与 ChatGPT 合计仅 4 题未能正确回答

MLM 总体平均正确率仅 35.3%；分档平均：≤7B 为 33.6%，10B–13B 为 35.4%，30B 以上（不含 ChatGPT）为 44.8%

Flan-T5（44.5%）与 Vicuna 13B（41.8%）的正确答案互补，合计 62.7% 已超过 ChatGPT 的 60.9%

指令微调收益显著：GPT-J 17.3% → GPT-JT 28.2% → Instruct GPT-J 39.1%；T5 base 13.6% → Flan-T5 44.5%；WizardLM 7B 以 47.3% 领跑 7B 档；Nous Hermes 与 Minotaur 13B 达 56.4%；Lazarus 30B 达 64%

4bit GPTQ 量化未降低性能：WizardLM 13B 4bit（53.6%）甚至略优于 FP16 版本

规模与性能无明确正相关：LLaMA-30B、OPT-30B、Galactica 30B、OPT-IML 30B（18.2%）均不及更小模型，70B 的 Luminous Supreme 仅 30%（instruct 版 41.8%）

人类基线平均仅 70.1%（87 名被试），部分 trick questions 正确率极低（如仅 26% 的人注意到电力火车不冒烟）

创新点

与依赖自动指标（选择题、ROUGE/BLEU）的 Natural Questions、BIGbench、MMLU 等基准不同，论文为开放式生成式答案建立人工评估流程并设置人类基线；同时提出 6B–100B 的 MLM 定义，对 2022 年底至 2023 年中的大量开源模型做同题全集（而非稀疏矩阵）横向对比，并给出'微调数据比参数量更重要''30B 模型欠训练''量化无损''不同模型正确答案互补''聚合式人类反馈不足以改进长答案、需类似 aspect-based sentiment analysis 的细粒度反馈'等实证发现与论点。
