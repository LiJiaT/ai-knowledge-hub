YaRN: Efficient Context Window Extension of Large Language Models

YaRN：大型语言模型的高效上下文窗口扩展方法

简介

基于 RoPE 的 LLM 无法泛化到预训练上下文长度之外，已有扩展方法要么微调成本高，要么损失高频信息或破坏局部相对距离。论文系统整理了 PI、"NTK-aware"、"NTK-by-parts" 等插值方法并提出 YaRN：按各 RoPE 维度波长与预训练上下文长度之比差异化插值（低频插值、高频不动），叠加 attention softmax 前的温度缩放，仅需不足预训练数据 0.1% 的微调（比此前方法少 10 倍 token、2.5 倍训练步数）即可将 Llama 2 扩展到 128k 上下文，passkey 检索准确率超 99%，标准基准几乎无退化；配合推理时 Dynamic Scaling 还能免微调扩展 2 倍以上。对团队而言，其价值主要在长上下文策略的底层认知与"有效上下文长度"的评测方法（困惑度低不等于模型能 attend 到所有 token），而非 YaRN 微调流程本身的落地。

问题

基于 Rotary Position Embeddings (RoPE) 的 Transformer LLM 无法泛化到预训练时见过的上下文长度之外。已有扩展手段存在不足：PI 均匀拉伸所有维度会丢失高频信息且微调后 scale 超过约 8 倍即退化；"NTK-aware" 依赖经验性 base 选择、难以确定最优超参。论文目标是高效、低成本地把 LLaMA/Llama 2 等模型的上下文窗口扩展到 128k，并支持无微调的推理时扩展。

方法

YaRN 由三部分组合而成：(1) "NTK-by-parts" 插值——按每个 RoPE 维度的波长 λ 与预训练上下文长度之比 r=L/λ，用 ramp 函数 γ 与参数 α、β 划分插值边界：低频维度（r<α）按 scale s 线性插值，高频维度（r>β）不做插值，避免 PI 均匀拉伸造成的高频信息丢失与局部相对距离破坏；(2) attention softmax 前引入温度 t 缩放，通过等比缩放 RoPE 复数嵌入实现，不修改 attention 代码、训练与推理零额外开销，修正长上下文下注意力熵增大带来的困惑度上升；(3) 推理时 Dynamic Scaling——随实际序列长度动态调整 scale 因子 s，使模型超过训练长度时优雅退化而非突然失效，Dynamic-YaRN 无需微调即可获得 2 倍以上扩展。方法与 Flash Attention 2 直接兼容。

关键结果

微调所需 token 比此前方法少 10 倍、训练步数少 2.5 倍；微调数据量不足原预训练数据的约 0.1%

Llama 2 7B/13B 扩展到 128k 上下文并成功外推；s=32 模型仅从 s=16 checkpoint 用 64k 数据再训 200 步即外推到 128k（迁移学习）

128k 上下文内 passkey 检索准确率 > 99%（7B 与 13B 模型，覆盖全部测试的上下文长度）

Hugging Face Open LLM 基准（ARC/HellaSwag/MMLU/TruthfulQA）上与 Llama 2 基线相比退化极小，s=16 到 s=32 平均分数仅下降 0.49%

相同训练步数下，YaRN 在 Proof-pile 困惑度上持续优于 PI、"NTK-aware"、"NTK-by-parts"；Llama 2 7B 从 4k 扩到 8k 时 400 步即达到 PI 1000 步的相近结果

Dynamic-YaRN 无需任何微调即可实现 2 倍以上上下文扩展，且在 Llama 2 7B 上优于 Dynamic-PI

创新点

与 PI 均匀拉伸所有 RoPE 维度不同，YaRN 按维度波长差异化处理（低频插值、高频不动），并额外引入 attention softmax 前的温度缩放以修正长上下文下的困惑度上升；相比 "NTK-aware" 依赖经验性 base 选择，"NTK-by-parts" 用显式的 α/β ramp 函数参数化插值边界。论文还完整整理了此前未正式发表的 "NTK-aware"/"Dynamic NTK"/"NTK-by-parts" 工作，并证明可在不修改 attention 代码、与 Flash Attention 2 兼容的前提下实现上下文扩展，可作为 PI 的 drop-in 替换。
