Iterative Forward Tuning Boosts In-Context Learning in Language Models

迭代前向调优提升语言模型的 In-Context Learning 能力

下载原文 PDF

简介

现有 ICL 研究大多围绕 demonstration 选择等提示工程手段，假设模型对 demonstrations 只做一次前向计算。本文提出一个无需训练的两阶段框架：将 ICL 解耦为 Deep-Thinking 阶段与 test 阶段，前者通过新设计的 Iterative Enhanced Attention（IEA）对 Transformer 各层 Key-Value 矩阵做门控更新，让模型对固定 demonstrations 进行多轮前向"思考"并累积信息，后者仅用精炼后的 KV cache 对测试输入做推理。在 SST2、AGNews 等五个常规 ICL 任务上超越 LENS 等 demonstration 选择方法，dev 设置下平均超出 Random 基线 6.2%；在 MMLU 与 BBH 上对 LLaMA2、Pythia 全系列模型均有一致提升，LLaMA2-7B 在 STEM 类任务上提升 3.9%。方法还显著降低了对随机种子与 demonstration 顺序的敏感性，表明在示例固定且稀少时"多想几遍"比单纯增加示例数量更具成本效益。

问题

现有 ICL 方法（demonstration 选择、指令设计、CoT 等）均假设模型对 demonstrations 仅做单次前向处理，性能高度依赖提示工程，且在真实场景中示例固定稀少、没有候选池时，demonstration 选择方法不可行；论文探究能否通过多次迭代前向推理从固定 demonstrations 中深度学习，从而提升 ICL 性能。

方法

提出两阶段 ICL 框架：Deep-Thinking 阶段对 demonstrations 执行 T 次迭代前向，核心是 Iterative Enhanced Attention（IEA）——将本轮投影出的 Key-Value 矩阵与上一轮历史 Key-Value 矩阵拼接计算注意力，并用超参数 η 的门控机制融合更新历史 KV 矩阵，使其充当跨迭代的记忆载体；LLM 参数全程冻结、不引入额外参数。test 阶段将测试输入与经 T 轮更新的最终 KV cache 一起推理。附录 D 给出基于 HuggingFace Transformers 的最小实现代码。

关键结果

常规 ICL 任务（SST2/SST5/MR/AGNews/TREC，GPT2-L）：Deep-Thinking 一致超越 Herding、K-Center Greedy、CAL、CRAIG、LENS 等 demonstration 选择基线；dev 设置下平均超出 Random（vanilla ICL，使用完全相同 demonstrations）6.2%，提升仅来自迭代前向操作

跨模型可迁移：在 OPT（125M/350M/2.7B）、GPT-2（Medium/Large/XL）、GPT-Neo（2.7B）、LLaMA2（7B/13B）上均有效，在 LLaMA2 等更强模型上仍保持竞争力

MMLU 与 BBH 上，LLaMA2（7B/13B）与 Pythia（70M–12B）所有模型均获一致提升，小模型（Pythia）相对提升更显著

MMLU 细粒度分析：LLaMA2-7B 在 STEM 上较 vanilla ICL 提升 3.9%，Humanities、Social Science、Others 分别提升 2.3%、2.6%、2.5%

鲁棒性：对随机种子与 demonstration 顺序的方差显著小于 vanilla ICL；Deep-Thinking 用更少 demonstrations 即可取得更好结果且方差更小

超参数设置：无 dev set 时固定 T=5、η=0.01；有 dev set 时迭代次数 T 最大放宽至 15，dev 与 test 结果基本对齐

创新点

以往工作聚焦 demonstration 选择、模板/指令设计与 CoT 等"单次前向"的提示工程改进；本文声称首次将 ICL 解耦为 Deep-Thinking 与 test 两个阶段，通过在推理时操纵 Key-Value 矩阵实现多次前向的信息累积，无需训练、不新增参数，研究重心从"如何挑选 demonstrations"转向"如何从固定且稀少的 demonstrations 中深度学习"。
