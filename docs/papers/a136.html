UniMS-RAG: A Unified Multi-source Retrieval-Augmented Generation for Personalized Dialogue Systems

UniMS-RAG：面向个性化对话系统的统一多源检索增强生成

简介

论文针对个性化对话系统中的多知识源使用问题：现有方法要么只依赖单一来源、要么无差别拼接全部来源，且检索器与生成器独立训练导致分布偏移。作者将任务分解为知识源选择、知识检索与回复生成三个子任务，提出 UniMS-RAG，用同一个 LLM（ChatGLM-6B + LoRA）以 Seq2Seq 方式统一训练：acting tokens 按需决定调用哪个知识源（含不调用任何源的 NULL）及依赖顺序，evaluation tokens 预测对话上下文与证据的相关性分数，推理阶段再用 NLI 一致性分数与相关性分数相乘做证据自精炼与重生成。在 DuLeMon 与 KBP 两个数据集上，规划 F1 在 7 项指标中 4 项最优，生成在至少 5/7 指标上超过全部基线，模型自身可作检索器（w/ DPR 变体超过 ChatGPT），消融显示无差别使用全部知识源会使性能大幅下降。对团队而言，其"多源按需路由 + 相关性自评过滤 + 证据自精炼"的统一 RAG 范式可直接借鉴到知识库问答与上下文组装流程中。

问题

现有知识增强对话系统要么只聚焦单一知识源（系统 persona、用户记忆/画像、Wikipedia 等），要么无差别地把所有来源拼进上下文，无法根据对话动态决定该用哪个源（或完全不用），也忽略了知识源之间的依赖关系（如需先定位 persona 再检索相关文档）；同时以往工作要么独立训练 retriever 与 reader 导致次优和分布偏移，要么设计复杂架构联合优化，在大模型时代计算成本不可负担。

方法

将个性化知识对话生成（PerDS）分解为知识源选择、知识检索、回复生成三个子任务，用同一个 LLM（ChatGLM-6B，LoRA 微调）以 Seq2Seq 范式统一训练：1) Planning：把源名与 NULL 作为特殊 acting tokens 加入词表，直接按执行顺序输出所需知识源，支持源间依赖的调用顺序；2) Retrieval：引入 evaluation tokens（0~1、步长 0.1 的相似度 token）把检索相关性分类任务改写为生成任务，配合 evidence attention mask 屏蔽无关证据；相关性标签可来自零样本提示 ChatGPT/GPT-4o 或微调 DPR（形成蒸馏）；3) Generation：拼接源名、证据与相似度分数生成回复。训练时打乱证据顺序防止位置捷径，只对 acting/evaluation/response token 计损失；推理阶段用微调 NLI 模型计算回复与证据的一致性分数，与相关性分数相乘更新证据列表并迭代重生成（self-refinement）。

关键结果

规划（知识源选择）：在 DuLeMon 与 KBP 共 7 项 F1 指标中 4 项取得最优；消融显示无差别使用全部知识源使性能从 63.18% 降至 1.23%（DuLeMon）、从 42.07% 降至 36.21%（KBP）

检索：UniMS-RAG 各变体 Recall@1 均超过稀疏检索器 BM25，UniMS-RAG w/ DPR 甚至超过 ChatGPT 零样本检索；w/ GPT4o 明显优于 w/ ChatGPT，说明可蒸馏更强检索器的能力

生成：无论用自身还是独立检索器，UniMS-RAG 在至少 5/7 项自动指标上超过所有基线，配合更强外部检索器达到新 SOTA

检索证据数从 1 增到 2 时 KBP 性能明显提升，继续增至 3 略有下降（噪声引入）

自精炼：within self-refinement 与 multi-step self-refinement 均提升一致性分数（DuLeMon 的 P.C，KBP 的 P.C、K.C），但多步精炼的提升不如单步一致

人工评测：UniMS-RAG w/ DPR 在 DuLeMon 显著更优、KBP 略优；三名标注者一致性约 82%；微调 NLI 一致性模型在两个数据集上准确率均 >95%

训练成本：LoRA 单张 RTX 3090 训练约 4-6 小时

创新点

论文指出现有文献在"多知识源规划"与"以 LLM 自身为骨干的自回归检索器"方面存在空白。与以往独立训练 retriever/reader 或用复杂架构联合优化的工作不同，UniMS-RAG 用 acting/evaluation 两类特殊 token 把规划、检索相关性评估与生成统一进单个 LLM 的 Seq2Seq 训练，同时处理多源的按需选择与源间依赖调用顺序，并使模型自身可作检索器（从 DPR 或 LLM 相似度信号蒸馏）；区别于 Self-RAG 的单源设定与 TPE 的多 persona 协作框架，它探索 LLM 一体化充当 planner、retriever、reader。
